AI Summary Helper 是一款免費、開放原始碼的 Chrome 擴充功能，能把任何網頁、PDF 或 YouTube 影片整理成你慣用語言的重點摘要。你可以使用自己的 AI 金鑰，也可以透過 Ollama 執行完全在本機運作的模型。它適合每天大量閱讀新聞、論文、報告與部落格的學生、研究人員和上班族，並把你讀過的內容變成一座私人、可搜尋的資料庫，內建畫線標註、追問對話、知識圖譜、閱讀統計、RSS 閱讀器與傳送到 Kindle。你的資料庫還能在 Claude Desktop、Cursor 等 AI 應用程式中使用。使用自己的金鑰或本機模型完全不必註冊帳號，文章也只會保存在你的裝置上。

AI Summary Helper 是免費的嗎？
是的。這個擴充功能免費且開放原始碼。使用自己的 API 金鑰時，費用直接付給服務商，通常每月只要幾美分；本機模型則完全免費。byphil Cloud 每天提供少量免費額度，升級 Pro 即可解除限制。

可以用本機 AI 模型摘要網頁嗎？
可以。安裝 Ollama、下載一個開放模型，再於初始設定中選擇本機選項即可。之後包括追問與訂閱回顧在內的所有功能都在你的電腦上執行；改用區域網路中的自架伺服器也同樣適用。

自備 API 金鑰可以搭配哪些 AI 服務商？
OpenAI、Google Gemini、Mistral AI 與 DeepSeek，另外也支援本機與自架模型。

支援 PDF 和 YouTube 嗎？
支援。在 Chrome 中開啟的 PDF（包括你電腦裡的檔案），以及有字幕的 YouTube 影片，都能像一般網頁一樣處理。

可以把英文文章整理成中文重點嗎？
可以。41 種輸出語言任你選擇，包括繁體中文；原文可以是另一種語言。

要怎麼把網路文章傳送到 Kindle？
登入 byphil，在 Amazon 帳號中把 kindle@byphil.eu 加入核准的寄件者清單，在「設定 → 傳送」輸入裝置的電子郵件地址，然後在傳送選項中選擇它。前三次傳送免費，Pro 不限次數。

可以在 Claude Desktop 或 Cursor 中使用我的資料庫嗎？
可以。在「設定 → AI 應用程式」開啟功能並配對一次，應用程式就能搜尋你的資料庫、引用你的標註並附上來源。預設為關閉，在你的電腦上執行，並遵守你允許的範圍。

我的資料安全嗎？
你的資料庫保存在瀏覽器中。網頁文字只會傳給你挑選的 AI 服務商；使用本機模型時則不會傳到任何地方。擴充功能不含任何追蹤 SDK，程式碼也公開供人審查。

它和其他 AI 摘要擴充功能有什麼不同？
多數 AI 閱讀工具會把你綁定在單一服務商、要求註冊帳號，並以月費訂閱的方式讓所有內容經過自家伺服器。AI Summary Helper 讓你自備金鑰或完全在本機執行，兩者都不需要帳號，還能把你讀過的內容變成可搜尋的資料庫，附知識圖譜、閱讀統計、RSS 與電子書閱讀器匯出。

🚀 開始使用
━━━━━━━━━━━━━━━━━━━━
1. 把 AI Summary Helper 加到 Chrome，並釘選在工具列上。
2. 在簡短的初始設定中，選擇 byphil Cloud、自己的 API 金鑰或本機模型。
3. 開啟任何文章、PDF 或影片，按下 Ctrl+Shift+E（Mac 為 ⌘+Shift+E）。
4. 閱讀、聆聽、追問，之後隨時能在歷史紀錄中找到它。
