AI Summary Helper는 웹페이지, PDF, YouTube 영상을 원하는 언어로 요약해 주는 무료 오픈소스 크롬 확장 프로그램입니다. 내 AI API 키를 쓰거나, Ollama로 내 컴퓨터에서 완전한 로컬 AI를 실행할 수 있습니다. 긴 글을 빠르게 파악해야 하는 학생, 연구자, 직장인, 뉴스를 많이 읽는 분을 위한 도구로, 읽은 내용은 하이라이트, 후속 질문, 지식 그래프, 읽기 분석, RSS 리더, Send to Kindle을 갖춘 나만의 비공개 검색 라이브러리로 쌓입니다. 이 라이브러리는 Claude Desktop, Cursor 같은 AI 앱에서도 쓸 수 있습니다. 내 API 키나 로컬 모델을 쓸 때는 계정이 필요 없고, 저장한 글은 모두 내 기기에만 남습니다.

• 요약 후 탭 닫기: 요점을 받아 두고 다시 볼 시점을 정하면 탭이 알아서 닫힙니다.

🌍 한국어로 요약, 원하는 언어로 핵심 정리
━━━━━━━━━━━━━━━━━━━━

💬 페이지에 무엇이든 질문하기
━━━━━━━━━━━━━━━━━━━━

• 답변에는 기사 속 정확한 문단을 가리키는 출처 칩이 함께 표시됩니다.

• 좋은 답변은 고정해 두면 기사와 함께 저장되고 내보낼 때도 포함됩니다.

🎧 내 방식대로 읽기

• 인스턴트 읽기(Instant Read): AI가 문장을 쓰는 즉시 소리로 들려주므로 손을 쓸 필요가 없습니다.
• 속독(RSVP): AI 답변이 생성되는 대로 한 단어씩 느리게, 보통, 빠르게 읽을 수 있습니다.

• 저장한 모든 기사에 가독성 점수(Flesch Reading Ease 및 학년 수준)가 표시됩니다.

🗂️ 나만의 읽기 라이브러리
━━━━━━━━━━━━━━━━━━━━
모든 결과는 이 기기의 기록(History)에 보관되며, 받은편지함, 읽음, 보냄, 리서치, 컬렉션, 보관함으로 정리됩니다.

• 검색: 저장한 모든 기사를 기기 안에서 즉시 전문 검색합니다.
• 비슷한 글: 지금 읽는 기사와 관련된 글을 라이브러리에서 찾아 줍니다.
• 링크, 제목, 내용 기준 중복 감지로 라이브러리를 깔끔하게 유지합니다.
• archive.ph, Wayback Machine, 12ft에서 저장해도 원문 링크가 유지되어, 라이브러리가 진짜 출처를 가리킵니다.
• 컬렉션: 하나의 질문 아래 기사를 묶고, 출처 검증 워크시트로 하나씩 검토할 수 있습니다.
• 즐겨찾기, 태그, 메모, 시간 지정 알림.

📊 읽기 분석
━━━━━━━━━━━━━━━━━━━━
• 절약한 시간: 원문을 끝까지 읽었을 때와 짧은 버전을 읽었을 때의 시간 차이를 보여 줍니다.
• 읽은 기사 수와 단어 수, 연속 읽기 일수와 최고 기록을 보여 줍니다.
• 최근 30일 또는 12주간의 활동 차트.
• 많이 읽은 카테고리와 워드 클라우드.
• 시간에 따른 분위기: 읽은 뉴스의 논조를 일·주·월 단위로 보여 주고, 무엇이 그 변화를 이끌었는지 알려 줍니다.

모든 분석은 기기 안에서 계산되며, 추적 서비스로 보내는 데이터는 없습니다.

🖥️ 와이드 모드와 분할 보기 (2.2 신규)
━━━━━━━━━━━━━━━━━━━━
별도 탭에서 열거나 사이드 패널을 넓게 드래그하면 기록과 피드가 분할 보기로 바뀝니다. 너비 720픽셀부터는 목록과 지식 그래프가 나란히, 1,100픽셀부터는 목록·그래프·분석이 세 개의 창으로 표시됩니다. 헤더에서 창 개수(1~3)와 각 창의 내용을 정할 수 있습니다.

📰 AI 리캡을 더한 RSS 리더
━━━━━━━━━━━━━━━━━━━━
• 블로그, 신문, 팟캐스트를 RSS 또는 Atom으로 구독하고, 구독 목록을 OPML로 가져오거나 내보낼 수 있습니다.
• 선택한 AI가 일간 리캡을 작성하고, 이를 주간·월간 개요로 묶어 줍니다. 전송되는 것은 제목과 발췌문뿐이며, 요청할 때만 전송됩니다.
• 로컬 모델을 쓰면 15분~6시간 간격으로 새 항목을 백그라운드에서 평가하고 정리합니다.
• 스토리 스택: 여러 매체의 같은 소식을 하나로 묶습니다.
• 피드 인사이트: 활동, 주제, 최근 30일간의 '소스 다이어트', 시간에 따른 피드 분위기를 보여 줍니다.
• 내장 팟캐스트 플레이어는 팝업을 닫아도 계속 재생되며 0.75~2배속을 지원합니다.
• 항목에 별표를 달면 요점을 정리해 기록에 보관합니다.

🎓 리서치 모드와 인용
━━━━━━━━━━━━━━━━━━━━
• PubMed, Springer, Wiley, JSTOR 등 학술 출판사의 논문을 자동으로 인식합니다.
• DOI를 바탕으로 APA 7, MLA 9, Chicago(저자-연도), BibTeX, RIS 형식의 정확한 인용을 만듭니다. 인용 데이터는 AI가 아니라 doi.org에서 가져오며, 기기 밖으로 나가는 정보는 DOI뿐입니다.
• Zotero, Mendeley, LaTeX에서 쓸 수 있는 references.bib 또는 .ris 파일을 내려받을 수 있습니다.
• 모든 페이지에서 출처 검증: 유형, 저자, 날짜, 발행처와 함께, 출처를 믿기 전에 따져 볼 수 있는 수평적 읽기(lateral reading) 질문 4개를 제시합니다. 점수를 매기는 것이 아니라 판단을 돕는 힌트입니다.
• 리뷰, 임상시험, 프리프린트 필터가 있는 리서치 탭.

━━━━━━━━━━━━━━━━━━━━
📤 보내기, 내보내기, 공유
━━━━━━━━━━━━━━━━━━━━
• Send to Kindle: 개요와 서식이 정리된 기사를 하이라이트까지 포함해 전자책 리더로 바로 보냅니다. EPUB(텍스트 또는 이미지 포함)과 HTML 형식을 지원합니다. 무료 byphil 로그인이 필요하며, 3회까지 무료이고 Pro에서는 무제한입니다.
• LocalSend: 클라우드를 거치지 않고 집 Wi-Fi로 휴대폰, 태블릿, KOReader 전자책 리더에 기사를 보냅니다.
• 휴대폰으로 보내기: QR 코드로 휴대폰을 연결하면, 휴대폰에서 공유한 링크가 종단 간 암호화되어 기록에 도착합니다. 전체 기사를 휴대폰으로 다시 보낼 수도 있습니다.
• 매거진 다이제스트: 여러 기사를 한 권의 호로 묶어 전자책 리더, LocalSend 또는 Markdown으로 보냅니다.
• 내보내기: Markdown(기사 한 편, 또는 프런트매터가 포함된 전체 라이브러리 ZIP), Word(DOCX), OpenDocument(ODT), PDF로 저장하거나 Obsidian으로 바로 보낼 수 있습니다.
• 지원되는 환경에서는 시스템 공유 시트로 공유할 수 있습니다.
• 라이브러리 전체와 설정을 백업·복원할 수 있으며, API 키와 로그인 정보는 직접 선택하지 않는 한 백업에서 제외됩니다.

☁️ 내 저장소에 내 라이브러리를 (신규)
━━━━━━━━━━━━━━━━━━━━
라이브러리를 누구에게도 넘기지 않고 모든 컴퓨터에서 최신으로 유지하고, 백업하고, 일부를 공개할 수 있습니다. 설정 → 동기화 및 백업에서 장소를 추가하세요: WebDAV 서버, S3 호환 버킷, 또는 내 컴퓨터의 폴더입니다.

• 암호화: 기기를 떠나기 전에 모든 것이 브라우저에서 암호문으로 암호화되므로 서버에는 읽을 수 없는 파일만 보입니다. 복구 키가 발급되며, 이것과 암호문을 모두 잃으면 누구도(저희도) 읽을 수 없습니다.
• 기기 간 양방향 동기화: 항목별로 병합됩니다. 같은 페이지를 두 번 저장해도 글은 하나가 되고, 다른 기기에서 온 대량 삭제는 확인을 기다립니다.
• 백업 전용 장소와 한 번의 클릭 복원.
• 내 웹사이트에 목록 공개: 태그로 글을 고르면 일반 파일과 검색, 타임라인, 태그 그래프, 3D 지도가 있는 보기 페이지가 만들어집니다. 메모와 전문은 켜지 않는 한 포함되지 않습니다.
• 메모와 댓글: 텍스트를 선택해 하이라이트하거나, 댓글을 달거나, 인용과 함께 메모로 저장하세요.
• 장소를 추가하기 전까지는 꺼져 있습니다. 동기화 서버를 운영하지 않으며 아무것도 볼 수 없습니다.

🔌 내 라이브러리를 AI 앱에서 (신규)
━━━━━━━━━━━━━━━━━━━━
AI 앱은 내가 읽은 글을 알지 못했습니다. 설정에서 AI 앱을 켜면 내 컴퓨터의 Claude Desktop, Cursor, LM Studio 등 MCP 앱이 내 라이브러리를 활용할 수 있습니다.

• 저장한 기사 검색, 하이라이트 인용, 다시 볼 항목 확인, 컬렉션과 피드 탐색이 가능합니다.
• 주간 리뷰, 컬렉션 하나를 바탕으로 한 브리핑, 올해의 읽기 리포트를 요청하면 모든 주장에 출처 링크가 붙습니다.
• 기본값은 꺼짐입니다. 앱이 읽을 수 있는 범위(라이브러리, 기사 전문, 피드, 링크 저장 허용 여부)는 내가 정합니다.
• "private" 태그가 붙은 기사는 절대 노출되지 않으며, 활동 로그에서 모든 호출을 확인할 수 있습니다.
• 내 컴퓨터에서만 실행되며, 우리 서버를 거치지 않습니다.

━━━━━━━━━━━━━━━━━━━━
🔒 설계 단계부터 지키는 개인정보
━━━━━━━━━━━━━━━━━━━━
• 기사, 하이라이트, 피드, 분석 데이터는 모두 내 기기의 브라우저에 저장됩니다.
• 페이지 내용은 내가 선택한 AI 제공업체에만 전송되며, 기기 내 모델을 쓰면 어디에도 전송되지 않습니다.
• AI 앱은 내가 켠 경우에만, 내 컴퓨터에서만, 내가 허용한 범위만 라이브러리를 읽을 수 있습니다.
• 추적·분석 SDK, 광고, 데이터 판매가 없습니다.
• 오픈소스: 전체 코드가 GitHub(philffm/ai-summary-helper)에 공개되어 있어 누구나 검토할 수 있습니다.
• EU에서 byphil이 만들었습니다.

♿ 접근성과 편안한 읽기 환경
━━━━━━━━━━━━━━━━━━━━
• 라이트, 다크, 고대비 테마를 지원하며, 시스템 설정을 따르게 할 수도 있습니다.
• 글자 크기 85~150%, 줄 간격 3단계 조절.
• 가독성을 높이는 Atkinson Hyperlegible 글꼴(선택 사항).
• 동작 줄이기 설정을 따르며, 키보드 단축키를 곳곳에서 지원합니다(?로 전체 목록 보기).
• 프리셋: 기본, 크게, 고대비, 차분하게.

━━━━━━━━━━━━━━━━━━━━
⌨️ 사용할 수 있는 곳
━━━━━━━━━━━━━━━━━━━━
• 브라우저 사이드 패널, 팝업, 페이지 내 사이드바, 별도 탭, 팝아웃 창.
• 키보드: Ctrl+Shift+E는 현재 페이지의 핵심을 정리하고, Ctrl+Shift+Y는 AI Summary Helper를 엽니다(Mac은 ⌘). 앱 안에서는 Ctrl+F 또는 /로 검색, j·k로 카드 이동, Esc로 뒤로 가기.
• 오른쪽 클릭 메뉴: 이 페이지 요약, 요약 후 탭 닫기, 선택 영역 하이라이트, 모든 하이라이트 제거.
• 다른 브라우저와 휴대폰: 북마클릿을 쓰면 iOS와 Android를 포함한 모든 브라우저에서 이용할 수 있습니다(byphil Cloud 필요).

❓ 자주 묻는 질문
━━━━━━━━━━━━━━━━━━━━
AI Summary Helper는 무료인가요?
네. 확장 프로그램 자체는 무료이며 오픈소스입니다. 내 API 키를 쓰면 AI 제공업체에 직접 비용을 내며, 보통 한 달에 몇 센트 수준입니다. 기기 내 모델은 비용이 전혀 들지 않습니다. byphil Cloud에는 매일 소량의 무료 사용량이 포함되어 있고, Pro를 이용하면 제한이 없어집니다.

로컬 AI 모델로 웹페이지를 요약할 수 있나요?
네. Ollama를 설치하고 오픈 모델을 내려받은 뒤, 초기 설정에서 로컬 옵션을 고르면 됩니다. 그러면 후속 질문과 피드 리캡을 포함한 모든 처리가 내 컴퓨터에서 실행됩니다. 내부 네트워크의 자체 호스팅 서버도 쓸 수 있습니다.

내 API 키로 어떤 AI 제공업체를 쓸 수 있나요?
OpenAI, Google Gemini, Mistral AI, DeepSeek를 쓸 수 있으며, 로컬 및 자체 호스팅 모델도 지원합니다.

PDF와 YouTube 영상도 요약할 수 있나요?
네. 크롬에서 연 PDF(내 컴퓨터에 있는 파일 포함)와 자막이 있는 YouTube 영상도 일반 웹페이지와 똑같이 처리됩니다.

영어 기사를 한국어로 요약할 수 있나요?
네. 41개 결과 언어 중 원하는 언어를 고르면 됩니다. 원문이 다른 언어로 되어 있어도 괜찮습니다.

웹 기사를 Kindle로 보내려면 어떻게 하나요?
byphil에 로그인하고, Amazon 계정에서 kindle@byphil.eu를 승인된 발신자로 추가합니다. 그런 다음 설정 → 보내기에 기기의 이메일 주소를 입력하고, 보내기 메뉴에서 해당 기기를 선택하면 됩니다. 3회까지 무료이며 Pro에서는 무제한입니다.

Claude Desktop이나 Cursor에서 내 라이브러리를 쓸 수 있나요?
네. 설정 → AI 앱에서 켜고 한 번 연결하면, 앱이 라이브러리를 검색하고 하이라이트를 인용하며 출처를 밝힐 수 있습니다. 기본값은 꺼짐이고, 내 컴퓨터에서만 실행되며, 내가 허용한 범위만 읽습니다.

내 데이터는 안전하게 보호되나요?
라이브러리는 내 브라우저에만 저장됩니다. 페이지 텍스트는 내가 고른 AI 제공업체에만 전송되며, 기기 내 모델을 쓰면 어디로도 전송되지 않습니다. 확장 프로그램에는 추적 SDK가 없고, 코드는 누구나 검토할 수 있도록 공개되어 있습니다.

다른 AI 요약 확장 프로그램과 무엇이 다른가요?
대부분의 AI 읽기 도구는 한 가지 제공업체에 묶여 있고, 계정을 요구하며, 월 구독료를 받고 모든 내용을 자사 서버로 거쳐 보냅니다. AI Summary Helper는 내 API 키를 쓰거나 완전히 로컬로 실행할 수 있고, 두 방식 모두 계정이 필요 없습니다. 또한 읽은 내용을 지식 그래프, 분석, RSS, 전자책 리더 내보내기를 갖춘 검색 가능한 라이브러리로 쌓아 줍니다.

🚀 시작하기
━━━━━━━━━━━━━━━━━━━━
1. AI Summary Helper를 Chrome에 추가하고 툴바에 고정합니다.
2. 짧은 초기 설정에서 byphil Cloud, 내 API 키, 기기 내 모델 중 하나를 고릅니다.
3. 기사, PDF, 영상 중 아무것이나 열고 Ctrl+Shift+E(Mac은 ⌘+Shift+E)를 누릅니다.
4. 읽고, 듣고, 후속 질문을 던지고, 나중에 기록에서 다시 찾아봅니다.

피드백과 기능 제안은 GitHub에서 언제든 환영합니다. byphil이 만들었습니다.
