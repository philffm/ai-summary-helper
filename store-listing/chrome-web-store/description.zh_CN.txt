AI Summary Helper 是一款免费、开源的 Chrome 扩展，可以用你的语言为任何网页、PDF 或 YouTube 视频生成摘要。你可以使用自己的 AI 密钥，也可以通过 Ollama 运行完全本地的模型。它会把你读过的内容变成一个私人、可搜索的资料库，内置高亮标注、追问对话、知识图谱、阅读统计、RSS 阅读器和发送到 Kindle。你的资料库还可以在 Claude Desktop、Cursor 等 AI 应用中使用。使用自己的密钥或本地模型无需账号，你的文章只保存在你的设备上。

❓ 常见问题
━━━━━━━━━━━━━━━━━━━━
AI Summary Helper 免费吗？
是的。这个扩展免费且开源。使用自己的 API 密钥时，费用直接付给服务商，通常每月只需几美分；设备端模型完全免费。byphil Cloud 每天提供少量免费额度；Support Pass 是对项目的捐赠，可以解除限制。

可以用本地 AI 模型为网页生成摘要吗？
可以。安装 Ollama，下载一个开源模型，然后在设置向导中选择本地选项即可。之后包括追问和订阅回顾在内的所有功能都在你的电脑上运行，使用网络内自建的 Ollama 服务器也同样适用。

自带 API 密钥可以搭配哪些 AI 服务商？
OpenAI、Google Gemini、Mistral AI 和 DeepSeek，另外也支持本地和自建模型。

支持 PDF 和 YouTube 吗？
支持。在 Chrome 中打开的 PDF（包括你电脑上的文件），以及带字幕的 YouTube 视频，都可以像普通网页一样处理。

可以把英文文章总结成其他语言吗？
可以。41 种摘要语言任你选择；原文可以是另一种语言。

如何把网页文章发送到我的 Kindle？
登录 byphil，在你的 Amazon 账号中把 kindle@byphil.eu 添加为已认可的发件人，在“设置 → 发送”中输入设备的邮箱地址，然后在发送选项中选择它。前三次发送免费；Support Pass 可以让发送不限次数。

可以在 Claude Desktop 或 Cursor 中使用我的资料库吗？
可以。在“设置 → AI 应用”中开启功能并配对一次，应用就可以搜索你的资料库、引用你的高亮并标注来源。默认关闭，在你的电脑上运行，并遵守你允许的范围。

我的数据是私密的吗？
你的资料库保存在浏览器中。网页文字只会发送给你选择的 AI 服务商；使用设备端模型时则不会发送到任何地方。扩展不含任何追踪 SDK，代码也公开可供审查。

它和其他 AI 摘要扩展有什么不同？
大多数 AI 阅读工具会把你绑定在单一服务商，要求注册账号，并以月度订阅的方式让所有内容经过它们的服务器。AI Summary Helper 让你自带密钥或完全在本地运行，两种方式都不需要账号，还能把你读过的内容变成可搜索的资料库，配有知识图谱、阅读统计、RSS 和电子书阅读器导出。

🚀 开始使用
━━━━━━━━━━━━━━━━━━━━
1. 把 AI Summary Helper 添加到 Chrome，并固定在工具栏上。
2. 在简短的设置向导中，选择 byphil Cloud、自己的 API 密钥或设备端模型。
3. 打开任何文章、PDF 或视频，按下 Ctrl+Shift+E（Mac 上为 ⌘+Shift+E）。
4. 阅读、聆听、追问，之后随时可以在历史记录中找到它。
