주요 기능

읽기 목록 서비스가 본래 갖추었어야 할 모든 기능

추가 구독 결제에 아카이브가 묶이는 일 없이, 저장하고 이해하며 다시 찾아 실제로 읽어보세요.

원하는 모델로 생성하는 AI 요약

OpenAI, Gemini, Mistral, DeepSeek뿐만 아니라 OpenRouter를 통한 100개 이상의 모델을 지원합니다. 로컬 Ollama 모델을 지정하면 네트워크 통신 없이도 요약을 생성할 수 있습니다.

진정한 온디바이스 검색

브라우저 내에서 구축된 TF-IDF 인덱스를 통해 제목, 태그, 본문 전체를 대상으로 전문 검색을 지원합니다. 서버 왕복이나 지연이 없으며 데이터가 외부로 전송되지 않습니다.

목적 있는 나중에 읽기

다시 열어보지 않을 목록에 쌓아두는 대신, 이유와 기한을 설정해 "결정" 항목으로 표시하고 알림을 받아보세요.

자동으로 선별되는 다이제스트

탭 한 번으로 저장한 글 중 중복되지 않는 다채로운 글을 선별하여, Kindle이나 LocalSend용 단일 파일로 묶어 제공합니다.

단순한 목록을 넘어선 지식 그래프

공유 태그뿐만 아니라 공통 태그가 없더라도 주제별 유사성을 분석하여 저장된 글들의 연결 관계를 확인하세요.

20개 이상의 언어 지원 및 크로스 플랫폼

원하는 언어로 읽고 요약하세요. 확장 프로그램, 기본 사이드 패널, 북마클릿을 지원하여 브라우저 확장을 사용할 수 없는 환경에서도 활용할 수 있습니다.

84%의 문제

저장한 글의 대부분은 다시 읽지 않게 됩니다

북마크 행동에 관한 연구에 따르면 저장된 글의 대다수는 다시 열리지 않는 것으로 나타납니다. 이는 사용자의 의지 부족이 아니라, 저장은 쉽게 만들면서 정작 무엇을 읽어야 할지 선택하는 데에는 아무런 도움을 주지 않는 도구의 구조적 문제입니다.

1. 다이제스트 클릭

최신성과 다양성을 고려하여 저장된 글 5편을 선별하므로, 같은 주제의 뉴스를 반복해서 보지 않아도 됩니다.

2. 원하는 분위기 설정

가벼운 톤, 중립적인 톤, 깊이 있는 진지한 톤 등 현재 읽고 싶은 분위기에 맞춰 선별 결과를 조정합니다.

3. 오프라인으로 전송

하나의 번들로 묶어 Kindle이나 로컬 네트워크상의 기기로 바로 전송하세요. 비행기 탑승 전, 출퇴근길, 인터넷이 연결되지 않는 주말에 유용합니다.

byphil의 철학으로 제작

데이터의 소유권은 온전히 사용자에게 있습니다

검색, 중복 감지, 태그 정리, 읽기 수준 및 톤 분석, '유사한 글' 추천 등 모든 기능이 브라우저 내부에서만 실행됩니다. 서버나 계정 없이도 핵심 기능을 온전히 활용할 수 있습니다. 기기 외부로 나가는 데이터는 사용자가 직접 설정한 AI 제공업체로의 요약 요청 호출뿐이며, 로컬 Ollama 모델을 사용하는 경우 이 과정마저도 완전히 기기 내부에서 처리됩니다.

설치 전 확인사항

이용하려면 계정이 필요한가요?

아닙니다. 프로그램을 설치하고 보유 중인 AI 제공업체 키를 입력하거나(또는 로컬 Ollama 모델 사용) 바로 저장을 시작할 수 있습니다. Support Pass를 통해 byphil Cloud를 이용하거나 무제한 Kindle/LocalSend 전송을 원하실 때만 계정이 필요합니다.

브라우저 외부로 전송되는 데이터는 무엇인가요?

설정하신 AI 제공업체로 전달되는 요약 요청 데이터뿐입니다. 검색, 중복 감지, 태그 정리, 읽기 수준 및 감성 분석, '유사한 글' 추천 등은 모두 사용자가 저장한 로컬 아카이브 내에서 직접 실행됩니다.

클라우드 의존성 없이 완전히 독립적으로 실행할 수 있나요?

네, 로컬 Ollama 모델을 연결하면 요약 과정까지 기기 내부에서 완전히 처리됩니다. 그 외 모든 기능은 이미 로컬에서 동작하고 있습니다.

Support Pass 결제를 중단하면 저장된 글은 어떻게 되나요?

저장된 아카이브는 기기 내 브라우저 로컬 저장소에 그대로 유지됩니다. Support Pass는 클라우드 기반 부가 기능(byphil Cloud AI 이용, 무제한 Kindle/LocalSend 전송)에만 적용되며, 이미 저장된 데이터에 대한 접근은 절대 제한되지 않습니다.
