     🎨 UI/UX Overhaul

    Horizontal slide transitions — Screens now slide horizontally with smooth CSS transforms instead of instant show/hide.
    Split layout — Input controls (textarea, chips, fetch button) fixed at bottom, feed scrollable on top.
    Streaming progress bubble — Live preview of the summary being generated, elapsed timer, model name, and real-time word count.
    Language quick-select grid — Searchable tag grid replaces the native <select> dropdown. Auto-focuses search on open.
    Model quick-select panel — Two-row layout: provider tags (OpenAI, DeepSeek, etc.) + model ID tags. Custom model IDs can be added inline.
    Chip panels pop up — Language/Length/Mode/Model panels now float above the chip row instead of pushing content down.
    Accessibility pass — Higher contrast colors in both light and dark modes, darker text, more saturated accents, improved nav active states.
    🔧 Settings
    Auto-save on every change — Theme, model, prompt, toggles all save instantly with a green flash confirmation.
    Save button moved to top-right — No longer fixed at the bottom of the settings page.
    Danger Zone section — Delete Settings / Delete History buttons grouped under a red-bordered section.
    "Open Large by Default" toggle — Opens the hybrid injected iframe sidebar instead of the small popup.
    "Use Native Side Panel" toggle — Opt-in to Chrome's native side panel API.
    🚀 Side Panel / Popout
    Hybrid iframe fallback — When native side panel is unavailable, injects a 420px iframe sidebar into the page with smooth slide animation.
    Popout button restored — ↗️** — Re-added to header. Priority: Native side panel (if enabled) → Hybrid iframe (if "Open Large") → Hybrid iframe (default).
    Background script sync — setPanelBehavior dynamically updates when toggling the native side panel setting.
    🐛 Bug Fixes
    Missing </div> in HTML — #mainScreen was never closed, nesting all other screens inside it and breaking navigation.
    article.content.split() crash — Undefined content caused TypeError, silently killing all screens silently failed.
    <img> tags in saved content — Stripped from rendered HTML to prevent chrome-extension:// 404s.
    Storage race conditions — Fixed hoisting bug where summaryMode was used before destructuring.
    Storage race conditions — modelManager.js now uses StorageManager.updateService() instead of raw chrome.storage.sync to prevent overwrites.
    activeModelId separate from custom list — Separate storage field so clicking a model tag never mutates your saved custom models list.
    Slider fill track — Dispatches input event after loading saved value so the blue fill bar renders correctly on init.
    Summary bubble disappearing — Removed race condition where loadFeed() cleared the feed before storage write completed.
    🧹 Cleanup
    Removed header settings/popout buttons (re-added popout only).
    Removed unused fixed-bottom CSS, article-content inline HTML, displayArticleDetails function.
    Consolidated all storage reads/writes to chrome.storage.sync for consistency.
