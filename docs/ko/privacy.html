개인정보 처리방침

API 키, 아티클 기록, 하이라이트는 사용자의 기기에만 보관됩니다. 페이지 콘텐츠는 사용자가 선택한 AI 제공자에게만 전송되며, 완전한 로컬 모델을 선택할 경우 어떤 데이터도 기기 밖으로 나가지 않습니다.

최종 업데이트: 2026년 10월

본 개인정보 처리방침은 AI Summary Helper가 처리하는 데이터의 종류와 저장 위치, 처리 목적을 설명합니다. 요약하자면, API 키, 아티클 기록, 하이라이트는 사용자의 기기에만 안전하게 보관됩니다. 페이지 콘텐츠는 사용자가 직접 선택한 AI 제공자에게만 전송되며, 완전한 로컬 모델을 선택하면 데이터가 외부로 일절 전송되지 않습니다. 본 서비스는 광고를 게재하지 않고, 데이터를 판매하지 않으며, 핵심 기능을 이용할 때 별도의 계정을 요구하지 않습니다.

본 정책의 내용에 동의하지 않으시는 경우 확장 프로그램을 설치하거나 사용하지 마시기 바랍니다.

개인정보 처리 책임자

GDPR 제4조 제7항에 따른 개인정보 처리자는 Phil Wornath입니다. 송달 가능한 전체 성명 및 주소는 다음에서 확인하실 수 있습니다: 법적 고지(Legal Notice). 본 개인정보 처리방침 하단의 연락처를 통해서도 문의하실 수 있습니다.

핵심 기능은 계정 없이도 바로 사용할 수 있어요

AI Summary Helper는 웹페이지 요약, 하이라이트 표시, 피드 구독, 아카이브 보관 등의 기능을 사용할 때 계정 생성이나 로그인, 어떠한 개인정보도 요구하지 않아요. 직접 등록한 API 키(사용하는 경우)와 전체 아티클 기록은 모두 브라우저의 로컬 스토리지에 안전하게 보관됩니다.

계정은 자체 호스팅 서비스인 byphil Cloud(개인 키 없이 요약) 및 Send to Kindle 기능을 이용할 때만 필요해요. 이메일 주소와 일회용 코드로 간편하게 로그인할 수 있습니다. 요금제 한도를 적용하기 위해 해당 이메일 주소, 플랜 또는 라이선스 상태, 기본 사용량 통계(예: 요청 횟수 및 Kindle 전송 횟수)만 저장됩니다.

처리하는 데이터 및 데이터 전송 위치

AI 서비스 연결 방식

요약 생성 방식을 직접 선택할 수 있습니다:

  • 개인 API 키 직접 사용 (BYOK) — OpenAI, Google Gemini, Mistral AI, DeepSeek 또는 커스텀 엔드포인트를 지원합니다. API 키는 사용자의 기기 로컬에만 저장되며, 동기화되거나 당사 서버로 전송되지 않습니다. 요약하도록 선택한 페이지 콘텐츠는 본인의 API 키를 사용하여 브라우저에서 해당 AI 제공업체로 직접 전송되며, 해당 제공업체의 개인정보 처리방침을 따릅니다. 당사는 이 콘텐츠를 확인하거나 기록(로그), 저장하지 않습니다.
  • Ollama를 통한 로컬 모델 — 로컬에서 직접 AI 모델을 실행할 경우, 페이지 콘텐츠는 사용자 본인의 컴퓨터로만 전송됩니다. 어떤 데이터도 기기 외부로 나가지 않습니다.
  • byphil Cloud (선택형 유료 플랜) — API 키를 직접 관리하지 않고 편리하게 사용하고자 하는 분들을 위한 호스팅 옵션입니다. 이 플랜을 선택하면 요약을 요청한 텍스트가 당사 백엔드를 거쳐 OpenRouter를 통해 기본 모델 제공업체로 안전하게 중계(relay)된 후 요약 결과가 반환됩니다. 이는 중계 역할만 수행하므로 페이지 콘텐츠, URL, 요약 내용은 일절 저장하지 않습니다. 계정별로 기록되는 정보는 완료된 요청 수, 토큰 사용량, 최근 요청 시각 및 사용된 모델과 같은 사용 통계 메타데이터뿐입니다. 계정 등록은 선택 사항이며, 계정이 없어도 다른 모든 기능을 자유롭게 이용하실 수 있습니다. “Prefer EU servers(EU 서버 선호)” 설정을 활성화하면 유럽 엔드포인트를 보유한 모델의 경우 해당 엔드포인트에서만 실행되며, 앱 내에서 지원 여부가 표시됩니다. 이는 모델이 실행되는 위치를 제한할 뿐 전송 경로 자체를 생략하지는 않습니다. 텍스트는 모델로 전달되는 과정에서 당사 서비스(독일 서버) 및 미국 기업인 OpenRouter를 거치게 되며, 소리 내어 읽기(read-aloud) 및 음성 텍스트 변환(speech-to-text) 기능은 EU 전용 옵션을 제공하지 않습니다.

라이선스 및 구독 상태

Pro 라이선스 또는 byphil Cloud 구독을 활성화하면 라이선스 키가 기기 로컬에 저장되며(동기화되지 않음), 백엔드를 통해 구독 상태를 확인하는 데 사용됩니다. 기본적인 계정 및 결제 메타데이터는 결제 대행사와 백엔드에서 처리하며, 사용자의 페이지 콘텐츠나 읽기 기록은 당사 서버에 일절 저장하지 않습니다.

삭제 피드백

확장 프로그램을 삭제하면 Chrome에서 본 웹사이트의 간단한 피드백 페이지가 열립니다. 해당 웹 주소에는 확장 프로그램 버전과 설치 기간(일수)만 포함되며 식별자, 페이지 콘텐츠, 방문 기록은 전혀 포함되지 않습니다. 양식에 선택하거나 입력하신 내용(삭제 이유, 선택적 의견)은 확장 프로그램 버전 및 설치 기간과 함께 쿠키를 사용하지 않는 자체 호스팅 분석 도구에 이벤트로 기록되며, 오직 확장 프로그램 개선 목적으로만 사용됩니다. 브라우저에서 '추적 거부(Do Not Track)' 신호를 보내거나 분석 수집을 거부하신 경우에는 아무런 데이터도 전송되지 않습니다. 이메일 입력란은 별도로 없으므로 답변이 필요하신 경우 GitHub 이슈를 등록해 주세요. 설문에 응답하지 않고 페이지를 그냥 닫으셔도 됩니다.

"동기화 (Sync)"로 표시된 항목은 사용자의 Google 계정과 연결된 Chrome 자체 동기화 기능을 사용합니다. 이 데이터는 북마크와 마찬가지로 당사가 아닌 Google의 인프라를 거쳐 처리되며, 당사는 이에 접근할 수 없습니다.

Settings → Library & Data → Backup & restore 메뉴에서 언제든지 데이터를 내보낼 수 있어요. 백업 시 API 키, 로그인 정보, 라이선스 키 및 설치 식별자는 기본적으로 제외됩니다. 해당 백업 파일이 있으면 누구나 이 정보를 사용할 수 있으므로, 포함하려면 경고 확인 후 직접 선택해야 해요. 내보낸 파일은 안전하게 비공개로 보관하시고, 이전 백업 파일에 민감한 정보가 포함되어 있을 수 있다는 점도 기억해 주세요. 같은 위치에 있는 Danger zone에서는 삭제될 항목 수와 함께 카테고리별로 데이터를 삭제할 수 있어요. 대상 항목은 요약 및 아카이브, 하이라이트, 피드, 팟캐스트, API 키 / 로그인 / 라이선스, 전송 대상(Kindle, LocalSend), 환경설정입니다. 모든 데이터 삭제 을(를) 실행하면 확장 프로그램이 기기에 저장한 모든 데이터가 삭제되고 초기 상태로 재설정됩니다. 확장 프로그램을 삭제하셔도 관련 데이터가 함께 제거됩니다. 이러한 작업은 로컬 데이터만 삭제합니다. 계정 및 당사 서버에 보관된 기록(하단 참조)은 다음 페이지에서 직접 관리하실 수 있습니다: byphil.eu/#account. 해당 페이지에서 데이터를 내보내거나 계정을 삭제할 수 있습니다. 확장 프로그램과 Android 앱의 계정 설정에서도 이 링크로 바로 이동할 수 있습니다.

RSS 피드

내장된 Feeds 리더는 구독 정보와 가져온 피드 항목을 브라우저에 로컬로 저장하며, 외부와 동기화되거나 당사 서버로 전송되지 않습니다. 피드를 추가하거나 새로고침하면 브라우저에서 사이트를 직접 방문할 때와 마찬가지로 확장 프로그램이 발행사 서버에 피드 주소를 직접 요청하므로 발행사에서 해당 요청을 확인할 수 있습니다. 당사는 사용자의 구독 정보나 읽기 목록을 프록시 처리하거나 기록(로그)을 남기거나 열람하지 않습니다. OPML 가져오기는 전적으로 기기 내에서 처리됩니다. 백그라운드 확인 기능(기본값: 꺼짐)을 켜면 툴바 아이콘에 개수를 표시하기 위해서만 설정한 주기에 따라 피드를 다시 요청합니다. 피드 항목 요약은 일반 페이지 요약과 동일하게 작동하며, 요약을 실행할 때만 사용자가 선택한 AI 제공업체로 콘텐츠가 전송됩니다. 선택 기능인 AI 일일 요약(AI day recap) 및 AI 톤 스코어링(AI tone scoring)도 동일하게 작동합니다. 클릭할 때만 확장 프로그램이 전체 본문이 아닌 항목 제목, 출처 이름, 짧은 발췌문만을 선택한 AI 제공업체로 전송하며, 생성된 요약 결과는 기기에 캐시됩니다. 피드의 팟캐스트 에피소드는 재생(Play)을 누를 때 발행사 서버에서 직접 스트리밍됩니다.

아티클 전송: Kindle, LocalSend 및 공유 시트

전송 방식은 두 가지 경로로 나뉘며, 그중 하나만 당사 서버를 거칩니다:

  • Send to Kindle은 당사 서버를 거쳐 전송됩니다. Amazon은 승인된 발신자의 이메일로만 문서를 수신하므로, 확장 프로그램이 아티클(제목, 요약본, 본문, 하이라이트 및 출처 주소)을 byphil 백엔드로 전송한 후 입력하신 Kindle 주소로 이메일을 발송합니다. Amazon 계정의 승인된 발신자 목록에 발신용 이메일(kindle@byphil.eu)을 추가해 주셔야 해요. 전송된 콘텐츠는 이메일 생성 및 발송 목적으로만 사용됩니다. Kindle 전송 기능은 로그인 또는 라이선스가 필요하며, 무료 티어에서는 3회까지 전송할 수 있습니다.
  • LocalSend 및 시스템 공유 시트(예: AirDrop)는 기기간 직접 전송됩니다. 파일은 브라우저에서 로컬 네트워크상의 지정한 기기나 공유 시트에서 선택한 앱으로 직접 전송돼요. 당사는 이 과정에 전혀 관여하지 않으며 콘텐츠를 확인하거나 저장하지 않습니다. LocalSend는 호환 앱이 설치된 스마트폰, 태블릿, PC 및 전자책 리더기에서 원활하게 작동합니다.

라이브러리 동기화, 백업 및 게시 (선택 사항)

설정 → 동기화 및 백업에서 위치를 추가하기 전까지는 꺼져 있습니다. 위치란 직접 선택한 서버의 폴더(Nextcloud 또는 기타 WebDAV 서버, AWS S3, Cloudflare R2, Backblaze B2와 같은 S3 호환 버킷)나 내 컴퓨터의 로컬 폴더를 말합니다. 저희는 이러한 서버를 운영하지 않으며, 어떠한 관여도 하지 않고, 저장된 데이터를 절대 열람할 수 없습니다.

  • 암호화된 위치 기기 간에 전체 라이브러리를 항상 최신 상태로 동기화하거나 백업해 두세요. 아티클, 요약, 전문 텍스트, 하이라이트, 메모, 컬렉션, 태그까지 모두 지원합니다. 모든 데이터는 기기 외부로 전송되기 전 브라우저 내에서 안전하게 암호화(패스프레이즈 기반 키를 사용한 AES-256-GCM 방식)되며, 파일 이름도 난독화 처리됩니다. 서버나 저장 폴더에서는 오직 암호화된 파일, 파일 크기, 변경 시점만 확인할 수 있습니다. 패스프레이즈로 생성된 키는 현재 브라우저의 로컬 스토리지에만 보관되어 백그라운드 동기화가 원활하게 진행됩니다. 자동 생성된 추천 단어 조합을 사용하는 경우 해당 단어 역시 로컬에 보관되어 설정에서 다시 확인할 수 있으며, 직접 입력한 패스프레이즈는 어디에도 저장되지 않습니다. 이 모든 인증 정보는 절대 동기화되거나 백업에 포함되지 않습니다. 패스프레이즈를 분실하면 개발팀을 포함해 그 누구도 파일을 복구하거나 열람할 수 없습니다.
  • 읽기 가능한 위치 개인 웹사이트나 도구에서 사용할 수 있도록 일반 텍스트 파일(원하는 경우 간단한 뷰어 페이지 포함)로 게시합니다. 설정한 태그 필터와 일치하는 기사만 전송됩니다. 메모, 알림, 기사 전문은 위험 영역 설정에서 직접 활성화하지 않는 한 절대 게시되지 않으며, 활성화 시 해당 폴더에 접근할 수 있는 모든 사용자가 열람할 수 있게 됩니다.
  • 전송 방식 요청은 입력하신 로그인 정보 또는 액세스 키를 사용하여 HTTPS를 통해 브라우저에서 직접 지정한 주소로 전송됩니다. 해당 로그인 정보는 로컬에만 저장되며, 동기화되지 않고, 직접 활성화하지 않는 한 백업에서도 제외됩니다. 서버 운영자는 사용자의 IP 주소와 동기화 시점만 확인할 수 있습니다.
  • 이 컴퓨터의 로컬 폴더 브라우저의 폴더 접근 권한을 사용합니다. 사용자가 폴더를 선택하면 브라우저에서 권한을 요청하며, 브라우저 재시작 후 다시 요청할 수 있습니다. 저희는 해당 폴더에 대한 브라우저 핸들만 유지합니다. 해당 폴더를 다른 기기로 동기화하는 데 사용하는 도구(Syncthing, iCloud Drive, Dropbox 등)에는 해당 서비스의 개인정보 처리방침이 적용됩니다.

내 컴퓨터의 AI 앱 (MCP)

기본적으로 꺼져 있습니다. 설정 → AI 앱 (MCP)을 켜면 연결된 내 컴퓨터의 AI 앱(예: Claude Desktop, LM Studio, Cursor, VS Code 등)이 허용된 라이브러리 항목을 읽을 수 있습니다. 여기에는 저장된 글과 요약, 하이라이트가 포함되며, 직접 활성화한 경우에 한해 전체 본문, 피드 항목, 받은편지함 링크 저장 기능까지 지원합니다. 데이터는 브라우저에서 컴퓨터 내 가벼운 도우미 프로그램(aish-mcp)을 거쳐 해당 앱으로 전달됩니다. 서버를 전혀 거치지 않으므로 개발사에서도 절대 볼 수 없습니다. 도우미 프로그램은 사용자 본인의 컴퓨터 연결만 허용하며 페어링 코드가 필요합니다. 또한 글을 저장하거나 전달 내역을 기록하지 않습니다. 제외하도록 설정한 태그(private 가 기본값)가 붙은 글은 절대 공유되지 않습니다. 확장 프로그램은 기기 내에 최근 50건의 호출 기록(도구 이름, 일시, 결과 개수만 기록되며 본문 내용은 미포함)을 보관하며, 같은 설정 패널에서 언제든 확인할 수 있습니다. AI 앱이 모델로 전송하는 데이터 범위는 사용하는 앱과 모델에 따라 다르며, 로컬 모델을 사용할 경우 어떤 데이터도 컴퓨터 외부로 유출되지 않습니다. 언제든지 설정을 끄거나 '연결 해제'를 선택할 수 있습니다.

거의 모든 데이터는 고객님의 기기 내에서 로컬로 처리되며 당사 서버로 전송되지 않습니다. 당사에서 데이터를 처리하는 경우, 그 법적 근거 및 보유 기간은 다음과 같습니다:

  • Kindle로 보내기 (전송할 문서/기사, 고객님의 Kindle 이메일 주소) — 요청하신 발송 작업을 수행하기 위함(GDPR 제6조 제1항 (b)호). 해당 이메일을 생성하고 발송하는 목적으로만 일회성으로 사용됩니다.

타사 서비스 (Third-Party Services)

확장 프로그램 설정에 따라 페이지 콘텐츠가 다음 대상으로 전송될 수 있습니다:

  • OpenAI, Google (Gemini), Mistral AI 또는 DeepSeek — 해당 제공업체의 자체 API 키를 입력하고 활성 페이지의 요약을 직접 실행한 경우에만 해당합니다.
  • 독일 IONOS SE에서 호스팅하는 byphil 백엔드 및 데이터베이스 — 로그인하거나 byphil Cloud 또는 Send to Kindle 기능을 이용할 때만 해당됩니다.
  • byphil Cloud가 AI 모델에 연결하기 위해 사용하는 OpenRouter 및 해당 중계 모델 제공자 — 요약할 텍스트는 해당 요청 처리를 위해서만 사용 중인 모델로 안전하게 중계됩니다.
  • Stripe — 등록 판매자(Merchant of Record)로서 결제 및 구독 관리를 처리합니다.
  • Amazon — 아티클을 Kindle로 전송하는 경우, Amazon의 개인정보 처리방침에 따라 전송 및 전달됩니다.
  • 사용자의 로컬 Ollama 인스턴스 — 타사 서비스가 아니며 모든 데이터는 사용자의 컴퓨터 내에만 유지됩니다.

당사는 사용자가 연결하기로 선택한 타사 AI 제공업체의 개인정보 보호 관행에 대해 책임을 지지 않습니다. 계정을 연결하기 전에 해당 업체의 개인정보 처리방침을 검토해 보시기 바랍니다.

어떤 모델로 텍스트를 처리할지는 전적으로 고객님이 결정합니다. 개인 API 키를 사용하든 byphil Cloud를 이용하든, 설정에서 AI 제공자와 모델을 직접 선택할 수 있으며 해당 제공자의 이용약관 및 데이터 처리 지역을 확인할 책임은 사용자 본인에게 있습니다. OpenRouter, 연동된 AI 모델 제공자 및 Amazon은 자체 보호 조치(예: 표준계약조항/SCC)에 따라 EU/EEA 외부에서 데이터를 처리할 수 있습니다. 당사는 고객님의 데이터를 제3국으로 직접 이전하지 않습니다.

데이터 보안

대부분의 데이터는 브라우저 로컬에 저장되어 애초에 당사 서버로 전송되지 않으며, 취급하는 데이터에 적합한 합리적인 기술적 조치를 적용하고 있습니다. 백엔드와의 통신(byphil Cloud 및 라이선스 확인)은 전송 중 암호화됩니다. 완벽하게 안전한 전송이나 저장 방법은 없으므로 절대적인 보안을 보장할 수는 없지만, 설명된 기능을 제공하는 데 필요한 것 이상의 데이터를 수집하지 않습니다.

아동 개인정보 보호

이용자의 권리 (GDPR, CCPA 등)

대부분의 데이터는 고객님의 기기에만 안전하게 로컬로 저장되므로, 사용자가 데이터를 완전히 통제할 수 있습니다. 확장 프로그램의 '설정' 메뉴에서 언제든지 데이터를 확인, 내보내기, 삭제할 수 있으며 확장 프로그램을 제거하여 삭제할 수도 있습니다. 당사 서버에 저장되는 일부 데이터(byphil Cloud 구독/결제 메타데이터)의 경우 다음 링크에서 관리, 내보내기 및 계정 삭제가 가능합니다: byphil.eu/#account. 또는 하단의 연락처로 문의해 주시기 바랍니다.

귀하는 정보주체로서 열람 청구권(제15조), 정정 청구권(제16조), 삭제 청구권(제17조), 처리 제한 청구권(제18조), 데이터 이동권(제20조), 처리 거부권(제21조) 및 언제든지 동의를 철회할 권리를 가집니다. 또한 거주지 관할 감독 기관에 불복을 제기할 권리(제77조)도 보유합니다. 당사는 귀하의 데이터를 법적 효력을 발생시키는 자동화된 의사결정이나 프로파일링에 활용하지 않습니다.
