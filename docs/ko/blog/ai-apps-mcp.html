AI 생성 일러스트

가이드 · 2026년 10월

Claude, LM Studio 등 다양한 AI 앱에서 라이브러리를 활용해 보세요

AI 앱은 내가 읽은 내용을 기억하지 못하지만, AI Summary Helper는 모두 기억합니다. 내 컴퓨터에서 두 앱을 연결하면 AI 앱이 저장된 글을 검색하고, 하이라이트를 인용하며, 출처를 명시할 수 있습니다.

AI Summary Helper는 Model Context Protocol(MCP)을 지원하는 AI 앱(Claude Desktop, LM Studio, Cursor, VS Code, Jan, 로컬 에이전트 등)과 내 라이브러리를 공유할 수 있습니다. AI 앱이 질문을 던지면 AI Summary Helper가 저장된 글에서 관련 내용을 찾아 내 컴퓨터의 앱으로 바로 답변을 전달합니다.

기본적으로 꺼져 있습니다. 저희 서버는 전혀 관여하지 않으며, 확장 프로그램과 앱은 컴퓨터에 설치된 작은 헬퍼 프로그램을 통해 서로 통신합니다 aish-mcp, 이 프로그램은 글을 저장하지 않으며 어디로도 데이터를 전송하지 않습니다.

어떤 질문을 할 수 있나요

  • 인터넷 대신 내가 읽은 글에 물어보세요. “AI와 감시에 대해 저장해 둔 글이 뭐가 있지? 주제별로 분류하고 글마다 의견이 어떻게 다른지 알려줘.”
  • 직접 수집한 출처를 바탕으로 글쓰기. “AI의 탄소 배출 비용에 대한 글 초안을 작성하고, 내가 남긴 하이라이트를 인용해 줘.”
  • 컬렉션의 핵심 질문에 답변하기. “인플레이션 컬렉션을 사용해 줘. 해당 출처만을 기반으로 질문에 답하고, 부족한 정보가 무엇인지 알려줘.”
  • ‘나중에 읽기’ 목록 확인하기. “‘나중에 읽기’ 목록에서 이번 주 기한인 글이 뭐야? 각각 5분 분량으로 요약해 줘.”
  • 피드 정리 및 선별하기. “오늘 올라온 AI 관련 미확인 피드를 살펴보고 읽어볼 만한 글 3편을 추천해 줘.”
  • 한 해의 독서 기록 돌아보기. “2026년 독서 연말 결산을 만들어 줘. 주요 주제, 가장 많이 읽은 달, 올해를 대표하는 글을 정리해 줘.”
  • 에이전트가 대신 저장하도록 하기. “로컬 퍼스트 소프트웨어에 관한 좋은 자료 3개를 찾아 메모와 함께 내 AISH 수신함에 저장해 줘.”

LM Studio의 로컬 모델을 사용하면 네트워크가 꺼진 오프라인 상태에서도 이 모든 작업이 작동합니다.

설정 방법

Chrome, Edge 또는 Brave 브라우저의 AI Summary Helper, Node.js 20 이상 및 MCP 지원 앱이 필요합니다.

  1. 기능 켜기. AI Summary Helper에서 설정 → AI 앱(MCP)을 열고 다음 항목을 켭니다: 이 컴퓨터의 AI 앱이 내 라이브러리를 사용하도록 허용.
  2. 페어링 코드 받기. 터미널에서 다음 명령어를 실행합니다: npx -y aish-mcp pair. 페어링 코드가 출력되고 사용자 폴더에 저장됩니다. 설정 패널에 코드를 붙여넣고 연결을 선택하세요.
  3. 앱에 AI Summary Helper 추가하기. 아래에서 사용 중인 앱에 맞는 스니펫을 적용한 뒤, 앱을 완전히 종료했다가 다시 여세요.
  4. 연결 상태 확인하기. 설정 패널에 다음과 같이 표시됩니다: 연결됨 앱이 실행되면 표시됩니다. 라이브러리에 대해 AI 앱에 질문해 보세요. 앱이 호출한 모든 내역이 패널의 최근 활동에 나타납니다.

Claude Desktop

Settings → Developer → Edit Config를 열고 다음을 추가합니다:

{
  "mcpServers": {
    "aish": { "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

Claude Desktop에서 다음을 찾을 수 없는 경우: npx, 전체 경로를 사용하세요. 전체 경로는 which npx 명령어를 터미널에서 실행하여 확인할 수 있습니다 (예: /opt/homebrew/bin/npx).

Cursor

다음 파일( ~/.cursor/mcp.json (모든 프로젝트) 또는 .cursor/mcp.json (단일 프로젝트))에 Claude Desktop과 동일한 "aish" 항목을 추가합니다.

VS Code

다음 파일( .vscode/mcp.json):

{
  "servers": {
    "aish": { "type": "stdio", "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

LM Studio 및 기타 앱

설정에 mcpServers 항목이 있는 앱(LM Studio의 mcp.json, Jan 등 대부분의 앱)은 Claude Desktop과 동일한 설정을 사용합니다. HTTP를 통해서만 연결되는 앱은 다음 명령어로 npx -y aish-mcp --http 주소( http://127.0.0.1:47616/)에서 사용할 수 있으며, 헤더는 Authorization: Bearer <your pairing code>를 전달합니다. 로컬 모델의 경우 Qwen 3 또는 Llama 3.1 이상과 같이 도구 호출(Tool Calling)을 지원하는 모델을 선택하세요.

앱에서 사용할 수 있는 기능

도구주요 기능필요 권한

기능을 켤 때는 내 라이브러리 권한만 기본으로 활성화됩니다. 필요한 경우 설정 패널에서 글 전문, 피드, 링크 저장을 켤 수 있으며, 변경 사항은 다시 연결할 필요 없이 다음 호출부터 즉시 적용됩니다. AI 앱은 AI Summary Helper의 데이터를 수정하거나 삭제할 수 없습니다.

개인정보 보호 및 보안

  • 어떤 데이터도 외부 서버를 거치지 않습니다. 데이터는 브라우저에서 헬퍼 프로그램을 거쳐 내 컴퓨터의 AI 앱으로 전달됩니다. 이후 앱이 모델로 전송하는 데이터는 선택한 앱과 모델에 따라 달라집니다. 로컬 모델을 사용하면 모든 데이터가 내 기기 내에 유지됩니다.
  • 다음으로 태그된 글: private 절대 노출되지 않음 태그가 지정된 글은 검색 결과, 통계, 컬렉션 어디에도 절대 나타나지 않습니다. 설정 패널에서 다른 태그를 지정할 수도 있습니다.
  • 내 컴퓨터에서만 연결할 수 있습니다. 헬퍼 프로그램은 127.0.0.1에서만 수신 대기하므로 네트워크 상의 다른 기기에서는 접근할 수 없습니다. 방문하는 웹사이트에서도 사용할 수 없습니다. AI Summary Helper의 고유 확장 프로그램 주소만 허용되며, 모든 연결에는 페어링 코드가 필요합니다.
  • 모든 호출 내역을 확인할 수 있습니다. 설정 패널에는 최근 50회의 호출 내역이 도구 이름 및 시간과 함께 표시되며, 내용은 절대 기록되지 않습니다.
  • 언제든지 연결을 차단할 수 있습니다. 기능을 끄거나 연결 해제를 선택하세요. 다음 명령어를 실행하면 npx -y aish-mcp reset 이전 페어링 코드의 작동이 중지됩니다.
  • 저장된 페이지는 웹에서 가져온 텍스트입니다. AI 앱은 저장된 페이지를 지시사항이 아닌 단순 정보로 처리하도록 안내받지만, 저장된 웹페이지가 AI를 오도하려고 시도할 가능성은 여전히 존재합니다. 사용하지 않을 때는 링크 저장 권한을 꺼두는 것을 권장합니다.

문제 해결

증상해결 방법
패널 상태: 연결되지 않음AI 앱이 실행되지 않았거나 아직 설정되지 않았습니다. 앱을 열거나 터미널에서 npx -y aish-mcp 명령어를 실행하여 연결을 테스트해 보세요.
AI 앱에 AI Summary Helper 도구가 표시되지 않거나 업데이트 후 새 도구가 누락되는 경우앱을 완전히 종료한 후 다시 실행하세요. 일부 앱은 시작할 때만 도구 목록을 불러옵니다.
“AISH is not running”브라우저가 닫혀 있거나 기능이 꺼져 있습니다. 브라우저를 열고 설정 패널을 확인하세요.
“Scope … is not enabled”앱에서 허용되지 않은 권한을 요청했습니다. 필요한 경우 설정 패널에서 해당 권한을 켜세요.
코드를 붙여넣은 후에도 패널이 연결되지 않는 경우다음 명령어를 실행하고 npx -y aish-mcp pair 출력된 코드를 다시 붙여넣으세요. 이 코드는 다음 실행 후 변경됩니다: reset.

여러 AI 앱을 동시에 실행해도 문제없습니다. 하나의 연결을 공유합니다.
