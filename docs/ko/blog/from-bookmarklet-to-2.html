북마크릿에서 2.0까지: AI Summary Helper는 지금 어떤 도구일까요

Kindle에서 글을 읽기 위한 원클릭 북마클릿으로 시작했습니다. 2년의 시간과 전면적인 재구축을 거친 지금, 현재 제공하는 대부분의 기능은 초기 100명이 가입했을 당시에는 아예 존재하지도 않았습니다.

AI Summary Helper는 무료 오픈소스 Chrome 확장 프로그램입니다. 보유한 AI 제공자나 완전 로컬 모델을 활용해 웹 페이지를 요약하고, 알림 시간과 함께 나중에 볼 아티클로 저장하며, 읽기 기록을 검색과 연결이 가능한 아카이브로 바꿔줍니다. 첫 번째 버전에는 이런 기능이 전혀 없었습니다. 초기에 무엇이 있었고, 어떻게 지금에 이르게 되었는지 살펴보겠습니다.

프로젝트의 시작

2024년 7월, 이 도구는 확장 프로그램도 아닌 북마클릿이었습니다. 흥미로운 아티클을 찾아 탭을 수십 개씩 열어두고도 다른 많은 사람들처럼 대부분 읽지 못하곤 했습니다. 처음 기획 의도는 단순하고 개인적이었습니다. 맞춤 프롬프트 요약기가 생성 결과를 페이지에 바로 삽입해 주면, 다음 서비스를 통해 글을 Kindle로 보낼 때 요약본도 함께 전송되도록 하는 것이었죠. Reabble의 Send-to-Kindle 도구. 그게 제품의 전부였습니다. AI 제공자 하나, 프롬프트 입력창 하나, 그리고 iOS Safari를 포함해 어디서나 작동하는 북마클릿 버전과 즉석에서 프롬프트를 조정하고 싶은 사람들을 위한 Chrome 확장 프로그램 버전뿐이었습니다.

몇 주 만에 활성 사용자 수가 100명을 넘었습니다. 제품으로 만들려던 것이 아니라 한 사람의 개인 독서 습관을 해결하려고 만든 도구였기에 정말 놀라웠습니다.

그때와 2.0 사이에 실제로 바뀐 점

‘원하는 방식으로 요약하고, 브라우저 탭보다 더 편안한 곳에서 읽는다’는 핵심 아이디어는 변하지 않았습니다. 하지만 그 외의 거의 모든 것이 바뀌었습니다.

단일 제공자에서 5가지 선택지로 확장

v1은 자체 키와 단일 엔드포인트를 사용하는 OpenAI 전용이었습니다. 2.0은 자체 API 키를 활용하는 OpenAI, Google Gemini, Mistral, DeepSeek뿐 아니라 Ollama를 통한 완전 로컬 실행까지 지원합니다. 즉, 원하지 않는다면 페이지 콘텐츠가 사용자의 기기 외부로 전혀 유출되지 않는 완벽한 프라이버시를 보장합니다. 키 관리를 번거로워하는 사용자를 위해 호스팅 플랜(byphil Cloud)도 선택적으로 제공하지만, 결코 강제하지는 않습니다. 이는 단순한 기능 추가가 아니라 제품의 본질을 바꾼 변화였습니다. v1이 기본적으로 한 기업을 신뢰하도록 요구했다면, 2.0은 사용자가 직접 선택하지 않은 그 어떤 대상도 신뢰하도록 강요하지 않습니다.

‘페이지에 단순 삽입’에서 ‘완전한 워크플로우’로

‘브라우저보다 편안한 환경에서 나중에 읽는다’는 원래의 통찰은 여전히 유지되지만, 이제 단순히 DOM에 요약을 붙여넣는 수준에 머물지 않습니다. 이제 페이지를 마우스 우클릭하면 다음 기능이 제공됩니다. 요약 후 탭 닫기: 읽을 시점(내일, 주말, 이번 주, 리서치 세션)을 선택하고 메모를 추가하면, RSVP 오버레이로 요약을 빠르게 훑어본 뒤 탭이 자동으로 닫힙니다. Chrome 알림이 '언젠가', '생각날 때'가 아니라 정확히 지정한 시간에 다시 글을 읽을 수 있도록 불러옵니다.

쌓여만 가던 아티클 목록을 체계적인 내비게이션으로

v1에는 기록 기능이 전혀 없었습니다. 요약은 페이지 위에 떴다가 사라지면 끝이었죠. 이제 저장된 모든 아티클은 로컬에 저장되어 검색 가능한 아카이브로 관리됩니다. 텍스트 하이라이트 기능(주요 구문에 대한 AI 추천 ‘고스트’ 하이라이트 포함), 독서 분석 히트맵, 그리고 읽은 내용을 단순 목록 대신 주제별로 묶어주는 D3 지식 그래프까지 함께 제공됩니다.

핵심이었던 Kindle 연동, 이제는 여러 선택지 중 하나로

Reabble 도구를 통한 Send-to-Kindle은 이 프로젝트가 탄생한 유일한 이유였습니다. 지금도 기본적으로 지원되지만, 이제 브라우저를 벗어나 읽는 방법이 훨씬 다양해졌습니다. iPhone이나 iPad로 AirDrop하여 Apple Books에서 바로 열거나, 자체 Wi-Fi를 통해 LocalSend로 KOReader 같은 리더기에 전송할 수도 있습니다. ‘브라우저에서 벗어나 읽기에 최적화된 기기에서 읽는다’는 본래의 목적을 달성하는 경로가 더 넓어졌습니다.

변하지 않은 점

여전히 무료이며 오픈 소스(AGPL-3.0, GitHub에 전체 코드 공개, 별도 조건이 필요한 기업은 상용 라이선스 이용 가능)이고, 어떤 핵심 기능에도 계정이 필요하지 않아요. 이 원칙은 결코 타협 대상이 아니었습니다. v1이 처음에 북마클릿 형태로 탄생했던 이유도 바로 이 때문이죠. 읽기 도구를 빌려 쓰지 않고 온전히 소유하고 싶었던 사람이 직접 만들었으니까요.

자주 묻는 질문(FAQ)

처음 나왔던 북마클릿과 동일한 프로젝트인가요?
네, 맞습니다. 2024년 7월부터 꾸준히 개발되어 온 동일한 오픈소스 프로젝트이자 GitHub 저장소입니다. 별도 설치 없이 브라우저에 구애받지 않고 사용하고 싶은 분들을 위해 북마클릿 버전도 여전히 제공됩니다.

사용하려면 OpenAI 계정이 필요한가요?
아닙니다. v1에서는 그랬지만 오래전에 바뀌었습니다. 지원되는 모든 AI 제공자를 사용할 수 있으며, Ollama를 통한 완전 로컬 모델을 사용하면 외부 계정이 전혀 필요하지 않습니다.

Gumroad 버전은 어떻게 되었나요?
프로젝트 초기에 초기 사용자들의 후원을 받기 위한 창구로 활용했습니다. 확장 프로그램 자체는 언제나 무료 오픈소스였으며, Gumroad가 도구 사용을 막는 유료 장벽이었던 적은 없습니다.
