제품 · 2026년 11월

byPhil Cloud, 이제 EU 모드 지원: 스위치 하나, 솔직한 표시

선택형 호스팅 서비스가 이제 요청을 EU 엔드포인트로만 보낼 수 있고, 모델 선택기에서는 어떤 모델이 EU 기업의 것이고 어떤 모델이 EU 리전에서 실행될 뿐인지 알려 줘요.

한 줄 요약. byPhil Cloud를 사용한다면 이제 다음을 켤 수 있어요: EU 서버 우선 사용. 그러면 요청은 모델 제공업체의 EU 엔드포인트로만 가고, 다른 곳으로 우회하지 않아요. 모델 선택기는 모든 모델에 EU 기업 또는 EU 서버라는 표시를 붙이고, 클릭 한 번으로 쓰는 자동 프리셋을 제공업체별로 마련해요. 이는 EU 옵션을 갖춘 편의 기능이며, 서비스가 완전한 주권을 갖췄다는 주장은 아니에요. 이 글에서 차이를 설명해요.

달라진 점

byPhil Cloud는 AI Summary Helper를 사용하는 선택형 호스팅 방식이에요. byPhil 계정에 포함되어 있어 API 키가 필요 없어요. 지금까지는 모델을 고르면 가장 저렴하고 빠른 경로가 사용됐어요. 이제 모델 선택기에 EU 모드와 더 명확한 구성이 생겼어요:

  • 스위치 하나. 설정에서 EU 서버 우선 사용 항목을 켜면 요청이 모델 제공업체의 EU 엔드포인트에 고정돼요. 모델에 EU 경로가 없어도 요청이 몰래 다른 곳으로 보내지지 않아요.
  • 자동 프리셋. 자동, 자동 · Mistral, 자동 · Google, 자동 · DeepSeek, 자동 · Anthropic 그리고 자동 · OpenAI 프리셋이 알맞은 모델을 골라 줘요. EU 스위치가 켜져 있으면 EU 경로가 있는 모델만 선택해요.
  • 두 가지 배지. EU 기업 표시는 제공업체의 본사가 유럽에 있다는 뜻이에요(Mistral, 파리). EU 서버 표시는 다른 지역의 기업이 EU 리전에서 모델을 실행한다는 뜻이에요.
  • 검색과 최근 모델. 최근에 사용한 모델은 맨 위에 있고, 검색창에서 모든 클라우드 모델을 찾을 수 있어요. EU 경로가 없는 모델도 선택할 수 있지만 표시가 붙으므로 실수로 바꿀 일이 없어요.

모델 선택기는 모델을 쓰는 다른 두 가지 방법, 즉 직접 발급한 키와 로컬 Ollama 모델과 같은 곳에 있어서, 마음이 바뀌면 클릭 한 번이면 돼요(세 가지 방법 비교).

EU 기업과 EU 서버는 같지 않아요

대부분의 제품 페이지가 흐릿하게 넘어가는 부분이에요. 어떤 모델은 물리적으로 유럽에 있으면서도 미국 법의 적용을 받는 기업의 것일 수 있어요. 미국의 CLOUD Act는 데이터가 어디에 저장되어 있든, 미국에 기반을 둔 제공업체가 관리하는 데이터를 미국 당국이 제출하도록 요구할 수 있게 해요. 이것이 GDPR과 어떻게 양립하는지는 논란이 있어요(법적 배경과 출처). 그래서 두 경우를 따로 표시하고, 읽는 내용에 어느 쪽이 중요한지는 직접 결정할 수 있게 했어요.

  • EU 기업: EU 법과 국내법의 적용을 받아요. 관할권이 걱정이라면 적합해요.
  • EU 서버: 처리되는 동안 텍스트가 EU에 머물러요. 데이터 위치가 걱정이라면 적합하며, 유럽산이 아닌 더 강력한 모델도 쓸 수 있어요.

둘 다 보증은 아니에요. 제공업체, 제휴 관계, 투자자는 바뀌므로 제공업체의 최신 약관을 확인하세요.

해 주지 않는 것

깔끔한 이야기보다 한계를 분명히 하는 것이 더 중요해요:

  • 호스팅 서비스의 서버와 데이터베이스는 독일의 IONOS에서 운영돼요. 그다음 텍스트는 미국 기업인 OpenRouter를 거쳐 모델 제공업체로 전달돼요. EU 스위치는 모델이 실행되는 위치를 고정할 뿐, 관련 기업이 누구인지는 바꾸지 않아요.
  • 가장 강력한 구성이 필요하다면 신뢰하는 제공업체의 키를 직접 쓰거나, Ollama로 로컬 모델을 사용하세요. 이 경우 페이지 텍스트가 컴퓨터를 벗어나지 않아요.
  • 모델은 모두 같지 않아요. 유럽 모델은 일상적인 읽기에 합리적인 선택이지만, 가장 좋은 품질이 필요하다면 EU 라우팅이 있는 미국 모델이 더 나을 수 있어요. 그 선택은 사용자의 몫이고, 바로 그것이 모델 선택기의 목적이에요.

이렇게 만든 이유

주권은 가장 좋은 모델을 소유하는 것이 아니에요. 모델은 발전하고 소유자, 가격, 약관도 바뀌어요. 사용자를 지켜 주는 것은 바꿀 수 있다는 점이에요. 한 모델에서 다른 모델로, 클라우드에서 직접 발급한 키로, 키에서 로컬 모델로, 라이브러리를 잃거나 도구를 다시 배우지 않고도요. 글, 요약, 하이라이트는 어떤 경우에도 기기에 남아요(개인정보 처리방침). 모델 선택기는 질문하는 페이지의 텍스트를 누가 읽을지만 결정해요.

그러니 EU 모드는 그 사다리의 한 칸일 뿐 종착점은 아니에요. 키도 설정도 필요 없는 가장 손쉬운 방법이 텍스트가 어디로 가는지에 조금 더 신경 쓰게 해 줘요.

켜는 방법

  1. AI Summary Helper에서 모델 선택기를 열고 다음을 선택하세요: byPhil Cloud.
  2. 설정에서 EU 서버 우선 사용 항목을 켜세요.
  3. 다음 배지가 있는 모델을 고르세요: EU 기업 또는 EU 서버 . 또는 다음 프리셋을 선택하세요: 자동 .

관련 항목: 개인을 위한 디지털 주권 그리고 내 키. 내 모델. 내 데이터.

자주 묻는 질문

byPhil Cloud에는 API 키가 필요한가요?

아니요. byPhil 계정에 포함되어 있어요. 원한다면 직접 발급한 키나 로컬 모델도 계속 사용할 수 있어요.

byPhil Cloud는 주권적인 선택인가요?

아니요, 그렇게 설명하지 않아요. 독일에서 운영되지만 미국 기업인 OpenRouter를 통해 모델에 연결해요. 최대한의 통제권을 원하면 직접 발급한 키나 로컬 모델을 사용하세요.

모델에 EU 경로가 없으면 어떻게 되나요?

선택할 수는 있지만 표시가 붙어요. EU 스위치가 켜져 있으면 자동 프리셋은 그 모델을 절대 고르지 않으며, 요청이 EU 밖으로 우회되지도 않아요.

EU 기업과 EU 서버 중 무엇을 골라야 하나요?

관할권이 가장 중요하면 EU 기업을 고르세요. 데이터를 EU에 두되 더 강력한 모델이 필요하면 EU 서버를 고르세요.
