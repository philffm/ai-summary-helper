내 키. 내 모델. 내 데이터.

대부분의 AI 도구는 사용자와 모델 사이에 자체 서버를 둡니다. 중개 서버가 없을 때 무엇이 달라지는지, 그리고 여전히 사용자가 직접 관리해야 하는 부분은 무엇인지 살펴봅니다.

모든 AI 요약의 기본 구조는 동일합니다. 텍스트가 전송되고, 결과가 반환됩니다. 도구의 신뢰도를 결정짓는 핵심은 바로 '중간에 누가 있는가'입니다. 수많은 서비스에서는 그 자리에 기업의 중개 서버가 자리 잡고 있어, 사용자가 읽는 콘텐츠가 직접 고르지도 않은 모델로 전달되기 전에 해당 서버를 거치게 됩니다.

여기서 'API 키 직접 사용'이 의미하는 것

신뢰하는 제공업체에서 API 키를 생성한 후 AI Summary Helper에 붙여넣고 모델을 선택하기만 하면 됩니다. 웹페이지를 요약할 때 확장 프로그램의 백그라운드 워커가 해당 제공업체로 텍스트를 직접 전송하고 답변을 실시간 스트리밍으로 받아옵니다. 직접 등록한 API 키를 사용하는 경로에는 AI Summary Helper 서버가 전혀 개입하지 않습니다.

Ollama 등을 통해 내 컴퓨터에서 직접 실행되는 로컬 모델과 연동할 수도 있습니다. 이 경우 웹페이지 텍스트는 컴퓨터 외부로 전혀 전송되지 않습니다.

API 키가 저장되는 위치

API 키는 동기화 저장소가 아닌 브라우저의 로컬 확장 프로그램 저장소에 저장됩니다. 즉, 브라우저 계정을 통해 다른 기기로 복사되지 않습니다. 대신 브라우저마다 한 번씩 입력해야 합니다. API 키는 설정해 둔 제공업체와의 통신에만 사용됩니다.

보호할 수 있는 부분과 보호할 수 없는 부분

이 점은 명확히 짚고 넘어갈 필요가 있습니다. API 키를 직접 등록하면 중간 중개자는 사라지지만, 모델 제공업체 자체가 사라지는 것은 아닙니다. 호스팅 모델로 전송하는 모든 데이터는 해당 제공업체의 이용약관 및 데이터 보관 정책의 적용을 받으므로 직접 확인해야 합니다. 텍스트를 내 컴퓨터에 온전히 유지하는 방법은 로컬 모델을 사용하는 것뿐이며, 로컬 모델은 일반적으로 호스팅 모델에 비해 규모가 작고 처리 속도가 느립니다.

이 프로젝트는 오픈소스이므로 이 설명을 그대로 믿을 필요 없이 직접 검증할 수 있습니다. 키와 요청을 처리하는 코드는 저장소에 공개되어 있어 누구나 확인할 수 있습니다.

상황에 맞는 설정 선택하기

  1. 일상적인 읽기: 이용약관을 신뢰할 수 있는 제공업체의 호스팅 모델을 추천합니다. 속도가 빠르고 품질이 뛰어나며, 키를 직접 제어할 수 있습니다.
  2. 민감한 자료: 로컬 모델을 추천합니다. 속도가 느리고 성능은 다소 낮지만, 데이터가 기기 외부로 절대 나가지 않습니다.
  3. 테스트 및 비교: 여러 제공업체를 추가하고 동일한 글에 대한 요약 결과를 비교해 보세요. 어떤 모델이 어떤 유형의 글에 가장 적합한지 파악하는 가장 빠른 방법입니다.

어느 한 가지 설정만이 정답인 것은 아닙니다. 핵심은 선택권이 온전히 사용자에게 있다는 점입니다.
