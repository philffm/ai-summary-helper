경계를 잃지 않고 도구 연결하기

상호 운용성은 접근이 명시적이고 범위가 정해져 있으며 감사 가능할 때 유용합니다. 프로토콜이 최소 권한이나 소스 검토의 필요성을 없애주지는 않습니다.

주요 기능

읽기 목록 서비스가 본래 갖추었어야 할 모든 기능

추가 구독 결제에 아카이브가 묶이는 일 없이, 저장하고 이해하며 다시 찾아 실제로 읽어보세요.

읽기 목록 앱이 처음부터 갖췄어야 할 모든 것.

읽기 목록 앱이 처음부터 갖췄어야 할 모든 것. 모델과 서버는 물론, 데이터의 기기 외부 전송 여부까지 직접 선택할 수 있습니다. 문제는 저장이 아닙니다. 저장한 내용을 다시 찾아보는 것이 핵심이죠. 바로 이 점에 집중해 만들었습니다. 저장하는 모든 콘텐츠는 검색하고 연결하며 내보낼 수 있습니다. 쌓아만 두는 곳이 아닌 진정한 아카이브가 됩니다. 관심 있는 주제를 구독하고, 중요한 소식을 먼저 확인하며, 하루의 핵심 내용을 요약해 보세요. 자투리 시간마다 읽거나 듣고, Kindle로 바로 전송해 보세요.

내장 RSS 리더

블로그와 뉴스 사이트를 구독하고, 출처·태그·날짜·무드로 필터링하고, OPML을 가져오고, 어떤 항목이든 클릭 한 번으로 요약해요. 확장 프로그램에서 팟캐스트 피드를 재생하고 원할 때 AI 요약을 받아 보세요. 피드와 즐겨찾기는 내 기기에 그대로 남아 있어요.

20개 이상의 언어 지원 및 크로스 플랫폼

확장 프로그램, 네이티브 사이드 패널, 또는 북마클릿 확장 프로그램이 페이지에 접근할 수 없을 때 쓰는 북마클릿으로 20개 이상의 언어를 읽고 요약하세요.

원하는 모델로 생성하는 AI 요약

OpenAI, Gemini, Mistral, DeepSeek, 사용자 지정 엔드포인트, 또는 로컬 Ollama 중에서 선택하세요. 기기 밖으로 나가지 않는 요약을 만들 수 있어요.

진정한 온디바이스 검색

브라우저 기반 TF-IDF 인덱스로 제목, 태그, 아티클 내용을 검색해요. 전체 텍스트 검색은 서버 왕복 없이 기기 안에서 처리돼요.

Claude, LM Studio, Cursor에서 직접 만나는 내 라이브러리

Claude Desktop, LM Studio, Cursor 등 MCP 앱에서 라이브러리를 검색하고, 하이라이트를 인용하고, 예정된 항목을 확인할 수 있어요. 접근 권한은 내가 관리하며, 어떤 데이터도 저희 서버를 거치지 않아요.

내 저장소에 암호화되어 안전하게 보관되는 라이브러리

암호화된 라이브러리를 내 Nextcloud, WebDAV 서버, S3 버킷 또는 로컬 폴더에 동기화하세요. 태그 그래프와 3D 맵이 있는 검색 가능한 목록을 공개할 수 있어요. 저희는 동기화 서버를 운영하지 않아요. 설정 방법 · 동기화 설정 사용해 보기

자주 묻는 질문

설치 전 확인사항

주제, 제공자, 프라이버시, 아카이브, 플랫폼별로 답변을 검색해 보세요.

이용하려면 계정이 필요한가요?

아니요. 설치하고, 사용하는 AI 제공자의 키를 가져오거나 로컬 Ollama 모델을 사용하면 바로 저장을 시작할 수 있어요. 계정은 선택 사항인 byphil Cloud 접근이나 추가 Kindle/LocalSend 전송에만 필요해요. 제공자 옵션 보기 →

브라우저 외부로 전송되는 데이터는 무엇인가요?

설정한 AI 제공자에게는 요약 요청만 전송돼요. RSS는 구독한 피드에도 요청을 보내야 해요. AI 리캡은 요청할 때만 헤드라인과 짧은 스니펫을 전송해요. 검색, 중복 감지, 태그, 추천은 로컬에서 실행돼요. 기기 내 아키텍처 보기 →

제 페이지나 하이라이트가 모델 학습에 사용되나요?

AI Summary Helper는 사용자의 콘텐츠를 자체 모델 학습에 사용하지 않아요. BYOK를 사용하면 선택한 제공자의 데이터 정책이 적용돼요. Ollama를 사용하면 요약 요청이 내 컴퓨터를 벗어나지 않아요. 프라이버시 모델 읽기 →

클라우드 의존성 없이 완전히 독립적으로 실행할 수 있나요?

네. 로컬 Ollama 모델을 지정하면 요약 단계도 내 컴퓨터에서 처리돼요. 나머지 기능은 이미 모두 로컬에서 실행돼요. BYOK와 Ollama 비교하기 →

읽기 아카이브는 어디에 저장되나요?

기본적으로 내 기기의 브라우저에 저장돼요. Markdown으로 내보내거나, 내 Nextcloud, WebDAV 서버, S3 버킷 또는 로컬 폴더에 암호화해 백업할 수 있어요. 동기화 가이드 읽기 →

브라우저 데이터를 삭제하면 어떻게 되나요?

백업이 없다면 브라우저의 로컬 데이터를 삭제할 때 로컬 아카이브도 사라질 수 있어요. 브라우저 데이터를 삭제하거나 프로필을 변경하기 전에 라이브러리를 내보내거나, 내 저장소로 암호화 동기화를 설정해 두세요. 백업 및 동기화 가이드 읽기 →

어떤 AI 제공자와 모델을 지원하나요?

OpenAI, Gemini, Mistral, DeepSeek, 호환되는 사용자 지정 엔드포인트 또는 로컬 Ollama 모델을 사용할 수 있어요. 직접 키를 가져오거나, 선택 사항인 byphil Cloud 접근을 이용하세요. BYOK 작동 방식 알아보기 →

어떤 브라우저와 플랫폼을 지원하나요?

브라우저 확장 프로그램, 네이티브 사이드 패널 또는 북마클릿을 사용하세요. Android 앱으로 휴대폰에서 링크를 추가할 수 있어요. iOS는 아직 지원되지 않아요. 브라우저 및 캡처 워크플로 보기 →

오픈 소스인가요?

네, 확장 프로그램의 소스 코드는 다음에 공개되어 있습니다: GitHub, AGPL-3.0 라이선스에 따라 제공돼요. 개인, 교육 및 비영리 목적으로는 무료로 이용할 수 있으며, AGPL 조건 외의 용도로 사용하려는 기업은 상용 라이선스를 취득할 수 있어요. 로컬 아키텍처 알아보기 →
