अपनी Reading Library को Nextcloud, S3 या Local Folder में Encrypted Sync कैसे करें

आपके saved articles, summaries, highlights और notes आपके सभी computers पर, वहीं store होंगे जहाँ आप चाहें, और सिर्फ आपकी key से ही पढ़े जा सकेंगे। बस 10 मिनट का setup, हमारे साथ किसी account की ज़रूरत नहीं।

Short version. AI Summary Helper में खोलें Settings → Sync & backup → Add a place, Nextcloud/WebDAV, S3-compatible storage या अपने computer पर कोई folder चुनें, और suggested passphrase रखें। Upload होने से पहले सब कुछ आपके browser में encrypt हो जाता है। अपने दूसरे computer पर वही place add करें और passphrase enter करें। बस इतना ही setup है। इस page के बाकी हिस्से में हर storage type, क्या sync होता है, और कुछ गलत होने पर क्या करना है, यह समझाया गया है।

यह सब करने की ज़रूरत ही क्यों है? क्योंकि reading library संभाल कर रखने लायक होती है, और जिस tool पर आप depend करते हैं वह कभी भी बंद हो सकता है (इसके बारे में और यहाँ पढ़ें)। अपने खुद के storage पर sync करने का मतलब है कि आपकी library किसी एक app या account के भरोसे नहीं रहती।

क्या sync होता है, और क्या नहीं

  • Synced: saved articles उनके full text और summaries के साथ, tags, highlights, आपके notes और comments, और collections।
  • Not synced: आपकी API keys, sign-in details, sync login खुद, और per-device settings। Backups और sync जानबूझकर इन्हें छोड़ देते हैं।
  • One article per page: अगर आपने वही page दो computers पर save किया है, तो आपको एक ही article मिलेगा (tags और missing fields combine हो जाते हैं)।
  • Edits merge field by field: अगर एक computer पर title बदला गया और दूसरे पर tag जोड़ा गया, तो दोनों changes रहेंगे। अगर दोनों जगह एक ही field बदला गया, तो बाद वाला change मान्य होगा, हर device पर एक समान।

Step 1: चुनें कि डेटा कहाँ store होगा

Nextcloud या कोई अन्य WebDAV server

बेस्ट रहेगा अगर आप पहले से Nextcloud run कर रहे हैं या hosted service यूज़ कर रहे हैं। आपको तीन चीज़ों की ज़रूरत होगी:

  1. आपकी files का address. Nextcloud के लिए यह कुछ ऐसा दिखता है https://your-server/remote.php/dav/files/your-username/। Nextcloud में खोलें Files → Settings और वहाँ दिख रहा WebDAV address copy करें।
  2. आपका username.
  3. App password, आपका main password नहीं। Nextcloud में: Settings → Security → Devices & sessions → create a new app password। अगर आप कभी access revoke करना चाहें, तो बस उस एक entry को delete कर दें।

Folder name चुनें, जैसे कि aish-sync। यह आपके लिए automatically create हो जाएगा। बाकी WebDAV servers (जैसे NAS boxes, ownCloud) भी इसी तरह काम करते हैं; बस address format अलग होता है।

S3-compatible bucket

अगर आप object storage पसंद करते हैं तो सबसे बढ़िया: AWS S3, Cloudflare R2, Backblaze B2, MinIO आदि। एक bucket बनाएं, फिर एक access key create करें सिर्फ इसी bucket के लिए जिसमें read, write, list और delete की permission हो। कभी भी अपने account की main key use न करें। Extension में endpoint address enter करें (उदाहरण के लिए https://s3.eu-central-1.amazonaws.com, या जो address आपका provider दिखाए), bucket name, region (अगर provider न पूछे तो default छोड़ दें), access key ID और secret key।

आपके computer पर एक folder

बेस्ट रहेगा अगर कोई दूसरा tool पहले से आपके devices के बीच folder sync कर रहा हो: Syncthing, आपका desktop sync client, iCloud Drive, या USB drive। चुनें इस computer पर एक folder और एक अपना नया, empty folderचुनें, जैसे कि Documents/AISH-sync। Chrome इसके लिए सीधे Desktop, Documents या Downloads folder को accept नहीं करता, इसलिए कोई subfolder चुनें। यह computer पर Chrome और Edge में काम करता है। दो बातें ध्यान रखें: browser restart के बाद आपसे दोबारा access allow करने को कह सकता है (settings screen पर इसके लिए button है), और folder तभी sync होता रहेगा जब browser चल रहा हो।

Step 2: Encrypted चुनें, और passphrase words संभाल कर रखें

जब आप place add करते हैं, Encrypted default रूप से selected होता है और Sync my devices purpose सेट होता है। Extension आपके passphrase के तौर पर छह random words suggest करता है। आप Another suggestion press कर सकते हैं जब तक कि मनपसंद combination न मिल जाए, या अपना खुद का passphrase चुन सकते हैं (कम से कम 12 characters, weak होने पर hint मिलेगा)।

Connect करने के बाद, आपको वे छह words एक बार दिखाई देंगे। उन्हें password manager में save कर लें; Copy button उन्हें dashes से जोड़कर clipboard पर copy कर देता है, जिससे config files और chat apps में format खराब नहीं होता। इनके ज़रिए आप किसी भी device पर place open कर सकते हैं; इनके बिना कोई भी files नहीं पढ़ सकता, हम भी नहीं। जिस computer पर आपने setup किया है, वहाँ आप place की settings में इन्हें फिर से देख सकते हैं, Show passphrase। अगर आपने इसके बजाय अपना खुद का passphrase चुना था, तो वह कहीं भी store नहीं होता, इसलिए extension उसे दोबारा नहीं दिखा सकता।

Storage provider को क्या दिखता है: scrambled names वाली scrambled files, उनकी कुल संख्या, उनका size, और वे कब modify हुईं। उसे titles, links या text दिखाई नहीं देते। Device से बाहर निकलने से पहले आपकी library browser में ही AES-256-GCM के साथ encrypt हो जाती है।

Step 3: अपना दूसरा computer add करें

  1. Extension install करें और खोलें Settings → Sync & backup → Add a placeपर।
  2. वही server details enter करें (या वही folder चुनें)।
  3. Extension detect कर लेगा कि folder में पहले से encrypted library मौजूद है और आपसे passphrase मांगेगा। Words को किसी भी capitalization में, spaces या dashes के साथ type करने पर काम हो जाएगा।
  4. यह आपसे confirm करने को कहेगा कि आपने पहले इस device का backup ले लिया है, क्योंकि join करने पर इस computer की library folder वाली library के साथ merge हो जाती है, और जहाँ दोनों में अंतर होगा वहाँ folder वाला data प्राथमिकता पाएगा। इस्तेमाल करें Make a backup nowपर।
  5. Press करें Connect। बड़ी library के लिए पहला sync थोड़ा समय ले सकता है; screen पर progress दिखेगी।

Backup only, restore, और publishing

  • Backup only. चुनें Backup only बजाय Sync my devices और computer केवल उस place पर data write करेगा, वहाँ से कभी read नहीं करेगा। ज़रूरत पड़ने पर place की settings से Restore करें: यह सब कुछ वापस ले आता है, और जहाँ इस computer का data अलग होगा वहाँ place वाला data रखा जाएगा। कुछ भी delete नहीं होगा।
  • Publish to your website. एक अलग तरह का place, Readable, आपकी website के लिए plain files write करता है, सिर्फ उन्हीं articles के लिए जिन्हें आप tag करते हैं, optional viewer page के साथ। Notes और full texts तब तक शामिल नहीं होते जब तक आप उन्हें enable न करें, क्योंकि जो भी उस folder को open कर सकता है वह इसे पढ़ सकता है। Private data के लिए readable place का use न करें।

Troubleshooting: अगर कुछ गड़बड़ हो जाए

"Allow access to the folder again"

Browser restart होने के बाद folder access revoke कर लेता है। इसके top पर दिया button press करें: Sync & backup। अगर यह बार-बार fail हो रहा है, तो folder शायद Chrome द्वारा protected folders में से एक हो सकता है (Desktop, Documents, Downloads या आपका home folder): अपना बनाया हुआ subfolder चुनें।

"The server did not accept the username and password"

Nextcloud के लिए app password use करें। Check करें कि address आपके username folder पर खत्म हो रहा हो और two-factor authentication app password को block न कर रहा हो।

"Wrong passphrase"

Words check करें: capitalization, spaces और dashes से कोई फर्क नहीं पड़ता, लेकिन हर word सही होना चाहिए। जो computer पहले से set up है, उस पर place की settings खोलें और press करें Show passphrase। अगर आपने इसे हर जगह से खो दिया है, तो files को कोई भी open नहीं कर पाएगा: यहाँ से place remove करें, नया बनाएं और अपने computer की library से दोबारा शुरू करें।

एक साथ बहुत सारे deletions wait कर रहे हैं

अगर कोई दूसरा device एक साथ कई articles delete कर देता है, तो extension कुछ articles apply करता है और बाकी के लिए पहले confirm करता है, ताकि एक गलती से पूरी library खाली न हो जाए। Check करें, फिर उन्हें apply करने के लिए button press करें।

Computer कई महीनों तक offline था

लगभग तीन महीने के बाद, computer सिर्फ वही भेजता है जो तब से बदला है और खुद से कुछ भी delete नहीं करता, ताकि कहीं और delete किए गए पुराने articles गलती से वापस न आएं।

अक्सर पूछे जाने वाले सवाल

क्या मुझे आपके साथ account बनाने की ज़रूरत है?

नहीं। Sync सीधे आपके browser से आपके द्वारा दिए गए storage के साथ बात करता है। हम कोई sync server run नहीं करते।

क्या यह मेरे phone पर काम करता है?

Android पर, हाँ। Companion app ( GitHub releasesसे APK; यह अभी Google Play पर नहीं है) आपकी library को join कर सकती है, यहाँ से: Settings → Library sync। सबसे तेज़ तरीका code है: browser में अपने place की settings खोलें, press करें Show code for the phone और इसे scan करें। इसमें आपका server login होता है, इसलिए इसे केवल अपने phone पर ही scan करें। Phone आपके saved articles को उनकी summaries और highlights के साथ दिखाता है, और notes दोनों तरफ sync होते हैं। Phone पर summarize किए गए pages और mark किए गए passages भी आपकी library में चले जाते हैं, लेकिन सिर्फ वही pages जो पहले से मौजूद नहीं हैं: browser का text कभी replace नहीं होता। अभी iPhone app available नहीं है।

क्या मैं एक से ज़्यादा places use कर सकता हूँ?

हाँ। एक standard setup यह होता है कि computers के बीच sync के लिए एक encrypted place और किसी दूसरे provider पर एक backup-only place रखा जाए।

क्या अपनी library को cloud पर रखना safe है?

ज़्यादातर setups से ज़्यादा safe, क्योंकि provider के पास केवल encrypted files रहती हैं। फिर भी, यह उतना ही सुरक्षित है जितना आपका passphrase और आपका device। पढ़ें the honest limits, जिसमें यह भी शामिल है कि encryption का कोई independent audit नहीं हुआ है।

AI Summary Helper एक free, open-source browser extension है। Sync तब तक off रहता है जब तक आप कोई place add नहीं करते।
