Claude, LM Studio और अन्य AI apps में अपनी library इस्तेमाल करें

आपका AI app वह सब कुछ भूल जाता है जो आपने पढ़ा है। AI Summary Helper उसे याद रखता है। दोनों को अपने कंप्यूटर पर कनेक्ट करें, और आपका app आपके saved articles सर्च कर सकता है, आपके highlights कोट कर सकता है और आपके sources cite कर सकता है।

AI Summary Helper आपकी library को उन AI apps के साथ शेयर कर सकता है जो Model Context Protocol (MCP) सपोर्ट करते हैं: Claude Desktop, LM Studio, Cursor, VS Code, Jan, और local agents। आपका app सवाल पूछता है, AI Summary Helper उसे आपके saved articles में ढूंढता है, और जवाब सीधे आपकी मशीन पर app के पास वापस आ जाता है।

यह डिफ़ॉल्ट रूप से बंद रहता है। इसमें हमारे सर्वर का कोई रोल नहीं है: extension और app आपके कंप्यूटर पर मौजूद एक छोटे helper program के ज़रिए एक-दूसरे से बात करते हैं, aish-mcp, जो कोई article स्टोर नहीं करता और कहीं भी कुछ फ़ॉरवर्ड नहीं करता।

आप क्या पूछ सकते हैं

  • इंटरनेट से नहीं, अपनी रीडिंग से पूछें। “मैंने AI और surveillance के बारे में क्या सेव किया है? इसे थीम के हिसाब से ग्रुप करें और बताएं कि आर्टिकल्स में कहां असहमति है।”
  • अपने खुद के sources से लिखें। “AI की CO₂ कॉस्ट पर एक पोस्ट ड्राफ्ट करें, और मेरे highlights कोट करें।”
  • किसी collection के सवाल का जवाब पाएं। “inflation पर मेरी collection का इस्तेमाल करें। सिर्फ़ उन्हीं sources का इस्तेमाल करके इसके सवाल का जवाब दें, और बताएं कि क्या मिसिंग है।”
  • Saved-for-later को कैच अप करें। “मेरी saved-for-later लिस्ट में से इस हफ़्ते क्या due है? हर एक का पांच मिनट का वर्शन दें।”
  • अपनी feeds को triage करें। “AI के बारे में आज के unread feed आइटम्स को चेक करें और मुझे बताएं कि कौन से तीन पढ़ने लायक हैं।”
  • अपना साल देखें। “2026 के लिए मेरा reading year in review बनाएं: टॉप टॉपिक्स, सबसे बिज़ी महीना और वे आर्टिकल्स जिन्होंने इसे डिफाइन किया।”
  • एजेंट को अपने लिए सेव करने दें। “Local-first software पर तीन अच्छे sources खोजें और उन्हें एक नोट के साथ मेरे AISH inbox में सेव करें।”

LM Studio में local model के साथ, यह सब कुछ नेटवर्क बंद होने पर (offline) भी काम करता है।

सेटअप कैसे करें

आपको Chrome, Edge या Brave में AI Summary Helper की ज़रूरत होगी, Node.js 20 या नया वर्शन, और एक MCP app।

  1. इसे चालू करें। AI Summary Helper में, Settings → AI apps (MCP) खोलें और इसे ऑन करें Let AI apps on this computer use my libraryपर।
  2. अपना pairing code प्राप्त करें। टर्मिनल में रन करें npx -y aish-mcp pair। यह एक pairing code प्रिंट करता है और इसे आपके user folder में स्टोर करता है। कोड को settings panel में पेस्ट करें और Connect चुनें।
  3. अपने app में AI Summary Helper जोड़ें। नीचे अपने app के लिए snippet का इस्तेमाल करें, फिर app को पूरी तरह से quit करें और दोबारा खोलें।
  4. कनेक्शन चेक करें। जब आपका app रन हो रहा होगा, तो settings panel दिखाएगा Connected । अपने app से अपनी library के बारे में कुछ पूछें: इसके द्वारा की जाने वाली हर कॉल panel में Recent activity के तहत दिखाई देती है।

Claude Desktop

Settings → Developer → Edit Config, फिर जोड़ें:

{
  "mcpServers": {
    "aish": { "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

अगर Claude Desktop को नहीं मिलता npx, तो इसके full path का इस्तेमाल करें, जिसे which npx टर्मिनल में प्रिंट करता है (उदाहरण के लिए /opt/homebrew/bin/npx)।

Cursor

में ~/.cursor/mcp.json (सभी प्रोजेक्ट्स) या .cursor/mcp.json (एक प्रोजेक्ट), वही "aish" एंट्री जोड़ें जैसा Claude Desktop के लिए था।

VS Code

में .vscode/mcp.json:

{
  "servers": {
    "aish": { "type": "stdio", "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

LM Studio और अन्य apps

जिन apps में mcpServers सेटिंग होती है (LM Studio का mcp.json, Jan, और बाकी ज़्यादातर) उनमें Claude Desktop जैसी ही एंट्री होती है। केवल HTTP पर कनेक्ट होने वाले apps इस्तेमाल कर सकते हैं npx -y aish-mcp --http पर http://127.0.0.1:47616/, हेडर के साथ Authorization: Bearer <your pairing code>। Local model के लिए, ऐसा मॉडल चुनें जो tool calling सपोर्ट करता हो, जैसे Qwen 3 या Llama 3.1 और नए।

Privacy और सुरक्षा

  • हमारे सर्वर से कुछ भी नहीं गुज़रता। डेटा आपके ब्राउज़र से helper program में जाता है और फिर आपके कंप्यूटर पर मौजूद app में जाता है। इसके बाद app अपने मॉडल को क्या भेजता है यह आपके द्वारा चुने गए app और मॉडल पर निर्भर करता है। Local model सब कुछ आपकी मशीन पर ही रखता है।
  • जिन आर्टिकल्स को आप टैग करते हैं private कभी नहीं दिखते, किसी भी रिजल्ट, काउंट या collection में नहीं दिखते। आप settings panel में दूसरा टैग चुन सकते हैं।
  • केवल आपका कंप्यूटर ही कनेक्ट हो सकता है। Helper सिर्फ़ 127.0.0.1 पर सुनता है, इसलिए आपके नेटवर्क पर कोई अन्य डिवाइस इस तक नहीं पहुँच सकता। आपके द्वारा विज़िट की जाने वाली वेबसाइटें भी इसका उपयोग नहीं कर सकतीं: यह केवल AI Summary Helper के अपने extension address को स्वीकार करता है, और प्रत्येक कनेक्शन में आपका pairing code होना ज़रूरी है।
  • आप हर कॉल देख सकते हैं। Settings panel टूल के नाम और समय के साथ अंतिम 50 कॉल्स की लिस्ट दिखाता है, कॉन्टेंट कभी नहीं।
  • आप इसे कभी भी डिस्कनेक्ट कर सकते हैं। फ़ीचर को स्विच ऑफ करें या Disconnect चुनें। पुराने pairing code को काम करने से रोकने के लिए रन करें npx -y aish-mcp reset ।
  • सेव किए गए पेज वेब से लिया गया टेक्स्ट हैं। आपके app को निर्देश दिया जाता है कि वह इन्हें जानकारी के रूप में ले, निर्देशों के रूप में नहीं, लेकिन फिर भी सेव किया गया कोई पेज AI को गुमराह करने की कोशिश कर सकता है। जब तक ज़रूरत न हो, Save links की परमिशन बंद रखें।

अगर कुछ काम न करे

क्या दिख रहा हैक्या करें
Panel कहता है Not connectedआपका AI app रन नहीं हो रहा है, या अभी तक सेटअप नहीं हुआ है। इसे खोलें, या कनेक्शन टेस्ट करने के लिए टर्मिनल में रन करें npx -y aish-mcp ।
आपका app AI Summary Helper के कोई टूल्स नहीं दिखाता, या अपडेट के बाद नए टूल्स मिस करता हैApp को पूरी तरह से quit करें और दोबारा खोलें। कुछ apps केवल स्टार्ट होते समय ही टूल लिस्ट पढ़ते हैं।
“AISH is not running”आपका ब्राउज़र बंद है, या फ़ीचर ऑफ़ है। ब्राउज़र खोलें और settings panel चेक करें।
“Scope … is not enabled”आपके app ने कुछ ऐसा मांगा जिसकी आपने अनुमति नहीं दी है। अगर आप चाहें तो settings panel में इसे ऑन करें।
कोड पेस्ट करने के बाद भी panel कभी कनेक्ट नहीं होतारन करें npx -y aish-mcp pair और जो कोड प्रिंट हो उसे फिर से पेस्ट करें। यह इसके बाद बदल जाता है resetपर।

एक साथ कई AI apps रन करना बिल्कुल ठीक है: वे एक ही कनेक्शन शेयर करते हैं।
