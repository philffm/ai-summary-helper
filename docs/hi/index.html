वो सब कुछ, जो एक reading list को शुरू से ही करना चाहिए था। Model, server और आपकी machine से कोई data बाहर जाएगा या नहीं — यह सब आप खुद तय करते हैं। दिक्कत कभी save करने में नहीं थी। असली समस्या थी save किए गए content पर वापस लौटना — और इसे ठीक इसी बात को ध्यान में रखकर बनाया गया है। हर save किया गया आइटम searchable, connected और exportable बन जाता है — एक असली archive, न कि आर्टिकल्स का बढ़ता हुआ ढेर। जो आपके काम का है उसे follow करें, अच्छी खबरें पहले देखें और पूरे दिन की summary पाएं। पढ़ें, सुनें या अपने Kindle पर भेजें — जब भी आपके पास थोड़ा खाली समय हो।

एक built-in RSS reader

Blogs और news sites को follow करें, source, tag, date या mood के हिसाब से filter करें, अपना OPML import करें, और बस एक click में किसी भी item को open या summarize करें। सीधे extension में ही podcast feeds play करें, और headlines से हर दिन का एक optional AI recap पाएं। Favorites आपके archive में save होते हैं, और feeds आपके device पर ही store रहती हैं।

YouTube videos, उनके captions से

कोई भी video open करें और summarize करें। यह extension captions को read करके आपकी भाषा में key points तैयार करता है, और follow-up answers में exact passage cite करता है।

PDFs, किसी भी आम page की तरह

Browser में PDF open करें या disk से attach करें, और किसी भी page की तरह summarize करें। “What I used” दिखाता है कि model ने क्या read किया: words, tokens और model।

20+ भाषाएं, क्रॉस-प्लेटफ़ॉर्म

अपनी पसंद की भाषा में पढ़ें और summarize करें। Extension, native side panel, या bookmarklet — हर उस जगह के लिए जहां browser extension नहीं पहुंच सकता।

AI summaries, आपकी पसंद का model

OpenAI, Gemini, Mistral, DeepSeek, या कोई custom endpoint — या इसे local Ollama model पर point करें और बिना किसी network usage या recurring cost के पूरी तरह offline चलाएं।

Ghost highlights, सीधे पेज पर

AI हल्के से highlight करता है सबसे महत्वपूर्ण verbatim passages को आर्टिकल में — ताकि आप key insights को एक नज़र में skim कर सकें, और ये summary के साथ Kindle, LocalSend, या Markdown पर भी चले जाते हैं।

Research mode: DOI से पहचाने जाने वाले papers

Scientific papers को उनके DOI और citation metadata से पहचानकर trial, review या preprint के रूप में flag किया जाता है। Design, sample और limitations अलग से extract होते हैं, और citation सीधे DOI registry से बनती है, AI द्वारा नहीं।

एक ही सवाल पर multiple sources compare करें

Saved articles को collection में bundle करें, हर source का type चुनें (peer-reviewed, preprint, news, opinion), lateral-reading check run करें, और AI को summaries compare करने दें: वे कहाँ agree करते हैं, कहाँ disagree, और क्या miss हुआ है।

Instant read: AI लिखते-लिखते सुनाता भी जाए

Summary तैयार होने के दौरान ही audio में सुनाई देती है: पहले title, फिर sentence by sentence — pause, mute और speed controls के साथ। इसे किसी भी card से दोबारा सुनें।

Real search, सीधे on-device

Titles, tags और article content में full-text search — आपके ब्राउज़र में बने TF-IDF index द्वारा संचालित। कोई सर्वर round-trip नहीं, कोई lag नहीं, और कोई डेटा बाहर नहीं जाता।

सिर्फ एक लिस्ट नहीं, एक Knowledge Graph

देखें कि आपके सेव किए गए आर्टिकल्स कैसे जुड़े हैं — shared tags से, और टॉपिक सिमिलरिटी से भी भले ही उनमें कोई कॉमन टैग न हो।

सोच-समझकर Save for later करें

किसी सेव किए गए आर्टिकल को कारण और समय-सीमा के साथ "decision" मार्क करें और रिमाइंडर पाएं — न कि उसे ऐसी फाइलों के ढेर में खो जाने दें जिसे आप कभी नहीं खोलेंगे।

एक Digest जो खुद आर्टिकल्स चुनता है

एक टैप में आपके सेव किए गए आर्टिकल्स का एक छोटा, विविध सेट तैयार — एक ही कहानी के पांच वर्ज़न नहीं — Kindle या LocalSend के लिए एक ही फ़ाइल में बंडल।

Mood filter और समय के साथ mood trends

AI headlines को heavy से good के बीच rate करता है। Single tap में केवल good news देखें, और day, week व month के अनुसार अपनी reading के mood को track करें।

आपकी library, Claude, LM Studio और Cursor के अंदर

Settings में AI apps चालू करें, और आपके कंप्यूटर पर Claude Desktop, LM Studio, Cursor और अन्य MCP apps आपकी library search कर सकते हैं, आपके highlights quote कर सकते हैं और क्या due है यह बता सकते हैं। अगर आप allow करें, तो वे आपके लिए links भी save कर सकते हैं। हमारे server से कुछ भी नहीं जाता, और वे क्या read कर सकते हैं यह पूरी तरह आप तय करते हैं।

आपकी library आपके खुद के storage पर, पूरी तरह encrypted

अपनी library को अपने खुद के Nextcloud, WebDAV server, S3 bucket या कंप्यूटर के किसी folder में sync और back up करें। सब कुछ पहले आपके browser में ही encrypt होता है, इसलिए server को सिर्फ scrambled files दिखती हैं। आप search, tag graph और 3D map के साथ अपनी website पर list भी publish कर सकते हैं। जब तक आप कोई location add नहीं करते यह off रहता है; हम कोई sync server नहीं चलाते और आपका data कभी नहीं देखते। इसे set up कैसे करें · यह क्यों ज़रूरी है

किसी भी page पर Notes और comments

Text select करें और choose करें: उसे highlight करें, comment करें या quote के साथ note save करें। सब कुछ Notes tab में आ जाता है — list या sticky notes के grid के रूप में, article या tag के हिसाब से, और आपकी बाकी library के साथ sync होता रहता है।

Obsidian, Markdown, Word और PDF में export करें

Summary को सीधे अपने Obsidian vault में भेजें, या title, source, tags और अपने highlights को एक ही note में Markdown, Word (DOCX), OpenDocument या PDF के रूप में export करें।

आपकी reading की एक analytics report

Reading streak, summaries से time saved, activity, हफ़्तों भर के topics और एक word cloud — सीधे आपकी अपनी library से compute किया गया।

Read-later का ढेर

आप जितना पढ़ पाएंगे, उससे कहीं ज़्यादा सेव कर लेते हैं

हम जो कुछ भी save करते हैं, उसमें से ज़्यादातर चीज़ें शायद ही दोबारा कभी खुलती हैं। Digest आपके लिए पाँच saves चुनता है और उन्हें offline पढ़ने के लिए भेजता है।

1. Digest पर टैप करें

आपके पाँच saved items, जो recency और variety के आधार पर चुने गए हैं।

2. चाहें तो अपना मूड सेट करें

Upbeat, neutral या deep: चुनाव आपके mood के हिसाब से होता है।

3. इसे Offline भेजें

आपकी Kindle या network device पर एक single bundle, flight या commute के दौरान पढ़ने के लिए तैयार।

नहीं। बस install करें, अपनी AI provider key लगाएं (या local Ollama model इस्तेमाल करें), और save करना शुरू करें। Account की ज़रूरत केवल तब होती है जब आप byphil Cloud (बिना key के कई AI models) या ज़्यादा Kindle/LocalSend सेंड्स चाहते हों, जो donation से अनलॉक होते हैं।

मेरे ब्राउज़र से वास्तव में क्या डेटा बाहर जाता है?

सिर्फ summarization request — जो आपके configured AI provider को भेजी जाती है — इसके अलावा, अगर आप RSS reader use करते हैं, तो आपके subscribed feeds की requests, और सिर्फ तब जब आप AI recap पर click करते हैं, उस दिन की headlines और short snippets। Search, duplicate detection, tag cleanup, reading-level और sentiment scoring, और "similar articles" recommendations सब कुछ आपके अपने saved archive पर पूरी तरह locally run होते हैं।

क्या मैं इसे बिना किसी Cloud निर्भरता के (पूरी तरह offline) चला सकता हूँ?

हाँ — इसे local Ollama model से कनेक्ट करें और summarization भी आपके अपने कंप्यूटर पर ही रहेगा। बाकी सब कुछ तो पहले से ही on-device चलता है।

अगर मैं project को सपोर्ट करना बंद कर दूँ तो मेरे saves का क्या होगा?

आपका आर्काइव ठीक वहीं रहता है जहाँ वह हमेशा से था — आपके डिवाइस के ब्राउज़र लोकल स्टोरेज में। Support Pass केवल क्लाउड-आधारित एक्स्ट्रा फीचर्स (byphil Cloud AI एक्सेस, अनलिमिटेड Kindle/LocalSend सेंड्स) को कंट्रोल करता है, आपके पहले से सेव किए गए डेटा को कभी लॉक नहीं करता।

Android companion कैसे install करें?

ऊपर दिए गए लिंक (या latest release) से APK डाउनलोड करें, इसे open करें और Android द्वारा पूछे जाने पर browser से installs allow करें। फिर extension में Settings → Phone inbox में जाकर QR code scan करके pair करें। यह अभी Google Play पर उपलब्ध नहीं है।

क्या यह ओपन सोर्स है?

हाँ — इस एक्सटेंशन का सोर्स कोड उपलब्ध है GitHub, AGPL-3.0 license के तहत। यह personal, educational और non-profit use के लिए free है; जो companies इसे AGPL की terms के बाहर use करना चाहती हैं, वे commercial license ले सकती हैं।
