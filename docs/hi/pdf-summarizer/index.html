वो सब कुछ, जो एक reading list को शुरू से ही करना चाहिए था।

वो सब कुछ, जो एक reading list को शुरू से ही करना चाहिए था। Model, server और आपकी machine से कोई data बाहर जाएगा या नहीं — यह सब आप खुद तय करते हैं। दिक्कत कभी save करने में नहीं थी। असली समस्या थी save किए गए content पर वापस लौटना — और इसे ठीक इसी बात को ध्यान में रखकर बनाया गया है। हर save किया गया आइटम searchable, connected और exportable बन जाता है — एक असली archive, न कि आर्टिकल्स का बढ़ता हुआ ढेर। जो आपके काम का है उसे follow करें, अच्छी खबरें पहले देखें और पूरे दिन की summary पाएं। पढ़ें, सुनें या अपने Kindle पर भेजें — जब भी आपके पास थोड़ा खाली समय हो।

PDFs, किसी भी आम page की तरह

Browser के PDF या disk की files को किसी भी page की तरह summarize करें। “What I used” दिखाता है कि AI ने कितने words और tokens किस model से पढ़े।

20+ भाषाएं, क्रॉस-प्लेटफ़ॉर्म

20+ भाषाओं में पढ़ें और summarize करें: extension, native side panel या bookmarklet जब extension किसी page तक न पहुँच सके।

AI summaries, आपकी पसंद का model

OpenAI, Gemini, Mistral, DeepSeek, custom endpoint या local Ollama चुनें, ताकि summaries को कभी आपका डिवाइस छोड़ना ही न पड़े।

Ghost highlights, सीधे पेज पर

AI highlight करता है ज़रूरी हिस्से शब्दशः ताकि आप मुख्य insights पर नज़र डाल सकें और उन्हें summary के साथ Kindle, LocalSend या Markdown में export कर सकें।

Research mode: DOI से पहचाने जाने वाले papers

DOI और citation metadata से research papers पहचानें, trial, review या preprint status flag करें, और design, sample, limitations व DOI registry citations निकालें।

एक ही सवाल पर multiple sources compare करें

आर्टिकल bundle करें, sources को peer-reviewed, preprint, news या opinion label करें, lateral-reading check करें, और देखें कि summaries कहाँ सहमत हैं, कहाँ अलग हैं या context छोड़ती हैं।

सिर्फ एक लिस्ट नहीं, एक Knowledge Graph

देखें कि सेव किए आर्टिकल shared tags और topic similarity से कैसे जुड़ते हैं, चाहे कोई tag common न हो।

आपकी library, Claude, LM Studio और Cursor के अंदर

Claude Desktop, LM Studio, Cursor और दूसरे MCP apps आपकी library search कर सकते हैं, highlights quote कर सकते हैं और due items दिखा सकते हैं। Access आपके हाथ में है; कुछ भी हमारे server से नहीं गुज़रता।

आपकी library आपके खुद के storage पर, पूरी तरह encrypted

Encrypted library को अपने Nextcloud, WebDAV server, S3 bucket या local folder से sync करें। Tag graph और 3D map के साथ searchable list publish करें; हम कोई sync server नहीं चलाते। इसे set up कैसे करें · Sync setup आज़माएँ

किसी भी page पर Notes और comments

Text highlight करें, उस पर comment करें या quoted note सेव करें। Notes को article या tag के हिसाब से list या sticky-note grid में, अपनी library के साथ रखें।

Obsidian, Markdown, Word और PDF में export करें

Summaries को title, source, tags और highlights के साथ एक ही note में Obsidian, Markdown, Word (DOCX), OpenDocument या PDF में export करें।

Topic, provider, privacy, archive या platform से जवाब search करें।

क्या इसका उपयोग करने के लिए मुझे अकाउंट की आवश्यकता है?

नहीं। Install करें, अपनी AI provider key लाएँ या local Ollama model इस्तेमाल करें, और सेव करना शुरू करें। Account सिर्फ़ optional byphil Cloud access या अतिरिक्त Kindle/LocalSend sends के लिए चाहिए। Provider विकल्प देखें →

मेरे ब्राउज़र से वास्तव में क्या डेटा बाहर जाता है?

सिर्फ़ summary की request आपके चुने AI provider को जाती है। RSS के लिए आपकी subscribed feeds को requests भी जाती हैं; AI recap तभी headlines और छोटे snippets भेजता है जब आप माँगें। Search, duplicate detection, tags और recommendations local चलते हैं। On-device architecture देखें →

मेरा reading archive कहाँ रहता है?

Default रूप से आपके डिवाइस के browser में। आप इसे Markdown में export कर सकते हैं या encrypted backup अपने Nextcloud, WebDAV server, S3 bucket या local folder में रख सकते हैं। Sync guide पढ़ें →

Browser data clear करने पर क्या होगा?

Backup न होने पर browser का local data हटाने से local archive भी जा सकता है। Data clear करने या profile बदलने से पहले library export करें या अपने storage पर encrypted sync set करें। Backup और sync guide पढ़ें →

कौन से AI providers और models supported हैं?

आप OpenAI, Gemini, Mistral, DeepSeek, कोई compatible custom endpoint या local Ollama model इस्तेमाल कर सकते हैं। अपनी key लाएँ, या optional byphil Cloud access लें। जानें BYOK कैसे काम करता है →

क्या मैं PDF, YouTube वीडियो और RSS items summarize कर सकता हूँ?

हाँ। Browser में खुले या disk से attach किए PDF, captions के ज़रिए YouTube वीडियो और built-in RSS reader के आर्टिकल summarize करें। Workflow वीडियो देखें → Feed digests के बारे में पढ़ें →

AI summaries कितनी भरोसेमंद हैं?

AI का output गलत हो सकता है और source जाँचने की जगह नहीं लेता। Follow-up जवाब वह हिस्सा दिखाते हैं जिस पर वे टिके हैं, ताकि आप summary को original page से मिला सकें। 10-second source check सीखें →

कौन से browsers और platforms supported हैं?

Browser extension, native side panel या bookmarklet इस्तेमाल करें। Android companion app आपके phone से links जोड़ता है; iOS अभी उपलब्ध नहीं है। Browser और capture workflow देखें →

क्या यह ओपन सोर्स है?

हाँ — इस एक्सटेंशन का सोर्स कोड उपलब्ध है GitHub, AGPL-3.0 license के तहत। यह personal, educational और non-profit use के लिए free है; जो companies इसे AGPL की terms के बाहर use करना चाहती हैं, वे commercial license ले सकती हैं। Local architecture के बारे में पढ़ें →
