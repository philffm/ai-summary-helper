AI Summary Helperは、内蔵RSSリーダーでお気に入りのサイトをフォローし、あらゆるWebページを要約付きで検索可能な記事として保存します。さらに、オンデバイスで作成されるダイジェストを通じてKindleや他のデバイスへ直接送信し、オフラインでもスムーズに読み返せるようサポートします。

主な機能

リーディングリストが本来備えるべきだったすべての機能

保存し、理解し、再検索し、実際に読み返す。アーカイブが外部サブスクリプションに人質に取られる心配はありません。

使用するモデルやサーバーの選択から、データを端末外へ送信するかどうかまで、すべてご自身で管理・設定いただけます。

AI要約、モデルは自由に選択可能

OpenAI、Gemini、Mistral、DeepSeek、カスタムエンドポイントに対応。ローカルのOllamaモデルを指定すれば、このステップでネットワーク通信を一切行わずに処理することも可能です。

ページ上に直接、さりげなくハイライト

AIが 最も重要な原文の抜粋 を記事内で自然にハイライトするため、 重要なポイントを一目で把握でき、要約と一緒に Kindle、LocalSend、Markdown にも引き継がれます。

オンデバイスでの本格的な全文検索

タイトル、タグ、本文を対象とした全文検索。ブラウザ内で構築されるTF-IDFインデックスにより駆動します。サーバーとの通信遅延はなく、外部へのデータ送信も一切発生しません。

意図を持った「後で読む」

理由や期限を設定して「アクション/判断」としてフラグを立てることで、リマインドを受け取ることができます。二度と開かれないリストの山に埋もれさせることはありません。

自動キュレーション型ダイジェスト

ワンクリックで保存記事から小規模かつ多様なセットを自動選定。同じ話題ばかりが重なるのを防ぎ、1つのファイルにまとめてKindleやLocalSendへ転送します。

単なるリストを超えたナレッジグラフ

共有タグによる関連性だけでなく、タグが付いていなくても内容の類似度に基づいて保存記事間のつながりを可視化します。

内蔵RSSリーダー

ブログやニュースサイトをフォローし、ソース、タグ、日付、ムード別に絞り込んだり、OPMLをインポートしてワンクリックで記事を開いたり要約したりできます。拡張機能内でポッドキャストを直接再生できるほか、日々のヘッドラインからAIダイジェストを受け取ることも可能です。お気に入りはアーカイブに保存され、フィードデータはお使いのデバイス内に安全に保存されます。

20以上の言語に対応、クロスプラットフォーム

お好みの言語で閲覧・要約。拡張機能、ネイティブサイドパネル、または ブックマークレット — 拡張機能が使えない環境でもご利用いただけます。

「84%」の課題

保存した記事のほとんどは、二度と読まれない

ブックマーク行動に関する調査では、保存された記事の大半が二度と開かれないことが一貫して示されています。これは利用者の規律の問題ではありません。保存を容易にする一方で、何を実際に読むべきかの選定を支援しないツールの構造的な課題です。

1. 「ダイジェスト」をクリック

保存記事から5本を選定。最新性とテーマの多様性を重視するため、同一ニュースの類似記事ばかりが並ぶことはありません。

2. 必要に応じてトーンを設定

ポジティブ、ニュートラル、あるいは深層的・専門的など、そのときの気分や読書目的に応じて選定傾向を調整できます。

3. オフライン端末へ送信

1つのパッケージにまとめ、Kindleや同一ネットワーク上の端末へ直接送信。フライト前、通勤時、電波の届かないオフライン環境での読書に備えられます。

新機能 · Android ベータ

スマホからリンクを共有、PCで要約をチェック

AISH Companion をインストールすると、スマートフォンの共有メニューに「AISH」が追加されます。リンクはエンドツーエンドで暗号化されてブラウザに届き、「History」に保存。ワンタップで要約できます。

1. 初回ペアリング

拡張機能の「Settings → Phone inbox」を開き、コンパニオンアプリでQRコードをスキャンします。アカウント登録は不要です。

2. お好きなアプリから共有

ブラウザ、ニュースレター、チャットなどで「共有 → AISH」をタップ。オフラインでも動作し、オンラインに復帰次第すぐに送信されます。

3. 「Summarize」をタップ

共有したリンクは「History → From phone」に表示されます。「Summarize」をタップすれば、設定したAIプロバイダーを使って拡張機能が自動で要約します。

インストール前の確認事項

利用にあたってアカウント登録は必要ですか？

いいえ、不要です。インストール後、お手持ちのAIプロバイダーのAPIキーを設定する（またはローカルのOllamaモデルを使用する）だけで、すぐに保存を開始できます。アカウントが必要となるのは、byphil Cloudへのアクセスや、Support PassによるKindle/LocalSendへの無制限送信機能を利用する場合のみです。

ブラウザから外部へ送信されるデータは何ですか？

外部へ送信されるのは、設定したAIプロバイダーへの要約リクエストのみです（RSSリーダー使用時の購読フィードへのリクエスト、およびAIダイジェストをクリックした際のその日のヘッドラインと短いスニペットを含みます）。検索、重複検出、タグの整理、読解レベルや感情分析のスコアリング、「関連記事」のレコメンドは、すべて保存されたアーカイブに対してローカル環境で実行されます。

クラウドに一切依存せずに運用することは可能ですか？

可能です。ローカルのOllamaモデルを指定すれば、要約処理も含めてすべて端末内で完結します。その他の機能はすでに完全にオンデバイスで動作しています。

Support Passの支払いを停止した場合、保存したデータはどうなりますか？

アーカイブはお使いの端末のブラウザローカルストレージ内にそのまま保持されます。Support Passはクラウド依存の追加機能（byphil Cloud AIアクセス、無制限のKindle/LocalSend送信）のみを制限するものであり、保存済みのデータへのアクセスが制限されることはありません。

Androidコンパニオンアプリのインストール方法は？

上記のリンク（または 最新リリース）からAPKをダウンロードして開き、Androidの確認画面でブラウザからのインストールを許可してください。その後、拡張機能の「Settings → Phone inbox」にあるQRコードをスキャンしてペアリングします。※現在Google Playでは未配信です。

オープンソースですか？

はい。拡張機能のソースコードは GitHubにて公開されています。
