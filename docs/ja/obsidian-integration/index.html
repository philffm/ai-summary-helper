実際の使い方

保存した記事を、もう一度活かす

アーカイブがただ溜まるだけではなく、価値を持つ4つの方法

主な機能

リーディングリストが本来備えるべきだったすべての機能

保存し、理解し、再検索し、実際に読み返す。アーカイブが外部サブスクリプションに人質に取られる心配はありません。

これこそが、リーディングリストが本来あるべきだった姿です。

これこそが、リーディングリストが本来あるべきだった姿です。 使用するモデルやサーバーの選択から、データを端末外へ送信するかどうかまで、すべてご自身で管理・設定いただけます。 課題は「保存する」ことではなく、「保存したものを振り返る」ことでした。本ツールはまさにその体験を中心に設計されています。 保存したデータは検索・関連付け・エクスポートが可能。ただ溜まる一方の山ではなく、真のアーカイブへと進化します。 関心のあるトピックをフォローし、価値あるニュースを優先的にチェック。1日の要点をスマートに把握できます。 読む、聴く、あるいはKindleへ送信。ちょっとしたスキマ時間にいつでもアクセスできます。

20以上の言語に対応、クロスプラットフォーム

拡張機能やネイティブのサイドパネル、または ブックマークレット 拡張機能がページにアクセスできない場合に使えるブックマークレットで、20以上の言語の読み取りと要約ができます。

オンデバイスでの本格的な全文検索

タイトル、タグ、記事本文をブラウザベースのTF-IDFインデックスで検索。全文検索はオンデバイスで完結し、外部への往復通信はありません。

単なるリストを超えたナレッジグラフ

保存した記事が、共通のタグやトピックの類似性を通じてどうつながっているかを確認できます。共通のタグが一つもない場合でも表示されます。

意図を持った「後で読む」

決定事項を理由と期限とともに保存すると、未読の山に埋もれる前にリマインドされます。

自動キュレーション型ダイジェスト

ワンタップで、同じ話題の5つの記事ではなく、変化に富んだダイジェストを編集し、KindleやLocalSend用にまとめます。

Claude、LM Studio、Cursor内でライブラリを活用

Claude Desktop、LM Studio、CursorなどのMCPアプリから、ライブラリを検索し、ハイライトを引用し、期限が来たものを一覧表示できます。アクセスはあなたが管理し、当社のサーバーを経由することはありません。

ご自身のストレージに、暗号化してライブラリを保管

暗号化されたライブラリを、ご自身のNextcloud、WebDAVサーバー、S3バケット、ローカルフォルダに同期できます。タググラフと3Dマップ付きの検索可能なリストを公開できます。当社は同期サーバーを運営していません。 設定方法 · 同期の設定を試す

あらゆるページにノートやコメントを追加

テキストをハイライトし、コメントを付け、引用ノートを保存できます。ノートは記事別またはタグ別に、リストまたは付箋グリッドでライブラリと並べて整理できます。

Obsidian、Markdown、Word、PDFへエクスポート

要約をObsidian、Markdown、Word（DOCX）、OpenDocument、PDFへエクスポート。タイトル、出典、タグ、ハイライトを1つのノートにまとめます。

読書状況を分析するアナリティクスレポート

読書の連続記録、要約で節約した時間、アクティビティ、週ごとのトピック、ご自身のライブラリから生成されたワードクラウドを確認できます。

よくある質問

インストール前の確認事項

トピック、プロバイダー、プライバシー、アーカイブ、プラットフォームから回答を検索できます。

利用にあたってアカウント登録は必要ですか？

いいえ。インストールし、ご自身のAIプロバイダーのキーを持ち込むか、ローカルのOllamaモデルを使えば、すぐに保存を始められます。アカウントが必要なのは、任意のbyphil Cloudアクセスや、追加のKindle/LocalSend送信を利用する場合だけです。 プロバイダーの選択肢を見る →

ブラウザから外部へ送信されるデータは何ですか？

AIプロバイダーに送信されるのは、要約リクエストのみです。RSSも購読フィードへのリクエストが必要です。AIまとめは、あなたが要求したときにのみ見出しと短い抜粋を送信します。検索、重複検出、タグ、レコメンドはローカルで実行されます。 オンデバイスアーキテクチャを見る →

読書アーカイブはどこに保存されますか？

デフォルトでは、お使いのデバイスのブラウザ内です。Markdownとしてエクスポートしたり、ご自身のNextcloud、WebDAVサーバー、S3バケット、ローカルフォルダに暗号化してバックアップできます。 同期ガイドを読む →

ブラウザのデータを消去するとどうなりますか？

バックアップがない場合、ローカルのブラウザデータを消去するとローカルアーカイブが失われる可能性があります。ブラウザデータの消去やプロファイルの変更の前に、ライブラリをエクスポートするか、ご自身のストレージへの暗号化同期を設定してください。 バックアップと同期のガイドを読む →

対応しているブラウザとプラットフォームは？

ブラウザ拡張機能、ネイティブのサイドパネル、ブックマークレットを使用できます。Androidコンパニオンアプリでスマートフォンからリンクを追加できます。iOSはまだ利用できません。 ブラウザとキャプチャのワークフローを見る →

プロジェクトへの支援を停止した場合、保存したデータはどうなりますか？

アーカイブはお使いの端末のブラウザローカルストレージ内にそのまま保持されます。Support Passはクラウド依存の追加機能（byphil Cloud AIアクセス、無制限のKindle/LocalSend送信）のみを制限するものであり、保存済みのデータへのアクセスが制限されることはありません。 Digestが保存した記事を再び役立つものにする方法を見る →

オープンソースですか？

はい。拡張機能のソースコードは GitHub、AGPL-3.0ライセンスの下で提供されています。個人利用、教育目的、非営利目的でのご利用は無料です。AGPLの条項外での利用をご希望の企業向けには、商用ライセンスをご用意しています。 ローカルアーキテクチャについて読む →
