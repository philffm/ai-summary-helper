キュレーション

情報源を選ぶ

発行元、アナリスト、研究グループ、そして本当に信頼できるフィードから、焦点を絞ったRSS購読リストを作りましょう。

理解

フィードをブリーフィングに変える

リンクやタイムスタンプ、元の文脈を失うことなく、最新記事のセットを要約します。

接続

アーカイブ全体に問いかける

対応するローカルAIツールでMCPを使い、最近の報道を比較したり、複数の情報源をまたいで問いを掘り下げたりできます。

内蔵RSSリーダー

ブログやニュースサイトをフォローし、ソース、タグ、日付、気分で絞り込み、OPMLをインポートして、どの記事もワンクリックで要約できます。拡張機能内でポッドキャストのフィードを再生し、任意でAIによるまとめも取得できます。フィードとお気に入りはデバイス上に保存されます。

YouTube動画も、字幕からすばやく要約

YouTube動画を字幕から要約し、要点をお使いの言語で取得。出典の引用付きで追加の質問もできます。

20以上の言語に対応、クロスプラットフォーム

拡張機能やネイティブのサイドパネル、または ブックマークレット 拡張機能がページにアクセスできない場合に使えるブックマークレットで、20以上の言語の読み取りと要約ができます。

インスタント読み上げ：生成しながら同時に音声再生

要約が書かれる様子を聞けます。まずタイトル、次に一文ずつ。一時停止、ミュート、速度調整も可能です。どのカードからでも再生できます。

ムードフィルターと感情の推移

見出しを「重い」から「良い」まで評価し、良いニュースだけを絞り込み、日別、週別、月別に記事のトーンを追跡できます。

読書状況を分析するアナリティクスレポート

読書の連続記録、要約で節約した時間、アクティビティ、週ごとのトピック、ご自身のライブラリから生成されたワードクラウドを確認できます。

よくある質問

インストール前の確認事項

トピック、プロバイダー、プライバシー、アーカイブ、プラットフォームから回答を検索できます。

利用にあたってアカウント登録は必要ですか？

いいえ。インストールし、ご自身のAIプロバイダーのキーを持ち込むか、ローカルのOllamaモデルを使えば、すぐに保存を始められます。アカウントが必要なのは、任意のbyphil Cloudアクセスや、追加のKindle/LocalSend送信を利用する場合だけです。 プロバイダーの選択肢を見る →

ブラウザから外部へ送信されるデータは何ですか？

AIプロバイダーに送信されるのは、要約リクエストのみです。RSSも購読フィードへのリクエストが必要です。AIまとめは、あなたが要求したときにのみ見出しと短い抜粋を送信します。検索、重複検出、タグ、レコメンドはローカルで実行されます。 オンデバイスアーキテクチャを見る →

対応しているAIプロバイダーとモデルは？

OpenAI、Gemini、Mistral、DeepSeek、互換性のあるカスタムエンドポイント、またはローカルのOllamaモデルを使用できます。ご自身のキーを持ち込むか、任意のbyphil Cloudアクセスを利用できます。 BYOKの仕組みを見る →

PDF、YouTube動画、RSSの項目も要約できますか？

はい。ブラウザで開いたPDFやディスクから添付したPDF、字幕を使ったYouTube動画、内蔵RSSリーダーの記事を要約できます。 ワークフロー動画を見る → フィードダイジェストについて読む →

AIの要約はどの程度信頼できますか？

AIの出力は誤ることがあり、出典の確認に代わるものではありません。追加の回答には、根拠とした箇所が表示されるので、要約と元のページを比較できます。 10秒でできる出典チェックを見る →

対応しているブラウザとプラットフォームは？

ブラウザ拡張機能、ネイティブのサイドパネル、ブックマークレットを使用できます。Androidコンパニオンアプリでスマートフォンからリンクを追加できます。iOSはまだ利用できません。 ブラウザとキャプチャのワークフローを見る →

オープンソースですか？

はい。拡張機能のソースコードは GitHub、AGPL-3.0ライセンスの下で提供されています。個人利用、教育目的、非営利目的でのご利用は無料です。AGPLの条項外での利用をご希望の企業向けには、商用ライセンスをご用意しています。 ローカルアーキテクチャについて読む →
