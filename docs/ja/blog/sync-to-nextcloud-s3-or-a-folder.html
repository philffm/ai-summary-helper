イラスト（AI生成）

使い方ガイド · 2026年10月

読書ライブラリをNextcloud、S3、またはローカルフォルダへ暗号化して同期する方法

保存した記事、要約、ハイライト、メモをすべてのPCで利用可能に。保管場所はご自身で指定でき、お持ちのキーでのみ復号できます。設定は約10分、当サービスのアカウント作成は不要です。

手短なまとめ。 AI Summary Helperで 設定 → 同期とバックアップ → 保存場所を追加を開き、Nextcloud/WebDAV、S3互換ストレージ、またはPC上のフォルダを選択して、提示されたパスフレーズを保持します。すべてのデータはアップロード前にブラウザ上で暗号化されます。2台目のPCでも同じ場所を追加し、パスフレーズを入力するだけで設定は完了です。以降では各ストレージタイプ、同期される対象、トラブルシューティングについて解説します。

なぜ同期するのか？ 読書ライブラリは手元に残す価値があり、依存しているツールはある日使えなくなる可能性があるからです（詳しくはこちら）。ご自身が所有するストレージに同期しておくことで、特定のアプリやアカウントの存続に左右されずにライブラリを保護できます。

同期されるもの・されないもの

  • 同期されるもの: 保存された記事（全文および要約を含む）、タグ、ハイライト、メモやコメント、コレクション。
  • 同期されないもの: APIキー、ログイン情報、同期自体のログイン資格情報、デバイスごとの個別設定。これらは意図的にバックアップおよび同期から除外されます。
  • 1ページにつき1記事: 同じページを2台のPCで保存した場合、1つの記事にまとめられます（タグや不足しているフィールドは統合されます）。
  • 項目ごとの編集内容のマージ: 片方のPCでタイトルを変更し、もう片方でタグを追加した場合、両方の変更が保持されます。同じ項目を両方で変更した場合は、すべてのデバイスにおいて後に変更された方が優先されます。

ステップ1: 保管場所を選択する

Nextcloud またはその他の WebDAV サーバー

すでにNextcloudを運用している場合や、ホスティングサービスを利用している場合に最適です。必要な情報は以下の3点です:

  1. ファイルの保存先アドレス。 Nextcloudの場合、形式は次のようになります: https://your-server/remote.php/dav/files/your-username/。Nextcloudで ファイル → ファイル設定 を開き、表示されているWebDAVアドレスをコピーします。
  2. ユーザー名。
  3. メインのパスワードではなくアプリパスワード。 Nextcloudの場合: 個人設定 → セキュリティ → デバイスとセッション → 新しいアプリパスワードを作成。アクセスを遮断したい場合は、そのエントリを削除するだけで済みます。

フォルダ名を指定します（例: aish-sync）。フォルダは自動で作成されます。その他のWebDAVサーバー（NASやownCloudなど）も同様の手順で利用できます（アドレス形式は異なります）。

S3互換バケット

オブジェクトストレージ（AWS S3、Cloudflare R2、Backblaze B2、MinIOなど）を利用したい場合に最適です。バケットを作成し、 対象バケット専用 の読み取り、書き込み、一覧表示、削除権限を持つアクセスキーを作成します。アカウントのメインキーは絶対に使用しないでください。拡張機能側で、エンドポイントアドレス（例: https://s3.eu-central-1.amazonaws.com、またはプロバイダが提示するアドレス）、バケット名、リージョン（指定不要なプロバイダの場合はデフォルトのまま）、アクセスキーID、シークレットキーを入力します。

パソコン上のローカルフォルダ

Syncthing、デスクトップ同期クライアント、iCloud Drive、USBメモリなど、既存のツールでデバイス間のフォルダ同期を行っている場合に最適です。 このコンピュータ上のフォルダ を選択し、 新規に作成した空のフォルダ（例: Documents/AISH-sync）を指定します。Chromeでは「デスクトップ」「書類」「ダウンロード」フォルダ自体を直接指定できないため、サブフォルダを作成して選択してください。これはPC版のChromeおよびEdgeで動作します。注意点として、ブラウザの再起動後にアクセスの再許可を求められる場合がある点（設定画面にボタンが表示されます）と、ブラウザの起動中のみ同期が行われる点があります。

ステップ2: 暗号化を選択し、パスフレーズを保存する

保存場所を追加する際、初期設定で 暗号化 が選択され、用途には デバイス間で同期 が設定されています。拡張機能がパスフレーズとして6つのランダムな単語を提示します。好みの組み合わせになるまで 別の候補を表示 をクリックするか、独自のもの（12文字以上、強度が不十分な場合はヒントが表示されます）を設定することも可能です。

接続後、6つの単語が一度だけ表示されます。パスワードマネージャーに保存してください。「コピー」ボタンを押すとハイフン繋ぎでクリップボードにコピーされるため、設定ファイルやチャットアプリでも安全に扱えます。このフレーズがあればどのデバイスからでも開くことができますが、紛失した場合は開発元を含め誰もファイルを復号・閲覧できません。セットアップを行ったPCであれば、保存先の設定メニューの パスフレーズを表示から再確認できます。ご自身で独自のパスフレーズを設定した場合はどこにも保持されないため、拡張機能側で再表示することはできません。

ストレージ側に表示される情報: 暗号化されたファイルと乱数化されたファイル名、ファイル数、サイズ、変更日時のみです。記事のタイトル、リンク、本文などは一切見えません。ライブラリはデバイスから送信される前に、ブラウザ内でAES-256-GCMにより暗号化されます。

ステップ3: 2台目のPCを追加する

  1. 2台目のPCに拡張機能をインストールし、 設定 → 同期とバックアップ → 保存場所を追加にて公開されています。
  2. を開きます。同じサーバー情報（または同じフォルダ）を入力・選択します。
  3. フォルダ内に既存の暗号化ライブラリが検出され、パスフレーズの入力が求められます。単語の大文字・小文字、スペースやハイフンの有無にかかわらず入力可能です。
  4. 参加処理を行うと現在のPCのライブラリとフォルダ内のデータが統合され、競合がある場合はフォルダ側のデータが優先されるため、事前にこのデバイスのバックアップを作成したか確認されます。 今すぐバックアップを作成にて公開されています。
  5. を活用してください。準備ができたら 接続をクリックします。ライブラリのサイズが大きい場合、初回の同期に少し時間がかかることがあります（画面に進捗が表示されます）。

バックアップ専用、復元、および公開

  • バックアップ専用モード。 選択 バックアップ専用 ではなく デバイス間で同期 を選択すると、そのPCは指定した場所への書き込みのみを行い、読み込みは行いません。必要に応じて設定画面から「復元」を実行できます。すべてが復元され、差異がある場合は保存先のデータが優先されます。データが勝手に削除されることはありません。
  • Webサイトに公開。 別のモードとして、 平文（Readable）を設定すると、タグ付けした記事のみをご自身のWebサイト用プレーンテキストとして書き出し、必要に応じて閲覧用ページを付与できます。フォルダを開ける人なら誰でも読めるようになるため、有効にしない限りメモや全文は書き出されません。プライベートな情報に読み取り可能なモードを使用しないでください。

トラブルシューティング

「フォルダへのアクセスを再許可してください」と表示される場合

ブラウザを再起動するとフォルダへのアクセス権がリセットされます。 同期とバックアップの上部にあるボタンを押してください。それでも失敗する場合は、Chromeで保護されているフォルダ（デスクトップ、書類、ダウンロード、ホームディレクトリなど）の可能性があります。ご自身で作成したサブフォルダを選択してください。

「ユーザー名またはパスワードがサーバーに拒否されました」と表示される場合

Nextcloudをご利用の場合はアプリパスワードを使用してください。また、アドレスがご自身のユーザー名フォルダで終わっているか、二要素認証がアプリパスワードをブロックしていないか確認してください。

「パスフレーズが違います」と表示される場合

単語を再確認してください。大文字・小文字、スペース、ハイフンは区別されませんが、すべての単語が正しい必要があります。すでに設定済みのPCがある場合は、保存先の設定を開き、 パスフレーズを表示を押して確認してください。すべての端末で紛失した場合、ファイルを復元することは不可能です。その場合は保存先を一度削除し、PC上のライブラリから新しく作り直してください。

大量の削除保留が表示される場合

別のデバイスで大量の記事が一括削除された場合、誤操作によるライブラリ消失を防ぐため、拡張機能は少数の削除を適用したのち残りの処理について確認を求めます。内容を確認した上で、適用ボタンを押してください。

数ヶ月間オフラインだったPCを起動した場合

約3ヶ月以上経過したPCは、それ以降に変更された差分のみを送信し、自動で削除を行うことはありません。これにより、他所で削除済みの古い記事が誤って復活するのを防ぎます。

よくある質問

アカウント作成は必要ですか？

いいえ、不要です。同期はブラウザから指定したストレージへ直接通信します。当サービス側で同期サーバーを運用・保持することはありません。

スマートフォンでも使えますか？

Androidに対応しています。コンパニオンアプリ（ GitHubのReleasesから入手可能なAPK版。Google Playでは未公開）を使用して、 設定 → ライブラリ同期からライブラリに参加できます。最も手軽な方法はQRコードです。ブラウザ上で保存先の設定を開き、 スマホ用のコードを表示 を押してスキャンしてください。サーバーのログイン情報が含まれているため、ご自身のスマートフォンのみに読み取らせるようにしてください。アプリ上では保存した記事、要約、ハイライトの確認が可能で、メモは双方向に同期されます。スマートフォン上で要約したページやマーキングもライブラリに追加されますが、まだライブラリに存在しないページのみが対象となり、ブラウザ側の本文が上書きされることはありません。なお、iPhoneアプリは現在開発されていません。

複数の保存場所を併用できますか？

はい、可能です。例えば、PC間の同期用に暗号化された保存先を1つ設定し、別のプロバイダにバックアップ専用の保存先をもう1つ用意する、といった運用が一般的です。

クラウドにライブラリを置くのは安全ですか？

プロバイダ側には暗号化されたファイルのみが保存されるため、一般的な構成よりも安全です。ただし、安全性はパスフレーズの強度とご自身のデバイスの管理状態に依存します。暗号化処理について第三者機関による独立したセキュリティ監査は受けていない点など、 セキュリティ上の制限事項もあわせてご確認ください。

AI Summary Helperは無料・オープンソースのブラウザ拡張機能です。保存先を追加するまで同期機能は無効になっています。
