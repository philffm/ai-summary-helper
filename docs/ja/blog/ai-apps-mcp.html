イラスト（AI生成）

ガイド · 2026年10月

ClaudeやLM StudioをはじめとするAIアプリでライブラリを活用できます

AIアプリは読んだ内容をすべて忘れてしまいますが、AI Summary Helperは記憶します。お使いのコンピューター上で両者を接続すれば、保存した記事の検索、ハイライトの引用、情報源の提示をAIアプリが行えるようになります。

AI Summary Helperは、Model Context Protocol（MCP）をサポートするAIアプリ（Claude Desktop、LM Studio、Cursor、VS Code、Jan、ローカルエージェントなど）とライブラリを共有できます。アプリが質問すると、AI Summary Helperが保存済み記事から検索し、その回答がお使いのマシン上のアプリに直接返されます。

この機能はデフォルトでオフになっています。サーバーとの通信は一切発生しません。拡張機能とアプリは、お使いのコンピューター上にある小さなヘルパープログラムを介して相互通信します。 aish-mcpこのプログラムは記事を保存せず、外部へデータを転送することもありません。

質問できる内容の例

  • ネットではなく、自分が読んだ記事に質問する。 「AIと監視について保存した記事を教えて。テーマ別にグループ分けして、記事間で意見が対立している点も挙げて。」
  • 自分自身の情報源をもとに執筆する。 「AIのCO₂排出コストに関する投稿の下書きを作成し、自分のハイライトを引用して。」
  • コレクションの問いに答える。 「インフレに関するコレクションを使って。それらの情報源のみを参照して問いに答え、不足している情報があれば教えて。」
  • 「後で読む」リストを効率よく消化する。 「『後で読む』リストの中で今週期限のものは？それぞれ5分で読めるダイジェストを作成して。」
  • フィードをトリアージする。 「AIに関する今日の未読フィードを確認して、読む価値のある3件を教えて。」
  • 1年間の読書を振り返る。 「2026年の読書年次レビューを作成して：上位トピック、最も活発だった月、そして今年を代表する記事を教えて。」
  • エージェントに保存を任せる。 「ローカルファーストなソフトウェアに関する良質な情報源を3つ見つけて、メモを添えてAISHの受信トレイに保存して。」

LM Studioのローカルモデルを使用すれば、ネットワークを完全に遮断した状態（オフライン）でもすべて動作します。

設定方法

Chrome、Edge、またはBraveにインストールされたAI Summary Helperと、 Node.js 20以降、そしてMCP対応アプリが必要です。

  1. オンに設定します。 AI Summary Helperで、設定 → AI apps (MCP) を開き、 このコンピューター上のAIアプリにライブラリの利用を許可するにて公開されています。
  2. ペアリングコードを取得する。 ターミナルで次のコマンドを実行します： npx -y aish-mcp pairペアリングコードが表示され、ユーザーフォルダーに保存されます。このコードを設定パネルに貼り付け、「接続」を選択します。
  3. お使いのアプリにAI Summary Helperを追加する。 お使いのアプリに対応する以下のスニペットを追加し、アプリを完全に終了してから再起動してください。
  4. 接続を確認する。 アプリの起動後、設定パネルに 接続済み と表示されます。ライブラリについてアプリに質問してみてください。アプリが行ったすべての呼び出しが、パネルの「最近のアクティビティ」に表示されます。

Claude Desktop

設定 → Developer → Edit Config を開き、以下を追加します：

{
  "mcpServers": {
    "aish": { "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

Claude Desktopが npxを見つけられない場合は、ターミナルで which npx を実行して表示されるフルパス（例： /opt/homebrew/bin/npx）を指定してください。

Cursor

以下のファイル（ ~/.cursor/mcp.json 、または単一プロジェクト向け： .cursor/mcp.json ）に、Claude Desktopと同様の "aish" エントリを追加します。

VS Code

以下のファイル（ .vscode/mcp.json）に追加します：

{
  "servers": {
    "aish": { "type": "stdio", "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

LM Studioおよびその他のアプリ

設定項目に mcpServers があるアプリ（LM Studioの mcp.json、Jan、その他多数）では、Claude Desktopと同じエントリを使用できます。HTTP経由でのみ接続可能なアプリの場合は、 npx -y aish-mcp --http （エンドポイント： http://127.0.0.1:47616/、ヘッダー： Authorization: Bearer <ペアリングコード>）を使用します。ローカルモデルを使用する場合は、Qwen 3やLlama 3.1以降など、ツール呼び出し（Tool Calling）をサポートするモデルを選択してください。

機能を有効化した直後は、 ライブラリ のみがオンになっています。「記事の全文」「フィード」「リンクを保存」が必要な場合は、設定パネルで有効にしてください。変更内容は再接続なしで次回の呼び出しから適用されます。なお、アプリ側からAI Summary Helper内のデータを編集・削除することはできません。

プライバシーとセキュリティ

  • 当社のサーバーを経由することは一切ありません。 データはブラウザからヘルパープログラムを経由し、お使いのコンピューター上のアプリへと送られます。アプリがモデルに何を送信するかは、選択したアプリとモデルに依存します。ローカルモデルを使用すれば、すべてがお使いのマシン内だけで完結します。
  • 以下のタグを付けた記事： private 完全に非公開タグを付けた記事は、検索結果、カウント、コレクションのいずれにも一切表示されません。除外タグは設定パネルで自由に変更できます。
  • お使いのコンピューターからのみ接続可能。 ヘルパーは127.0.0.1（ローカルホスト）でのみリッスンするため、ネットワーク上の他の端末からアクセスされることはありません。また、アクセスしたWebサイトから利用されることも防ぎます。AI Summary Helper専用の拡張機能アドレスのみを受け入れ、すべての接続にペアリングコードが要求されます。
  • すべての呼び出しを確認可能。 設定パネルには直近50件の呼び出し履歴が表示されます（ツール名と日時のみ。コンテンツ本文は記録されません）。
  • いつでも接続を遮断可能。 機能をオフにするか、「切断」を選択してください。次のコマンドを実行すると、 npx -y aish-mcp reset 古いペアリングコードを即座に無効化できます。
  • 保存されたページはWeb上のテキストです。 アプリにはそれらを指示（プロンプト）ではなく情報として扱うよう指示されていますが、保存されたページが悪意を持ってAIを誘導しようとする可能性はゼロではありません。「リンクを保存」権限は、実際に使用する場合を除いてオフにしておくことを推奨します。

問題が発生した場合

症状対処法
パネルの表示： 未接続AIアプリが実行されていないか、設定が完了していません。アプリを起動するか、ターミナルで npx -y aish-mcp を実行して接続をテストしてください。
アプリにAI Summary Helperのツールが表示されない、またはアップデート後の新機能が表示されないアプリを完全に終了し、再起動してください。一部のアプリは起動時にのみツール一覧を読み込みます。
「AISH is not running」と表示されるブラウザが閉じられているか、機能がオフになっています。ブラウザを開き、設定パネルを確認してください。
「Scope … is not enabled」と表示される許可されていない権限をアプリが要求しました。使用する場合は設定パネルで該当の権限をオンにしてください。
コードを貼り付けてもパネルが接続中にならない次のコマンドを実行し、 npx -y aish-mcp pair 表示されたコードを再度貼り付けてください。コードは次のコマンドの実行後に変更されます： resetにて公開されています。

複数のAIアプリを同時に実行しても問題ありません。1つの接続が共有されます。
