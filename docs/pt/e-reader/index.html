Dúvidas frequentes

Perguntas sobre arquivo e e-reader

Como envio um artigo da web para o meu Kindle pelo Chrome ou Firefox?

Instale o AI Summary Helper, adicione kindle@byphil.eu à lista de e-mails aprovados de documentos pessoais na sua conta Amazon uma vez, depois arquive um artigo e escolha Enviar para o Kindle. Os artigos chegam como EPUB, com ou sem imagens.

Isso custa alguma coisa?

A extensão é gratuita e de código aberto. Os três primeiros envios para o Kindle são gratuitos; envios ilimitados para o Kindle precisam do Support Pass. Enviar com o LocalSend é gratuito e nunca passa pelo nosso servidor.

Posso usá-lo com um Kobo ou outro e-reader?

Sim, em dispositivos que rodam KOReader (Kobo, reMarkable e Kindles com jailbreak): instale o plugin LocalSend do KOReader, inicie o receptor e envie pela extensão usando sua Wi-Fi. Leitores sem KOReader, como Tolino e PocketBook, ainda não têm suporte direto.

O que é o LocalSend?

O LocalSend é um app de código aberto que envia arquivos diretamente entre dispositivos na mesma rede. O arquivo vai do seu navegador para o dispositivo, sem nuvem no meio.

As imagens são mantidas quando arquivo um artigo?

Sim. As imagens são redimensionadas para uma largura máxima e comprimidas, para que o artigo continue legível e pequeno.

Meu arquivo sai do meu dispositivo?

O arquivo fica no seu navegador. O envio para o Kindle é a exceção: a Amazon só aceita documentos por e-mail de remetentes aprovados, então o artigo passa pelo nosso serviço nesse envio. LocalSend e AirDrop vão direto para o seu dispositivo.
