Иллюстрация, сгенерировано ИИ

Руководство · Октябрь 2026

Используйте свою библиотеку в Claude, LM Studio и других ИИ-приложениях

Ваше ИИ-приложение забывает всё, что вы читали. AI Summary Helper помнит всё. Свяжите их на своём компьютере, и приложение сможет искать по вашим сохранённым статьям, цитировать выделенные фрагменты и указывать ваши источники.

AI Summary Helper может предоставить доступ к вашей библиотеке ИИ-приложениям с поддержкой Model Context Protocol (MCP): Claude Desktop, LM Studio, Cursor, VS Code, Jan и локальным агентам. Приложение задаёт вопрос, AI Summary Helper ищет ответ в сохранённых статьях, и результат отправляется напрямую обратно в приложение на вашем устройстве.

По умолчанию функция отключена. Наш сервер никак в этом не участвует: расширение и приложение взаимодействуют напрямую через небольшую вспомогательную программу на вашем компьютере, aish-mcp, которая не сохраняет статьи и ничего никуда не передаёт.

Что можно спросить

  • Ищите по своим материалам, а не по всему интернету. «Что у меня сохранено об ИИ и слежке? Сгруппируй по темам и покажи, в чём статьи расходятся во мнениях».
  • Пишите тексты на основе собственных источников. «Составь черновик поста о выбросах CO₂ от ИИ и процитируй мои выделения текста».
  • Отвечайте на вопросы коллекций. «Используй мою коллекцию об инфляции. Ответь на её главный вопрос только по этим источникам и укажи, чего не хватает».
  • Разберите список «прочитать позже». «Что из списка “прочитать позже” запланировано на эту неделю? Сделай краткую выжимку по каждому материалу на 5 минут».
  • Сортируйте свои ленты. «Просмотри сегодняшние непрочитанные материалы из ленты об ИИ и выбери три самых интересных».
  • Взгляните на свои итоги года. «Подведи итоги моего чтения за 2026 год: главные темы, самый активный месяц и ключевые статьи».
  • Позвольте агенту сохранять материалы за вас. «Найди три хороших источника по local-first софту и сохрани их во входящие AISH с заметкой».

С локальной моделью в LM Studio всё это работает даже при отключённом интернете.

Настройка

Вам понадобятся AI Summary Helper в Chrome, Edge или Brave, Node.js версии 20 или новее и MCP-приложение.

  1. Включите функцию. В AI Summary Helper откройте Настройки → ИИ-приложения (MCP) и включите Разрешить ИИ-приложениям на этом компьютере доступ к библиотеке.
  2. Получите код сопряжения. В терминале выполните команду npx -y aish-mcp pair. Она выведет код сопряжения и сохранит его в вашей пользовательской папке. Вставьте код в панель настроек и нажмите «Подключить».
  3. Добавьте AI Summary Helper в своё приложение. Используйте фрагмент конфигурации для вашего приложения ниже, затем полностью закройте приложение и откройте его снова.
  4. Проверьте подключение. В панели настроек появится статус Подключено , как только ваше приложение запустится. Задайте приложению вопрос о вашей библиотеке: каждый вызов будет отображаться в панели в разделе «Недавняя активность».

Claude Desktop

Settings → Developer → Edit Config, затем добавьте:

{
  "mcpServers": {
    "aish": { "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

Если Claude Desktop не может найти npx, укажите полный путь, который можно узнать с помощью команды which npx в терминале (например, /opt/homebrew/bin/npx).

Cursor

В файле ~/.cursor/mcp.json (для всех проектов) или .cursor/mcp.json (для одного проекта) добавьте ту же запись "aish" , что и для Claude Desktop.

VS Code

В файле .vscode/mcp.json:

{
  "servers": {
    "aish": { "type": "stdio", "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

LM Studio и другие приложения

Приложения с настройкой mcpServers (в LM Studio это mcp.json, Jan и большинство других) используют ту же запись, что и Claude Desktop. Приложения, работающие только по HTTP, могут использовать npx -y aish-mcp --http по адресу http://127.0.0.1:47616/с заголовком Authorization: Bearer <ваш код сопряжения>. При выборе локальной модели используйте ту, которая поддерживает вызов инструментов (tool calling), например Qwen 3 или Llama 3.1 и новее.

При включении функции активно только разрешение Ваша библиотека . Включите «Полный текст статьи», «Ленты» и «Сохранение ссылок» в панели настроек, если они вам нужны; изменения применятся при следующем вызове без повторного подключения. Приложение не может изменять или удалять что-либо в AI Summary Helper.

Конфиденциальность и безопасность

  • Никакие данные не проходят через наш сервер. Данные передаются из браузера во вспомогательную программу, а оттуда — в приложение на вашем компьютере. То, что приложение затем отправляет в модель, зависит от выбранного вами приложения и модели. Локальная модель сохраняет абсолютно все данные на вашем устройстве.
  • Статьи с тегом private никогда не отображаются, ни в одном результате, подсчёте или коллекции. В панели настроек можно выбрать другой тег.
  • Подключиться может только ваш компьютер. Вспомогательная программа слушает подключения только на 127.0.0.1, поэтому никто другой в вашей сети не сможет получить к ней доступ. Сайты, которые вы посещаете, также не могут её использовать: принимаются запросы только от адреса самого расширения AI Summary Helper, и каждое подключение должно содержать ваш код сопряжения.
  • Вы видите каждый вызов. В панели настроек отображаются последние 50 вызовов с указанием инструмента и времени, без содержимого.
  • Доступ можно отозвать в любой момент. Выключите функцию или нажмите «Отключить». Выполните команду npx -y aish-mcp reset , чтобы старый код сопряжения перестал действовать.
  • Сохранённые страницы — это текст из интернета. Ваше приложение получает указание воспринимать их как информацию, а не как инструкции, однако сохранённая страница всё равно может попытаться ввести ИИ в заблуждение. Держите разрешение «Сохранение ссылок» выключенным, если вы им не пользуетесь.

Если что-то не работает

Вы видитеЧто делать
В панели указано Не подключеноВаше ИИ-приложение не запущено или ещё не настроено. Откройте его или выполните в терминале команду npx -y aish-mcp , чтобы проверить соединение.
В приложении нет инструментов AI Summary Helper или не появились новые после обновленияПолностью закройте приложение и запустите его снова. Некоторые приложения считывают список инструментов только при запуске.
«AISH is not running»Ваш браузер закрыт или функция выключена. Откройте браузер и проверьте панель настроек.
«Scope … is not enabled»Приложение запросило доступ, который вы не разрешили. Включите нужное разрешение в панели настроек.
Панель не подключается после ввода кодаВыполните команду npx -y aish-mcp pair и вставьте выведенный код заново. Он обновляется после reset.

Можно запускать несколько ИИ-приложений одновременно: они используют одно и то же подключение.
