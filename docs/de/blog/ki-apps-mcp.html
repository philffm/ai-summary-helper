Nutzen Sie Ihre Bibliothek in Claude, LM Studio und weiteren KI-Apps

Ihre KI-App vergisst alles, was Sie gelesen haben. AI Summary Helper erinnert sich daran. Verbinden Sie beides direkt auf Ihrem Computer, damit Ihre App gespeicherte Artikel durchsuchen, Ihre Highlights zitieren und Ihre Quellen belegen kann.

AI Summary Helper kann Ihre Bibliothek mit KI-Apps teilen, die das Model Context Protocol (MCP) unterstützen: Claude Desktop, LM Studio, Cursor, VS Code, Jan und lokale Agenten. Ihre App stellt eine Frage, AI Summary Helper schlägt in Ihren gespeicherten Artikeln nach, und die Antwort gelangt direkt zurück an die App auf Ihrem Rechner.

Die Funktion ist standardmäßig deaktiviert. Nichts daran berührt unsere Server: Die Erweiterung und die App kommunizieren direkt über ein kleines Hilfsprogramm auf Ihrem Computer miteinander, aish-mcp, das keinerlei Artikel speichert und nichts an Dritte weiterleitet.

Was Sie fragen können

  • Befragen Sie Ihre eigenen Lesematerialien statt das Internet. „Was habe ich zu KI und Überwachung gespeichert? Gruppiere es nach Themen und zeige mir, wo sich die Artikel widersprechen.“
  • Schreiben Sie basierend auf Ihren eigenen Quellen. „Entwirf einen Beitrag über die CO₂-Kosten von KI und zitiere dabei meine Highlights.“
  • Beantworten Sie Leitfragen einer Sammlung. „Nutze meine Sammlung zum Thema Inflation. Beantworte deren Kernfrage ausschließlich anhand dieser Quellen und nenne mir, was noch fehlt.“
  • Holen Sie Leselisten-Einträge nach. „Welche Artikel aus meiner Leseliste sind diese Woche fällig? Fasse jeden davon in einer 5-Minuten-Version zusammen.“
  • Filtern Sie Ihre Feeds effizient. „Gehe die heutigen ungelesenen Feed-Beiträge über KI durch und nenne mir die drei wichtigsten Artikel.“
  • Überblicken Sie Ihr Lesejahr. „Erstelle meinen Lese-Jahresrückblick für 2026: Top-Themen, der lesestärkste Monat und die prägendsten Artikel.“
  • Lassen Sie einen Agenten für sich speichern. „Finde drei gute Quellen zu Local-First-Software und speichere sie mit einer Notiz in meinem AISH-Posteingang.“

Mit einem lokalen Modell in LM Studio funktioniert all dies sogar komplett offline bei getrennter Netzwerkverbindung.

Einrichtung

Sie benötigen AI Summary Helper in Chrome, Edge oder Brave, Node.js 20 oder neuer und eine MCP-fähige App.

  1. Aktivieren Sie die Option. Öffnen Sie in AI Summary Helper Einstellungen → KI-Apps (MCP) und aktivieren Sie KI-Apps auf diesem Computer Zugriff auf meine Bibliothek gewähren.
  2. Kopplungscode abrufen. Führen Sie im Terminal folgenden Befehl aus: npx -y aish-mcp pair. Dadurch wird ein Kopplungscode ausgegeben und in Ihrem Benutzerordner abgelegt. Fügen Sie den Code in das Einstellungsfeld ein und wählen Sie „Verbinden“.
  3. AI Summary Helper zu Ihrer App hinzufügen. Verwenden Sie den passenden Codeabschnitt für Ihre App unten, beenden Sie die App anschließend vollständig und starten Sie sie neu.
  4. Verbindung überprüfen. Das Einstellungsfeld zeigt Verbunden an, sobald Ihre App ausgeführt wird. Fragen Sie Ihre App etwas über Ihre Bibliothek: Jeder Aufruf erscheint im Bereich „Letzte Aktivitäten“.

Claude Desktop

Einstellungen → Entwickler → Konfiguration bearbeiten, dann hinzufügen:

{
  "mcpServers": {
    "aish": { "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

Falls Claude Desktop npxnicht finden kann, verwenden Sie den vollständigen Pfad, den which npx im Terminal ausgibt (zum Beispiel /opt/homebrew/bin/npx).

Cursor

In ~/.cursor/mcp.json (alle Projekte) oder .cursor/mcp.json (einzelnes Projekt) denselben "aish" -Eintrag wie für Claude Desktop hinzu.

VS Code

In .vscode/mcp.json:

{
  "servers": {
    "aish": { "type": "stdio", "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

LM Studio und weitere Apps

Apps mit einer mcpServers -Einstellung (LM Studios mcp.json, Jan und die meisten anderen) verwenden denselben Eintrag wie Claude Desktop. Apps, die sich ausschließlich über HTTP verbinden, können npx -y aish-mcp --http unter http://127.0.0.1:47616/verwenden, zusammen mit dem Header Authorization: Bearer <Ihr Kopplungscode>. Wählen Sie für ein lokales Modell eines, das Tool Calling (Funktionsaufrufe) unterstützt, wie etwa Qwen 3 oder Llama 3.1 und neuer.

Nur Ihre Bibliothek ist standardmäßig aktiv, wenn Sie die Funktion einschalten. Aktivieren Sie „Vollständiger Artikeltext“, „Feeds“ und „Links speichern“ in den Einstellungen, falls gewünscht; Änderungen gelten ab dem nächsten Aufruf ohne erneutes Verbinden. Ihre App kann in AI Summary Helper nichts bearbeiten oder löschen.

Datenschutz und Sicherheit

  • Nichts wird über unsere Server geleitet. Daten gelangen von Ihrem Browser zum Hilfsprogramm und weiter zur App auf Ihrem Computer. Was die App anschließend an ihr Modell sendet, hängt von der gewählten App und dem Modell ab. Ein lokales Modell stellt sicher, dass alles vollständig auf Ihrem Rechner verbleibt.
  • Artikel mit dem Tag private tauchen niemals auf, in keinem Ergebnis, keiner Zählung und keiner Sammlung. Sie können in den Einstellungen ein anderes Tag festlegen.
  • Nur Ihr eigener Computer kann eine Verbindung herstellen. Das Hilfsprogramm lauscht ausschließlich auf 127.0.0.1, sodass kein anderes Gerät in Ihrem Netzwerk darauf zugreifen kann. Von Ihnen besuchte Websites können es ebenfalls nicht nutzen: Es akzeptiert nur die interne Erweiterungsadresse von AI Summary Helper, und jede Verbindung erfordert Ihren Kopplungscode.
  • Sie können jeden Aufruf nachvollziehen. Das Einstellungsfeld führt die letzten 50 Aufrufe mit Tool-Name und Uhrzeit auf – niemals den Inhalt.
  • Sie können den Zugriff jederzeit widerrufen. Deaktivieren Sie die Funktion oder wählen Sie „Trennen“. Führen Sie npx -y aish-mcp reset aus, um den alten Kopplungscode ungültig zu machen.
  • Gespeicherte Seiten sind Webinhalte Dritter. Ihrer App wird mitgeteilt, Inhalte rein als Information und nicht als Anweisungen zu behandeln; dennoch könnte eine gespeicherte Seite versuchen, eine KI zu manipulieren. Lassen Sie die Berechtigung „Links speichern“ deaktiviert, sofern Sie sie nicht aktiv nutzen.

Problembehandlung

FehleranzeigeLösung
Das Panel zeigt Nicht verbundenIhre KI-App läuft nicht oder ist noch nicht eingerichtet. Öffnen Sie die App oder führen Sie npx -y aish-mcp im Terminal aus, um die Verbindung zu testen.
Ihre App zeigt keine AI Summary Helper-Tools an oder erkennt neue Tools nach einem Update nichtBeenden Sie die App vollständig und starten Sie sie neu. Manche Apps lesen die Tool-Liste nur beim Programmstart ein.
„AISH läuft nicht“Ihr Browser ist geschlossen oder die Funktion ist deaktiviert. Öffnen Sie den Browser und überprüfen Sie das Einstellungsfeld.
„Scope … ist nicht aktiviert“Ihre App hat Zugriff auf Daten angefordert, die Sie nicht freigegeben haben. Aktivieren Sie die entsprechende Berechtigung in den Einstellungen.
Das Panel stellt nach dem Einfügen des Codes keine Verbindung herFühren Sie npx -y aish-mcp pair aus und fügen Sie den ausgegebenen Code erneut ein. Er ändert sich nach einem reset.

Mehrere KI-Apps gleichzeitig auszuführen ist problemlos möglich: Sie teilen sich dieselbe Verbindung.
