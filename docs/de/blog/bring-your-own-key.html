Ihr Key. Ihr Modell. Ihre Daten.

Die meisten KI-Tools schalten einen Server zwischen Sie und das Modell. Hier erfahren Sie, was sich ändert, wenn kein Zwischenserver existiert – und was weiterhin in Ihrer Verantwortung liegt.

Jede KI-Zusammenfassung folgt demselben Schema: Text wird gesendet, Text kommt zurück. Die entscheidende Frage für Ihr Vertrauen in das Tool lautet: Wer sitzt dazwischen? Bei vielen Produkten steht dort ein Unternehmensserver, über den Ihre gelesenen Inhalte geleitet werden – auf dem Weg zu einem Modell, das Sie nicht selbst gewählt haben.

Was „Bring Your Own Key“ hier konkret bedeutet

Sie erstellen einen API-Key bei einem Anbieter, dem Sie bereits vertrauen, fügen ihn in AI Summary Helper ein und wählen ein Modell aus. Wenn Sie eine Seite zusammenfassen, sendet der Background-Worker der Erweiterung den Text direkt an diesen Anbieter und streamt die Antwort zurück. Bei Nutzung Ihres eigenen Keys existiert auf diesem Weg kein Server von AI Summary Helper.

Sie können die Erweiterung auch mit einem Modell verbinden, das lokal auf Ihrem eigenen Rechner läuft – beispielsweise über Ollama. In diesem Fall verlässt der Text Ihrer Seiten zu keinem Zeitpunkt Ihren Computer.

Wo Ihr Key gespeichert wird

Der Key wird im lokalen Erweiterungsspeicher Ihres Browsers abgelegt, nicht im synchronisierten Cloud-Speicher. Das bedeutet, dass er nicht über Ihr Browser-Konto auf andere Geräte übertragen wird. Im Gegenzug geben Sie ihn einmal pro Browser ein. Keys werden ausschließlich für die Kommunikation mit dem von Ihnen konfigurierten Anbieter verwendet.

Was geschützt ist – und was nicht

Hier gilt es präzise zu sein: Die Nutzung eines eigenen Keys schaltet den Zwischenhändler aus. Sie entbindet Sie jedoch nicht vom Modellanbieter: Alles, was Sie an ein gehostetes Modell senden, unterliegt den Nutzungs- und Speicherbedingungen dieses Anbieters – prüfen Sie diese daher sorgfältig. Nur ein lokales Modell behält die Daten vollständig auf Ihrem Rechner; lokale Modelle sind jedoch meist kompakter und langsamer als gehostete Varianten.

Das Projekt ist Open Source – Sie müssen sich also nicht auf bloße Versprechen verlassen. Der Code für die Verarbeitung von Keys und Anfragen liegt im Repository und ist vollständig einsehbar.

Die passende Konfiguration wählen

  1. Tägliche Lektüre: ein gehostetes Modell eines Anbieters, dessen Bedingungen Sie akzeptieren. Schnell, hohe Qualität und Sie behalten die Kontrolle über den Key.
  2. Sensible Inhalte: ein lokales Modell. Etwas langsamer und limitierter, aber kein Byte verlässt Ihr Gerät.
  3. Experimentieren: Binden Sie mehrere Anbieter ein und vergleichen Sie die Antworten für denselben Artikel. So finden Sie am schnellsten heraus, welches Modell für welche Textart am besten geeignet ist.

Es geht nicht darum, dass es nur ein einziges richtiges Setup gibt – sondern darum, dass die Entscheidung stets bei Ihnen liegt.

AI Summary Helper ist eine kostenlose Chrome-Erweiterung.
