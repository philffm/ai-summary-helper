Fragen & Antworten

Wissenswertes vor der Installation

Durchsuchen Sie die Antworten nach Thema, Anbieter, Datenschutz, Archiv oder Plattform.

Benötige ich ein Benutzerkonto?

Nein. Installieren Sie es, verwenden Sie Ihren eigenen Schlüssel eines KI-Anbieters oder ein lokales Ollama-Modell und legen Sie los. Ein Konto ist nur für den optionalen byphil Cloud-Zugang oder zusätzliche Kindle/LocalSend-Sendungen nötig.

Welche Daten verlassen meinen Browser?

Nur die Zusammenfassungsanfrage geht an den von Ihnen konfigurierten KI-Anbieter. RSS erfordert außerdem Anfragen an Ihre abonnierten Feeds; eine KI-Zusammenfassung sendet Schlagzeilen und kurze Ausschnitte nur, wenn Sie sie anfordern. Suche, Duplikaterkennung, Tags und Empfehlungen laufen lokal. Sehen Sie sich die Architektur auf dem Gerät an →

Wo wird mein Lesearchiv gespeichert?

Standardmäßig in Ihrem Browser auf Ihrem Gerät. Sie können es als Markdown exportieren oder verschlüsselt in Ihrer eigenen Nextcloud, Ihrem WebDAV-Server, S3-Bucket oder lokalen Ordner sichern. Lesen Sie die Sync-Anleitung →

Was passiert, wenn ich meine Browserdaten lösche?

Lokale Browserdaten können ein lokales Archiv entfernen, wenn Sie kein Backup haben. Exportieren Sie Ihre Bibliothek oder richten Sie eine verschlüsselte Synchronisierung mit Ihrem eigenen Speicher ein, bevor Sie Browserdaten löschen oder Profile wechseln.

Welche KI-Anbieter und Modelle werden unterstützt?

Sie können OpenAI, Gemini, Mistral, DeepSeek, einen kompatiblen eigenen Endpoint oder ein lokales Ollama-Modell verwenden. Nutzen Sie Ihren eigenen Schlüssel oder den optionalen byphil Cloud-Zugang. Erfahren Sie, wie BYOK funktioniert →

Kann ich PDFs, YouTube-Videos und RSS-Einträge zusammenfassen?

Ja. Fassen Sie PDFs zusammen, die im Browser geöffnet oder von der Festplatte angehängt werden, YouTube-Videos über ihre Untertitel und Artikel aus dem integrierten RSS-Reader. Sehen Sie sich die Workflow-Videos an →

Wie zuverlässig sind die KI-Zusammenfassungen?

KI-Ausgaben können falsch sein und ersetzen nicht die Prüfung der Quelle. Rückfrage-Antworten zeigen die Passage, auf die sie sich stützen, sodass Sie die Zusammenfassung mit der Originalseite vergleichen können. Lernen Sie den 10-Sekunden-Quellencheck kennen →

Welche Browser und Plattformen werden unterstützt?

Nutzen Sie die Browser-Erweiterung, den nativen Seitenbereich oder ein Bookmarklet. Eine Android-Begleit-App fügt Links von Ihrem Smartphone hinzu; iOS ist noch nicht verfügbar.

Was passiert mit meinen gespeicherten Inhalten, wenn ich das Projekt nicht mehr unterstütze?

Ihr Archiv verbleibt unverändert dort, wo es gespeichert wurde: im lokalen Speicher Ihres Browsers auf Ihrem Gerät. Der Support Pass regelt lediglich den Zugang zu cloudbasierten Zusatzleistungen (byphil Cloud AI, unbegrenzter Versand an Kindle/LocalSend) – Ihr Zugriff auf bereits gespeicherte Daten bleibt davon unberührt. So macht Digest gespeicherte Inhalte wieder nützlich →

Ist der Quellcode Open Source?

Ja — der Quellcode der Erweiterung ist öffentlich einsehbar auf GitHub, unter der AGPL-3.0-Lizenz. Es ist für die private, bildungsbezogene und gemeinnützige Nutzung kostenlos; Unternehmen, die es außerhalb der Bedingungen der AGPL nutzen möchten, können eine kommerzielle Lizenz erwerben.
