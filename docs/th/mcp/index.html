เปรียบเทียบทางเลือกแทน Pocket: สิ่งที่สำคัญจริง ๆเปลี่ยนเครื่องมือบันทึกบทความโดยไม่สูญเสียคลังข้อมูลเดิม ความเป็นส่วนตัวคีย์ของคุณ โมเดลของคุณ ข้อมูลของคุณทำไมการใช้ API key ของตนเองถึงคุ้มค่ากว่าการสมัครสมาชิกรายเดือน ความน่าเชื่อถือตรวจสอบสรุปจาก AI เทียบกับแหล่งที่มาต้นฉบับตรวจเช็กผลลัพธ์จาก AI ได้ทันทีในเวลาไม่ถึงหนึ่งนาที วิธีใช้งานถามสิ่งที่คุณไฮไลต์ไว้เปลี่ยนข้อความที่ไฮไลต์ไว้ให้กลายเป็นคำตอบ ฟีดรวมสรุปฉบับเดียวแทนที่จะต้องตามอ่าน 40 ฟีดสรุปรายวันจากทุกแหล่งข้อมูลที่คุณติดตาม เบื้องหลังการทำงานค้นหาและจัดการแท็กได้โดยไม่ต้องพึ่งระบบคลาวด์ระบบการทำงานที่เก็บรักษาข้อมูลทั้งหมดไว้บนอุปกรณ์ของคุณ บทความทั้งหมด →

ในการใช้งานจริง

แอป AI ทำอะไรได้และไม่ได้

ข้อจำกัดฝังอยู่ในระบบและคุณเป็นผู้ตั้ง รายละเอียดอยู่ในเอกสารโอเพนซอร์สของตัวส่งต่อ

การทำงาน

ทุกสิ่งที่รายการอ่านควรทำได้ตั้งแต่วันแรก

บันทึก ทำความเข้าใจ ค้นหาได้ง่าย และกลับมาอ่านได้จริง — โดยไม่ต้องจ่ายค่าสมาชิกรายเดือนเพื่อล็อกคลังข้อมูลของคุณไว้

ทุกสิ่งที่รายการอ่านควรทำได้มาโดยตลอด

ทุกสิ่งที่รายการอ่านควรทำได้มาโดยตลอด เลือกโมเดล เลือกเซิร์ฟเวอร์ และควบคุมได้เองว่าจะให้ข้อมูลออกจากเครื่องหรือไม่ ปัญหาไม่เคยอยู่ที่การกดบันทึก แต่อยู่ที่การกลับมาเปิดอ่านสิ่งที่บันทึกไว้ — ระบบนี้จึงถูกสร้างขึ้นมาเพื่อตอบโจทย์จุดนี้โดยเฉพาะ ทุกสิ่งที่บันทึกสามารถค้นหา เชื่อมโยง และส่งออกได้ — จัดเก็บเป็นคลังข้อมูลที่เป็นระเบียบ ไม่ใช่แค่กองสะสมที่ไม่ได้ใช้งาน ติดตามสิ่งที่คุณสนใจ เห็นคอนเทนต์คุณภาพก่อนใคร พร้อมสรุปภาพรวมประจำวันได้ทันที อ่าน ฟัง หรือส่งต่อไปยัง Kindle — ได้ทุกที่ทุกเวลาที่มีเวลาว่าง

ตัวอ่าน RSS ในตัว

ติดตามบล็อกและเว็บข่าว กรองตามแหล่ง แท็ก วันที่ หรืออารมณ์ นำเข้า OPML และสรุปรายการใดก็ได้ด้วยคลิกเดียว เล่นฟีดพอดแคสต์ในส่วนขยายและเลือกรับสรุปจาก AI ได้ ฟีดและรายการโปรดอยู่บนอุปกรณ์ของคุณ

รองรับมากกว่า 20 ภาษา ใช้งานได้ข้ามแพลตฟอร์ม

อ่านและสรุปได้กว่า 20 ภาษาด้วยส่วนขยาย แผงด้านข้างของเบราว์เซอร์ หรือ Bookmarklet เมื่อส่วนขยายเข้าถึงหน้าไม่ได้

สรุปด้วย AI ตามโมเดลที่คุณเลือก

เลือก OpenAI, Gemini, Mistral, DeepSeek, เอนด์พอยต์ที่กำหนดเอง หรือ Ollama ในเครื่อง เพื่อให้บทสรุปไม่จำเป็นต้องออกจากอุปกรณ์เลย

ระบบค้นหาจริง ทำงานบนอุปกรณ์

ค้นหาชื่อเรื่อง แท็ก และเนื้อหาบทความด้วยดัชนี TF-IDF ที่ทำงานในเบราว์เซอร์ การค้นหาข้อความเต็มอยู่ในเครื่องโดยไม่ต้องส่งไปกลับ

เข้าถึงคลังข้อมูลของคุณได้โดยตรงจาก Claude, LM Studio และ Cursor

Claude Desktop, LM Studio, Cursor และแอป MCP อื่นค้นคลังของคุณ อ้างข้อความที่ไฮไลต์ และแสดงรายการที่ถึงกำหนดได้ คุณควบคุมสิทธิ์เอง ไม่มีข้อมูลผ่านเซิร์ฟเวอร์ของเรา

คลังข้อมูลส่วนตัวบนพื้นที่จัดเก็บของคุณเอง พร้อมการเข้ารหัสความปลอดภัย

ซิงค์คลังที่เข้ารหัสไปยัง Nextcloud เซิร์ฟเวอร์ WebDAV บัคเก็ต S3 หรือโฟลเดอร์ในเครื่อง เผยแพร่รายการที่ค้นหาได้พร้อมกราฟแท็กและแผนที่ 3D เราไม่ได้ให้บริการเซิร์ฟเวอร์ซิงค์ วิธีตั้งค่า · ลองตั้งค่าการซิงค์

คำถามที่พบบ่อย

สิ่งที่ควรรู้ก่อนติดตั้ง

ค้นคำตอบตามหัวข้อ ผู้ให้บริการ ความเป็นส่วนตัว คลัง หรือแพลตฟอร์ม

จำเป็นต้องมีบัญชีเพื่อใช้งานหรือไม่?

ไม่ต้อง ติดตั้ง ใส่คีย์ผู้ให้บริการ AI ของคุณเองหรือใช้โมเดล Ollama ในเครื่อง แล้วเริ่มบันทึกได้เลย บัญชีจำเป็นเฉพาะการใช้ byphil Cloud ซึ่งเป็นทางเลือก หรือการส่งไป Kindle/LocalSend เพิ่มเติม ดูตัวเลือกผู้ให้บริการ →

มีข้อมูลอะไรบ้างที่ส่งออกจากเบราว์เซอร์?

มีเพียงคำขอสรุปเท่านั้นที่ส่งไปยังผู้ให้บริการ AI ที่คุณตั้งค่าไว้ RSS ต้องส่งคำขอไปยังฟีดที่ติดตามด้วย สรุปจาก AI จะส่งพาดหัวและข้อความสั้นเฉพาะเมื่อคุณสั่ง การค้นหา การตรวจรายการซ้ำ แท็ก และคำแนะนำทำงานในเครื่อง ดูสถาปัตยกรรมบนอุปกรณ์ →

หน้าเว็บหรือไฮไลต์ของฉันถูกใช้ฝึกโมเดลหรือไม่

AI Summary Helper ไม่ใช้เนื้อหาของคุณฝึกโมเดลของตัวเอง เมื่อใช้คีย์ของตัวเอง นโยบายข้อมูลของผู้ให้บริการที่เลือกจะมีผล เมื่อใช้ Ollama คำขอสรุปจะอยู่บนเครื่องของคุณ อ่านแนวทางความเป็นส่วนตัว →

สามารถใช้งานแบบไม่พึ่งพาคลาวด์เลยได้หรือไม่?

ได้ ชี้ไปยังโมเดล Ollama ในเครื่อง ขั้นตอนการสรุปก็จะอยู่บนเครื่องของคุณด้วย ส่วนอื่นทำงานในเครื่องอยู่แล้ว เปรียบเทียบคีย์ของตัวเองกับ Ollama →

คลังการอ่านเก็บอยู่ที่ไหน

ตามค่าเริ่มต้นอยู่ในเบราว์เซอร์บนอุปกรณ์ของคุณ ส่งออกเป็น Markdown หรือสำรองแบบเข้ารหัสไปยัง Nextcloud เซิร์ฟเวอร์ WebDAV บัคเก็ต S3 หรือโฟลเดอร์ในเครื่องของคุณได้ อ่านคู่มือการซิงค์ →

ถ้าล้างข้อมูลเบราว์เซอร์จะเกิดอะไรขึ้น

การลบข้อมูลในเบราว์เซอร์อาจทำให้คลังในเครื่องหายไปหากไม่มีสำเนาสำรอง ส่งออกคลังหรือตั้งค่าซิงค์แบบเข้ารหัสไปยังที่เก็บของคุณก่อนล้างข้อมูลหรือเปลี่ยนโปรไฟล์ อ่านคู่มือสำรองและซิงค์ →

รองรับผู้ให้บริการและโมเดล AI ใดบ้าง

ใช้ OpenAI, Gemini, Mistral, DeepSeek, เอนด์พอยต์กำหนดเองที่เข้ากันได้ หรือโมเดล Ollama ในเครื่องได้ ใช้คีย์ของคุณเอง หรือเลือกใช้ byphil Cloud ดูวิธีใช้คีย์ของตัวเอง →

รองรับเบราว์เซอร์และแพลตฟอร์มใดบ้าง

ใช้ส่วนขยายเบราว์เซอร์ แผงด้านข้างของเบราว์เซอร์ หรือบุ๊กมาร์กเล็ต แอปคู่หูบน Android ใช้เพิ่มลิงก์จากโทรศัพท์ ส่วน iOS ยังไม่มี ดูขั้นตอนบนเบราว์เซอร์และการเก็บลิงก์ →

โปรเจกต์นี้เป็นโอเพนซอร์สหรือไม่?

ใช่ — ซอร์สโค้ดของส่วนขยายเปิดเผยต่อสาธารณะบน GitHub, ภายใต้สัญญาอนุญาต AGPL-3.0 โดยเปิดให้ใช้งานได้ฟรีสำหรับการใช้งานส่วนบุคคล ทางการศึกษา และองค์กรไม่แสวงหากำไร สำหรับบริษัทที่ต้องการใช้งานนอกเหนือจากข้อกำหนดของ AGPL สามารถขอรับ commercial license ได้ อ่านเรื่องสถาปัตยกรรมในเครื่อง →
