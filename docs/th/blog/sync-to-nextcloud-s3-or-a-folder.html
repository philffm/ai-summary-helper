เปรียบเทียบทางเลือกแทน Pocket: สิ่งที่สำคัญจริง ๆเปลี่ยนเครื่องมือบันทึกบทความโดยไม่สูญเสียคลังข้อมูลเดิม ความเป็นส่วนตัวคีย์ของคุณ โมเดลของคุณ ข้อมูลของคุณทำไมการใช้ API key ของตนเองถึงคุ้มค่ากว่าการสมัครสมาชิกรายเดือน ความน่าเชื่อถือตรวจสอบสรุปจาก AI เทียบกับแหล่งที่มาต้นฉบับตรวจเช็กผลลัพธ์จาก AI ได้ทันทีในเวลาไม่ถึงหนึ่งนาที วิธีใช้งานถามสิ่งที่คุณไฮไลต์ไว้เปลี่ยนข้อความที่ไฮไลต์ไว้ให้กลายเป็นคำตอบ ฟีดรวมสรุปฉบับเดียวแทนที่จะต้องตามอ่าน 40 ฟีดสรุปรายวันจากทุกแหล่งข้อมูลที่คุณติดตาม เบื้องหลังการทำงานค้นหาและจัดการแท็กได้โดยไม่ต้องพึ่งระบบคลาวด์ระบบการทำงานที่เก็บรักษาข้อมูลทั้งหมดไว้บนอุปกรณ์ของคุณ บทความทั้งหมด →

ภาพประกอบ, สร้างโดย AI

คู่มือการใช้งาน · ตุลาคม 2026

วิธีซิงค์คลังบทความสำหรับอ่านไปยัง Nextcloud, S3 หรือโฟลเดอร์ในเครื่อง พร้อมเข้ารหัสข้อมูล

บทความ สรุป ไฮไลต์ และโน้ตที่บันทึกไว้พร้อมใช้งานบนคอมพิวเตอร์ทุกเครื่อง จัดเก็บในที่ที่คุณกำหนด และอ่านได้เฉพาะเมื่อมีคีย์ของคุณ ใช้เวลาเพียง 10 นาทีโดยไม่ต้องสมัครบัญชีกับเรา

สรุปสั้นๆ ใน AI Summary Helper ให้เปิด Settings → Sync & backup → Add a placeเลือก Nextcloud/WebDAV, พื้นที่จัดเก็บข้อมูลที่รองรับ S3 หรือโฟลเดอร์บนคอมพิวเตอร์ และเก็บ Passphrase ที่ระบบแนะนำไว้ ข้อมูลทุกอย่างจะได้รับการเข้ารหัสในเบราว์เซอร์ก่อนอัปโหลด บนคอมพิวเตอร์เครื่องที่สอง ให้เพิ่มปลายทางเดียวกันแล้วป้อน Passphrase เท่านี้การตั้งค่าก็เสร็จสมบูรณ์ ส่วนที่เหลือของหน้านี้จะอธิบายที่เก็บข้อมูลแต่ละประเภท สิ่งที่ซิงค์ และวิธีแก้ไขเมื่อเกิดปัญหา

ทำไมต้องทำเช่นนี้? เพราะคลังการอ่านมีคุณค่าควรแก่การเก็บรักษา และเครื่องมือที่พึ่งพาอยู่อาจปิดตัวลงได้ (อ่านเพิ่มเติมได้ที่นี่) การซิงค์ไปยังที่จัดเก็บข้อมูลที่คุณเป็นเจ้าของช่วยให้คลังข้อมูลคงอยู่ได้ยาวนานกว่าแอปหรือบัญชีใดๆ

ข้อมูลที่ซิงค์และไม่ซิงค์

  • ข้อมูลที่ซิงค์: บทความที่บันทึกไว้พร้อมข้อความฉบับเต็มและบทสรุป, แท็ก, ไฮไลต์, โน้ตและความคิดเห็น ตลอดจนคอลเลกชันต่างๆ
  • ข้อมูลที่ไม่ซิงค์: API key, ข้อมูลการเข้าสู่ระบบ, ข้อมูลล็อกอินสำหรับการซิงค์ และการตั้งค่าเฉพาะของแต่ละอุปกรณ์ ระบบสำรองข้อมูลและซิงค์ตั้งใจละเว้นข้อมูลเหล่านี้ไว้
  • หนึ่งบทความต่อหนึ่งหน้าเว็บ: หากบันทึกหน้าเดียวกันบนคอมพิวเตอร์สองเครื่อง ข้อมูลจะรวมเป็นบทความเดียว (แท็กและฟิลด์ที่ขาดหายไปจะถูกนำมารวมกัน)
  • รวมการแก้ไขแบบทีละฟิลด์: หากเปลี่ยนชื่อเรื่องในเครื่องหนึ่งและเพิ่มแท็กในอีกเครื่องหนึ่ง การเปลี่ยนแปลงทั้งสองจะยังคงอยู่ แต่หากแก้ไขฟิลด์เดียวกัน การเปลี่ยนแปลงล่าสุดจะมีผลในทุกอุปกรณ์

ขั้นตอนที่ 1: เลือกตำแหน่งจัดเก็บข้อมูล

Nextcloud หรือเซิร์ฟเวอร์ WebDAV อื่นๆ

เหมาะที่สุดหากใช้งาน Nextcloud อยู่แล้ว หรือใช้บริการโฮสต์ (มีผู้ให้บริการหลายรายในยุโรปเปิดให้บริการ) โดยต้องเตรียม 3 สิ่งนี้:

  1. ที่อยู่ไฟล์ของคุณ สำหรับ Nextcloud จะมีรูปแบบดังนี้ https://your-server/remote.php/dav/files/your-username/ใน Nextcloud ให้เปิด Files → Settings และคัดลอกที่อยู่ WebDAV ที่แสดงอยู่
  2. ชื่อผู้ใช้ของคุณ
  3. รหัสผ่านสำหรับแอป (App Password) ไม่ใช่รหัสผ่านหลัก ใน Nextcloud: Settings → Security → Devices & sessions → create a new app passwordหากต้องการยกเลิกการเข้าถึงในภายหลัง ก็เพียงแค่ลบรายการดังกล่าวออก

ตั้งชื่อโฟลเดอร์ เช่น aish-syncระบบจะสร้างโฟลเดอร์นี้ให้โดยอัตโนมัติ สำหรับเซิร์ฟเวอร์ WebDAV อื่นๆ (เช่น NAS หลายรุ่น, ownCloud) จะทำงานในลักษณะเดียวกัน แต่อาจมีรูปแบบที่อยู่แตกต่างกัน

Bucket ที่รองรับ S3

เหมาะที่สุดหากต้องการใช้ Object Storage เช่น AWS S3, Cloudflare R2, Backblaze B2, MinIO หรือระบบอื่นที่คล้ายกัน ให้สร้าง Bucket จากนั้นสร้าง Access Key เฉพาะสำหรับ Bucket นี้ ที่มีสิทธิ์อ่าน เขียน แสดงรายการ และลบไฟล์ใน Bucket นั้น โดยไม่ควรใช้คีย์หลักของบัญชีเด็ดขาด ในส่วนขยาย ให้ป้อนที่อยู่ Endpoint (เช่น https://s3.eu-central-1.amazonaws.comหรือที่อยู่ที่ผู้ให้บริการแสดงไว้), ชื่อ Bucket, Region (ใช้ค่าเริ่มต้นหากผู้ให้บริการไม่ได้ระบุ), Access Key ID และ Secret Key

โฟลเดอร์บนคอมพิวเตอร์ของคุณ

เหมาะที่สุดหากมีเครื่องมืออื่นซิงค์โฟลเดอร์ระหว่างอุปกรณ์อยู่แล้ว เช่น Syncthing, โปรแกรมซิงค์บนเดสก์ท็อป, iCloud Drive หรือแฟลชไดรฟ์ USB ให้เลือก โฟลเดอร์ในคอมพิวเตอร์เครื่องนี้ และเลือก โฟลเดอร์ใหม่ที่ว่างเปล่าที่คุณสร้างขึ้นตัวอย่างเช่น Documents/AISH-syncทั้งนี้ Chrome ไม่อนุญาตให้ใช้ Desktop, Documents หรือ Downloads เป็นโฟลเดอร์โดยตรง จึงควรเลือกโฟลเดอร์ย่อย ฟังก์ชันนี้ใช้งานได้ใน Chrome และ Edge บนคอมพิวเตอร์ ข้อควรรู้ 2 ประการ: เบราว์เซอร์อาจขออนุญาตเข้าถึงโฟลเดอร์อีกครั้งหลังจากรีสตาร์ต (มีปุ่มให้กดในหน้าการตั้งค่า) และโฟลเดอร์จะซิงค์เฉพาะขณะที่เบราว์เซอร์กำลังทำงานอยู่เท่านั้น

ขั้นตอนที่ 2: เลือกเข้ารหัสและบันทึกชุดคำ

เมื่อเพิ่มปลายทางจัดเก็บข้อมูล Encrypted จะถูกเลือกไว้เป็นค่าเริ่มต้น และ Sync my devices คือวัตถุประสงค์ ส่วนขยายจะแนะนำชุดคำสุ่ม 6 คำเพื่อใช้เป็น Passphrase คุณสามารถกด Another suggestion จนกว่าจะได้ชุดคำที่ต้องการ หรือกำหนดเอง (ต้องมีความยาวอย่างน้อย 12 ตัวอักษร และจะมีคำแนะนำแสดงขึ้นหากรหัสผ่านไม่ปลอดภัยพอ)

หลังจากเชื่อมต่อแล้ว จะเห็นชุดคำ 6 คำนี้เพียงครั้งเดียว แนะนำให้บันทึกไว้ในโปรแกรมจัดการรหัสผ่าน ปุ่ม Copy จะคัดลอกชุดคำทั้งหมดโดยคั่นด้วยเครื่องหมายขีดกลาง ซึ่งปลอดภัยต่อการนำไปวางในไฟล์ config หรือแอปแชต หากมีชุดคำนี้ คุณจะสามารถเปิดที่จัดเก็บข้อมูลบนอุปกรณ์ใดก็ได้ แต่หากไม่มี จะไม่มีใครอ่านไฟล์ได้เลย รวมถึงทีมงานของเราด้วย บนคอมพิวเตอร์เครื่องที่ตั้งค่าไว้ คุณสามารถดูชุดคำนี้อีกครั้งได้ในการตั้งค่าของปลายทางนั้นๆ ที่ Show passphraseแต่หากคุณเลือกกำหนด Passphrase เอง ระบบจะไม่มีการจัดเก็บไว้ที่ใด ทำให้ส่วนขยายไม่สามารถแสดงให้ดูได้

สิ่งที่ผู้ให้บริการพื้นที่จัดเก็บข้อมูลมองเห็น: ไฟล์ที่ถูกเข้ารหัสพร้อมชื่อไฟล์ที่ถูกแปลงรหัส จำนวนไฟล์ ขนาดไฟล์ และเวลาที่ไฟล์เปลี่ยนแปลง แต่จะไม่สามารถมองเห็นชื่อเรื่อง ลิงก์ หรือข้อความใดๆ ได้ คลังข้อมูลของคุณจะได้รับการเข้ารหัสด้วย AES-256-GCM ในเบราว์เซอร์ก่อนออกจากอุปกรณ์เสมอ

ขั้นตอนที่ 3: เพิ่มคอมพิวเตอร์เครื่องที่สอง

  1. ติดตั้งส่วนขยายแล้วเปิด Settings → Sync & backup → Add a place.
  2. ป้อนรายละเอียดเซิร์ฟเวอร์เดียวกัน (หรือเลือกโฟลเดอร์เดียวกัน)
  3. ส่วนขยายจะตรวจพบว่าโฟลเดอร์มีคลังข้อมูลที่เข้ารหัสอยู่แล้ว และจะขอให้ป้อน Passphrase ซึ่งสามารถพิมพ์ตัวพิมพ์เล็กหรือใหญ่ คั่นด้วยเว้นวรรคหรือขีดกลางก็ได้
  4. ระบบจะขอให้ยืนยันว่าได้สำรองข้อมูลของอุปกรณ์นี้ไว้ก่อนแล้ว เนื่องจากการเชื่อมต่อจะรวมคลังข้อมูลของคอมพิวเตอร์เครื่องนี้เข้ากับคลังในโฟลเดอร์ และหากมีข้อมูลที่ขัดแย้งกัน ข้อมูลในโฟลเดอร์จะมีความสำคัญกว่า ให้ใช้ Make a backup now.
  5. กด Connectการซิงค์ครั้งแรกอาจใช้เวลาสักครู่หากคลังข้อมูลมีขนาดใหญ่ โดยหน้าจอจะแสดงความคืบหน้าให้ทราบ

สำรองข้อมูลอย่างเดียว กู้คืน และการเผยแพร่

  • Backup only เลือก Backup only แทน Sync my devices คอมพิวเตอร์จะทำหน้าที่เขียนข้อมูลไปยังปลายทางเท่านั้น และจะไม่อ่านข้อมูลกลับมา สามารถกู้คืนข้อมูลได้จากการตั้งค่าของปลายทางเมื่อต้องการ โดยระบบจะนำข้อมูลทั้งหมดกลับมา และหากมีความแตกต่างกับเครื่องนี้ ข้อมูลจากปลายทางจะมีความสำคัญกว่า และจะไม่มีข้อมูลใดถูกลบ
  • เผยแพร่ไปยังเว็บไซต์ของคุณ ปลายทางอีกประเภทหนึ่งคือ Readableจะเขียนไฟล์ข้อความธรรมดาสำหรับเว็บไซต์ของคุณ โดยจะเลือกเฉพาะบทความที่คุณติดแท็ก พร้อมหน้าสำหรับเปิดอ่าน (Viewer) ที่เลือกเปิดใช้งานได้ โน้ตและข้อความฉบับเต็มจะไม่ถูกรวมเข้ามาเว้นแต่คุณจะเปิดใช้งาน เนื่องจากใครก็ตามที่เข้าถึงโฟลเดอร์นั้นจะสามารถอ่านได้ทันที จึงไม่ควรใช้ปลายทางแบบเปิดอ่านได้นี้กับข้อมูลส่วนตัว

เมื่อเกิดปัญหาในการใช้งาน

"อนุญาตให้เข้าถึงโฟลเดอร์อีกครั้ง"

เบราว์เซอร์จะยกเลิกสิทธิ์เข้าถึงโฟลเดอร์หลังจากรีสตาร์ต ให้กดปุ่มที่ด้านบนของ Sync & backupหากยังไม่สำเร็จ โฟลเดอร์ดังกล่าวอาจเป็นโฟลเดอร์ที่ Chrome ป้องกันไว้ (Desktop, Documents, Downloads หรือโฮมโฟลเดอร์): ให้เลือกโฟลเดอร์ย่อยที่คุณสร้างขึ้นเอง

"เซิร์ฟเวอร์ไม่ยอมรับชื่อผู้ใช้และรหัสผ่าน"

สำหรับ Nextcloud ให้ใช้รหัสผ่านสำหรับแอป (App Password) ตรวจสอบว่าที่อยู่ลงท้ายด้วยโฟลเดอร์ชื่อผู้ใช้ของคุณ และการยืนยันตัวตนแบบสองขั้นตอน (2FA) ไม่ได้บล็อกรหัสผ่านสำหรับแอป

"Passphrase ไม่ถูกต้อง"

ตรวจสอบชุดคำ: ตัวพิมพ์เล็ก/ใหญ่ เว้นวรรค และขีดกลางไม่มีผล แต่ทุกคำต้องถูกต้อง บนคอมพิวเตอร์ที่ตั้งค่าไว้แล้ว ให้เปิดการตั้งค่าปลายทางแล้วกด Show passphraseหากทำชุดคำหายจากทุกอุปกรณ์ จะไม่มีใครสามารถเปิดไฟล์ได้เลย: ให้ลบปลายทางนี้ออก สร้างปลายทางใหม่ และเริ่มซิงค์ใหม่จากคลังข้อมูลบนคอมพิวเตอร์ของคุณ

มีรายการลบจำนวนมากกำลังรอการดำเนินการ

หากอุปกรณ์อื่นลบบทความจำนวนมากพร้อมกัน ส่วนขยายจะดำเนินการเพียงบางส่วนและถามยืนยันก่อนลบส่วนที่เหลือ เพื่อป้องกันไม่ให้ความผิดพลาดเพียงครั้งเดียวทำให้คลังข้อมูลว่างเปล่า ให้ตรวจสอบแล้วกดปุ่มเพื่อยืนยันการลบ

คอมพิวเตอร์ไม่ได้เปิดใช้งานเป็นเวลาหลายเดือน

หลังจากผ่านไปประมาณ 3 เดือน คอมพิวเตอร์จะส่งเฉพาะข้อมูลที่มีการเปลี่ยนแปลงนับจากนั้น และจะไม่ลบสิ่งใดด้วยตัวเอง เพื่อป้องกันไม่ให้บทความเก่าที่ถูกลบไปจากที่อื่นถูกกู้คืนกลับมาโดยไม่ตั้งใจ

คำถามที่พบบ่อย

จำเป็นต้องมีบัญชีกับผู้ให้บริการหรือไม่?

ไม่จำเป็น การซิงค์จะสื่อสารโดยตรงจากเบราว์เซอร์ไปยังที่จัดเก็บข้อมูลที่คุณระบุ เราไม่ได้ดำเนินการเซิร์ฟเวอร์สำหรับการซิงค์ใดๆ

ใช้งานบนโทรศัพท์มือถือได้หรือไม่?

สำหรับ Android สามารถใช้งานได้ แอปคู่หู (ไฟล์ APK จาก หน้า GitHub releasesซึ่งยังไม่มีบน Google Play) สามารถเชื่อมต่อกับคลังข้อมูลของคุณได้ที่ Settings → Library syncวิธีที่เร็วที่สุดคือใช้รหัส: ในเบราว์เซอร์ ให้เปิดการตั้งค่าปลายทางของคุณ แล้วกด Show code for the phone แล้วสแกนรหัสนั้น รหัสนี้มีข้อมูลการเข้าสู่ระบบเซิร์ฟเวอร์ของคุณ จึงควรสแกนด้วยโทรศัพท์ของคุณเองเท่านั้น โทรศัพท์จะแสดงบทความที่บันทึกไว้พร้อมบทสรุปและไฮไลต์ รวมถึงซิงค์โน้ตได้แบบสองทาง หน้าเว็บที่คุณสรุปบนโทรศัพท์และข้อความที่ทำเครื่องหมายไว้จะถูกเพิ่มลงในคลังของคุณด้วยเช่นกัน แต่จะเพิ่มเฉพาะหน้าที่ยังไม่มีในคลังเท่านั้น โดยจะไม่มีการเขียนทับข้อความเดิมในเบราว์เซอร์ สำหรับ iPhone ยังไม่มีแอปในขณะนี้

สามารถใช้ปลายทางมากกว่าหนึ่งแห่งได้หรือไม่?

ได้ การตั้งค่าที่นิยมใช้คือ กำหนดปลายทางแบบเข้ารหัสหนึ่งแห่งสำหรับซิงค์ระหว่างคอมพิวเตอร์ และกำหนดปลายทางสำหรับสำรองข้อมูลอย่างเดียวอีกหนึ่งแห่งไว้กับผู้ให้บริการรายอื่น

การเก็บคลังข้อมูลไว้บนคลาวด์ปลอดภัยหรือไม่?

ปลอดภัยกว่าการตั้งค่าทั่วไปส่วนใหญ่ เนื่องจากผู้ให้บริการจะเก็บเฉพาะไฟล์ที่เข้ารหัสไว้เท่านั้น แต่ความปลอดภัยยังคงขึ้นอยู่กับความรัดกุมของ Passphrase และอุปกรณ์ของคุณ โปรดอ่าน ข้อจำกัดตามความเป็นจริงซึ่งรวมถึงข้อเท็จจริงที่ว่าการเข้ารหัสนี้ยังไม่ผ่านการตรวจสอบอิสระจากภายนอก
