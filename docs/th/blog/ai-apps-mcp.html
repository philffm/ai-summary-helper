เปรียบเทียบทางเลือกแทน Pocket: สิ่งที่สำคัญจริง ๆเปลี่ยนเครื่องมือบันทึกบทความโดยไม่สูญเสียคลังข้อมูลเดิม ความเป็นส่วนตัวคีย์ของคุณ โมเดลของคุณ ข้อมูลของคุณทำไมการใช้ API key ของตนเองถึงคุ้มค่ากว่าการสมัครสมาชิกรายเดือน ความน่าเชื่อถือตรวจสอบสรุปจาก AI เทียบกับแหล่งที่มาต้นฉบับตรวจเช็กผลลัพธ์จาก AI ได้ทันทีในเวลาไม่ถึงหนึ่งนาที วิธีใช้งานถามสิ่งที่คุณไฮไลต์ไว้เปลี่ยนข้อความที่ไฮไลต์ไว้ให้กลายเป็นคำตอบ ฟีดรวมสรุปฉบับเดียวแทนที่จะต้องตามอ่าน 40 ฟีดสรุปรายวันจากทุกแหล่งข้อมูลที่คุณติดตาม เบื้องหลังการทำงานค้นหาและจัดการแท็กได้โดยไม่ต้องพึ่งระบบคลาวด์ระบบการทำงานที่เก็บรักษาข้อมูลทั้งหมดไว้บนอุปกรณ์ของคุณ บทความทั้งหมด →

ภาพประกอบ, สร้างโดย AI

คู่มือ · ตุลาคม 2026

ใช้งานคลังข้อมูลของคุณร่วมกับ Claude, LM Studio และแอป AI อื่นๆ

แอป AI ทั่วไปอาจจำสิ่งที่คุณเคยอ่านไม่ได้ แต่ AI Summary Helper จำได้ทั้งหมด เพียงเชื่อมต่อทั้งสองเข้าด้วยกันบนคอมพิวเตอร์ แอปของคุณก็สามารถค้นหาบทความที่บันทึกไว้ อ้างอิงไฮไลต์ และระบุแหล่งที่มาได้อย่างแม่นยำ

AI Summary Helper สามารถแชร์คลังข้อมูลของคุณไปยังแอป AI ที่รองรับ Model Context Protocol (MCP) เช่น Claude Desktop, LM Studio, Cursor, VS Code, Jan และ local agents เมื่อแอปส่งคำถาม AI Summary Helper จะค้นหาจากบทความที่บันทึกไว้ และส่งคำตอบกลับไปยังแอปบนเครื่องโดยตรง

ฟีเจอร์นี้ปิดใช้งานตามค่าเริ่มต้น ไม่มีการส่งข้อมูลผ่านเซิร์ฟเวอร์ของเรา โดยส่วนขยายและแอปจะสื่อสารกันผ่านโปรแกรม helper ขนาดเล็กบนคอมพิวเตอร์ของคุณ aish-mcp ซึ่งไม่มีการจัดเก็บบทความและไม่มีการส่งต่อข้อมูลไปยังที่อื่น

ตัวอย่างคำถามที่ใช้ถามได้

  • ถามจากสิ่งที่คุณอ่าน ไม่ใช่จากอินเทอร์เน็ต “มีบทความไหนที่บันทึกไว้เกี่ยวกับ AI และการสอดแนมบ้าง? ช่วยจัดกลุ่มตามหัวข้อและบอกจุดที่แต่ละบทความมีความเห็นต่างกัน”
  • เขียนเนื้อหาจากแหล่งข้อมูลของคุณเอง “ช่วยร่างโพสต์เกี่ยวกับผลกระทบด้าน CO₂ ของ AI พร้อมยกข้อความจากไฮไลต์มาอ้างอิง”
  • ตอบคำถามจากคอลเลกชัน “ใช้คอลเลกชันเรื่องเงินเฟ้อ ตอบคำถามโดยอ้างอิงจากแหล่งข้อมูลเหล่านี้เท่านั้น และระบุว่ามีข้อมูลส่วนไหนที่ยังขาดอยู่”
  • ตามเก็บเนื้อหาที่บันทึกไว้อ่านภายหลัง “มีบทความใดในรายการบันทึกไว้อ่านภายหลังที่ครบกำหนดในสัปดาห์นี้บ้าง? ขอสรุปสั้นๆ 5 นาทีของแต่ละเรื่อง”
  • คัดกรองฟีดข่าวสาร “ตรวจสอบฟีดที่ยังไม่ได้อ่านของวันนี้เกี่ยวกับ AI แล้วแนะนำ 3 บทความที่ควรอ่าน”
  • ดูสรุปภาพรวมประจำปี “สรุปภาพรวมการอ่านประจำปี 2026: หัวข้อยอดนิยม เดือนที่อ่านเยอะที่สุด และบทความเด่นประจำปี”
  • ให้ AI agent ช่วยบันทึกข้อมูล “ค้นหา 3 แหล่งข้อมูลที่น่าเชื่อถือเกี่ยวกับ local-first software แล้วบันทึกลงในกล่องข้อความ AISH พร้อมแนบบันทึก”

เมื่อใช้งานร่วมกับ local model ใน LM Studio ทุกฟังก์ชันจะทำงานได้แม้ออฟไลน์โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต

ขั้นตอนการตั้งค่า

จำเป็นต้องติดตั้ง AI Summary Helper ใน Chrome, Edge หรือ Brave Node.js เวอร์ชัน 20 ขึ้นไป และแอปที่รองรับ MCP

  1. เปิดใช้งาน ใน AI Summary Helper ให้เปิด การตั้งค่า → แอป AI (MCP) แล้วเปิดใช้งาน อนุญาตให้แอป AI บนคอมพิวเตอร์เครื่องนี้เข้าถึงคลังข้อมูล.
  2. รับรหัสจับคู่ เปิด Terminal แล้วรันคำสั่ง npx -y aish-mcp pair คำสั่งจะแสดงรหัสจับคู่และจัดเก็บไว้ในโฟลเดอร์ผู้ใช้ ให้นำรหัสไปวางในหน้าการตั้งค่าแล้วเลือก เชื่อมต่อ
  3. เพิ่ม AI Summary Helper ไปยังแอปของคุณ ใช้โค้ด snippet สำหรับแอปของคุณด้านล่าง จากนั้นปิดแอปให้สมบูรณ์แล้วเปิดใหม่อีกครั้ง
  4. ตรวจสอบการเชื่อมต่อ หน้าการตั้งค่าจะแสดงสถานะ เชื่อมต่อแล้ว เมื่อแอปเริ่มทำงาน ทดลองถามแอปเกี่ยวกับคลังข้อมูล โดยทุกคำขอที่แอปเรียกใช้จะแสดงใต้หัวข้อ กิจกรรมล่าสุด ในหน้าการตั้งค่า

Claude Desktop

Settings → Developer → Edit Config จากนั้นเพิ่มโค้ดต่อไปนี้:

{
  "mcpServers": {
    "aish": { "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

หาก Claude Desktop หา npx ไม่พบ ให้ระบุ full path ที่แสดงจากคำสั่ง which npx ใน Terminal (เช่น /opt/homebrew/bin/npx)

Cursor

ใน ~/.cursor/mcp.json (ทุกโปรเจกต์) หรือ .cursor/mcp.json (เฉพาะโปรเจกต์เดียว) ให้เพิ่มการตั้งค่า "aish" เช่นเดียวกับ Claude Desktop

VS Code

ใน .vscode/mcp.json:

{
  "servers": {
    "aish": { "type": "stdio", "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

LM Studio และแอปอื่นๆ

แอปที่มีการตั้งค่า mcpServers (เช่น mcp.json ของ LM Studio, Jan และแอปส่วนใหญ่) สามารถใช้การตั้งค่าเดียวกับ Claude Desktop สำหรับแอปที่เชื่อมต่อผ่าน HTTP เท่านั้น สามารถใช้ npx -y aish-mcp --http ที่ http://127.0.0.1:47616/ พร้อมระบุ header Authorization: Bearer <your pairing code> สำหรับ local model ให้เลือกโมเดลที่รองรับ tool calling เช่น Qwen 3 หรือ Llama 3.1 ขึ้นไป

สิ่งที่แอปของคุณทำได้

เครื่องมือการทำงานสิ่งที่ต้องเปิดใช้
search_libraryค้นหาบทความที่บันทึกไว้ โดยเลือกกรองตามแท็ก วันที่ หรือคอลเลกชันได้คลังข้อมูลของคุณ
get_articleบทความเดี่ยวพร้อมบทสรุปและไฮไลต์คลังข้อมูลของคุณ
list_highlightsไฮไลต์ของคุณ เรียงจากใหม่สุดไปเก่าสุดคลังข้อมูลของคุณ
list_dueรายการบันทึกไว้อ่านภายหลังที่ใกล้ถึงกำหนดคลังข้อมูลของคุณ
list_collections, get_collectionคอลเลกชันของคุณพร้อมแหล่งที่มาคลังข้อมูลของคุณ
library_statsเฉพาะสถิติจำนวน: การบันทึกตามช่วงเวลา, แท็กและเว็บไซต์ยอดนิยม, อารมณ์, ไฮไลต์คลังข้อมูลของคุณ
get_article พร้อมเนื้อหาฉบับเต็มเนื้อหาทั้งหมดของบทความที่บันทึกไว้ในรูปแบบข้อความล้วนเนื้อหาบทความฉบับเต็ม
list_feed_itemsรายการจากฟีดที่ติดตามไว้ฟีด
save_urlบันทึกลิงก์ไปยังกล่องข้อความพร้อมบันทึก และระบุว่าเพิ่มโดยแอป AIบันทึกลิงก์

เมื่อเปิดใช้งานฟังก์ชันนี้ ระบบจะเปิดเฉพาะ คลังข้อมูลของคุณ ไว้ตามค่าเริ่มต้น สามารถเปิดใช้งาน เนื้อหาบทความฉบับเต็ม, ฟีด และ บันทึกลิงก์ ในหน้าการตั้งค่าได้ตามต้องการ การเปลี่ยนแปลงจะมีผลในการเรียกใช้งานครั้งถัดไปโดยไม่ต้องเชื่อมต่อใหม่ ทั้งนี้แอปจะไม่สามารถแก้ไขหรือลบข้อมูลใดๆ ใน AI Summary Helper ได้

ความเป็นส่วนตัวและความปลอดภัย

  • ไม่มีข้อมูลใดส่งผ่านเซิร์ฟเวอร์ของเรา ข้อมูลจะถูกส่งจากเบราว์เซอร์ไปยังโปรแกรม helper และส่งต่อไปยังแอปบนคอมพิวเตอร์ ส่วนข้อมูลที่แอปจะส่งต่อไปยังโมเดลจะขึ้นอยู่กับแอปและโมเดลที่เลือกใช้งาน การใช้ local model จะช่วยให้ข้อมูลทั้งหมดอยู่บนเครื่องของคุณเท่านั้น
  • บทความที่ติดแท็ก private จะไม่ปรากฏ ในผลการค้นหา จำนวนนับ หรือคอลเลกชันใดๆ โดยสามารถเปลี่ยนแท็กที่ต้องการได้ในหน้าการตั้งค่า
  • เชื่อมต่อได้เฉพาะจากคอมพิวเตอร์ของคุณเท่านั้น โปรแกรม helper จะรับการเชื่อมต่อผ่าน 127.0.0.1 เท่านั้น อุปกรณ์อื่นในเครือข่ายจึงไม่สามารถเข้าถึงได้ เว็บไซต์ที่เข้าชมก็ไม่สามารถเรียกใช้งานได้เช่นกัน โดยระบบจะยอมรับเฉพาะที่อยู่ส่วนขยายของ AI Summary Helper และทุกการเชื่อมต่อจะต้องใช้รหัสจับคู่ของคุณ
  • ตรวจสอบประวัติการเรียกใช้งานได้ทุกครั้ง หน้าการตั้งค่าจะแสดงรายการคำขอล่าสุด 50 รายการ พร้อมชื่อเครื่องมือและเวลา โดยไม่มีการบันทึกเนื้อหา
  • ยกเลิกการเชื่อมต่อได้ทุกเมื่อ ปิดใช้งานฟีเจอร์นี้หรือเลือก ตัดการเชื่อมต่อ หรือรันคำสั่ง npx -y aish-mcp reset เพื่อยกเลิกรหัสจับคู่เดิม
  • หน้าเว็บที่บันทึกไว้เป็นข้อความจากอินเทอร์เน็ต แม้แอปจะได้รับคำสั่งให้ประมวลผลข้อมูลเป็นสารสนเทศไม่ใช่คำสั่งโดยตรง แต่หน้าเว็บที่บันทึกไว้อาจมีเนื้อหาที่ชี้นำ AI ได้ แนะนำให้ปิดสิทธิ์ บันทึกลิงก์ ไว้หากไม่ได้ใช้งาน

การแก้ปัญหาการใช้งาน

ปัญหาที่พบวิธีแก้ไข
หน้าการตั้งค่าแสดงข้อความ ไม่ได้เชื่อมต่อแอป AI ยังไม่เริ่มทำงานหรือยังไม่ได้ตั้งค่า ให้เปิดแอป หรือรันคำสั่ง npx -y aish-mcp ใน Terminal เพื่อทดสอบการเชื่อมต่อ
แอปไม่แสดงเครื่องมือของ AI Summary Helper หรือเครื่องมือใหม่ไม่แสดงหลังการอัปเดตปิดแอปให้สมบูรณ์แล้วเปิดใหม่อีกครั้ง เนื่องจากบางแอปจะโหลดรายการเครื่องมือเฉพาะตอนเริ่มต้นทำงานเท่านั้น
“AISH is not running”เบราว์เซอร์ปิดอยู่หรือฟีเจอร์ถูกปิดการใช้งาน ให้เปิดเบราว์เซอร์และตรวจสอบในหน้าการตั้งค่า
“Scope … is not enabled”แอปเรียกใช้ข้อมูลที่ยังไม่ได้รับอนุญาต สามารถเปิดการอนุญาตในหน้าการตั้งค่าได้ตามต้องการ
ระบบไม่เชื่อมต่อหลังจากวางรหัสจับคู่แล้วรันคำสั่ง npx -y aish-mcp pair แล้วนำรหัสที่แสดงมาวางใหม่อีกครั้ง รหัสจะเปลี่ยนไปหลังใช้คำสั่ง reset.

สามารถเปิดใช้งานแอป AI หลายตัวพร้อมกันได้ โดยแอปทั้งหมดจะใช้การเชื่อมต่อร่วมกัน
