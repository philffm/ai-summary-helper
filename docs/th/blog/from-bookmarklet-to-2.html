จาก Bookmarklet สู่เวอร์ชัน 2.0: ตัวตนที่แท้จริงของ AI Summary Helper ในปัจจุบัน

เริ่มต้นจากการเป็น bookmarklet คลิกเดียวเพื่อส่งไปอ่านบน Kindle สองปีต่อมาพร้อมการสร้างใหม่ทั้งหมด ฟีเจอร์ส่วนใหญ่ที่มีในวันนี้ยังไม่เคยมีอยู่เลยตอนที่มีผู้ใช้งาน 100 คนแรก

AI Summary Helper เป็นส่วนขยาย Chrome แบบโอเพนซอร์สที่ใช้งานได้ฟรี ช่วยสรุปเนื้อหาหน้าเว็บได้ทันทีด้วยผู้ให้บริการ AI ของคุณเอง หรือใช้งานโมเดลภายในเครื่อง (Local AI) แบบออฟไลน์ 100% บันทึกบทความไว้อ่านภายหลังพร้อมการแจ้งเตือนตามเวลา และเปลี่ยนประวัติการอ่านให้เป็นคลังความรู้ที่เชื่อมโยงและค้นหาได้ง่าย ไม่มีฟีเจอร์เหล่านั้นเลยในเวอร์ชันแรก และนี่คือสิ่งที่มีในวันนั้น รวมถึงเส้นทางที่พัฒนามาจนถึงจุดนี้

จุดเริ่มต้นที่แท้จริง

ในเดือนกรกฎาคม 2024 โปรเจกต์นี้เป็นเพียง bookmarklet ไม่ใช่ส่วนขยายด้วยซ้ำ หลายคนมักค้นพบบทความน่าสนใจ เปิดแท็บทิ้งไว้เป็นสิบๆ แท็บ แล้วสุดท้ายก็แทบไม่ได้อ่าน แนวคิดดั้งเดิมจึงเรียบง่ายและตอบโจทย์ส่วนตัว: เครื่องมือสรุปเนื้อหาตาม prompt ที่กำหนดเอง โดยแทรกผลลัพธ์ลงในหน้าเว็บโดยตรง เพื่อให้เนื้อหาสรุปติดไปด้วยเมื่อส่งบทความไปยัง Kindle ผ่าน เครื่องมือ Send-to-Kindle ของ Reabbleนั่นคือฟังก์ชันทั้งหมดของผลิตภัณฑ์ในตอนนั้น มีผู้ให้บริการ AI เพียงรายเดียว ช่องใส่ prompt ช่องเดียว มีทั้งรูปแบบ bookmarklet ที่ใช้ได้ทุกที่แม้แต่บน iOS Safari และส่วนขยาย Chrome สำหรับผู้ที่ต้องการปรับเปลี่ยน prompt ได้สะดวกรวดเร็ว

มีผู้ใช้งานประจำทะลุ 100 คนในเวลาเพียงไม่กี่สัปดาห์ — ซึ่งน่าประหลาดใจมาก เพราะสร้างขึ้นเพื่อแก้ปัญหาพฤติกรรมการอ่านของคนคนเดียว ไม่ได้ตั้งใจทำเป็นผลิตภัณฑ์ตั้งแต่แรก

สิ่งที่เปลี่ยนแปลงไปอย่างแท้จริงจากวันนั้นสู่เวอร์ชัน 2.0

แนวคิดหลักไม่เคยเปลี่ยน — สรุปเนื้อหาตามแบบที่ต้องการ อ่านในที่ที่สบายตากว่าแท็บบราวเซอร์ แต่ระบบรอบข้างเกือบทั้งหมดพัฒนาขึ้นใหม่อย่างสิ้นเชิง:

จากผู้ให้บริการรายเดียว สู่ 5 ตัวเลือกที่กำหนดเองได้

v1 รองรับเฉพาะ OpenAI พร้อม API key และ endpoint เดียว ส่วน 2.0 รองรับทั้ง OpenAI, Google Gemini, Mistral และ DeepSeek โดยใช้ API key ของคุณเอง รวมถึงตัวเลือกการประมวลผลแบบ Local AI เต็มรูปแบบผ่าน Ollama — ข้อมูลหน้าเว็บจึงไม่จำเป็นต้องถูกส่งออกจากเครื่อง ช่วยปกป้องความเป็นส่วนตัวสูงสุดและประมวลผลได้รวดเร็ว นอกจากนี้ยังมีตัวเลือกคลาวด์เสริม (byphil Cloud) สำหรับผู้ที่ไม่ต้องการจัดการ API key เอง โดยไม่บังคับใช้งาน การเปลี่ยนแปลงนี้ไม่ใช่แค่การเพิ่มฟีเจอร์เล็กๆ แต่เปลี่ยนทิศทางของผลิตภัณฑ์ เพราะ v1 ให้ส่งข้อมูลไปยังบริษัทเดียวเป็นค่าเริ่มต้น แต่ 2.0 มอบสิทธิ์การควบคุมให้คุณเลือกผู้ให้บริการด้วยตัวเองทั้งหมด

จาก "แทรกลงในหน้าเว็บ" สู่เวิร์กโฟลว์การทำงานจริง

แนวคิดดั้งเดิม — เก็บไว้อ่านทีหลังในบรรยากาศที่สบายตากว่าบราวเซอร์ — ยังคงอยู่ แต่ไม่ได้เป็นเพียงการวางข้อความสรุปลงใน DOM อีกต่อไป เมื่อคลิกขวาที่หน้าเว็บจะพบตัวเลือก Summarize & Close Tab: เลือกช่วงเวลาที่ต้องการ (Tomorrow, Weekend, This Week, Research Session) เพิ่มบันทึกสั้นๆ และแท็บจะปิดตัวเองอัตโนมัติเมื่ออ่านสรุปอย่างรวดเร็วผ่านหน้าต่าง RSVP เสร็จสิ้น จากนั้นการแจ้งเตือนของ Chrome จะเตือนให้กลับมาอ่านตรงตามเวลาที่ตั้งไว้ — ไม่ใช่แค่ "ไว้ค่อยอ่าน" หรือ "เมื่อนึกขึ้นได้"

จากกองบทความที่บันทึกไว้ สู่คลังข้อมูลที่จัดการและค้นหาได้จริง

v1 ไม่มีการเก็บประวัติเลย — เมื่อสรุปแสดงบนหน้าเว็บแล้วปิดไป ข้อมูลก็หายทันที แต่ปัจจุบัน ทุกบทความที่บันทึกจะถูกเก็บไว้ในคลังข้อมูลภายในเครื่อง (Local Archive) ที่ค้นหาได้ พร้อมฟังก์ชันไฮไลต์ข้อความ (รวมถึง "ghost highlights" ที่ AI ช่วยแนะนำจุดสำคัญ) แผนภาพความถี่การอ่าน (Heatmap) และ Knowledge Graph แบบ D3 ที่จัดกลุ่มบทความตามหัวข้อโดยอัตโนมัติ แทนที่จะเป็นเพียงรายการบทความเรียงต่อกัน

Kindle เคยเป็นเป้าหมายหลัก ตอนนี้เป็นหนึ่งในตัวเลือกที่หลากหลาย

การส่งเข้า Kindle ผ่านเครื่องมือของ Reabble เคยเป็นเหตุผลเดียวที่สร้างโปรเจกต์นี้ขึ้นมา ปัจจุบันระบบยังคงรองรับอยู่เช่นเดิม แต่การอ่านนอกบราวเซอร์เพิ่มตัวเลือกอย่าง AirDrop ไปยัง iPhone หรือ iPad (เปิดอ่านใน Apple Books ได้ทันที) หรือส่งผ่าน LocalSend ไปยังแอปอย่าง KOReader ผ่าน Wi-Fi วงเดียวกัน จุดประสงค์เดิมในการย้ายเนื้อหาออกจากบราวเซอร์ไปยังอุปกรณ์ที่ออกแบบมาเพื่อการอ่านโดยเฉพาะ ยังคงเดิม เพียงแต่มีช่องทางที่สะดวกและยืดหยุ่นขึ้น

สิ่งที่ไม่เคยเปลี่ยนแปลง

ยังคงใช้งานได้ฟรี เป็นโอเพนซอร์ส (สัญญาอนุญาต MIT พร้อมโค้ดทั้งหมดบน GitHub) และไม่จำเป็นต้องสมัครบัญชีเพื่อใช้งานฟีเจอร์หลัก จุดยืนนี้ไม่เคยเปลี่ยน — ด้วยเหตุผลเดียวกับที่ v1 ถือกำเนิดขึ้นในรูปแบบ bookmarklet: สร้างขึ้นโดยคนที่ต้องการเป็นเจ้าของเครื่องมืออ่านหนังสือของตัวเองอย่างแท้จริง

คำถามที่พบบ่อย (FAQ)

โปรเจกต์นี้เป็นโปรเจกต์เดียวกับ bookmarklet ดั้งเดิมหรือไม่?
ใช่ — เป็นโปรเจกต์โอเพนซอร์สเดียวกันและ GitHub repo เดิม ซึ่งพัฒนาอย่างต่อเนื่องมาตั้งแต่เดือนกรกฎาคม 2024 รูปแบบ bookmarklet ยังคงมีให้ใช้งานสำหรับผู้ที่ต้องการใช้งานบนทุกบราวเซอร์โดยไม่ต้องติดตั้งส่วนขยาย

จำเป็นต้องมีบัญชี OpenAI เพื่อใช้งานหรือไม่?
ไม่จำเป็น ใน v1 เคยต้องใช้ แต่ปัจจุบันรองรับผู้ให้บริการหลากหลาย หรือจะใช้งานผ่านโมเดลแบบ Local AI ด้วย Ollama ภายในเครื่องโดยไม่ต้องมีบัญชีภายนอกเลยก็ได้เช่นกัน

เกิดอะไรขึ้นกับเวอร์ชันบน Gumroad?
โปรเจกต์เคยเปิดรับการสนับสนุนจากผู้ใช้งานกลุ่มแรกผ่านช่องทางนั้น แต่ตัวส่วนขยายเป็นซอฟต์แวร์ฟรีและโอเพนซอร์สมาโดยตลอด — Gumroad ไม่เคยเป็นระบบปิดกั้นการเข้าถึงเครื่องมือนี้
