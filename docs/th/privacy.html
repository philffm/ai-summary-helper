เปรียบเทียบทางเลือกแทน Pocket: สิ่งที่สำคัญจริง ๆเปลี่ยนเครื่องมือบันทึกบทความโดยไม่สูญเสียคลังข้อมูลเดิม ความเป็นส่วนตัวคีย์ของคุณ โมเดลของคุณ ข้อมูลของคุณทำไมการใช้ API key ของตนเองถึงคุ้มค่ากว่าการสมัครสมาชิกรายเดือน ความน่าเชื่อถือตรวจสอบสรุปจาก AI เทียบกับแหล่งที่มาต้นฉบับตรวจเช็กผลลัพธ์จาก AI ได้ทันทีในเวลาไม่ถึงหนึ่งนาที วิธีใช้งานถามสิ่งที่คุณไฮไลต์ไว้เปลี่ยนข้อความที่ไฮไลต์ไว้ให้กลายเป็นคำตอบ ฟีดรวมสรุปฉบับเดียวแทนที่จะต้องตามอ่าน 40 ฟีดสรุปรายวันจากทุกแหล่งข้อมูลที่คุณติดตาม เบื้องหลังการทำงานค้นหาและจัดการแท็กได้โดยไม่ต้องพึ่งระบบคลาวด์ระบบการทำงานที่เก็บรักษาข้อมูลทั้งหมดไว้บนอุปกรณ์ของคุณ บทความทั้งหมด →

API key, ประวัติบทความ และไฮไลต์ของคุณจะอยู่บนอุปกรณ์ของคุณเสมอ เนื้อหาหน้าเว็บจะถูกส่งไปยังผู้ให้บริการ AI ที่คุณเลือกเท่านั้น — รวมถึงโมเดลแบบ Local ออฟไลน์ หากคุณเลือกใช้งาน

อัปเดตล่าสุด: ตุลาคม 2026

นโยบายความเป็นส่วนตัวนี้อธิบายว่า AI Summary Helper จัดการข้อมูลใดบ้าง ข้อมูลถูกส่งไปที่ไหน และทำไม สรุปสั้นๆ คือ: API key, ประวัติบทความ และไฮไลต์ของคุณจะอยู่บนอุปกรณ์ของคุณ เนื้อหาหน้าเว็บจะถูกส่งไปยังผู้ให้บริการ AI ที่คุณเลือกเชื่อมต่อเท่านั้น — รวมถึงหากคุณเลือกโมเดล Local ข้อมูลจะไม่มีการส่งออกจากเครื่องของคุณเลยแม้แต่น้อย เราไม่มีโฆษณา ไม่ขายข้อมูล และไม่จำเป็นต้องสร้างบัญชีสำหรับการใช้งานฟีเจอร์หลักใดๆ

หากคุณไม่เห็นด้วยกับส่วนใดส่วนหนึ่งของนโยบายนี้ โปรดอย่าติดตั้งหรือใช้งานส่วนขยายนี้

ผู้รับผิดชอบข้อมูล

ผู้ควบคุมข้อมูลตามมาตรา 4(7) GDPR คือ Phil Wornath ชื่อเต็มและที่อยู่สำหรับการติดต่อระบุไว้ใน ประกาศทางกฎหมาย (Legal Notice)และสามารถติดต่อเราได้ตามช่องทางการติดต่อที่ด้านท้ายของนโยบายนี้

ฟีเจอร์หลักใช้งานได้โดยไม่ต้องมีบัญชี

AI Summary Helper ไม่บังคับให้คุณต้องสร้างบัญชี เข้าสู่ระบบ หรือระบุข้อมูลส่วนบุคคลใดๆ เพื่อสรุปเนื้อหา ไฮไลต์ ติดตามฟีด หรือจัดเก็บคลังบทความ API key ของคุณ (หากคุณใช้คีย์ของตัวเอง) และประวัติบทความทั้งหมดจะถูกจัดเก็บไว้ในพื้นที่จัดเก็บในเบราว์เซอร์ของคุณ (Local Storage) เท่านั้น

บัญชีผู้ใช้จำเป็นเฉพาะเมื่อใช้งานบริการบนเซิร์ฟเวอร์เท่านั้น: byphil Cloud (บริการสรุปโดยไม่ต้องใช้คีย์ตัวเอง) และ Send to Kindle การเข้าสู่ระบบทำได้ผ่านอีเมลและรหัส OTP ใช้ครั้งเดียว เราจะจัดเก็บที่อยู่อีเมล สถานะแพ็กเกจหรือใบอนุญาต (License) และสถิติการใช้งานพื้นฐาน (เช่น จำนวนคำขอสรุปและจำนวนการส่งไป Kindle) เพื่อใช้ควบคุมขีดจำกัดของแต่ละแพ็กเกจ

ข้อมูลที่เราจัดการ และปลายทางของข้อมูล

การเชื่อมต่อผู้ให้บริการ AI ของคุณ

คุณสามารถเลือกวิธีสร้างบทสรุปได้เองตามต้องการ:

  • นำคีย์ของคุณมาใช้เอง (BYOK) — OpenAI, Google Gemini, Mistral AI, DeepSeek หรือเซิร์ฟเวอร์แบบ Custom Endpoint โดย API key ของคุณจะถูกจัดเก็บบนอุปกรณ์ของคุณเท่านั้น (ไม่ซิงก์ และไม่ส่งมาหาเราเด็ดขาด) เนื้อหาของหน้าที่คุณต้องการสรุปจะถูกส่งตรงจากเบราว์เซอร์ของคุณไปยังผู้ให้บริการที่คุณเลือก โดยใช้คีย์ของคุณเองและอยู่ภายใต้นโยบายความเป็นส่วนตัวของผู้ให้บริการรายนั้นๆ เราไม่สามารถมองเห็น บันทึก หรือจัดเก็บเนื้อหาเหล่านี้ได้เลย
  • โมเดล Local ผ่าน Ollama — หากคุณรันโมเดล AI ภายในเครื่อง เนื้อหาหน้าเว็บจะถูกส่งไปยังเครื่องของคุณเองเท่านั้น ไม่มีข้อมูลใดหลุดออกนอกอุปกรณ์
  • byphil Cloud (ตัวเลือกเสริมแบบชำระเงิน) — ตัวเลือกผ่านคลาวด์สำหรับผู้ที่ไม่ต้องการจัดการ API key ด้วยตนเอง หากเลือกตัวเลือกนี้ ข้อความที่คุณต้องการสรุปจะถูกส่งผ่านเซิร์ฟเวอร์ของเรา ซึ่งจะส่งต่อคำขอผ่าน OpenRouter ไปยังผู้ให้บริการโมเดลปลายทางในนามของคุณและส่งบทสรุปกลับมา ข้อมูลนี้เป็นการส่งผ่านทางเท่านั้น: เราไม่มีการจัดเก็บเนื้อหาหน้าเว็บ, URL หรือบทสรุป ข้อมูลที่เราบันทึกตามบัญชีผู้ใช้คือเมทาดาทาการใช้งาน ได้แก่: จำนวนคำขอที่เสร็จสมบูรณ์, การใช้โทเคน (Token), เวลาของคำขอล่าสุด และโมเดลที่ใช้ การมีบัญชีเป็นเพียงตัวเลือกเสริม ฟีเจอร์อื่นๆ ทั้งหมดยังคงใช้งานได้โดยไม่ต้องมีบัญชี

สถานะใบอนุญาตและการสมัครสมาชิก

หากคุณเปิดใช้งานใบอนุญาต Pro หรือการสมัครสมาชิก byphil Cloud รหัส License key ของคุณจะถูกจัดเก็บไว้ในอุปกรณ์ของคุณเท่านั้น (ไม่มีการซิงก์) และใช้เพื่อตรวจสอบสถานะสมาชิกกับระบบหลังบ้านของเรา ข้อมูลเมทาดาทาของบัญชีและการชำระเงินขั้นพื้นฐานจะได้รับการจัดการโดยผู้ให้บริการประมวลผลการชำระเงินและระบบหลังบ้านของเรา เราไม่มีการจัดเก็บเนื้อหาหน้าเว็บหรือประวัติการอ่านของคุณบนเซิร์ฟเวอร์

แบบสอบถามเมื่อถอนการติดตั้ง

เมื่อคุณถอนการติดตั้งส่วนขยาย Chrome จะเปิดหน้าแบบสอบถามสั้นๆ บนเว็บไซต์นี้ ข้อมูลที่อยู่เว็บประกอบด้วยเวอร์ชันของส่วนขยายและจำนวนวันที่ติดตั้งเท่านั้น — ไม่มีการระบุตัวตน ไม่มีเนื้อหาหน้าเว็บ และไม่มีประวัติการใช้งาน ข้อมูลที่คุณเลือกหรือพิมพ์ในแบบฟอร์ม (เหตุผล หรือความคิดเห็นเพิ่มเติม) จะถูกบันทึกเป็น Event ในระบบวิเคราะห์ข้อมูลแบบ Self-hosted ที่ไม่ใช้คุกกี้ของเรา พร้อมด้วยเวอร์ชันของส่วนขยายและจำนวนวันที่ติดตั้ง เพื่อใช้ในการปรับปรุงส่วนขยายเท่านั้น หากเบราว์เซอร์ของคุณเปิดใช้งาน Do Not Track หรือคุณเลือกปิดการวิเคราะห์ จะไม่มีการส่งข้อมูลใดๆ หน้าแบบสอบถามนี้ไม่มีช่องกรอกอีเมล หากต้องการติดต่อเพื่อรับการตอบกลับ สามารถเปิด GitHub Issue ได้ และคุณสามารถปิดหน้านั้นได้ทันทีโดยไม่ต้องตอบแบบสอบถาม

ประวัติบทความ, ไฮไลต์ และการตั้งค่า

ทุกสิ่งที่คุณบันทึกจะถูกจัดเก็บไว้ในเครื่องผ่านเบราว์เซอร์ของคุณ โดยใช้ Chrome Storage API ในตัว — ไม่มีการเก็บไว้บนเซิร์ฟเวอร์ของเราอย่างแน่นอน:

ข้อมูลการจัดเก็บซิงก์ผ่าน Chrome หรือไม่?
บทความและบทสรุปที่บันทึกไว้จัดเก็บในเครื่อง (Local)ไม่
การติดตามฟีด RSS และรายการบทความจัดเก็บในเครื่อง (Local)ไม่
API key / การตั้งค่าผู้ให้บริการจัดเก็บในเครื่อง (Local)ไม่ — ข้อมูลสำคัญ อยู่บนอุปกรณ์เท่านั้น
รหัสใบอนุญาต (License key)จัดเก็บในเครื่อง (Local)ไม่ — ข้อมูลสำคัญ อยู่บนอุปกรณ์เท่านั้น
IP เครือข่าย LocalSendจัดเก็บในเครื่อง (Local)ไม่
ไฮไลต์ข้อความและ AI Ghost Highlightจัดเก็บในเครื่อง (แยกตามหน้า)ไม่
Prompt เริ่มต้น, ภาษา, ความยาวของบทสรุปซิงก์ (Sync)ใช่ ผ่านบัญชี Chrome ของคุณเอง
การตั้งค่าเปิด/ปิดระบบไฮไลต์ซิงก์ (Sync)ใช่ ผ่านบัญชี Chrome ของคุณเอง

รายการที่ระบุว่า "ซิงก์" จะใช้ระบบซิงก์ข้อมูลของ Chrome ที่ผูกกับบัญชี Google ของคุณ — ข้อมูลนี้จะวิ่งผ่านโครงสร้างพื้นฐานของ Google ไม่ใช่ของเรา เช่นเดียวกับบุ๊กมาร์กของคุณ เราไม่สามารถเข้าถึงข้อมูลนี้ได้

คุณสามารถส่งออกข้อมูลของคุณได้ตลอดเวลาผ่านทาง การตั้งค่า → คลังข้อมูลและข้อมูล → การสำรองข้อมูลและการกู้คืน โดยค่าเริ่มต้น การสำรองข้อมูลจะไม่รวม API key, ข้อมูลเข้าสู่ระบบ, License key และตัวระบุการติดตั้ง การเลือกสำรองข้อมูลเหล่านี้จะต้องยินยอมพร้อมคำเตือนอย่างชัดเจน เนื่องจากผู้ที่มีไฟล์ดังกล่าวจะสามารถนำไปใช้ได้ โปรดเก็บไฟล์สำรองข้อมูลไว้เป็นความลับ และระลึกไว้ว่าไฟล์สำรองข้อมูลเก่าอาจมีข้อมูลความลับเหล่านี้อยู่ นอกจากนี้ ในหน้าเดียวกันยังมี "Danger Zone" ที่ให้คุณเลือกลบข้อมูลแยกตามหมวดหมู่พร้อมแสดงจำนวนรายการที่จะถูกลบ: บทสรุปและคลังบทความ, ไฮไลต์, ฟีด, พอดแคสต์, API key / การเข้าสู่ระบบ / ใบอนุญาต, ปลายทางการส่ง (Kindle, LocalSend) และการตั้งค่า ลบข้อมูลทั้งหมด จะลบทุกสิ่งที่ส่วนขยายจัดเก็บบนอุปกรณ์ และรีเซ็ตการทำงานใหม่ทั้งหมด การลบส่วนขยายออกก็จะลบข้อมูลเหล่านี้ด้วยเช่นกัน การดำเนินการเหล่านี้เป็นการลบเฉพาะข้อมูลในเครื่อง สำหรับบัญชีของคุณและข้อมูลที่เราเก็บบนเซิร์ฟเวอร์ (ดูด้านล่าง) คุณสามารถจัดการได้ที่ byphil.eu/#account: คุณสามารถส่งออกข้อมูลและลบบัญชีของคุณได้ที่นั่น ทั้งนี้ ส่วนขยายและแอป Android มีลิงก์ไปยังหน้านี้จากการตั้งค่าบัญชี

ฟังก์ชันตัวอ่านฟีดในตัวจะจัดเก็บรายการติดตามและเนื้อหาฟีดไว้ในเบราว์เซอร์ของคุณเท่านั้น — ไม่มีการซิงก์ และไม่ส่งมาหาเรา เมื่อคุณเพิ่มหรือรีเฟรชฟีด ส่วนขยายจะส่งคำขอไปยังที่อยู่ฟีดนั้นตรงไปยังเซิร์ฟเวอร์ของผู้เผยแพร่เนื้อหา เช่นเดียวกับการเปิดเว็บไซต์ด้วยตัวเอง ผู้เผยแพร่จึงสามารถเห็นคำขอนี้ได้ เราไม่ได้ทำหน้าที่เป็นพร็อกซี ไม่บันทึก และไม่เห็นการติดตามหรือรายการอ่านของคุณ การนำเข้าไฟล์ OPML จะดำเนินการบนอุปกรณ์ของคุณทั้งหมด หากเปิดใช้การตรวจสอบเบื้องหลัง (ปิดเป็นค่าเริ่มต้น) ส่วนขยายจะดึงข้อมูลฟีดซ้ำตามช่วงเวลาที่คุณตั้งไว้ เพียงเพื่อแสดงจำนวนบนไอคอนแถบเครื่องมือเท่านั้น การสรุปเนื้อหาฟีดทำงานเหมือนกับการสรุปหน้าเว็บทั่วไป: เนื้อหาจะถูกส่งไปยังผู้ให้บริการ AI ที่คุณเลือกเท่านั้น และส่งเมื่อคุณกดสั่งสรุปเท่านั้น ฟังก์ชันเสริมอย่าง AI สรุปประจำวันและ AI วิเคราะห์โทนเสียงก็ทำงานแบบเดียวกัน: เมื่อคุณคลิกใช้งานเท่านั้น ส่วนขยายจะส่งหัวข้อบทความ ชื่อแหล่งที่มา และตัวอย่างสั้นๆ (ไม่ใช่บทความเต็ม) ไปยังผู้ให้บริการ AI ที่คุณเลือก และบทสรุปที่ได้จะถูกแคชไว้บนอุปกรณ์ของคุณ ตอนพอดแคสต์ในฟีดจะสตรีมตรงจากเซิร์ฟเวอร์ของผู้เผยแพร่เมื่อคุณกดเล่น

การส่งบทความ: Kindle, LocalSend และ Share Sheet

มี 2 รูปแบบ และมีเพียงรูปแบบเดียวเท่านั้นที่ผ่านเซิร์ฟเวอร์ของเรา:

  • Send to Kindle จะดำเนินการผ่านเซิร์ฟเวอร์ของเรา Amazon รับเอกสารทางอีเมลจากผู้ส่งที่ได้รับอนุญาตเท่านั้น ดังนั้นส่วนขยายจะส่งบทความ (ชื่อเรื่อง, บทสรุป, ข้อความ, ไฮไลต์ และ URL ต้นทาง) ไปยังระบบหลังบ้านของ byphil เพื่อส่งอีเมลต่อไปยังที่อยู่ Kindle ที่คุณระบุ คุณจะต้องเพิ่มอีเมลผู้ส่งของเรา (kindle@byphil.eu) ลงในรายชื่อผู้ส่งที่ได้รับอนุญาตในบัญชี Amazon ของคุณ เนื้อหาจะถูกใช้เพื่อสร้างและส่งอีเมลนั้นเท่านั้น การส่งไปยัง Kindle จำเป็นต้องเข้าสู่ระบบหรือมีใบอนุญาต โดยแพ็กเกจฟรีรวมสิทธิ์ส่งได้ 3 ครั้ง
  • LocalSend และ Share Sheet ของระบบ (เช่น AirDrop) จะส่งตรงระหว่างอุปกรณ์ ไฟล์จะถูกส่งจากเบราว์เซอร์ไปยังอุปกรณ์ที่คุณเลือกในเครือข่าย Local ของคุณโดยตรง หรือไปยังแอปที่คุณเลือกใน Share Sheet เราไม่มีส่วนเกี่ยวข้อง และไม่สามารถเห็นหรือจัดเก็บเนื้อหานี้ได้ LocalSend ใช้งานได้กับทั้งโทรศัพท์ แท็บเล็ต คอมพิวเตอร์ และเครื่องอ่าน e-reader ที่มีแอปที่รองรับ

การวิเคราะห์ข้อมูลและคุกกี้

สรุปสั้นๆ: เว็บไซต์นี้ ไม่ใช้คุกกี้เลย และไม่มีการใช้โฆษณาหรือตัวติดตามข้ามเว็บไซต์ เรานับจำนวนการเข้าชมแบบไม่ระบุตัวตนด้วย Matomo ที่เราโฮสต์เอง (Self-hosted) และคุณสามารถปิดการทำงานนี้ได้ตลอดเวลา

ตัวส่วนขยายเบราว์เซอร์ไม่มีโค้ดสำหรับการวิเคราะห์ ข้อมูลการใช้งาน (Telemetry) หรือโค้ดติดตามใดๆ ทั้งสิ้น การส่งคำขอผ่านเครือข่ายจะมีเพียงแค่การติดต่อกับผู้ให้บริการ AI ที่คุณตั้งค่าไว้, ฟีดที่คุณติดตาม, หน้าเว็บที่คุณต้องการให้ดึงข้อมูล และ (หากใช้งาน) ระบบหลังบ้านของ byphil สำหรับ byphil Cloud, การเข้าสู่ระบบ, การตรวจสอบใบอนุญาต และ Send to Kindle

ข้อมูลที่เราเก็บสถิติ

การเปิดดูหน้าเว็บ, ภาษาของหน้าเว็บ, แหล่งที่มา (Referrer), ประเทศ/เบราว์เซอร์/ประเภทอุปกรณ์โดยประมาณ และส่วนของเว็บไซต์ที่คุณโต้ตอบด้วย (เช่น การคลิก "Add to Chrome", ปุ่มสลับดูราคา, คำถามที่พบบ่อย, ส่วนของหน้าที่คุณเลื่อนดู และขั้นตอนการสร้าง Bookmarklet) ข้อมูล Event เหล่านี้จะไม่มีที่อยู่อีเมล, API key, รหัส OTP, เนื้อหาหน้าเว็บ หรือข้อมูลบทความอย่างเด็ดขาด

การกำหนดค่าระบบวิเคราะห์

Matomo ทำงานบนเซิร์ฟเวอร์ของเราเอง (analytics.philwornath.de ในเยอรมนี) ไม่ได้อยู่บนบุคคลที่สาม มีการตั้งค่าโดยปิดการใช้งานคุกกี้และไม่ใช้วิธีระบุลายนิ้วมือเบราว์เซอร์ (Fingerprinting) มีการแปลง IP address ให้เป็นนิรนามก่อนจัดเก็บ ไม่มีการกำหนด User ID หรือตัวระบุข้ามเว็บไซต์ จึงไม่สามารถเชื่อมโยงการเข้าชมข้ามวันหรือข้ามอุปกรณ์ได้ ข้อมูลไม่มีการขายหรือส่งต่อให้บุคคลที่สาม

เนื่องจากไม่มีการจัดเก็บหรืออ่านข้อมูลใดๆ จากอุปกรณ์ของคุณเพื่อการติดตาม การเก็บสถิตินี้จึงอาศัยฐานประโยชน์อันชอบธรรมในการทำความเข้าใจการใช้งานเว็บไซต์ (Art. 6(1)(f) GDPR) และไม่จำเป็นต้องมีแบนเนอร์ขอความยินยอมเรื่องคุกกี้ตาม § 25 TDDDG / ข้อกำหนด ePrivacy คุณมีสิทธิคัดค้าน (Art. 21 GDPR) ได้ทุกเมื่อ

ตัวเลือกของคุณ

ระบบวิเคราะห์จะปิดการทำงานโดยอัตโนมัติหากเบราว์เซอร์ของคุณส่งสัญญาณ Do Not Track หรือ Global Privacy Controlนอกจากนี้ คุณยังสามารถเลือกปิดได้ด้วยตนเองผ่าน การตั้งค่าการวิเคราะห์ (มีอยู่ที่ส่วนท้ายของทุกหน้าเช่นกัน)

ข้อมูลที่จัดเก็บในเบราว์เซอร์ของคุณ

จัดเก็บเฉพาะการตั้งค่าสำหรับการทำงานเท่านั้น ไม่ใช้เพื่อการติดตามเด็ดขาด: aish_analytics (สถานะการปิดระบบวิเคราะห์ของคุณ), aish_analytics_notice (สถานะที่คุณปิดการแจ้งเตือนข้อมูล) และหากมีการใช้งาน จะมีตัวเลือกธีม, การปิดการแนะนำภาษา และการตั้งค่าสร้าง Bookmarklet ข้อมูลเหล่านี้จะอยู่บนอุปกรณ์ของคุณและไม่ถูกส่งมายังเรา

ฟอนต์และทรัพยากรภายนอก

ฟอนต์ (Inter, Space Grotesk, JetBrains Mono; ภายใต้สัญญาอนุญาต SIL Open Font License) ให้บริการจากเว็บไซต์นี้โดยตรง IP address ของคุณจึงไม่ถูกส่งไปยัง Google หรือผู้ให้บริการฟอนต์อื่นๆ เพียงเพราะการเข้าชมเว็บ คำขอภายนอกเพียงอย่างเดียวคือลิงก์ที่คุณคลิก และหน้าบัญชี byPhil / หน้าชำระเงินของ Stripe ที่คุณเลือกเปิดใช้งาน

ฐานทางกฎหมายและระยะเวลาการเก็บรักษาข้อมูล

ข้อมูลเกือบทั้งหมดได้รับการประมวลผลบนอุปกรณ์ของคุณและไม่เคยถูกส่งมาถึงเรา ในกรณีที่มีการประมวลผลข้อมูล นี่คือฐานทางกฎหมายและระยะเวลาในการเก็บรักษา:

  • บัญชีผู้ใช้และการเข้าสู่ระบบ (ที่อยู่อีเมล, รหัส OTP, License key, สถานะแพ็กเกจ) — เพื่อให้บริการบัญชีที่คุณร้องขอ ตาม Art. 6(1)(b) GDPR ข้อมูลจะถูกเก็บไว้ตราบเท่าที่ยังมีบัญชีอยู่ และจะถูกลบเมื่อคุณลบบัญชี
  • byphil Cloud (การส่งต่อข้อความที่คุณสรุป, สถิติการใช้งาน, การใช้โทเคน, คำขอล่าสุด, โมเดลล่าสุด) — เพื่อดำเนินการตามบริการ Art. 6(1)(b) ข้อความจะทำหน้าที่เพียงส่งผ่านเท่านั้นและไม่มีการจัดเก็บ เมทาดาทาการใช้งานจะถูกเก็บไว้ตราบเท่าที่ยังมีบัญชีและจะถูกลบพร้อมกับบัญชี
  • Send to Kindle (บทความที่คุณส่ง, ที่อยู่อีเมล Kindle ของคุณ) — เพื่อดำเนินการส่งตามที่คุณสั่ง Art. 6(1)(b) ข้อมูลจะถูกใช้เพียงเพื่อสร้างและส่งอีเมลนั้นเท่านั้น
  • การชำระเงินและการตรวจสอบใบอนุญาต — เพื่อปฏิบัติตามสัญญาและหน้าที่ทางบัญชี Art. 6(1)(b) และ (c) บันทึกการเรียกเก็บเงินจะถูกเก็บไว้ตามระยะเวลาที่กฎหมายกำหนด
  • การวิเคราะห์เว็บไซต์และแบบสอบถามเมื่อถอนการติดตั้ง — ฐานประโยชน์อันชอบธรรมของเราในการปรับปรุงเว็บไซต์และส่วนขยาย Art. 6(1)(f) ข้อมูลเป็นแบบไม่ระบุตัวตน (ดูหัวข้อ การวิเคราะห์ข้อมูลและคุกกี้)

คุณสามารถส่งออกข้อมูลบัญชีและลบบัญชีของคุณได้ตลอดเวลาที่ byphil.eu/#accountการลบบัญชีจะเป็นการลบข้อมูลทั้งหมดที่จัดเก็บไว้สำหรับบัญชีนั้น

offscreen, ttsเล่นเสียงพอดแคสต์และอ่านออกเสียงบทสรุปในเบื้องหลังขณะที่ปิดหน้าต่างป๊อปอัป
unlimitedStorageจัดเก็บคลังบทความและไฮไลต์ขนาดใหญ่ในเครื่องได้โดยไม่ติดโควตาความจุเริ่มต้น
host_permissions (<all_urls>)ช่วยให้คุณสรุปหน้าเว็บใดๆ ที่คุณเข้าชมได้ — เนื้อหาจะถูกอ่านและส่งเมื่อคุณสั่งสรุปด้วยตนเองเท่านั้น ไม่มีการอ่านข้อมูลในเบื้องหลังโดยที่คุณไม่ได้สั่ง

เราไม่นำสิทธิ์เหล่านี้ไปใช้ติดตามการท่องเว็บของคุณ ไม่สร้างโปรไฟล์เพื่อการโฆษณา และไม่เก็บรวบรวมข้อมูลเกินกว่าฟีเจอร์ที่ระบุไว้ข้างต้น

สิ่งที่เราไม่ทำอย่างแน่นอน

  • เราไม่แสดงโฆษณา และไม่ขาย ให้เช่า หรือแลกเปลี่ยนข้อมูลของคุณกับผู้โฆษณาหรือนายหน้าค้าข้อมูล (Data Brokers)
  • เราไม่บังคับให้ต้องมีบัญชีหรือเข้าสู่ระบบสำหรับการใช้งานฟีเจอร์หลัก
  • เราไม่บันทึกหรือเก็บรักษาเนื้อหาของหน้าที่คุณสรุปผ่าน API key ของคุณเองหรือผ่านโมเดล Local และเราไม่มีทางเห็นข้อมูลที่คุณส่งผ่าน LocalSend หรือ Share Sheet
  • เราไม่สามารถเข้าถึงประวัติบทความ ไฮไลต์ หรือ API key ที่จัดเก็บในเครื่องของคุณได้ — ข้อมูลจะไม่หลุดออกจากอุปกรณ์ของคุณ เว้นแต่คุณจะเลือกกดส่งออกด้วยตนเอง

บริการของบุคคลที่สาม

ขึ้นอยู่กับการตั้งค่าส่วนขยายของคุณ เนื้อหาหน้าเว็บอาจถูกส่งไปยัง:

  • OpenAI, Google (Gemini), Mistral AI หรือ DeepSeek — เฉพาะเมื่อคุณใส่ API key ของคุณเองสำหรับผู้ให้บริการนั้น และเฉพาะหน้าเว็บที่คุณสั่งสรุปเท่านั้น
  • ระบบหลังบ้าน byphil ของเรา ซึ่งโฮสต์โดย IONOS SE ในเยอรมนี — เฉพาะเมื่อคุณเข้าสู่ระบบ, ใช้งาน byphil Cloud หรือ Send to Kindle
  • OpenRouter ซึ่งเป็นช่องทางที่ byphil Cloud เชื่อมต่อไปยังโมเดลต่างๆ รวมถึงผู้ให้บริการโมเดลปลายทาง — ข้อความที่คุณสั่งสรุปจะถูกส่งต่อไปยังโมเดลที่คุณเลือก สำหรับคำขอนั้นๆ เท่านั้น
  • Stripe — ผู้ประมวลผลการชำระเงินและจัดการการสมัครสมาชิก ในฐานะ Merchant of Record
  • Amazon — หากคุณส่งบทความไปยัง Kindle ระบบของ Amazon จะดำเนินการจัดส่งภายใต้นโยบายความเป็นส่วนตัวของ Amazon เอง
  • Ollama บนเครื่องของคุณเอง — ไม่ใช่บุคคลที่สาม ข้อมูลอยู่บนคอมพิวเตอร์ของคุณเท่านั้น

เราไม่รับผิดชอบต่อแนวทางปฏิบัติด้านความเป็นส่วนตัวของผู้ให้บริการ AI บุคคลที่สามที่คุณเลือกเชื่อมต่อ ขอแนะนำให้ตรวจสอบนโยบายของผู้ให้บริการเหล่านั้นก่อนเชื่อมต่อบัญชี

คุณเป็นผู้กำหนดเองว่าต้องการให้โมเดลใดประมวลผลข้อความของคุณ ไม่ว่าคุณจะใช้คีย์ของตนเองหรือ byphil Cloud คุณเป็นผู้เลือกผู้ให้บริการและโมเดลในการตั้งค่า และคุณมีหน้าที่ตรวจสอบข้อกำหนดของผู้ให้บริการรายนั้นรวมถึงสถานที่ประมวลผลข้อมูล OpenRouter, ผู้ให้บริการโมเดลปลายทาง และ Amazon อาจประมวลผลข้อมูลนอกสหภาพยุโรป/EEA ภายใต้มาตรการคุ้มครองของตนเอง (เช่น Standard Contractual Clauses) โดยเราไม่มีการถ่ายโอนข้อมูลของคุณไปยังประเทศที่สามด้วยตัวเราเอง

ความปลอดภัยของข้อมูล

เราใช้มาตรการทางเทคนิคที่เหมาะสมและได้มาตรฐานกับข้อมูลที่เกี่ยวข้อง — ซึ่งข้อมูลส่วนใหญ่ไม่เคยถูกส่งมายังเซิร์ฟเวอร์ของเราตั้งแต่แรก เนื่องจากจัดเก็บอยู่ภายในเบราว์เซอร์ของคุณ การสื่อสารกับระบบหลังบ้านของเรา (สำหรับ byphil Cloud และการตรวจสอบใบอนุญาต) จะได้รับการเข้ารหัสขณะส่งข้อมูล (Encryption in transit) แม้ว่าจะไม่มีวิธีการส่งหรือจัดเก็บข้อมูลใดที่ปลอดภัย 100% และเราไม่สามารถรับประกันความปลอดภัยได้อย่างสมบูรณ์แบบ แต่เราไม่เก็บรวบรวมข้อมูลเกินกว่าความจำเป็นในการให้บริการฟีเจอร์ต่างๆ ตามที่ระบุไว้

ความเป็นส่วนตัวของเด็ก

AI Summary Helper ไม่ได้ออกแบบมาสำหรับเด็กอายุต่ำกว่า 13 ปี (หรือเกณฑ์อายุขั้นต่ำตามกฎหมายในเขตอำนาจศาลของคุณ) และเราไม่มีการเก็บรวบรวมข้อมูลส่วนบุคคลจากเด็กโดยเจตนา

สิทธิของคุณ (ตาม GDPR / CCPA และกฎหมายที่เกี่ยวข้อง)

เนื่องจากข้อมูลเกือบทั้งหมดของคุณจัดเก็บอยู่บนอุปกรณ์ของคุณเอง คุณจึงควบคุมข้อมูลได้อย่างสมบูรณ์ — คุณสามารถดู ส่งออก หรือลบข้อมูลได้ตลอดเวลาผ่านการตั้งค่าของส่วนขยาย หรือโดยการถอนการติดตั้งส่วนขยาย สำหรับข้อมูลที่เราจัดเก็บบนเซิร์ฟเวอร์ (การสมัครสมาชิก byphil Cloud / เมทาดาทาการเรียกเก็บเงิน) คุณสามารถจัดการ ส่งออก และลบบัญชีของคุณได้ที่ byphil.eu/#accountหรือติดต่อเราตามรายละเอียดด้านล่าง

คุณมีสิทธิในการเข้าถึงข้อมูล (Art. 15), สิทธิในการแก้ไขข้อมูล (Art. 16), สิทธิในการลบข้อมูล (Art. 17), สิทธิในการจำกัดการประมวลผล (Art. 18), สิทธิในการโอนย้ายข้อมูล (Art. 20) และสิทธิในการคัดค้าน (Art. 21) รวมถึงการเพิกถอนความยินยอมได้ทุกเมื่อ นอกจากนี้คุณยังมีสิทธิยื่นเรื่องร้องเรียนต่อหน่วยงานกำกับดูแล (Art. 77) โดยเฉพาะในประเทศสมาชิกที่คุณพำนักอยู่ เราไม่นำข้อมูลของคุณไปใช้ในการตัดสินใจอัตโนมัติที่มีผลทางกฎหมายหรือการจัดทำโปรไฟล์ (Profiling)

การเปลี่ยนแปลงนโยบายนี้

เราอาจปรับปรุงนโยบายความเป็นส่วนตัวนี้เมื่อฟีเจอร์ของส่วนขยายมีการเปลี่ยนแปลง การเปลี่ยนแปลงที่เป็นสาระสำคัญจะแสดงให้เห็นที่นี่พร้อมระบุวันที่ใน "อัปเดตล่าสุด" การใช้งานส่วนขยายอย่างต่อเนื่องหลังจากมีการเปลี่ยนแปลงจะถือว่ายอมรับนโยบายที่อัปเดตแล้ว
