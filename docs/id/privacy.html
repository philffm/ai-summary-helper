Kebijakan Privasi

API key, riwayat artikel, dan sorotan Anda tetap berada di perangkat Anda. Konten halaman hanya dikirim ke penyedia AI yang Anda pilih — termasuk model lokal penuh jika Anda memilih opsi tersebut.

Terakhir diperbarui: Oktober 2026

Kebijakan Privasi ini menjelaskan data apa saja yang dikelola oleh AI Summary Helper, ke mana data tersebut dikirim, dan alasannya. Singkatnya: API key, riwayat artikel, dan sorotan Anda tetap berada di perangkat Anda. Konten halaman hanya dikirim ke penyedia AI yang Anda pilih untuk dihubungkan — termasuk model yang sepenuhnya lokal jika Anda memilihnya, di mana tidak ada data yang keluar dari perangkat Anda sama sekali. Kami tidak menampilkan iklan, tidak menjual data, dan tidak memerlukan akun untuk fitur utama apa pun.

Jika Anda tidak menyetujui bagian mana pun dari kebijakan ini, mohon untuk tidak memasang atau menggunakan ekstensi ini.

Pihak yang bertanggung jawab

Pengendali data dalam konteks Pasal 4(7) GDPR adalah Phil Wornath. Nama lengkap dan alamat untuk layanan tertera di pemberitahuan hukum; Anda dapat menghubungi kami melalui detail kontak di bagian akhir kebijakan ini.

Tidak Perlu Akun untuk Fitur Utama

AI Summary Helper tidak mewajibkan Anda membuat akun, masuk log, atau memberikan informasi pribadi apa pun untuk meringkas halaman, membuat sorotan, mengikuti feed, atau menyimpan arsip Anda. API key Anda (jika Anda menggunakan milik sendiri) dan seluruh riwayat artikel Anda tersimpan di local storage browser Anda.

Akun hanya diperlukan untuk layanan yang dihosting: byphil Cloud (ringkasan tanpa API key pribadi) dan Send to Kindle. Masuk log menggunakan alamat email Anda dan kode sekali pakai. Kami menyimpan alamat email tersebut, status paket atau lisensi Anda, dan penghitung penggunaan dasar (misalnya jumlah permintaan dan pengiriman ke Kindle) agar kami dapat menerapkan batas paket.

Data Apa yang Kami Kelola, dan Ke Mana Data Tersebut Dikirim

Koneksi penyedia AI Anda

Anda memilih cara ringkasan dibuat:

  • Gunakan API key sendiri (BYOK) — OpenAI, Google Gemini, Mistral AI, DeepSeek, atau custom endpoint. API key Anda hanya disimpan secara lokal di perangkat Anda (tidak pernah disinkronkan, tidak pernah dikirim ke kami). Konten halaman yang Anda pilih untuk diringkas dikirim langsung dari browser Anda ke penyedia yang Anda pilih, menggunakan key Anda sendiri dan tunduk pada kebijakan privasi penyedia tersebut. Kami tidak melihat, mencatat log, atau menyimpan konten ini.
  • Model lokal via Ollama — jika Anda menjalankan model secara lokal, konten halaman hanya dikirim ke perangkat Anda sendiri. Tidak ada data yang keluar dari perangkat Anda.
  • byphil Cloud (opsional, berbayar) — opsi hosting bagi mereka yang tidak ingin mengelola API key sendiri. Jika Anda memilih paket ini, teks yang ingin Anda rangkum akan melewati backend kami, yang meneruskan permintaan tersebut melalui OpenRouter ke penyedia model atas nama Anda dan mengembalikan hasil ringkasannya. Teks tersebut hanya diteruskan: kami tidak menyimpan konten halaman, URL, maupun ringkasan. Data yang kami catat per akun hanyalah metadata penggunaan: jumlah permintaan yang selesai, penggunaan token, waktu permintaan terakhir, dan model yang digunakan. Akun ini sendiri bersifat opsional; semua fitur lainnya tetap berfungsi tanpa akun. Dengan mengaktifkan pengaturan “Prefer EU servers”, model yang memiliki endpoint di Eropa hanya akan dijalankan pada endpoint tersebut, dan aplikasi akan menandai model mana saja yang mendukungnya. Ini membatasi lokasi model dijalankan. Hal ini tidak menghapus perantara dari jalurnya: teks Anda tetap melewati layanan kami (yang berjalan di server di Jerman) dan kemudian melalui OpenRouter, perusahaan asal AS, sebelum menuju ke model; selain itu, fitur read-aloud dan speech-to-text tidak memiliki opsi server UE.

Status lisensi dan langganan

Jika Anda mengaktifkan lisensi Pro atau langganan byphil Cloud, kunci lisensi Anda disimpan secara lokal di perangkat Anda (tidak pernah disinkronkan) dan digunakan untuk memverifikasi status langganan dengan backend kami. Metadata akun/penagihan dasar ditangani oleh pemroses pembayaran dan backend kami; kami tidak menyimpan konten halaman atau riwayat membaca Anda di server kami.

Umpan balik saat uninstal

Saat Anda mencopot pemasangan ekstensi, Chrome akan membuka halaman umpan balik singkat di situs web ini. Alamat tersebut hanya memuat versi ekstensi dan jumlah hari ekstensi terpasang — tanpa pengidentifikasi, tanpa konten halaman, tanpa riwayat. Apa yang Anda pilih atau ketik pada formulir (alasan, komentar opsional) dicatat sebagai peristiwa dalam analitik mandiri (self-hosted) tanpa cookie kami, bersama dengan versi ekstensi dan lama hari terpasang, dan hanya digunakan untuk menyempurnakan ekstensi. Jika browser Anda mengirimkan Do Not Track atau Anda menolak analitik, tidak ada data yang dikirim. Tidak ada kolom email; jika menginginkan tanggapan, silakan buat issue di GitHub. Anda dapat menutup halaman tanpa menjawab.

Hapus semua data menghapus semua yang disimpan ekstensi di perangkat dan memulainya dari awal. Menghapus ekstensi juga akan menghapus datanya. Tindakan ini hanya menghapus data lokal. Akun Anda dan catatan yang kami simpan di server kami (lihat di bawah) dapat Anda kelola di byphil.eu/#account: di sana Anda dapat mengekspor data dan menghapus akun Anda. Ekstensi dan aplikasi Android tertaut ke halaman tersebut dari pengaturan akun.

Feed RSS

Pembaca Feeds bawaan menyimpan langganan dan item feed yang diambil secara lokal di browser Anda — tidak pernah disinkronkan, tidak pernah dikirim ke kami. Saat Anda menambahkan atau memperbarui feed, ekstensi meminta alamat feed tersebut langsung dari server penerbit, persis seperti yang dilakukan browser Anda saat mengunjungi situs tersebut, sehingga penerbit dapat melihat permintaan tersebut. Kami tidak melakukan proksi, mencatat log, atau melihat langganan atau daftar bacaan Anda. Impor OPML diproses sepenuhnya di perangkat Anda. Jika Anda mengaktifkan pemeriksaan latar belakang (nonaktif secara default), ekstensi akan meminta ulang feed Anda pada interval yang Anda pilih, hanya untuk menampilkan jumlah pembaruan pada ikon toolbar. Meringkas item feed berfungsi persis seperti meringkas halaman lainnya: kontennya hanya dikirim ke penyedia AI yang Anda pilih, dan hanya saat Anda memicu pembuatan ringkasan. Rekap harian AI dan penilaian tone AI opsional berfungsi dengan cara yang sama: hanya saat Anda mengekliknya, ekstensi akan mengirimkan judul item, nama sumber, dan cuplikan pendek (bukan artikel lengkap) ke penyedia AI yang Anda pilih, dan ringkasan yang dihasilkan disimpan dalam cache di perangkat Anda. Episode podcast dalam feed di-streaming langsung dari server penerbit saat Anda menekan Putar.

Mengirim artikel: Kindle, LocalSend, dan menu berbagi

Terdapat dua jalur berbeda, dan hanya satu yang terhubung ke server kami:

  • Kirim ke Kindle melewati server kami. Amazon hanya menerima dokumen melalui email dari pengirim yang disetujui, sehingga ekstensi mengirimkan artikel (judul, ringkasan, teks, sorotan, dan alamat sumber) ke backend byphil, yang kemudian mengirimkannya melalui email ke alamat Kindle yang Anda masukkan. Anda perlu menambahkan alamat pengirim kami (kindle@byphil.eu) ke daftar pengirim yang disetujui di akun Amazon Anda. Konten hanya digunakan untuk membuat dan mengirim email tersebut. Pengiriman Kindle memerlukan login akun atau lisensi; paket gratis mencakup 3 kali pengiriman.
  • LocalSend dan menu berbagi sistem (misalnya AirDrop) bersifat langsung. File dikirim langsung dari browser Anda ke perangkat yang Anda pilih di jaringan lokal Anda, atau ke aplikasi yang Anda pilih di menu berbagi. Kami tidak terlibat dan tidak melihat atau menyimpan konten ini. LocalSend dapat digunakan dengan ponsel, tablet, komputer, dan e-reader yang menjalankan aplikasi yang kompatibel.

Library sync, backup, dan publikasi (opsional)

Nonaktif sampai Anda menambahkan lokasi di Pengaturan → Sync & backup. Lokasi dapat berupa folder di server pilihan Anda (Nextcloud atau server WebDAV lainnya, atau bucket yang kompatibel dengan S3 seperti AWS S3, Cloudflare R2, atau Backblaze B2) atau folder di komputer Anda sendiri. Kami tidak mengoperasikan server ini, kami tidak terlibat, dan kami tidak pernah melihat apa yang Anda simpan di sana.

  • Lokasi terenkripsi Sinkronkan seluruh library Anda di semua perangkat atau simpan backup: artikel, ringkasan, teks lengkap, sorotan, catatan, koleksi, dan tag. Semuanya dienkripsi di browser Anda (AES-256-GCM, dengan kunci yang dibuat dari passphrase Anda) sebelum keluar dari perangkat, dan nama file diacak. Server atau folder hanya dapat melihat file terenkripsi, ukuran file, serta waktu perubahannya. Kunci yang dibuat dari passphrase Anda tetap tersimpan di local storage browser ini, sehingga syncing dapat berjalan di background. Jika Anda menggunakan saran kata acak, kata-kata tersebut juga disimpan di sana agar Anda dapat melihatnya di pengaturan; passphrase yang Anda tentukan sendiri tidak akan disimpan. Semua ini tidak pernah di-sync atau menjadi bagian dari backup. Jika Anda kehilangan passphrase, tidak ada yang dapat membaca file tersebut, termasuk kami.
  • Lokasi terbaca publikasikan file biasa (dan, jika Anda mau, halaman viewer kecil) untuk situs web atau alat Anda sendiri. Hanya artikel yang cocok dengan filter tag yang Anda tentukan yang akan dikirim. Catatan, pengingat, dan teks artikel lengkap tidak pernah dipublikasikan kecuali Anda mengaktifkannya sendiri di danger zone, dan siapa pun yang dapat membuka folder tersebut akan dapat membacanya.
  • Cara pengiriman. Permintaan dikirim langsung dari browser Anda ke alamat yang Anda masukkan melalui HTTPS, menggunakan login atau access key yang Anda berikan. Login tersebut disimpan secara lokal, tidak pernah disinkronkan, dan tidak disertakan dalam backup kecuali Anda memilihnya. Operator server dapat melihat alamat IP Anda dan waktu Anda melakukan sinkronisasi.
  • Folder di komputer ini menggunakan akses folder browser. Anda memilih folder dan browser akan meminta izin Anda, yang mungkin diminta kembali setelah restart. Kami hanya menyimpan handle browser ke folder tersebut. Layanan apa pun yang Anda gunakan untuk menyinkronkan folder tersebut ke perangkat lain (Syncthing, iCloud Drive, Dropbox) memiliki ketentuan privasinya sendiri.

Aplikasi AI di komputer Anda (MCP)

Nonaktif secara default. Saat Anda mengaktifkan Pengaturan → Aplikasi AI (MCP), aplikasi AI di komputer yang Anda hubungkan (misalnya Claude Desktop, LM Studio, Cursor, atau VS Code) dapat membaca bagian pustaka yang Anda izinkan: artikel tersimpan beserta ringkasan dan sorotannya, serta—hanya jika Anda mengaktifkannya—teks artikel lengkap, item feed, dan penyimpanan tautan ke inbox Anda. Data dikirim dari browser Anda melalui program helper kecil di komputer Anda (aish-mcp) ke aplikasi tersebut. Data tidak pernah melewati server kami, dan kami tidak pernah melihatnya. Helper hanya menerima koneksi dari komputer Anda sendiri serta memerlukan pairing code; helper tidak menyimpan artikel apa pun dan tidak mencatat data yang diteruskannya. Artikel dengan tag yang Anda kecualikan (private secara default) tidak akan pernah dibagikan. Ekstensi menyimpan daftar 50 panggilan terakhir (tool name, waktu, dan jumlah hasil, tanpa konten) di perangkat Anda, yang dapat Anda lihat di panel pengaturan yang sama. Data yang dikirimkan aplikasi AI ke modelnya bergantung pada aplikasi dan model yang Anda pilih: dengan local model, tidak ada data yang keluar dari komputer Anda. Nonaktifkan pengaturan atau pilih Disconnect kapan saja.

Analitik & cookie

Versi singkat: situs web ini menetapkan tanpa cookie dan tidak menggunakan pelacak iklan atau pelacak lintas-situs. Kami menghitung kunjungan anonim menggunakan instance Matomo mandiri (self-hosted), dan Anda dapat menonaktifkannya kapan saja.

Ekstensi browser itu sendiri tidak mengandung kode analitik, telemetri, atau pelacakan apa pun. Satu-satunya permintaan jaringan yang dikirimkan hanya ditujukan ke penyedia AI yang Anda konfigurasikan, feed langganan Anda, halaman yang Anda minta untuk dimuat, server yang Anda siapkan untuk library sync, backup, atau publikasi, serta (jika Anda menggunakannya) backend byphil untuk byphil Cloud, login, pemeriksaan lisensi, dan Send to Kindle.

Apa yang kami ukur

Tampilan halaman, bahasa halaman, referrer, perkiraan negara/browser/kategori perangkat, dan bagian situs mana yang Anda gunakan untuk berinteraksi (misalnya klik pada "Tambahkan ke Chrome", pengalih harga, item FAQ, bagian yang Anda gulir, dan tahapan generator bookmarklet). Peristiwa tidak pernah memuat alamat email, API key, kode sekali pakai, konten halaman, atau data artikel.

Bagaimana konfigurasinya

Matomo berjalan di server kami sendiri (analytics.philwornath.de, Jerman), bukan di pihak ketiga. Matomo dimuat dengan cookie dinonaktifkan dan tanpa browser fingerprinting; alamat IP dianonimkan sebelum disimpan; tidak ada ID pengguna atau pengidentifikasi lintas-situs yang ditetapkan, sehingga kunjungan tidak dapat ditautkan antarhari atau antarperangkat. Data tidak dijual atau dibagikan dengan pihak ketiga.

Karena tidak ada yang disimpan atau dibaca dari perangkat Anda untuk tujuan pelacakan, pengukuran ini didasarkan pada kepentingan sah kami untuk memahami cara situs ini digunakan (Pasal 6(1)(f) GDPR) dan tidak memerlukan banner persetujuan cookie menurut § 25 TDDDG / ePrivacy Directive. Anda berhak untuk menolak (Pasal 21 GDPR) kapan saja.

Pilihan Anda

Analitik akan dinonaktifkan secara otomatis jika browser Anda mengirimkan Do Not Track atau Global Privacy Control. Anda juga dapat menonaktifkannya secara manual melalui Pengaturan analitik (juga tersedia di footer setiap halaman).

Apa yang disimpan di browser Anda

Hanya preferensi fungsional, tidak pernah untuk pelacakan: aish_analytics (pilihan penolakan analitik Anda), aish_analytics_notice (bahwa Anda telah menutup pemberitahuan informasi), dan, jika digunakan, pilihan tema, penutupan saran bahasa, serta pengaturan generator bookmarklet. Semuanya tetap berada di perangkat Anda dan tidak dikirimkan kepada kami.

Font & sumber daya eksternal

Font (Inter, Space Grotesk, JetBrains Mono; SIL Open Font License) disajikan langsung dari situs ini sendiri, sehingga alamat IP Anda tidak diteruskan ke Google atau penyedia font mana pun hanya karena mengunjungi situs ini. Satu-satunya permintaan eksternal adalah tautan yang Anda klik, dan halaman akun byPhil / checkout Stripe opsional yang Anda pilih untuk dibuka.

Dasar hukum dan retensi data

Hampir semua data diproses di perangkat Anda dan tidak pernah sampai kepada kami. Jika kami memproses data, berikut adalah dasar hukum dan durasi penyimpanannya:

  • Akun dan login (alamat email, kode sekali pakai, kunci lisensi, status paket) — untuk menyediakan akun yang Anda minta, Pasal 6(1)(b) GDPR. Disimpan selama akun masih ada; saat Anda menghapus akun, data ini akan dihapus.
  • byphil Cloud (meneruskan teks yang Anda ringkas, penghitung penggunaan, penggunaan token, permintaan terakhir, model terakhir) — untuk menjalankan layanan, Pasal 6(1)(b). Teks hanya diteruskan (relay) dan tidak disimpan. Metadata penggunaan disimpan selama akun masih ada dan dihapus bersamanya.
  • Kirim ke Kindle (artikel yang Anda kirim, alamat Kindle Anda) — untuk melakukan pengiriman yang Anda picu, Pasal 6(1)(b). Hanya digunakan untuk membuat dan mengirim email tersebut.
  • Pembayaran dan verifikasi lisensi — untuk melaksanakan kontrak dan memenuhi kewajiban akuntansi, Pasal 6(1)(b) dan (c). Catatan penagihan disimpan selama diwajibkan oleh hukum.
  • Analitik situs web dan umpan balik saat uninstal — kepentingan sah kami dalam menyempurnakan situs dan ekstensi, Pasal 6(1)(f). Datanya bersifat anonim (lihat Analitik & cookie).

Anda dapat mengekspor data akun dan menghapus akun Anda kapan saja di byphil.eu/#account. Menghapus akun akan menghapus seluruh data yang tersimpan untuk akun tersebut.

Hal yang Tidak Kami Lakukan

  • Kami tidak menayangkan iklan, dan kami tidak menjual, menyewakan, atau memperdagangkan data Anda kepada pengiklan atau pialang data.
  • Kami tidak mewajibkan pembuatan akun atau login untuk fitur utama apa pun.
  • Kami tidak mencatat log atau menyimpan konten halaman yang Anda ringkas melalui API key Anda sendiri atau model lokal, dan kami tidak pernah melihat apa yang Anda kirimkan melalui LocalSend atau menu berbagi.
  • Kami tidak memiliki akses ke riwayat artikel, sorotan, atau API key yang tersimpan secara lokal — data tersebut tidak pernah keluar dari perangkat Anda kecuali jika Anda mengekspornya secara eksplisit atau menyiapkan lokasi sync, backup, atau publikasi, dan data hanya dikirim ke tujuan yang Anda tentukan.

Layanan Pihak Ketiga

Tergantung pada cara Anda mengonfigurasi ekstensi, konten halaman Anda dapat dikirim ke:

  • OpenAI, Google (Gemini), Mistral AI, atau DeepSeek — hanya jika Anda telah memasukkan API key Anda sendiri untuk penyedia tersebut, dan hanya untuk halaman yang Anda ringkas secara aktif.
  • Backend byphil kami beserta databasenya, keduanya di-host oleh IONOS SE di Jerman — hanya jika Anda masuk (sign in), menggunakan byphil Cloud, atau Send to Kindle.
  • OpenRouter, jalur penghubung byphil Cloud ke model AI, dan penyedia model yang dituju — teks yang Anda ringkas hanya diteruskan ke model yang Anda gunakan, khusus untuk permintaan tersebut saja.
  • Stripe — pengelolaan pembayaran dan langganan, sebagai Merchant of Record.
  • Amazon — jika Anda mengirim artikel ke Kindle Anda, Amazon akan mengirimkannya berdasarkan ketentuan privasi mereka sendiri.
  • Instance Ollama lokal Anda sendiri — bukan pihak ketiga; data tetap berada di komputer Anda.

Kami tidak bertanggung jawab atas praktik privasi penyedia AI pihak ketiga yang Anda pilih untuk dihubungkan. Kami menyarankan Anda untuk meninjau kebijakan mereka sebelum menghubungkan akun.

Anda yang memutuskan model mana yang memproses teks Anda. Baik saat Anda menggunakan API key sendiri maupun byphil Cloud, Anda bebas memilih penyedia dan model di pengaturan, dan Anda bertanggung jawab untuk memeriksa ketentuan penyedia tersebut serta lokasi pemrosesan datanya. OpenRouter, penyedia model di baliknya, dan Amazon dapat memproses data di luar UE/EEA berdasarkan perlindungan mereka sendiri (misalnya klausul kontrak standar); kami tidak mentransfer data Anda ke negara ketiga secara mandiri.

Keamanan Data

Kami menerapkan langkah-langkah teknis yang wajar dan sesuai dengan data yang terlibat — sebagian besar data tersebut bahkan tidak pernah mencapai server kami karena disimpan secara lokal di browser Anda. Komunikasi dengan backend kami (untuk byphil Cloud dan verifikasi lisensi) dienkripsi selama transit. Tidak ada metode transmisi atau penyimpanan yang 100% aman, dan kami tidak dapat menjamin keamanan mutlak, namun kami tidak mengumpulkan lebih dari apa yang diperlukan untuk menyediakan fitur yang dijelaskan.

Privasi Anak

AI Summary Helper tidak ditujukan untuk anak-anak di bawah usia 13 tahun (atau batas usia minimum yang berlaku di wilayah hukum Anda), dan kami tidak dengan sengaja mengumpulkan informasi pribadi dari anak-anak.

Hak-Hak Anda (GDPR / CCPA dan sejenisnya)

Karena hampir semua data Anda disimpan secara lokal di perangkat Anda sendiri, Anda sudah memiliki kendali langsung atas data tersebut — Anda dapat melihat, mengekspor, atau menghapusnya kapan saja melalui Pengaturan ekstensi, atau dengan mencopot pemasangan ekstensi. Untuk setiap data yang kami simpan di server kami (metadata langganan/penagihan byphil Cloud), Anda dapat mengelola dan mengekspornya, serta menghapus akun Anda di byphil.eu/#account, atau hubungi kami di bawah ini.

Anda berhak atas akses (Pasal 15), perbaikan (Pasal 16), penghapusan (Pasal 17), pembatasan pemrosesan (Pasal 18), portabilitas data (Pasal 20), dan penolakan (Pasal 21), serta untuk menarik persetujuan kapan saja.
