Ilustrasi, dibuat oleh AI

Panduan · Oktober 2026

Gunakan library Anda di Claude, LM Studio, dan aplikasi AI lainnya

Aplikasi AI Anda melupakan semua yang telah Anda baca. AI Summary Helper mengingatnya. Hubungkan keduanya di komputer Anda sendiri, dan aplikasi Anda dapat mencari artikel tersimpan, mengutip sorotan, serta mencantumkan sumber Anda.

AI Summary Helper dapat membagikan library Anda dengan aplikasi AI yang mendukung Model Context Protocol (MCP): Claude Desktop, LM Studio, Cursor, VS Code, Jan, dan agen lokal. Aplikasi Anda mengajukan pertanyaan, AI Summary Helper mencarinya di artikel tersimpan Anda, dan jawabannya langsung dikirim kembali ke aplikasi di perangkat Anda.

Fitur ini dinonaktifkan secara default. Tidak ada yang melibatkan server kami: ekstensi dan aplikasi saling berkomunikasi melalui program helper kecil di komputer Anda, aish-mcp, yang tidak menyimpan artikel apa pun dan tidak meneruskan data ke tempat lain.

Pertanyaan yang bisa Anda ajukan

  • Tanyakan bacaan Anda, bukan internet. “Apa saja yang sudah saya simpan tentang AI dan pengawasan? Kelompokkan berdasarkan tema dan beri tahu letak perbedaan pandangan antarartikel.”
  • Tulis berdasarkan sumber Anda sendiri. “Buat draf postingan tentang jejak karbon CO₂ dari AI, dan kutip sorotan saya.”
  • Jawab pertanyaan dari suatu koleksi. “Gunakan koleksi saya tentang inflasi. Jawab pertanyaannya hanya menggunakan sumber tersebut, dan sebutkan informasi apa yang kurang.”
  • Selesaikan daftar simpan-untuk-nanti. “Artikel apa saja yang jatuh tempo minggu ini dari daftar simpan-untuk-nanti saya? Berikan rangkuman 5 menit untuk masing-masing artikel.”
  • Sortir feed Anda. “Periksa feed hari ini yang belum dibaca tentang AI dan pilihkan tiga yang paling layak dibaca.”
  • Lihat kilas balik tahunan Anda. “Buat kilas balik bacaan saya tahun 2026: topik teratas, bulan tersibuk, dan artikel-artikel paling berkesan.”
  • Biarkan agen AI menyimpan untuk Anda. “Cari tiga sumber bagus tentang software local-first dan simpan ke inbox AISH saya lengkap dengan catatan.”

Dengan model lokal di LM Studio, semua ini berfungsi bahkan saat internet Anda mati.

Cara penyiapan

Anda memerlukan AI Summary Helper di Chrome, Edge, atau Brave, Node.js 20 atau yang lebih baru, dan sebuah aplikasi MCP.

  1. Aktifkan fiturnya. Di AI Summary Helper, buka Pengaturan → Aplikasi AI (MCP) dan aktifkan Izinkan aplikasi AI di komputer ini menggunakan library saya.
  2. Dapatkan kode penyandingan Anda. Di terminal, jalankan npx -y aish-mcp pair. Perintah ini akan menampilkan kode penyandingan (pairing code) dan menyimpannya di folder pengguna Anda. Tempel kode tersebut ke panel pengaturan dan pilih Sambungkan.
  3. Tambahkan AI Summary Helper ke aplikasi Anda. Gunakan cuplikan kode untuk aplikasi Anda di bawah ini, lalu tutup aplikasi sepenuhnya dan buka kembali.
  4. Periksa koneksi. Panel pengaturan akan menampilkan status Tersambung setelah aplikasi Anda berjalan. Tanyakan sesuatu ke aplikasi AI Anda tentang library Anda: setiap panggilan yang dilakukan akan muncul di bagian Aktivitas terbaru pada panel.

Claude Desktop

Settings → Developer → Edit Config, lalu tambahkan:

{
  "mcpServers": {
    "aish": { "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

Jika Claude Desktop tidak dapat menemukan npx, gunakan path lengkapnya, yang dapat dilihat dengan which npx di terminal (misalnya /opt/homebrew/bin/npx).

Cursor

Di ~/.cursor/mcp.json (semua proyek) atau .cursor/mcp.json (satu proyek), tambahkan entri "aish" yang sama seperti untuk Claude Desktop.

VS Code

Di .vscode/mcp.json:

{
  "servers": {
    "aish": { "type": "stdio", "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

LM Studio dan aplikasi lainnya

Aplikasi dengan pengaturan mcpServers (milik LM Studio berupa mcp.json, Jan, dan sebagian besar lainnya) menggunakan entri yang sama seperti Claude Desktop. Aplikasi yang hanya terhubung melalui HTTP dapat menggunakan npx -y aish-mcp --http di http://127.0.0.1:47616/, dengan header Authorization: Bearer <your pairing code>. Untuk model lokal, pilih model yang mendukung tool calling, seperti Qwen 3 atau Llama 3.1 dan yang lebih baru.

Aplikasi Anda tidak dapat mengedit atau menghapus apa pun di AI Summary Helper.

Privasi dan keamanan

  • Tidak ada yang melewati server kami. Data berpindah dari browser Anda ke program helper dan diteruskan ke aplikasi di komputer Anda. Apa yang kemudian dikirimkan aplikasi ke modelnya bergantung pada aplikasi dan model yang Anda pilih. Model lokal menjaga semua data tetap berada di perangkat Anda.
  • Artikel yang Anda beri tag private tidak akan pernah muncul, di hasil, hitungan, maupun koleksi apa pun. Anda dapat memilih tag yang berbeda di panel pengaturan.
  • Hanya komputer Anda yang dapat terhubung. Program helper hanya mendengarkan di 127.0.0.1, sehingga tidak ada perangkat lain di jaringan Anda yang dapat mengaksesnya. Situs web yang Anda kunjungi juga tidak dapat menggunakannya: program ini hanya menerima alamat ekstensi AI Summary Helper sendiri, dan setiap koneksi wajib menyertakan kode penyandingan Anda.
  • Anda dapat memantau setiap panggilan. Panel pengaturan mencantumkan 50 panggilan terakhir beserta nama tool dan waktunya, tanpa pernah menampilkan kontennya.
  • Anda dapat memutus koneksi kapan saja. Nonaktifkan fitur ini atau pilih Putuskan sambungan. Jalankan npx -y aish-mcp reset agar kode penyandingan lama tidak dapat digunakan lagi.
  • Halaman tersimpan adalah teks dari web. Aplikasi Anda diinstruksikan untuk memperlakukannya sebagai informasi, bukan sebagai instruksi, tetapi halaman yang disimpan tetap berpotensi mengecoh AI. Biarkan izin Simpan tautan dinonaktifkan kecuali Anda memang memerlukannya.
