API Key Anda. Model Anda. Data Anda.

Sebagian besar alat AI menempatkan server perantara antara Anda dan model. Inilah yang terjadi jika tidak ada server perantara, dan apa yang tetap berada di bawah kendali Anda.

Setiap ringkasan AI memiliki pola yang sama: teks dikirim, ringkasan diterima. Pertanyaan kunci untuk menentukan seberapa aman alat tersebut adalah siapa pihak perantara di baliknya. Pada banyak produk, ada server perusahaan yang menjadi perantara, dan apa yang Anda baca melewatinya sebelum sampai ke model yang bahkan tidak Anda pilih sendiri.

Arti “bring your own key” di sini

Anda membuat API key dari provider pilihan Anda, menempelkannya ke AI Summary Helper, lalu memilih model. Saat Anda meringkas halaman, background worker ekstensi langsung mengirimkan teks ke provider tersebut dan menerima balasannya secara streaming. Tidak ada server AI Summary Helper sebagai perantara saat menggunakan API key Anda sendiri.

Anda juga dapat menghubungkannya ke model yang berjalan secara lokal di perangkat Anda, misalnya melalui Ollama. Dengan begitu, teks halaman tidak akan pernah keluar dari komputer Anda sama sekali.

Di mana API key Anda disimpan

API key disimpan di local extension storage pada browser Anda, bukan di synced storage. Artinya, key tidak akan disinkronkan ke perangkat lain melalui akun browser Anda. Konsekuensinya, Anda cukup memasukkannya sekali di setiap browser. API key hanya digunakan untuk berkomunikasi langsung dengan provider yang Anda atur.

Hal yang terlindungi dan tidak terlindungi

Penting untuk dipahami dengan jelas. Menggunakan API key sendiri menghilangkan pihak perantara. Namun, ini tidak menghilangkan provider model: apa pun yang Anda kirim ke hosted model tetap tunduk pada ketentuan dan kebijakan retensi provider tersebut, jadi pastikan Anda membacanya. Hanya local model yang benar-benar menjaga data tetap sepenuhnya di perangkat Anda secara offline, meskipun local model biasanya lebih kecil dan lebih lambat dibanding hosted model.

Proyek ini bersifat open source, sehingga Anda tidak perlu percaya begitu saja. Kode yang mengelola API key dan request tersedia di repository dan bebas untuk Anda periksa.

Memilih setup

  1. Bacaan sehari-hari: hosted model dari provider dengan ketentuan yang Anda setujui. Cepat, berkualitas tinggi, dan API key tetap dalam kendali penuh Anda.
  2. Materi sensitif: local model. Lebih lambat dan kemampuannya terbatas, tetapi data sama sekali tidak meninggalkan komputer Anda.
  3. Eksperimen: tambahkan lebih dari satu provider dan bandingkan hasilnya pada artikel yang sama. Ini cara tercepat untuk menemukan model yang paling cocok untuk berbagai jenis teks.

Intinya bukan setup mana yang paling tepat, melainkan kendali penuh tetap berada di tangan Anda.
