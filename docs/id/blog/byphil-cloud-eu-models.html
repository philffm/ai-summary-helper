Ilustrasi, dibuat oleh AI

Produk · November 2026

byPhil Cloud kini berbahasa UE: satu sakelar, label yang jujur

Layanan terhosting opsional kini bisa mengirim permintaan Anda hanya ke endpoint UE, dan pemilih model memberi tahu model mana yang berasal dari perusahaan UE dan mana yang sekadar berjalan di wilayah UE.

Ringkasnya. Jika Anda memakai byPhil Cloud, kini Anda bisa mengaktifkan Utamakan server UE. Permintaan lalu hanya menuju endpoint UE milik penyedia model, tanpa cadangan ke tempat lain. Pemilih model menandai setiap model sebagai Perusahaan UE atau Server UE, dan tersedia preset Otomatis sekali klik untuk tiap penyedia. Ini kemudahan dengan opsi UE, bukan klaim bahwa layanannya sepenuhnya berdaulat. Tulisan ini menjelaskan perbedaannya.

Apa yang berubah

byPhil Cloud adalah cara terhosting yang opsional untuk memakai AI Summary Helper: sudah termasuk dalam akun byPhil Anda, jadi tidak perlu kunci API. Sebelumnya Anda memilih model dan perutean mengambil yang termurah dan tercepat. Kini pemilih model punya mode UE dan tata letak yang lebih jelas:

  • Satu sakelar. Dengan Utamakan server UE aktif, permintaan dikunci ke endpoint UE milik penyedia model. Jika sebuah model tidak punya rute UE, permintaan tidak diam-diam dikirim ke tempat lain.
  • Preset Auto. Otomatis, Auto · Mistral, Auto · Google, Auto · DeepSeek, Auto · Anthropic dan Auto · OpenAI memilihkan model yang sesuai untuk Anda. Saat sakelar UE aktif, hanya model yang punya rute UE yang dipilih.
  • Dua jenis lencana. Perusahaan UE berarti penyedianya berkedudukan di Eropa (Mistral, di Paris). Server UE berarti perusahaan dari tempat lain menjalankan model di wilayah UE.
  • Pencarian dan yang terbaru. Model yang baru Anda pakai ada di atas, dan kotak pencarian menemukan model cloud apa pun. Model tanpa rute UE tetap bisa dipilih tetapi diberi tanda, sehingga Anda tidak pernah beralih tanpa sengaja.

Pemilih model berada di tempat yang sama dengan dua cara lain menjangkau model, kunci Anda sendiri dan model Ollama lokal, jadi berubah pikiran cukup sekali klik (perbandingan ketiganya).

Perusahaan UE dan server UE bukan hal yang sama

Inilah bagian yang dikaburkan kebanyakan halaman produk. Sebuah model bisa secara fisik berada di Eropa dan tetap milik perusahaan yang tunduk pada hukum AS. CLOUD Act AS memungkinkan otoritas AS mewajibkan penyedia berbasis AS menyerahkan data yang mereka kuasai, di mana pun disimpan; kesesuaiannya dengan GDPR masih diperdebatkan (latar belakang hukumnya, beserta sumber). Karena itu kami melabeli kedua kasus secara terpisah, dan Anda yang menentukan mana yang penting untuk bacaan Anda.

  • Perusahaan UE: tunduk pada hukum UE dan nasional. Cocok jika yang Anda khawatirkan adalah yurisdiksi.
  • Server UE: teks Anda tetap di UE selama diproses. Cocok jika yang Anda khawatirkan adalah lokasi data, dan Anda bisa memakai model lebih kuat yang bukan buatan Eropa.

Keduanya bukan jaminan. Penyedia, kemitraan, dan investor berubah, jadi periksa ketentuan terbaru penyedia.

Yang tidak dilakukan

Jelas soal batasan lebih penting daripada cerita yang rapi:

  • Layanan terhosting menjalankan server dan basis datanya di IONOS di Jerman. Teks Anda lalu diteruskan ke penyedia model lewat OpenRouter, perusahaan AS. Sakelar UE mengunci tempat model berjalan. Ia tidak mengubah siapa perusahaannya.
  • Jika Anda butuh pengaturan paling kuat, pakai kunci sendiri pada penyedia yang Anda percaya, atau model lokal dengan Ollama, sehingga teks halaman tidak pernah meninggalkan komputer Anda.
  • Model tidak setara. Model Eropa adalah pilihan wajar untuk bacaan sehari-hari, tetapi jika Anda butuh kualitas terbaik, model AS dengan rute UE mungkin lebih tepat. Pertimbangan itu milik Anda, dan itulah gunanya pemilih model.

Mengapa kami membuatnya begini

Kedaulatan bukan soal memiliki model terbaik. Model terus membaik serta berganti pemilik, harga, dan ketentuan. Yang melindungi Anda adalah kemampuan beralih: dari satu model ke model lain, dari cloud ke kunci sendiri, dari kunci sendiri ke model lokal, tanpa kehilangan pustaka atau belajar ulang alatnya. Artikel, ringkasan, dan sorotan Anda bagaimanapun tetap di perangkat Anda (kebijakan privasi); pemilih model hanya menentukan siapa yang membaca teks halaman yang Anda tanyakan.

Jadi mode UE adalah satu anak tangga lagi, bukan tujuan akhir. Ia membuat pilihan paling mudah, tanpa kunci dan tanpa pengaturan, sedikit lebih hati-hati soal ke mana teks Anda pergi.

Cara mengaktifkannya

  1. Buka pemilih model di AI Summary Helper dan pilih byPhil Cloud.
  2. Aktifkan Utamakan server UE di pengaturan.
  3. Pilih model dengan lencana Perusahaan UE atau Server UE , atau pilih preset Otomatis .

Terkait: Kedaulatan digital untuk individu dan API key Anda. Model Anda. Data Anda.

Pertanyaan yang Sering Diajukan

Apakah saya perlu kunci API untuk byPhil Cloud?

Tidak. Sudah termasuk dalam akun byPhil Anda. Jika mau, Anda tetap bisa memakai kunci sendiri atau model lokal.

Apakah byPhil Cloud pilihan yang berdaulat?

Tidak, dan kami tidak menyebutnya begitu. Ia berjalan di Jerman tetapi menjangkau model lewat OpenRouter, perusahaan AS. Untuk kendali terbesar, pakai kunci sendiri atau model lokal.

Apa yang terjadi jika model tidak punya rute UE?

Model tetap bisa dipilih tetapi diberi tanda. Saat sakelar UE aktif, Otomatis tidak pernah memilihnya dan permintaan tidak dialihkan ke luar UE.

Mana yang sebaiknya saya pilih, perusahaan UE atau server UE?

Pilih perusahaan UE jika yurisdiksi paling penting bagi Anda. Pilih server UE jika Anda ingin data tetap di UE tetapi butuh model yang lebih kuat.

AI Summary Helper adalah ekstensi browser gratis bersumber terbuka. Bawa kunci sendiri, jalankan model lokal, atau gunakan byPhil Cloud.
