Cara Menyinkronkan Reading Library ke Nextcloud, S3, atau Folder Lokal secara Terenkripsi

Artikel tersimpan, ringkasan, sorotan, dan catatan Anda di semua komputer, tersimpan di tempat yang Anda tentukan, hanya bisa dibaca dengan kunci Anda. Sepuluh menit, tanpa perlu akun di layanan kami.

Ringkasan singkat. Di AI Summary Helper, buka Settings → Sync & backup → Add a place, pilih Nextcloud/WebDAV, penyimpanan yang kompatibel dengan S3, atau folder di komputer Anda, lalu simpan passphrase yang disarankan. Semuanya dienkripsi di browser Anda sebelum diunggah. Di komputer kedua, tambahkan lokasi yang sama dan masukkan passphrase. Hanya itu pengaturannya. Sisa halaman ini membahas setiap jenis penyimpanan, apa saja yang disinkronkan, dan apa yang harus dilakukan jika terjadi kendala.

Mengapa melakukan ini? Karena reading library layak disimpan, dan alat yang Anda andalkan bisa saja hilang kapan saja (selengkapnya di sini). Menyinkronkan ke penyimpanan milik Anda sendiri memastikan library tetap bertahan melampaui aplikasi atau akun apa pun.

Apa yang disinkronkan, dan apa yang tidak

  • Disinkronkan: artikel yang disimpan beserta teks lengkap dan ringkasannya, tag, sorotan (highlights), catatan dan komentar Anda, serta koleksi.
  • Tidak disinkronkan: kunci API Anda, detail masuk (sign-in), kredensial sinkronisasi itu sendiri, dan pengaturan per perangkat. Pencadangan dan sinkronisasi sengaja mengecualikan data tersebut.
  • Satu artikel per halaman: jika Anda menyimpan halaman yang sama di dua komputer, hasilnya akan menjadi satu artikel (tag dan kolom yang belum terisi akan digabungkan).
  • Pengeditan digabungkan kolom demi kolom: judul yang diubah di satu komputer dan tag yang ditambahkan di komputer lain akan tetap dipertahankan. Jika keduanya mengubah kolom yang sama, perubahan terbaru yang akan dipakai di setiap perangkat.

Langkah 1: pilih tempat penyimpanan

Nextcloud atau server WebDAV lainnya

Paling cocok jika Anda sudah menjalankan Nextcloud atau menggunakan Nextcloud terkelola (banyak penyedia layanan menawarkannya). Anda memerlukan tiga hal:

  1. Alamat file Anda. Untuk Nextcloud, formatnya seperti https://your-server/remote.php/dav/files/your-username/. Di Nextcloud, buka Files → Settings dan salin alamat WebDAV yang tertera di sana.
  2. Nama pengguna (username) Anda.
  3. Kata sandi aplikasi (app password), bukan kata sandi utama Anda. Di Nextcloud: Settings → Security → Devices & sessions → create a new app password. Jika suatu saat Anda ingin mencabut akses, Anda cukup menghapus entri tersebut.

Pilih nama folder seperti aish-sync. Folder ini akan dibuatkan otomatis untuk Anda. Server WebDAV lainnya (banyak perangkat NAS, ownCloud) bekerja dengan cara yang sama; hanya format alamatnya yang berbeda.

Bucket yang kompatibel dengan S3

Pilihan terbaik jika Anda lebih memilih object storage: AWS S3, Cloudflare R2, Backblaze B2, MinIO, dan sejenisnya. Buat bucket, lalu buat access key khusus untuk bucket ini dengan izin membaca (read), menulis (write), melihat daftar (list), dan menghapus (delete) di dalamnya. Jangan pernah menggunakan access key utama akun Anda. Di ekstensi, masukkan alamat endpoint (misalnya https://s3.eu-central-1.amazonaws.com, atau alamat yang diberikan penyedia layanan Anda), nama bucket, wilayah (region — biarkan default jika penyedia Anda tidak memintanya), Access Key ID, dan Secret Key.

Folder di komputer Anda

Paling cocok jika Anda sudah menggunakan alat lain untuk menyinkronkan folder antarperangkat: Syncthing, desktop sync client, iCloud Drive, atau flashdisk/USB drive. Pilih Folder di komputer ini dan pilih folder baru yang masih kosong milik Anda, misalnya Documents/AISH-sync. Chrome tidak mengizinkan folder Desktop, Documents, atau Downloads utama untuk hal ini, jadi pilih subfolder. Cara ini berfungsi di Chrome dan Edge pada komputer. Dua hal yang perlu diketahui: browser mungkin meminta izin akses lagi setelah dimulai ulang (layar pengaturan menyediakan tombol untuk ini), dan folder hanya akan terus disinkronkan saat browser sedang berjalan.

Langkah 2: pilih terenkripsi, dan simpan kata-katanya

Saat Anda menambahkan lokasi, Encrypted dipilih secara default dan Sync my devices adalah tujuannya. Ekstensi akan menyarankan enam kata acak sebagai passphrase Anda. Anda dapat menekan Another suggestion hingga Anda menemukan kombinasi yang cocok, atau gunakan passphrase Anda sendiri (minimal 12 karakter, disertai petunjuk jika terlalu lemah).

Setelah terhubung, Anda akan melihat enam kata tersebut sekali. Simpan di password manager; tombol Salin (Copy) akan menyalinnya ke papan klip sekaligus dengan tanda hubung, sehingga aman untuk file konfigurasi dan aplikasi chat. Dengan kata-kata ini Anda bisa membuka lokasi tersebut di perangkat apa pun; tanpanya, tidak ada yang bisa membaca file tersebut, termasuk kami. Di komputer tempat Anda mengaturnya, Anda dapat melihatnya kembali di pengaturan lokasi, Show passphrase. Jika Anda memilih passphrase sendiri, passphrase tersebut tidak disimpan di mana pun, sehingga ekstensi tidak dapat menampilkannya kembali.

Apa yang dilihat oleh penyedia penyimpanan: file teracak dengan nama teracak, jumlah file, ukuran file, dan waktu perubahannya. Penyedia tidak dapat melihat judul, tautan, atau teks Anda. Library Anda dienkripsi di browser dengan AES-256-GCM sebelum keluar dari perangkat.

Langkah 3: tambahkan komputer kedua Anda

  1. Pasang ekstensi dan buka Settings → Sync & backup → Add a place.
  2. Masukkan detail server yang sama (atau pilih folder yang sama).
  3. Ekstensi akan mendeteksi bahwa folder tersebut sudah berisi library terenkripsi dan meminta passphrase. Anda dapat mengetik kata-kata tersebut dengan huruf besar/kecil bebas, menggunakan spasi atau tanda hubung.
  4. Ekstensi akan meminta konfirmasi bahwa Anda telah mencadangkan perangkat ini terlebih dahulu, karena proses ini akan menggabungkan library komputer ini dengan yang ada di folder, dan jika ada perbedaan, versi di folder yang akan diutamakan. Gunakan Make a backup now.
  5. Tekan Connect. Sinkronisasi pertama mungkin memerlukan waktu beberapa saat untuk library berukuran besar; layar akan menampilkan progresnya.

Hanya pencadangan (backup only), pemulihan, dan publikasi

  • Backup only. Pilih Backup only alih-alih Sync my devices dan komputer hanya akan menulis data ke lokasi tersebut tanpa pernah membaca darinya. Lakukan pemulihan (restore) dari pengaturan lokasi saat Anda membutuhkannya: ini akan memulihkan semuanya, dan jika ada perbedaan dengan komputer ini, data di lokasi penyimpanan yang akan diutamakan. Tidak ada yang akan dihapus.
  • Publikasikan ke situs web Anda. Jenis lokasi penyimpanan lain, Readable, menulis file teks biasa untuk situs web Anda sendiri, hanya untuk artikel yang Anda beri tag, dilengkapi halaman viewer opsional. Catatan dan teks lengkap tidak akan disertakan kecuali Anda mengaktifkannya, karena siapa pun yang dapat membuka folder tersebut dapat membacanya. Jangan gunakan lokasi jenis ini untuk data pribadi.

Jika terjadi kendala

"Izinkan akses ke folder lagi"

Browser mencabut akses folder setelah dimulai ulang. Tekan tombol di bagian atas Sync & backup. Jika terus gagal, folder tersebut mungkin termasuk yang dilindungi oleh Chrome (Desktop, Documents, Downloads, atau home folder Anda): pilih subfolder yang Anda buat sendiri.

"Server tidak menerima nama pengguna dan kata sandi"

Untuk Nextcloud, gunakan kata sandi aplikasi (app password). Pastikan alamat diakhiri dengan folder nama pengguna Anda dan verifikasi dua langkah (2FA) tidak memblokir kata sandi aplikasi.

"Passphrase salah"

Periksa kembali kata-katanya: huruf besar/kecil, spasi, dan tanda hubung tidak berpengaruh, tetapi setiap kata harus benar. Pada komputer yang sudah diatur, buka pengaturan lokasi dan tekan Show passphrase. Jika Anda kehilangan passphrase di semua tempat, file tersebut tidak dapat dibuka oleh siapa pun: hapus lokasi di sini, buat lokasi baru, dan mulai ulang dari library di komputer Anda.

Banyak penghapusan data yang tertunda

Jika perangkat lain menghapus banyak artikel sekaligus, ekstensi akan menerapkan beberapa artikel terlebih dahulu dan meminta konfirmasi sebelum melanjutkan sisanya, agar kesalahan tidak mengosongkan seluruh library Anda. Periksa, lalu tekan tombol untuk menerapkannya.

Komputer tidak terhubung selama berbulan-bulan

Setelah sekitar tiga bulan, komputer hanya akan mengirimkan perubahan terbaru dan tidak menghapus apa pun secara otomatis, sehingga artikel lama yang telah dihapus di perangkat lain tidak akan muncul kembali secara tidak sengaja.

Pertanyaan

Apakah saya memerlukan akun di layanan Anda?

Tidak. Sinkronisasi berkomunikasi langsung dari browser Anda ke penyimpanan yang Anda masukkan. Kami tidak mengoperasikan server sinkronisasi.

Apakah ini berfungsi di ponsel saya?

Di Android, ya. Aplikasi pendamping (file APK dari rilisan GitHub; belum tersedia di Google Play) dapat bergabung dengan library Anda di Settings → Library sync. Cara tercepat adalah dengan kode: di browser, buka pengaturan lokasi Anda, tekan Show code for the phone dan pindai kodenya. Kode ini memuat detail login server Anda, jadi hanya pindai dengan ponsel pribadi Anda. Ponsel akan menampilkan artikel tersimpan beserta ringkasan dan sorotannya, dan catatan disinkronkan dua arah. Halaman yang Anda ringkas di ponsel, serta bagian yang Anda tandai di sana, juga akan masuk ke library Anda, tetapi hanya untuk halaman yang belum ada di dalamnya: teks di browser tidak akan pernah ditimpa. Saat ini belum tersedia aplikasi untuk iPhone.

Bisakah saya menggunakan lebih dari satu lokasi penyimpanan?

Bisa. Pengaturan yang umum adalah satu lokasi terenkripsi untuk sinkronisasi antar-komputer dan satu lokasi khusus pencadangan (backup-only) di penyedia layanan yang berbeda.

Apakah aman menyimpan library saya di cloud?

Lebih aman dibandingkan kebanyakan pengaturan, karena penyedia layanan hanya menyimpan file terenkripsi. Keamanannya tetap bergantung pada kekuatan passphrase dan keamanan perangkat Anda. Baca batasan dan penjelasannya secara transparan, termasuk penjelasan bahwa enkripsi ini belum diaudit secara independen.
