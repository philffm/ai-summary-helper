개인정보 처리방침

API 키, 아티클 기록, 하이라이트는 사용자의 기기에만 보관됩니다. 페이지 콘텐츠는 사용자가 선택한 AI 제공자에게만 전송되며, 완전한 로컬 모델을 선택할 경우 어떤 데이터도 기기 밖으로 나가지 않습니다.

최종 수정일: 2026년 8월

본 개인정보 처리방침은 AI Summary Helper가 처리하는 데이터의 종류와 저장 위치, 처리 목적을 설명합니다. 요약하자면, API 키, 아티클 기록, 하이라이트는 사용자의 기기에만 안전하게 보관됩니다. 페이지 콘텐츠는 사용자가 직접 선택한 AI 제공자에게만 전송되며, 완전한 로컬 모델을 선택하면 데이터가 외부로 일절 전송되지 않습니다. 본 서비스는 광고를 게재하지 않고, 데이터를 판매하지 않으며, 핵심 기능을 이용할 때 별도의 계정을 요구하지 않습니다.

본 정책의 내용에 동의하지 않으시는 경우 확장 프로그램을 설치하거나 사용하지 마시기 바랍니다.

계정 가입 불필요

AI Summary Helper는 핵심 기능을 사용하기 위해 계정을 생성하거나 로그인하고, 개인정보를 제공할 필요가 없습니다. 사용자의 API 키(직접 등록한 경우)와 전체 아티클 기록은 브라우저의 로컬 스토리지에만 저장됩니다.

처리하는 데이터 및 데이터 전송 위치

AI 서비스 연결 방식

요약 생성 방식을 직접 선택할 수 있습니다:

  • 개인 API 키 직접 사용 (BYOK) — OpenAI, Google Gemini, Mistral AI, DeepSeek 또는 커스텀 엔드포인트를 지원합니다. API 키는 사용자의 기기 로컬에만 저장되며, 동기화되거나 당사 서버로 전송되지 않습니다. 요약하도록 선택한 페이지 콘텐츠는 본인의 API 키를 사용하여 브라우저에서 해당 AI 제공업체로 직접 전송되며, 해당 제공업체의 개인정보 처리방침을 따릅니다. 당사는 이 콘텐츠를 확인하거나 기록(로그), 저장하지 않습니다.
  • Ollama를 통한 로컬 모델 — 로컬에서 직접 AI 모델을 실행할 경우, 페이지 콘텐츠는 사용자 본인의 컴퓨터로만 전송됩니다. 어떤 데이터도 기기 외부로 나가지 않습니다.
  • byphil Cloud (선택형 유료 플랜) — API 키를 직접 관리하지 않고 간편하게 이용하고자 하는 사용자를 위한 호스팅 옵션입니다. 이 요금제를 선택하면 페이지 콘텐츠가 당사 백엔드로 전송되며, 백엔드가 사용자를 대신해 모델 제공업체에 요청을 전달하고 요약 결과를 반환합니다. 이 방식으로 처리된 페이지 콘텐츠는 영구 저장되지 않습니다.

라이선스 및 구독 상태

Pro 라이선스 또는 byphil Cloud 구독을 활성화하면 라이선스 키가 기기 로컬에 저장되며(동기화되지 않음), 백엔드를 통해 구독 상태를 확인하는 데 사용됩니다. 기본적인 계정 및 결제 메타데이터는 결제 대행사와 백엔드에서 처리하며, 사용자의 페이지 콘텐츠나 읽기 기록은 당사 서버에 일절 저장하지 않습니다.

아티클 기록, 하이라이트 및 설정

저장된 모든 정보는 당사 서버가 아닌 Chrome의 내장 스토리지 API를 통해 브라우저 로컬에 저장됩니다:

"동기화 (Sync)"로 표시된 항목은 사용자의 Google 계정과 연결된 Chrome 자체 동기화 기능을 사용합니다. 이 데이터는 북마크와 마찬가지로 당사가 아닌 Google의 인프라를 거쳐 처리되며, 당사는 이에 접근할 수 없습니다.

설정 → 백업 및 복원 메뉴를 이용하거나 확장 프로그램을 삭제하여 언제든지 전체 로컬 기록을 내보내거나 삭제할 수 있습니다.

Kindle, AirDrop 및 LocalSend

Kindle, AirDrop 또는 LocalSend 호환 기기로 아티클을 전송할 때 변환된 파일은 브라우저에서 선택한 목적지로 직접 전송됩니다. 당사는 중개 역할을 하지 않으며 해당 콘텐츠를 열람하거나 저장하지 않습니다.

통계 및 분석 (Analytics)

확장 프로그램의 사용 편의성을 개선하기 위해 개인정보를 존중하고 GDPR을 준수하는 통계 플랫폼인 Matomo를 사용하여 익명의 집계된 사용 패턴을 분석합니다. Matomo는 사이트 전반에 걸쳐 사용자를 개별적으로 추적하지 않으며 데이터를 판매하지 않습니다. 분석 이벤트에는 페이지 콘텐츠, API 키, 아티클 데이터가 일절 포함되지 않습니다.

쿠키를 사용하지 않습니다. 저희 Matomo 트래킹은 다음과 같이 실행되도록 설정되어 있습니다 쿠키 없이: 트래커는 쿠키 지원이 비활성화된 상태로 로드되므로 쿠키를 생성, 조회, 저장하지 않으며 방문이나 기기 간에 사용자를 식별하려고 시도하지도 않습니다. 쿠키를 전혀 사용하지 않으므로, 이 분석 방식은 EU ePrivacy 지침 및 GDPR에 따른 별도의 동의 배너가 필요하지 않습니다. 이는 오직 본 웹사이트의 총 페이지 뷰와 기능 사용량만을 측정하는 정당한 이익 기반의 개인정보 보호 친화적인 측정 방식입니다.

분석 이벤트는 페이지 뷰, 현재 보고 있는 언어, 상호작용하는 기능(예: 북마클릿 생성 또는 제공업체 선택)과 같은 비개인적이고 집계된 데이터로만 제한됩니다. 이 데이터로는 개인을 식별할 수 없으며, 위에서 설명한 로컬에 저장된 아티클 데이터와 결합되는 일도 절대 없습니다.

당사는 이러한 권한을 브라우징 활동 추적, 광고 프로필 생성, 또는 위에서 설명한 기능 제공 목적 이외의 데이터 수집에 절대 사용하지 않습니다.

수행하지 않는 행위

  • 광고를 게재하거나 노출하지 않으며, 광고주나 데이터 브로커에게 사용자 데이터를 판매, 대여 또는 거래하지 않습니다.
  • 어떤 핵심 기능에도 계정 생성이나 로그인을 요구하지 않습니다.
  • 사용자 본인의 API 키나 로컬 모델을 통해 요약된 페이지 콘텐츠를 기록(로그)하거나 보관하지 않습니다.
  • 기기 로컬에 저장된 아티클 기록, 하이라이트, API 키에 접근하지 않습니다. 사용자가 직접 내보내기를 하지 않는 한 데이터는 기기 밖으로 나가지 않습니다.

타사 서비스 (Third-Party Services)

확장 프로그램 설정에 따라 페이지 콘텐츠가 다음 대상으로 전송될 수 있습니다:

  • OpenAI, Google (Gemini), Mistral AI 또는 DeepSeek — 해당 제공업체의 자체 API 키를 입력하고 활성 페이지의 요약을 직접 실행한 경우에만 해당합니다.
  • byphil Cloud 백엔드 — 해당 요금제 옵션을 선택하여 이용하는 경우에만 해당합니다.
  • 사용자의 로컬 Ollama 인스턴스 — 타사 서비스가 아니며 모든 데이터는 사용자의 컴퓨터 내에만 유지됩니다.

당사는 사용자가 연결하기로 선택한 타사 AI 제공업체의 개인정보 보호 관행에 대해 책임을 지지 않습니다. 계정을 연결하기 전에 해당 업체의 개인정보 처리방침을 검토해 보시기 바랍니다.

데이터 보안

대부분의 데이터는 브라우저 로컬에 저장되어 애초에 당사 서버로 전송되지 않으며, 취급하는 데이터에 적합한 합리적인 기술적 조치를 적용하고 있습니다. 백엔드와의 통신(byphil Cloud 및 라이선스 확인)은 전송 중 암호화됩니다. 완벽하게 안전한 전송이나 저장 방법은 없으므로 절대적인 보안을 보장할 수는 없지만, 설명된 기능을 제공하는 데 필요한 것 이상의 데이터를 수집하지 않습니다.

아동 개인정보 보호

AI Summary Helper는 만 14세 미만(또는 해당 국가의 법정 최소 연령 미만) 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

이용자의 권리 (GDPR, CCPA 등)

거의 모든 데이터가 기기 로컬에 저장되므로, 사용자는 데이터에 대한 직접적인 제어권을 갖습니다. 확장 프로그램의 설정을 통해 언제든지 데이터를 확인, 내보내기 또는 삭제할 수 있으며, 확장 프로그램을 제거하여 삭제할 수도 있습니다. 당사 서버에 보관된 데이터(byphil Cloud 구독/결제 메타데이터)의 경우 아래 연락처로 접근, 정정 또는 삭제를 요청하실 수 있습니다.

개인정보 처리방침의 변경

확장 프로그램의 기능 변경에 따라 본 개인정보 처리방침이 업데이트될 수 있습니다. 중요한 변경 사항이 있는 경우 최신 "최종 수정일"과 함께 본 페이지에 공지됩니다. 변경 이후에도 확장 프로그램을 계속 사용하시면 수정된 정책에 동의하는 것으로 간주됩니다.
