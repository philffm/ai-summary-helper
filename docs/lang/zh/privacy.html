隐私政策

隐私政策

您的 API key、文章历史记录和高亮标注均保留在您的设备本地。页面内容仅会发送给您所选择的 AI 服务提供商 —— 如果您选择完全本地运行的模型，数据将绝不离开您的设备。

最后更新时间：2026 年 8 月

本隐私政策说明了 AI Summary Helper 处理哪些数据、数据流向以及处理原因。简而言之：您的 API key、文章历史记录和高亮标注均保留在您的本地设备上。页面内容仅会发送给您选择连接的 AI 服务商；如果您选用完全本地运行的模型，则任何数据都不会离开您的电脑。我们不投放广告、不转售数据，且无需注册账户即可使用所有核心功能。

如果您不同意本政策的任何内容，请勿安装或使用本扩展程序。

无需注册账户

使用 AI Summary Helper 的核心功能无需创建账户、登录或提供任何个人信息。您的 API key（如使用自有密钥）以及全部文章历史记录均保存在浏览器的本地存储中。

我们处理哪些数据及其流向

您的 AI 服务商连接

由您自主选择摘要生成方式：

  • 自带密钥（BYOK） — OpenAI、Google Gemini、Mistral AI、DeepSeek 或自定义端点。您的 API key 仅保存在本地设备上（绝不同步，绝不上报给我们）。您选择生成摘要的页面内容会使用您自己的密钥直接从浏览器发送给所选服务商，并受该服务商自身隐私政策的约束。我们无法查看、记录或存储这些内容。
  • 通过 Ollama 运行本地模型 — 如果您在本地运行模型，页面内容仅会发送到您自己的机器上。任何数据都不会离开您的设备。
  • byphil Cloud（可选，付费） — 为不想自行管理 API key 的用户提供的托管方案。如果您选择此服务，页面内容将发送至我们的后端，后端代表您将请求代理转发给底层模型提供商并返回摘要。我们不会永久存储以此方式处理的页面内容。

许可证与订阅状态

如果您激活了 Pro 许可证或 byphil Cloud 订阅，您的许可证密钥将保存在本地设备上（绝不同步），并用于向我们的后端验证订阅状态。基础账户/账单元数据由我们的支付处理商和后端处理；我们不会在服务器上存储您的页面内容或阅读历史。

文章历史、高亮标注与设置

您保存的所有内容均使用 Chrome 内置的 storage API 存储在浏览器本地 —— 绝不会上传到我们的服务器：

数据项存储位置是否通过 Chrome 同步？
保存的文章与摘要本地否
API key / 服务商配置本地否 — 敏感信息，仅限本机

标有“同步”的项目使用 Chrome 自带的同步功能，并与您的 Google 账户绑定 —— 与书签同步原理相同，该数据仅经由 Google 的基础设施传输，绝不经过我们的服务器。我们无法以任何独立方式访问该数据。

您可以随时通过“设置 → 备份与恢复”导出或删除全部本地历史记录，也可以直接卸载该扩展程序。

Kindle、AirDrop 与 LocalSend

当您将文章发送至 Kindle、AirDrop 或兼容 LocalSend 的设备时，格式化后的文件会直接从您的浏览器发送到所选目标。我们不充当中间人，也无法查看或存储这些内容。

数据分析

我们使用注重隐私保护且符合 GDPR 规范的 Matomo 分析平台，仅收集匿名的聚合使用趋势以优化扩展体验。Matomo 不会跨站点跟踪您的个人行为，也不会出售任何数据。分析事件中绝不会包含任何页面内容、API key 或文章数据。

我们绝不会做的事

  • 我们不投放或展示广告，也绝不出售、出租或向广告商及数据经纪人转让您的数据。
  • 任何核心功能均无需注册或登录账户。
  • 通过您自带的 API key 或本地模型生成摘要时，我们不会记录或保留任何网页内容。
  • 我们无法访问您本地存储的文章历史记录、高亮标注或 API key —— 除非您主动导出，否则它们绝不会离开您的设备。

第三方服务

根据您的配置偏好，您的页面内容可能会发送至：

  • OpenAI、Google (Gemini)、Mistral AI 或 DeepSeek —— 仅当您填入了对应服务商的 API key，且仅针对您主动要求生成摘要的网页。
  • 我们的 byphil Cloud 后端 —— 仅当您主动选择了该服务方案。
  • 您本地的 Ollama 实例 —— 非第三方服务，数据始终留在您的本机。

我们对您选择连接的第三方 AI 服务商的隐私政策和数据实践不承担责任。建议您在接入相应服务前查阅其隐私条款。

数据安全

我们采取了与所涉及数据相匹配的合理技术安全措施 —— 实际上大部分数据均存储在您的浏览器本地，根本不会传输至我们的服务器。与我们后端之间的所有通信（用于 byphil Cloud 和许可证验证）均在传输过程中进行加密。没有任何网络传输或存储方案能够保证 100% 安全，我们无法提供绝对安全保证，但我们绝不会收集超出提供上述功能所必需的数据。

未成年人隐私保护

AI Summary Helper 并非面向 13 周岁以下（或您所在司法管辖区规定的最低年龄）儿童设计，我们也不会故意收集儿童的个人信息。

您的权利（GDPR / CCPA 等相关法规）

由于绝大部分数据均存储在您的本地设备上，您已享有对数据的完全控制权 —— 您可以随时通过扩展程序的“设置”查看、导出或删除数据，也可以直接卸载扩展程序。对于我们服务器上留存的少量数据（byphil Cloud 订阅及账单元数据），您可以通过下方的联系方式请求访问、更正或删除。

隐私政策的更新

随着扩展功能的迭代，我们可能会适时更新本隐私政策。重大变更将在本页面公布，并更新“最后更新时间”。在政策更新后继续使用本扩展程序，即视为您接受修改后的政策条款。
