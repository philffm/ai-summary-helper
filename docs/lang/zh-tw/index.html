功能簡介

閱讀清單本該擁有的理想模樣

隨手儲存、迅速掌握、精準回找，更能真正重溫閱讀 — 不必再被另一個訂閱服務綁架你的知識庫。

模型與伺服器完全由你決定，甚至能確保任何資料都不離開你的電腦。

AI 智慧摘要，自由選擇模型

支援 OpenAI、Gemini、Mistral、DeepSeek 或自訂端點——或是直接指定本機 Ollama 模型，整個過程完全無需透過外網連線。

幽靈高亮標註，直接呈現在網頁上

AI 會自動以淡色標記文章中最關鍵的原文字句——讓您一眼掌握核心重點，並能隨摘要一同匯出至 Kindle、LocalSend 或 Markdown。

真正的本機端全文搜尋

涵蓋標題、標籤與文章內容的全文搜尋 — 由瀏覽器內建的 TF-IDF 索引驅動。零延遲、無網路往返，資料絕不上傳。

有目標地稍後閱讀

為「決策」標記原因與時限並接收提醒 — 告別塞進收藏夾後就再也沒打開過的窘境。

智慧挑選的專屬文摘

一鍵為你精選多樣化且不重複的已存內容 — 避免連續讀到同個話題的五個版本 — 並打包成單一檔案傳送至 Kindle 或 LocalSend。

超越清單的知識圖譜

視覺化呈現已存文章之間的關聯 — 透過共同標籤，甚至在沒有相同標籤時根據主題相似度建立連結。

支援 20 多種語言，跨平台通用

以你偏好的語言閱讀與摘要。支援擴充功能、原生側邊欄或 Bookmarklet 小工具 — 覆蓋瀏覽器外掛無法觸及的場景。

84% 的閱讀死角

你儲存的大多數內容，其實再也沒打開過

針對書籤收藏行為的研究一致顯示，絕大多數儲存的文章再也不會被重新打開。這不是自律問題 — 而是當工具讓「儲存」變得太容易，卻完全沒幫你「挑選該讀什麼」時的必然結果。

1. 點擊文摘（Digest）

系統會挑選 5 篇儲存的內容 — 兼顧時效性與主題多樣性，讓你不再一次面對五篇相同時事的重複文章。

2. 隨心設定閱讀氛圍

輕鬆、中立或深度嚴肅 — 文摘會依據你當下的閱讀心境微調推薦內容。

3. 傳送至離線裝置

一鍵打包直接傳送至 Kindle 或同區域網路內的裝置。在搭機、通勤或無訊號的週末前輕鬆載入。

常見問題

安裝前須知

使用前需要先註冊帳號嗎？

不需要。安裝後輸入你自己的 AI 服務商 API Key（或使用本機 Ollama 模型），即可開始儲存。只有在需要使用 byphil Cloud 或透過 Support Pass 享有無限次 Kindle/LocalSend 傳送時才需註冊帳號。

究竟有哪些資料會離開我的瀏覽器？

僅有摘要請求 — 且只會發送至你所設定的 AI 服務商。搜尋、重複偵測、標籤整理、閱讀難度與情緒分析，以及「相似文章」推薦全部都是針對你本機已存資料在本地執行。

可以完全不依賴雲端執行嗎？

可以 — 只要設定連接本機 Ollama 模型，就連摘要步驟也能完全在你的電腦上完成。其餘功能本來就完全在本機運行。

如果停止訂閱 Support Pass，我存下來的資料會怎樣？

你的檔案庫依然安全儲存在原處 — 即你裝置上的瀏覽器本機儲存空間（Local Storage）。Support Pass 僅限制依賴雲端的額外功能（byphil Cloud AI 存取、無限次 Kindle/LocalSend 傳送），絕不會鎖定或限制你已儲存的內容。

這是開源專案嗎？

是的 — 擴充功能原始碼已公開於 GitHub。
