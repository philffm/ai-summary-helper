隱私權政策

您的 API Key、文章歷史紀錄與劃線重點皆保存在您的裝置本機。網頁內容僅會發送至您選擇的 AI 服務商 — 若您選擇完全本地運行的模型，資料更絕不會離開您的電腦。

最後更新：2026 年 10 月

本隱私權政策說明 AI Summary Helper 處理哪些資料、傳輸目的地及其原因。簡而言之：您的 API Key、文章歷史紀錄與劃線重點皆僅保留在您的裝置上。網頁內容僅會發送至您選擇連接的 AI 服務商 — 若您選擇完全本地運行的模型，所有資料皆完全不會離開您的本機。我們不投放廣告、不販售資料，且所有核心功能皆無需註冊帳號。

若您不同意本政策的任何部分，請勿安裝或使用本擴充功能。

無需註冊帳號

使用 AI Summary Helper 的核心功能無需註冊帳號、登入或提供任何個人資料。您的 API Key（若使用自備金鑰）以及所有文章歷史紀錄均儲存於瀏覽器的本地儲存空間（Local Storage）中。

我們處理哪些資料及其流向

您的 AI 服務商連線

由您決定摘要的生成方式：

  • 自備金鑰（BYOK） — OpenAI、Google Gemini、Mistral AI、DeepSeek 或自訂端點（Custom Endpoint）。您的 API Key 僅儲存於您的本機裝置（絕不同步，亦絕不會傳送給我們）。您選擇摘要的網頁內容會直接從您的瀏覽器發送至指定的服務商，使用您自己的金鑰並受該服務商的隱私權政策規範。我們無法查看、記錄或儲存這些內容。
  • 透過 Ollama 運行本地模型 — 若您在本地運行模型，網頁內容僅會發送至您自己的電腦。任何資料都不會離開您的裝置。
  • byphil Cloud（可選，付費方案） — 適合不想自行管理 API Key 使用者的託管方案。若您選擇此方案，網頁內容將發送至我們的後端伺服器，由後端代為向底層模型服務商發出請求並回傳摘要。我們絕不會永久儲存以此方式處理的網頁內容。

授權與訂閱狀態

若您啟用 Pro 授權或 byphil Cloud 訂閱，您的授權金鑰會儲存在本機裝置（絕不同步），並用於向我們的後端伺服器驗證訂閱狀態。基本帳戶/帳單中繼資料由我們的金流處理商與後端負責處理；我們絕不會在伺服器上儲存您的網頁內容或閱讀歷史紀錄。

解除安裝意見回饋

當您解除安裝此擴充功能時，Chrome 會在本網站開啟一個簡短的意見回饋頁面。該網址僅包含擴充功能版本以及安裝的天數——不含任何識別碼、網頁內容或瀏覽紀錄。您在表單中填寫的任何內容（原因、意見，以及若需要回覆可選擇填寫的電子郵件）都會傳送至我們的問卷調查工具 Formbricks，且僅用於改善擴充功能。您可以直接關閉頁面而不做任何回覆。

文章歷史紀錄、劃線重點與設定

您儲存的所有內容均透過 Chrome 內建的儲存 API 保存在本機瀏覽器中，絕不會上傳至我們的伺服器：

資料類型儲存位置是否透過 Chrome 同步？
已儲存的文章與摘要本機否
RSS 訂閱與文章項目本機否
API Key / 服務商設定本機否 — 敏感資料，僅限本機
授權金鑰本機否 — 敏感資料，僅限本機

劃線功能啟用/關閉偏好同步是，透過您個人的 Chrome 帳號

標記為「同步」的項目採用與您的 Google 帳號繫結的 Chrome 內建同步功能 — 這些資料與您的書籤一樣，只會經過 Google 的基礎設施傳輸，絕不經過我們的伺服器，我們亦無法存取這些資料。

您可以隨時透過「設定」→「備份與還原」匯出或刪除完整的本機歷史紀錄，或是直接解除安裝擴充功能。

RSS 訂閱來源

內建的 Feeds 閱讀器會將您的訂閱項目與擷取的內容儲存在本機瀏覽器中——絕不同步，也絕不會傳送給我們。當您新增或重新整理訂閱來源時，擴充功能會直接向發布者的伺服器請求該來源網址，就像您用瀏覽器造訪該網站一樣，因此發布者會看到此請求。我們不會代理、記錄或查看您的訂閱項目或閱讀清單。OPML 匯入作業完全在您的裝置上處理。若您開啟背景檢查功能（預設關閉），擴充功能只會依照您自訂的時間間隔重新請求訂閱來源，僅用於在工具列圖示上顯示計數。為摘要項目產生 AI 摘要的運作方式與摘要任何其他網頁相同：只有在您觸發摘要時，內容才會傳送至您選擇的 AI 提供者。選用的 AI 每日回顧與 AI 語氣評分也是如此：只有在您點擊時，擴充功能才會將文章標題、來源名稱與簡短摘要（非完整全文）傳送給您選擇的 AI 提供者，而產生的回顧內容則會快取在您的裝置上。摘要中的 Podcast 單集會在您按下 Play 時，直接從發布者的伺服器串流播放。

Kindle、AirDrop 與 LocalSend

當您將文章傳送至 Kindle、AirDrop 或支援 LocalSend 的裝置時，格式化後的檔案會直接從您的瀏覽器發送至目標裝置。我們不擔任中介伺服器，亦無法存取或儲存傳輸內容。

分析與 Cookie

簡短摘要： 本網站設定 零 Cookie ，且不使用廣告或跨網站追蹤器。我們使用自行託管的 Matomo 統計匿名造訪次數，您可以隨時關閉此功能。

我們衡量的項目

頁面瀏覽量、頁面語言、推薦來源（Referrer）、概略的國家/瀏覽器/裝置類型，以及您與網站哪些部分進行互動（例如點擊「加到 Chrome」、價格切換開關、常見問題項目、滾動瀏覽的區塊，以及 Bookmarklet 產生器的操作步驟）。事件中絕不包含電子郵件地址、API Key、一次性驗證碼、網頁內容或文章資料。

配置方式

Matomo 運行在我們自己的伺服器上（位於德國的 analytics.philwornath.de），而非第三方託管。它在停用 Cookie 且不進行瀏覽器特徵指紋識別的情況下載入；IP 位址在儲存前均已匿名化；不會指派任何使用者 ID 或跨網站識別碼，因此無法跨天或跨裝置串聯造訪紀錄。我們絕不販售或與第三方分享這些資料。

由於我們不會為了追蹤目的在您的裝置上儲存或讀取任何資訊，此項統計是基於我們了解網站使用情況的正當利益（GDPR 第 6 條第 1 款 (f) 項），且依據德國 TDDDG 第 25 條 / 歐盟 ePrivacy 指令，無需跳出 Cookie 同意橫幅。您有權隨時提出異議（GDPR 第 21 條）。

您的選擇

如果您的瀏覽器傳送了 Do Not Track 或 Global Privacy Control，分析功能將會自動關閉。您也可以透過 數據分析設定 手動退出（在每個頁面的頁尾也能找到此選項）。

儲存在您瀏覽器中的內容

僅儲存功能性偏好設定，絕不用於追蹤： aish_analytics （您的退出偏好設定）、 aish_analytics_notice （記錄您已關閉通知訊息），以及若有使用時的外觀主題選擇、語言建議關閉狀態和 Bookmarklet 產生器設定。這些資料只會保留在您的裝置上，絕不會傳送給我們。

字型與外部資源

字型（Inter、Space Grotesk、JetBrains Mono；採用 SIL 開源字型授權）皆由本網站自行提供，因此光是造訪本站絕不會將您的 IP 位址傳送給 Google 或任何字型供應商。唯一的外部請求來自於您點擊的連結，以及您主動選擇開啟的 byPhil 帳號 / Stripe 結帳頁面。

我們絕不從事的事情

  • 我們不投放或展示廣告，亦絕不向廣告商或資料經紀商出售、出租或交換您的資料。

  • 我們無法存取您儲存於本地的文章歷史紀錄、劃線重點或 API Key — 除非您主動匯出，否則它們絕不會離開您的裝置。

第三方服務

視乎您的擴充功能設定，網頁內容可能會傳送至：

  • OpenAI、Google (Gemini)、Mistral AI 或 DeepSeek — 僅限於您已輸入該服務商的 API Key，且僅傳送您主動摘要的網頁。
  • 我們的 byphil Cloud 後端伺服器 — 僅限於您選擇加入該方案。
  • 您本地運行的 Ollama 執行個體 — 非第三方服務，資料完全保留於您的電腦。

我們對您選擇連線之第三方 AI 服務商的隱私權措施概不負責。建議您在連線前先詳閱其隱私權政策。

資料安全

我們針對所涉及的資料採取了相稱且合理的技術安全措施 — 由於大部分資料均儲存在您的本機瀏覽器中，根本不會傳輸至我們的伺服器。與我們後端之間的通訊（用於 byphil Cloud 及授權驗證）均在傳輸過程中進行加密。儘管任何傳輸或儲存方式都無法保證 100% 安全，但我們絕不會收集超過提供所述功能所需之外的資料。

兒童隱私權

AI Summary Helper 並非針對 13 歲以下（或您所在司法管轄區規定的最低法定年齡）兒童設計，我們亦不會刻意收集兒童的個人資料。

您的權利（GDPR / CCPA 等規範）

由於絕大部分資料均直接儲存在您的本機裝置上，您對其擁有完全的自主控制權 — 您可以隨時透過擴充功能的「設定」檢視、匯出或刪除資料，或直接解除安裝擴充功能。針對我們伺服器上保存的少數資料（byphil Cloud 訂閱／帳單中繼資料），您可以透過下方的聯絡方式向我們要求查閱、更正或刪除。

本政策的變更

隨著擴充功能推陳出新，我們可能會適時更新本隱私權政策。若有重大變更，將更新本頁面頂部的「最後更新日期」。在變更發布後繼續使用本擴充功能，即代表您接受更新後的政策。
