Gebruik je bibliotheek in Claude, LM Studio en andere AI-apps

Je AI-app vergeet alles wat je hebt gelezen. AI Summary Helper onthoudt het. Koppel de twee op je eigen computer, zodat je app door je opgeslagen artikelen kan zoeken, uit je markeringen kan citeren en je bronnen kan vermelden.

AI Summary Helper kan je bibliotheek delen met AI-apps die het Model Context Protocol (MCP) ondersteunen: Claude Desktop, LM Studio, Cursor, VS Code, Jan en lokale agents. Je app stelt een vraag, AI Summary Helper zoekt het op in je opgeslagen artikelen en het antwoord gaat direct terug naar de app op je apparaat.

Het staat standaard uit. Er komt geen server van ons aan te pas: de extensie en de app communiceren met elkaar via een klein hulpprogramma op je computer, aish-mcp, dat geen artikelen opslaat en niets naar buiten doorstuurt.

Wat je kunt vragen

  • Bevraag je eigen leeslijst, niet het internet. “Wat heb ik opgeslagen over AI en surveillance? Groepeer het per thema en geef aan waar de artikelen van mening verschillen.”
  • Schrijf op basis van je eigen bronnen. “Schrijf een conceptbericht over de CO₂-kosten van AI en citeer uit mijn markeringen.”
  • Beantwoord de vraag van een collectie. “Gebruik mijn collectie over inflatie. Beantwoord de bijbehorende vraag uitsluitend met die bronnen en geef aan wat er ontbreekt.”
  • Werk je bewaarde artikelen bij. “Wat staat er deze week op de planning van mijn bewaar-voor-later-lijst? Geef me van elk een samenvatting van vijf minuten.”
  • Filter je feeds. “Bekijk de ongelezen feedberichten over AI van vandaag en vertel me welke drie de moeite waard zijn.”
  • Bekijk je jaaroverzicht. “Maak een jaaroverzicht van mijn leesgedrag in 2026: belangrijkste onderwerpen, drukste maand en de bepalende artikelen.”
  • Laat een agent voor je opslaan. “Zoek drie goede bronnen over local-first software en sla ze op in mijn AISH-inbox met een notitie.”

Met een lokaal model in LM Studio werkt dit allemaal zelfs als je netwerkverbinding uitgeschakeld is.

Zo stel je het in

Je hebt AI Summary Helper nodig in Chrome, Edge of Brave, Node.js 20 of nieuwer, en een MCP-app.

  1. Schakel het in. Open in AI Summary Helper Instellingen → AI-apps (MCP) en schakel in: AI-apps op deze computer toegang geven tot mijn bibliotheek.
  2. Haal je koppelcode op. Voer in een terminal het volgende uit: npx -y aish-mcp pair. Dit toont een koppelcode en slaat deze op in je gebruikersmap. Plak de code in het instellingenvenster en kies Verbinden.
  3. Voeg AI Summary Helper toe aan je app. Gebruik het onderstaande codefragment voor je app, sluit de app vervolgens helemaal af en open deze opnieuw.
  4. Controleer de verbinding. In het instellingenvenster verschijnt Verbonden zodra je app actief is. Stel je app een vraag over je bibliotheek: elk verzoek verschijnt onder Recente activiteit in het venster.

Claude Desktop

Settings → Developer → Edit Config, en voeg toe:

{
  "mcpServers": {
    "aish": { "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

Als Claude Desktop npxniet kan vinden, gebruik dan het volledige pad dat which npx in een terminal toont (bijvoorbeeld /opt/homebrew/bin/npx).

Cursor

In ~/.cursor/mcp.json (alle projecten) of .cursor/mcp.json (één project) dezelfde "aish" -invoer toe als voor Claude Desktop.

VS Code

In .vscode/mcp.json:

{
  "servers": {
    "aish": { "type": "stdio", "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

LM Studio en andere apps

Apps met een mcpServers instelling (zoals LM Studio's mcp.json, Jan en de meeste andere) gebruiken dezelfde invoer als Claude Desktop. Apps die alleen via HTTP verbinden, kunnen npx -y aish-mcp --http gebruiken op http://127.0.0.1:47616/, met de header Authorization: Bearer <jouw koppelcode>. Kies bij een lokaal model een model dat tool calling ondersteunt, zoals Qwen 3 of Llama 3.1 en nieuwer.

Alleen Je bibliotheek staat aan wanneer je de functie inschakelt. Activeer Volledige artikeltekst, Feeds en Links opslaan in het instellingenvenster als je deze wilt gebruiken; wijzigingen zijn direct van toepassing bij het volgende verzoek zonder opnieuw te verbinden. Je app kan niets bewerken of verwijderen in AI Summary Helper.

Privacy en veiligheid

  • Er loopt niets via onze server. Gegevens gaan van je browser naar het hulpprogramma en door naar de app op je computer. Wat de app vervolgens naar zijn model stuurt, hangt af van de app en het model dat je kiest. Een lokaal model houdt alles volledig op je eigen apparaat.
  • Artikelen met de tag private verschijnen nooit, in geen enkel zoekresultaat, telling of collectie. Je kunt een andere tag instellen in het instellingenvenster.
  • Alleen je eigen computer kan verbinding maken. Het hulpprogramma luistert alleen op 127.0.0.1, zodat niets anders op je netwerk erbij kan. Websites die je bezoekt kunnen er ook geen gebruik van maken: het accepteert alleen het eigen extensie-adres van AI Summary Helper en elke verbinding vereist je koppelcode.
  • Je hebt inzicht in elk verzoek. Het instellingenvenster toont de laatste 50 verzoeken met de toolnaam en het tijdstip, nooit de inhoud.
  • Je kunt de verbinding op elk moment verbreken. Schakel de functie uit of kies Ontkoppelen. Voer npx -y aish-mcp reset uit om de oude koppelcode direct ongeldig te maken.
  • Opgeslagen pagina's zijn teksten van het web. Je app krijgt de instructie om ze als informatie en niet als instructies te behandelen, maar een opgeslagen pagina kan een AI alsnog proberen te misleiden. Laat de toestemming voor 'Links opslaan' uitgeschakeld tenzij je deze actief gebruikt.

Probleemoplossing

Wat je zietWat je kunt doen
Het venster geeft aan Niet verbondenJe AI-app is niet actief of nog niet ingesteld. Open de app, of voer npx -y aish-mcp uit in een terminal om de verbinding te testen.
Je app toont geen AI Summary Helper-tools, of mist nieuwe tools na een updateSluit de app volledig af en open deze opnieuw. Sommige apps laden de lijst met tools alleen bij het opstarten.
“AISH is not running”Je browser is gesloten of de functie staat uitgeschakeld. Open de browser en controleer het instellingenvenster.
“Scope … is not enabled”Je app vroeg om gegevens waarvoor je geen toestemming hebt gegeven. Schakel dit in via het instellingenvenster als je dit wilt toestaan.
Het venster maakt geen verbinding nadat je de code hebt geplaktVoer npx -y aish-mcp pair uit en plak de weergegeven code opnieuw. Deze verandert na reset.

Meerdere AI-apps tegelijk gebruiken is geen probleem: ze delen dezelfde verbinding.
