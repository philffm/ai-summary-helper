Guide · Octobre 2026

Utilisez votre bibliothèque dans Claude, LM Studio et d'autres applications d'IA

Votre application d'IA oublie tout ce que vous avez lu. AI Summary Helper s'en souvient. Connectez les deux directement sur votre ordinateur, et votre application pourra faire des recherches dans vos articles enregistrés, citer vos surlignages et référencer vos sources.

AI Summary Helper peut partager votre bibliothèque avec les applications d'IA prenant en charge le Model Context Protocol (MCP) : Claude Desktop, LM Studio, Cursor, VS Code, Jan et des agents locaux. Votre application pose une question, AI Summary Helper cherche dans vos articles enregistrés, et la réponse revient directement à l'application sur votre machine.

Cette fonctionnalité est désactivée par défaut. Aucun de vos contenus ne transite par nos serveurs : l'extension et l'application communiquent via un petit programme d'assistance sur votre ordinateur, aish-mcp, qui ne stocke aucun article et ne transfère rien ailleurs.

Ce que vous pouvez demander

  • Interrogez vos lectures, pas Internet. « Qu'ai-je enregistré sur l'IA et la surveillance ? Regroupe par thème et indique-moi les points de divergence entre les articles. »
  • Rédigez à partir de vos propres sources. « Rédige un article sur l'empreinte carbone de l'IA en citant mes surlignages. »
  • Répondez à la problématique d'une collection. « Utilise ma collection sur l'inflation. Réponds à sa question uniquement à partir de ces sources, et précise ce qui manque. »
  • Rattrapez vos lectures en attente. « Quels éléments arrivent à échéance cette semaine dans ma liste à lire plus tard ? Fais-moi un résumé de cinq minutes pour chacun. »
  • Faites le tri dans vos flux. « Parcours les flux non lus du jour sur l'IA et indique-moi les trois qui valent la peine d'être lus. »
  • Découvrez votre année de lecture. « Crée ma rétrospective de lecture pour 2026 : thèmes phares, mois le plus actif et articles les plus marquants. »
  • Laissez un agent enregistrer pour vous. « Trouve trois bonnes sources sur les logiciels local-first et enregistre-les dans ma boîte de réception AISH avec une note. »

Avec un modèle local dans LM Studio, tout cela fonctionne même sans connexion Internet.

Configuration

Vous avez besoin d'AI Summary Helper dans Chrome, Edge ou Brave, Node.js 20 ou plus récent, et d'une application MCP.

  1. Activez l'option. Dans AI Summary Helper, ouvrez Paramètres → Applications IA (MCP) et activez Autoriser les applications IA sur cet ordinateur à utiliser ma bibliothèque.
  2. Obtenez votre code d'association. Dans un terminal, exécutez npx -y aish-mcp pair. La commande affiche un code d'association et l'enregistre dans votre dossier utilisateur. Collez ce code dans le panneau des paramètres et sélectionnez Se connecter.
  3. Ajoutez AI Summary Helper à votre application. Utilisez l'extrait correspondant à votre application ci-dessous, puis fermez complètement l'application et rouvrez-la.
  4. Vérifiez la connexion. Le panneau des paramètres affiche Connecté dès que votre application est lancée. Posez une question à votre application sur votre bibliothèque : chaque requête effectuée apparaît sous Activité récente dans le panneau.

Claude Desktop

Settings → Developer → Edit Config, puis ajoutez :

{
  "mcpServers": {
    "aish": { "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

Si Claude Desktop ne trouve pas npx, utilisez son chemin complet, que which npx affiche dans un terminal (par exemple /opt/homebrew/bin/npx).

Cursor

Dans ~/.cursor/mcp.json (tous les projets) ou .cursor/mcp.json (un seul projet), ajoutez la même "aish" entrée que pour Claude Desktop.

VS Code

Dans .vscode/mcp.json :

{
  "servers": {
    "aish": { "type": "stdio", "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

LM Studio et autres applications

Les applications avec un paramètre mcpServers (le fichier mcp.jsonde LM Studio, Jan et la plupart des autres) utilisent la même configuration que Claude Desktop. Les applications qui se connectent uniquement via HTTP peuvent utiliser npx -y aish-mcp --http sur http://127.0.0.1:47616/, avec l'en-tête Authorization: Bearer <votre code d'association>. Pour un modèle local, choisissez-en un qui prend en charge l'appel d'outils (tool calling), comme Qwen 3 ou Llama 3.1 et versions ultérieures.

Seule l'option Votre bibliothèque est active lorsque vous enclenchez la fonctionnalité. Activez Texte intégral de l'article, Flux et Enregistrer des liens dans le panneau des paramètres si vous le souhaitez ; les modifications s'appliquent dès le prochain appel sans reconnexion. Votre application ne peut rien modifier ni supprimer dans AI Summary Helper.

Confidentialité et sécurité

  • Rien ne transite par nos serveurs. Les données transitent de votre navigateur vers le programme d'assistance, puis vers l'application sur votre ordinateur. Ce que l'application transmet ensuite à son modèle dépend de l'application et du modèle que vous avez choisis. Un modèle local conserve l'intégralité des données sur votre machine.
  • Les articles tagués private n'apparaissent jamais, dans aucun résultat, calcul statistique ou collection. Vous pouvez choisir un autre tag dans le panneau des paramètres.
  • Seul votre ordinateur peut se connecter. Le programme d'assistance écoute uniquement sur 127.0.0.1, de sorte qu'aucun autre appareil sur votre réseau ne peut y accéder. Les sites Web que vous visitez ne peuvent pas non plus l'utiliser : il n'accepte que l'adresse propre de l'extension AI Summary Helper, et chaque connexion doit comporter votre code d'association.
  • Vous pouvez voir chaque appel. Le panneau des paramètres liste les 50 derniers appels avec le nom de l'outil et l'heure, sans jamais afficher le contenu.
  • Vous pouvez couper l'accès à tout moment. Désactivez la fonctionnalité ou sélectionnez Se déconnecter. Exécutez npx -y aish-mcp reset pour révoquer l'ancien code d'association.
  • Les pages enregistrées sont du texte issu du Web. Votre application est configurée pour les traiter comme de l'information et non comme des instructions, mais une page enregistrée pourrait tout de même tenter d'induire une IA en erreur. Gardez l'autorisation Enregistrer des liens désactivée si vous ne l'utilisez pas.

En cas de problème

Ce qui s'afficheQue faire
Le panneau indique Non connectéVotre application d'IA n'est pas lancée ou n'est pas encore configurée. Ouvrez-la ou exécutez npx -y aish-mcp dans un terminal pour tester la connexion.
Votre application n'affiche aucun outil AI Summary Helper ou n'affiche pas les nouveaux après une mise à jourFermez complètement l'application et rouvrez-la. Certaines applications ne chargent la liste des outils qu'au démarrage.
« AISH is not running »Votre navigateur est fermé ou la fonctionnalité est désactivée. Ouvrez le navigateur et vérifiez le panneau des paramètres.
« Scope … is not enabled »Votre application a demandé un accès non autorisé. Activez-le dans le panneau des paramètres si vous souhaitez le lui accorder.
Le panneau ne se connecte pas après avoir collé le codeExécutez npx -y aish-mcp pair et collez à nouveau le code affiché. Il change après un reset.

Vous pouvez tout à fait utiliser plusieurs applications d'IA en même temps : elles partagent la même connexion.
