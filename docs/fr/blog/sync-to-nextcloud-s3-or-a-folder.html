Comment synchroniser votre bibliothèque de lecture vers Nextcloud, S3 ou un dossier local, de manière chiffrée

Vos articles enregistrés, résumés, surlignages et notes sur tous vos ordinateurs, stockés là où vous le décidez, lisibles uniquement avec votre clé. Dix minutes, sans créer de compte chez nous.

En résumé. Dans AI Summary Helper, ouvrez Paramètres → Synchronisation & sauvegarde → Ajouter un emplacement, choisissez Nextcloud/WebDAV, un stockage compatible S3 ou un dossier sur votre ordinateur, et conservez la phrase secrète suggérée. Tout est chiffré dans votre navigateur avant d'être téléversé. Sur votre second ordinateur, ajoutez le même emplacement et saisissez la phrase secrète. C'est tout ce qu'il y a à configurer. Le reste de cette page détaille chaque type de stockage, ce qui est synchronisé et la marche à suivre en cas de problème.

Pourquoi faire cela ? Parce qu'une bibliothèque de lecture mérite d'être conservée, et qu'un outil dont vous dépendez peut disparaître (en savoir plus ici). Synchroniser vers un stockage qui vous appartient garantit que votre bibliothèque survivra à n'importe quelle application ou compte.

Ce qui est synchronisé, et ce qui ne l'est pas

  • Synchronisé : les articles enregistrés avec leur texte intégral et leurs résumés, les étiquettes, les surlignages, vos notes et commentaires, ainsi que les collections.
  • Non synchronisé : vos clés d'API, vos identifiants de connexion, la connexion de synchronisation elle-même et les paramètres propres à chaque appareil. Les sauvegardes et la synchronisation les excluent délibérément.
  • Un article par page : si vous avez enregistré la même page sur deux ordinateurs, vous obtenez un seul article (les étiquettes et les champs manquants sont combinés).
  • Les modifications fusionnent champ par champ : un titre modifié sur un ordinateur et une étiquette ajoutée sur un autre sont tous deux conservés. Si les deux modifient le même champ, la modification la plus récente l'emporte, à l'identique sur chaque appareil.

Étape 1 : choisissez où stocker vos données

Nextcloud ou un autre serveur WebDAV

Idéal si vous utilisez déjà Nextcloud ou une solution hébergée (de nombreux hébergeurs européens le proposent). Vous avez besoin de trois choses :

  1. L'adresse de vos fichiers. Pour Nextcloud, cela ressemble à https://your-server/remote.php/dav/files/your-username/. Dans Nextcloud, ouvrez Fichiers → Paramètres et copiez l'adresse WebDAV affichée.
  2. Votre nom d'utilisateur.
  3. Un mot de passe d'application, pas votre mot de passe principal. Dans Nextcloud : Paramètres → Sécurité → Appareils & sessions → créer un nouveau mot de passe d'application. Si vous souhaitez révoquer l'accès un jour, il vous suffit de supprimer cette entrée.

Choisissez un nom de dossier comme aish-sync. Il sera créé automatiquement. Les autres serveurs WebDAV (de nombreux NAS, ownCloud) fonctionnent de la même manière ; seul le format de l'adresse change.

Un compartiment compatible S3

Idéal si vous préférez le stockage objet : AWS S3, Cloudflare R2, Backblaze B2, MinIO ou équivalent. Créez un compartiment (bucket), puis générez une clé d'accès dédiée à ce compartiment avec les droits de lecture, écriture, listage et suppression dans celui-ci. N'utilisez jamais la clé principale de votre compte. Dans l'extension, saisissez l'adresse du point de terminaison (par exemple https://s3.eu-central-1.amazonaws.com, ou l'adresse fournie par votre prestataire), le nom du compartiment, la région (laissez la valeur par défaut si votre prestataire ne le demande pas), l'ID de clé d'accès et la clé secrète.

Un dossier sur votre ordinateur

Idéal si un autre outil synchronise déjà un dossier entre vos appareils : Syncthing, votre client de synchronisation de bureau, iCloud Drive, une clé USB. Choisissez Un dossier sur cet ordinateur et sélectionnez un nouveau dossier vide créé par vos soins, par exemple Documents/AISH-sync. Chrome n'autorise pas directement les dossiers Bureau, Documents ou Téléchargements à cet effet ; choisissez donc un sous-dossier. Cela fonctionne sous Chrome et Edge sur ordinateur. Deux points à retenir : le navigateur peut vous redemander l'autorisation d'accès après un redémarrage (un bouton est prévu à cet effet dans les paramètres), et le dossier ne se synchronise que lorsque le navigateur est ouvert.

Étape 2 : choisissez le mode chiffré et conservez les mots

Lorsque vous ajoutez l'emplacement, Chiffré est sélectionné par défaut et Synchroniser mes appareils est l'objectif sélectionné. L'extension suggère six mots aléatoires en guise de phrase secrète. Vous pouvez cliquer sur Autre suggestion jusqu'à trouver une combinaison qui vous convienne, ou définir la vôtre (au moins 12 caractères, avec un avertissement si elle est trop faible).

Une fois connecté, les six mots s'affichent une seule fois. Enregistrez-les dans un gestionnaire de mots de passe ; le bouton Copier les place dans le presse-papiers sous forme d'un seul bloc relié par des tirets, ce qui évite les altérations dans les fichiers de configuration et les messageries. Grâce à eux, vous pouvez ouvrir l'emplacement sur n'importe quel appareil ; sans eux, personne ne peut lire les fichiers, pas même nous. Sur l'ordinateur où vous avez configuré l'accès, vous pouvez les retrouver dans les paramètres de l'emplacement, Afficher la phrase secrète. Si vous avez plutôt choisi votre propre phrase secrète, elle n'est conservée nulle part et l'extension ne pourra donc pas la réafficher.

Ce que voit votre hébergeur de stockage : des fichiers illisibles aux noms chiffrés, leur quantité, leur taille et la date de modification. Il ne voit ni titres, ni liens, ni textes. Votre bibliothèque est chiffrée dans votre navigateur avec AES-256-GCM avant même de quitter l'appareil.

Étape 3 : ajoutez votre second ordinateur

  1. Installez l'extension et ouvrez Paramètres → Synchronisation & sauvegarde → Ajouter un emplacement.
  2. Saisissez les mêmes informations de serveur (ou sélectionnez le même dossier).
  3. L'extension détecte que le dossier contient déjà une bibliothèque chiffrée et demande la phrase secrète. Vous pouvez saisir les mots en majuscules ou minuscules, séparés par des espaces ou des tirets.
  4. Elle vous demande de confirmer que vous avez d'abord effectué une sauvegarde de cet appareil, car la connexion fusionne la bibliothèque de cet ordinateur avec celle du dossier, et en cas de divergence, la version du dossier prévaut. Utilisez Créer une sauvegarde maintenant.
  5. Cliquez sur Se connecter. La première synchronisation peut prendre un certain temps si votre bibliothèque est volumineuse ; la progression s'affiche à l'écran.

Sauvegarde seule, restauration et publication

  • Sauvegarde seule. Choisissez Sauvegarde seule au lieu de Synchroniser mes appareils et l'ordinateur se contentera d'écrire vers cet emplacement sans jamais y lire de données. Restaurez depuis les paramètres de l'emplacement lorsque vous en avez besoin : cela rétablit tout, et en cas de divergence avec cet ordinateur, la version de l'emplacement prévaut. Rien n'est supprimé.
  • Publier sur votre site web. Un autre type d'emplacement, Lisible, génère des fichiers en clair pour votre propre site, uniquement pour les articles que vous étiquetez, avec une page de visualisation optionnelle. Les notes et les textes intégraux sont exclus à moins que vous ne les activiez, car toute personne pouvant ouvrir ce dossier peut les lire. N'utilisez pas un emplacement lisible en clair pour des données privées.

En cas de problème

« Réautoriser l'accès au dossier »

Le navigateur révoque l'accès au dossier après un redémarrage. Cliquez sur le bouton en haut de Synchronisation & sauvegarde. Si le problème persiste, le dossier est peut-être protégé par Chrome (Bureau, Documents, Téléchargements ou votre dossier personnel) : choisissez un sous-dossier que vous avez créé.

« Le serveur n'a pas accepté le nom d'utilisateur et le mot de passe »

Pour Nextcloud, utilisez un mot de passe d'application. Vérifiez que l'adresse se termine bien par le dossier de votre nom d'utilisateur et que l'authentification à deux facteurs ne bloque pas le mot de passe d'application.

« Phrase secrète incorrecte »

Vérifiez les mots : la casse, les espaces et les tirets n'ont pas d'importance, mais chaque mot doit être exact. Sur un ordinateur déjà configuré, ouvrez les paramètres de l'emplacement et cliquez sur Afficher la phrase secrète. Si vous l'avez perdue partout, personne ne pourra ouvrir les fichiers : supprimez l'emplacement ici, créez-en un nouveau et repartez de la bibliothèque présente sur votre ordinateur.

Un nombre important de suppressions est en attente

Si un autre appareil supprime de nombreux articles à la fois, l'extension en applique quelques-uns et vous demande confirmation avant le reste, évitant ainsi qu'une fausse manipulation ne vide votre bibliothèque. Vérifiez, puis cliquez sur le bouton pour les appliquer.

Un ordinateur n'a pas été synchronisé pendant plusieurs mois

Après environ trois mois d'inactivité, un ordinateur envoie uniquement ce qui a changé depuis et ne supprime rien de son propre chef, évitant ainsi que d'anciens articles supprimés ailleurs ne réapparaissent par accident.

Questions fréquentes

Dois-je créer un compte chez vous ?

Non. La synchronisation communique directement depuis votre navigateur avec le stockage que vous avez configuré. Nous n'hébergeons aucun serveur de synchronisation.

Est-ce que cela fonctionne sur mon téléphone ?

Sur Android, oui. L'application mobile (un fichier APK depuis les versions GitHub ; elle n'est pas encore sur Google Play) peut rejoindre votre bibliothèque dans Paramètres → Synchronisation de la bibliothèque. La méthode la plus rapide est le code : dans le navigateur, ouvrez les paramètres de votre emplacement, cliquez sur Afficher le code pour le téléphone et scannez-le. Il contient vos identifiants de serveur, ne le montrez donc qu'à votre propre téléphone. Le téléphone affiche vos articles enregistrés avec leurs résumés et surlignages, et les notes se synchronisent dans les deux sens. Les pages que vous résumez sur le téléphone et les passages que vous y surlignez rejoignent également votre bibliothèque, mais uniquement pour les pages qu'elle ne contient pas encore : le texte du navigateur n'est jamais écrasé. Il n'existe pas encore d'application iPhone.

Puis-je utiliser plusieurs emplacements ?

Oui. Une configuration courante consiste à utiliser un emplacement chiffré pour la synchronisation entre ordinateurs et un emplacement de sauvegarde seule chez un autre prestataire.

Est-il sûr de placer ma bibliothèque dans le cloud ?

Plus sûr que la plupart des configurations, car le prestataire ne stocke que des fichiers chiffrés. La sécurité reste toutefois tributaire de la robustesse de votre phrase secrète et de votre appareil. Consultez les limites en toute transparence, y compris le fait que le chiffrement n'a pas fait l'objet d'un audit indépendant.

AI Summary Helper est une extension de navigateur gratuite et open source. La synchronisation reste désactivée tant que vous n'ajoutez pas d'emplacement.
