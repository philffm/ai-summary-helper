连接方式

你的资料库始终留在你的电脑上

一个小型中继会把请求从你的 AI 应用转发到扩展程序。中继不存储任何资料库数据。

在你的电脑上
  1. 你的 AI 应用Claude Desktop、LM Studio、Cursor
  2. stdio
  3. aish-mcp relay转发请求，不保留任何资料库数据
  4. localhost · 已校验 token
  5. AI Summary Helper搜索、存储、授权与活动日志

默认关闭：你需要在设置中手动开启，并可随时撤销。只有你的 AI 应用发送给其自身模型的内容才会离开你的电脑。

这才是阅读清单原本该有的样子。 你可以自由选择模型与服务器，并完全掌控数据是否离开你的本地设备。 问题从来不在于如何收藏，而在于如何重新找回与回顾——这正是我们精心打造的核心功能。 每一次保存都可检索、有关联、支持导出——构建真正的知识归档，而非越堆越多的收藏积压。 追踪你关注的内容，优先浏览优质资讯，轻松获取每日摘要。 随时阅读、收听或发送至 Kindle——充分利用碎片时间。

内置 RSS 阅读器

关注博客和新闻网站，按来源、标签、日期或心情筛选，导入 OPML，一键摘要任意条目。在扩展中播放播客订阅源，还可选择获取 AI 摘要回顾；订阅源和收藏都保存在你的设备上。

支持 20 多种语言与跨平台

使用扩展、原生侧边栏，或 Bookmarklet 在扩展无法访问页面时使用，以 20 多种语言阅读和摘要。

AI 摘要，模型随心选择

选择 OpenAI、Gemini、Mistral、DeepSeek、自定义端点，或本地 Ollama，让摘要无需离开你的设备。

真正的设备端本地搜索

通过基于浏览器的 TF-IDF 索引搜索标题、标签和文章内容。全文搜索在设备本地完成，无需往返服务器。

在 Claude、LM Studio 和 Cursor 中直接调用您的文库

Claude Desktop、LM Studio、Cursor 及其他 MCP 应用可以搜索你的资料库、引用高亮内容并列出待办事项。访问权限由你掌控；任何内容都不会经过我们的服务器。

你的知识库保存在自有存储中，全程加密

将加密的资料库同步到你的 Nextcloud、WebDAV 服务器、S3 存储桶或本地文件夹。发布带标签图谱和 3D 地图的可搜索列表；我们不运营任何同步服务器。 如何配置 · 试试同步设置

常见问题

安装前需知

按主题、服务商、隐私、归档或平台搜索答案。

使用该工具需要注册账户吗？

不需要。安装后，带上你自己的 AI 服务商密钥或使用本地 Ollama 模型，即可开始保存。只有使用可选的 byphil Cloud 访问或额外的 Kindle/LocalSend 发送时才需要账号。 查看服务商选项 →

哪些数据会被发送到外部？

只有摘要请求会发送到你配置的 AI 服务商。RSS 也需要向你订阅的订阅源发起请求；AI 摘要回顾仅在你主动请求时发送标题和简短片段。搜索、重复检测、标签和推荐都在本地运行。 了解设备端架构 →

我的页面或高亮内容会被用于训练模型吗？

AI Summary Helper 不会使用你的内容训练自己的模型。使用 BYOK 时，适用你所选服务商的数据政策。使用 Ollama 时，摘要请求留在你的机器上。 了解隐私模型 →

是否可以完全脱离云端依赖运行？

可以。将它指向本地 Ollama 模型，摘要步骤也会留在你的机器上。其他一切本来就已在本地运行。 对比 BYOK 与 Ollama →

我的阅读归档存放在哪里？

默认存放在你设备上的浏览器中。你可以将其导出为 Markdown，或加密备份到你自己的 Nextcloud、WebDAV 服务器、S3 存储桶或本地文件夹。 阅读同步指南 →

如果我清除浏览器数据会怎样？

如果没有备份，清除本地浏览器数据可能会删除本地归档。在清除浏览器数据或切换配置文件之前，请先导出你的资料库，或配置加密同步到你自己的存储。 阅读备份与同步指南 →

支持哪些 AI 服务商和模型？

你可以使用 OpenAI、Gemini、Mistral、DeepSeek、兼容的自定义端点，或本地 Ollama 模型。带上你自己的密钥，或使用可选的 byphil Cloud 访问。 了解 BYOK 如何运作 →

支持哪些浏览器和平台？

使用浏览器扩展、原生侧边栏或书签小工具。Android 配套应用可从手机添加链接；iOS 暂不可用。 了解浏览器与采集工作流 →

这个项目开源吗？

是的——该扩展程序的源代码已公开在 GitHub，采用 AGPL-3.0 许可证。个人、教育及非营利用途可免费使用；企业若需在 AGPL 条款范围外使用，可获取商业授权。 了解本地架构 →
