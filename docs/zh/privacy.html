隐私政策

您的 API key、文章历史记录和高亮标注均保留在您的设备本地。页面内容仅会发送给您所选择的 AI 服务提供商 —— 如果您选择完全本地运行的模型，数据将绝不离开您的设备。

最后更新：2026 年 10 月

本隐私政策说明了 AI Summary Helper 处理哪些数据、数据流向以及处理原因。简而言之：您的 API key、文章历史记录和高亮标注均保留在您的本地设备上。页面内容仅会发送给您选择连接的 AI 服务商；如果您选用完全本地运行的模型，则任何数据都不会离开您的电脑。我们不投放广告、不转售数据，且无需注册账户即可使用所有核心功能。

如果您不同意本政策的任何内容，请勿安装或使用本扩展程序。

责任主体

根据 GDPR 第 4(7) 条，数据控制者为 Phil Wornath。完整的法定名称与送达地址详见 法律声明；您也可以通过本政策末尾的联系方式与我们取得联系。

核心功能无需注册账号

使用 AI Summary Helper 进行网页总结、高亮标注、订阅 Feed 或保存归档时，均无需注册账号、登录或提供任何个人信息。您的 API key（如使用自有密钥）以及全部文章历史记录均仅保存在浏览器的本地存储中。

仅在使用托管服务时才需要账号，包括：byphil Cloud（无需自有密钥即可生成摘要）和 Send to Kindle。您可以使用邮箱地址和一次性验证码登录。我们会保存该邮箱地址、您的订阅方案或许可证状态以及基础用量计数（例如请求次数和 Kindle 发送次数），以便执行方案配额限制。

我们处理哪些数据及其流向

您的 AI 服务商连接

由您自主选择摘要生成方式：

  • 自带密钥（BYOK） — OpenAI、Google Gemini、Mistral AI、DeepSeek 或自定义端点。您的 API key 仅保存在本地设备上（绝不同步，绝不上报给我们）。您选择生成摘要的页面内容会使用您自己的密钥直接从浏览器发送给所选服务商，并受该服务商自身隐私政策的约束。我们无法查看、记录或存储这些内容。
  • 通过 Ollama 运行本地模型 — 如果您在本地运行模型，页面内容仅会发送到您自己的机器上。任何数据都不会离开您的设备。
  • byphil Cloud（可选，付费） — 专为不想自行管理 API key 的用户提供的云端托管方案。若选择此方案，您请求摘要的文本会经由我们的后端，代表您通过 OpenRouter 转发至底层模型提供商，并返回摘要结果。这仅为中继传输：我们不会存储网页内容、URL 或摘要。针对每个账户，我们仅记录用量元数据：已完成的请求数、Token 消耗量、最后一次请求的时间以及所使用的模型。账户本身为可选项；所有其他功能在未登录状态下均可正常使用。开启“优先使用欧盟服务器”设置后，具备欧洲节点的模型将仅在这些节点上运行，应用也会标明哪些模型支持、哪些不支持。这仅限制了模型的运行位置，并未缩短传输链路：您的文本仍会先经过我们的服务（运行于德国服务器），再通过美国公司 OpenRouter 传输至模型，且朗读和语音转文字功能暂无欧盟节点选项。

许可证与订阅状态

如果您激活了 Pro 许可证或 byphil Cloud 订阅，您的许可证密钥将保存在本地设备上（绝不同步），并用于向我们的后端验证订阅状态。基础账户/账单元数据由我们的支付处理商和后端处理；我们不会在服务器上存储您的页面内容或阅读历史。

卸载反馈

当您卸载扩展程序时，Chrome 会在此网站上打开一个简短的反馈页面。该请求地址仅包含扩展版本和已安装天数 —— 不含任何个人身份标识、页面内容或浏览历史。您在表单中选择或输入的内容（原因及可选的反馈意见）将连同扩展版本和安装天数一起，作为事件记录在我们自建且不使用 Cookie 的分析系统中，仅用于改进扩展程序。如果您的浏览器启用了 Do Not Track 或您已选择停用数据分析，则不会发送任何信息。表单无需填写邮箱；如需交流回复，请提交 GitHub issue。您可以直接关闭该页面而不做任何填写。

您可以随时通过“设置 → 资料库与数据 → 备份与恢复”（Settings → Library & Data → Backup & restore）导出数据。默认情况下，备份会自动排除 API keys、登录凭据、license keys 以及安装标识符；若要包含这些项，需由您明确主动开启并确认安全警告，因为任何获取该文件的人均可直接使用它们。请妥善保管导出的文件，并注意较旧的备份文件中可能仍含有敏感凭据。在同一页面中，危险区域（Danger zone）支持按类别清理数据，并会清晰列出各项即将删除的数量：摘要与归档、划线高亮、订阅源（feeds）、播客、API keys / 登录信息 / 许可证、发送目标（Kindle、LocalSend）以及偏好设置。 删除所有数据 会清除扩展程序存储在设备上的所有数据并重置为初始状态。卸载扩展程序同样会清除其全部本地数据。这些操作仅删除本地数据。您的账户以及我们在服务器上保存的记录（见下文），均可在以下页面进行管理： byphil.eu/#account：您可以在该页面导出个人数据并注销账户。扩展程序和 Android 应用均可在账户设置中直接跳转至该页面。

RSS 订阅源

内置的 Feeds 阅读器会将您的订阅和抓取的 Feed 内容完整保存在本地浏览器中——绝不同步，也绝不会发送给我们。当您添加或刷新订阅源时，插件会直接向发布者的服务器发起请求（就像您在浏览器中直接访问该网站一样），因此发布者端可以看到该网络请求。我们绝不代理、记录或查看您的任何订阅与阅读列表。OPML 导入完全在您的本地设备上处理。若开启后台检查（默认关闭），插件仅会按您设定的时间间隔重新请求 Feed，以在工具栏图标上显示未读计数。对 Feed 内容生成摘要的机制与普通网页相同：仅在您主动触发摘要时，内容才会被发送至您指定的 AI 提供商。可选的 AI 每日回顾与 AI 语气评分机制亦然：只有在您点击时，插件才会将条目标题、来源名称及简短摘要片段（非全文）发送至您选择的 AI 提供商，生成的总结内容也仅缓存在您的本地设备上。点击播放时，Feed 中的播客单集将直接从发布者服务器进行流式传输播放。

发送文章：Kindle、LocalSend 和系统分享面板

传输途径分为两种，其中只有一种会经过我们的服务器：

  • Send to Kindle 会经过我们的服务器。 由于 Amazon 仅接收来自已获批准发件人邮箱的文档，插件会将文章（标题、摘要、正文、高亮及源地址）发送至 byphil 后端，再由后端通过邮件推送至您填写的 Kindle 邮箱。您需在 Amazon 账户中将我们的发件地址（kindle@byphil.eu）添加到已认可的发件人列表。文章内容仅用于生成并发送该邮件。Kindle 推送需要登录账号或拥有许可证；免费方案包含 3 次推送配额。
  • LocalSend 与系统分享面板（例如 AirDrop）均为点对点直连。 文件会直接从您的浏览器传输至局域网中选定的设备，或传送至系统分享面板中选择的应用。我们不会介入，也无法查看或存储这些内容。LocalSend 支持运行兼容应用的手机、平板、电脑及电子书阅读器。

文库同步、备份与发布（可选）

默认处于关闭状态，直到你在“设置 → 同步与备份”中添加存储位置。存储位置可以是你自选服务器上的文件夹（如 Nextcloud 或其他 WebDAV 服务器，亦或是 AWS S3、Cloudflare R2 或 Backblaze B2 等 S3 兼容存储桶），也可以是你本地电脑上的文件夹。我们不运营这些服务器，不参与任何中转，也绝无法查看你存放的内容。

  • 加密存储位置 在多台设备间同步您的整个资料库，或妥善保留一份备份：文章、摘要、全文、高亮标注、笔记、合集及标签。所有数据在离开设备前均已在浏览器内完成加密（采用基于您密码派生的 AES-256-GCM 密钥），文件名亦经过混淆处理。服务器或存储目录仅能看到加密文件、文件大小及修改时间。由密码派生的密钥始终仅保留在当前浏览器的本地存储中，以确保同步可在后台运行。如果您使用系统推荐的随机词组，词组也会保存在本地，方便您随时在对应设置中查阅；若使用自定义密码，系统则不会予以存储。这些敏感信息绝不会被同步，也不会包含在任何备份中。若遗失密码，任何人（包括我们）都无法解密并读取您的文件。
  • 明文存储位置 发布明文文件（如需要，还可包含轻量级查看页面），供你自己的网站或工具调用。仅会导出符合你设定的标签筛选条件的文章。除非你在危险区域设置中主动开启，否则笔记、提醒事项和文章全文绝不会被发布；一旦开启，任何有权访问该文件夹的人都可以直接阅读这些内容。
  • 传输方式。 网络请求通过 HTTPS 协议直接从你的浏览器发送至你输入的地址，并使用你提供的登录凭证或 Access Key 进行认证。这些登录信息仅保存在本地，绝不会被同步，且除非你主动选择，否则不会包含在备份中。目标服务器的运营者可以看到你的 IP 地址以及同步时间。
  • 本台电脑上的文件夹 使用浏览器的文件夹访问权限（File System Access）。由你指定文件夹并由浏览器请求授权，浏览器在重启后可能会再次要求确认权限。我们仅在本地保留浏览器对该文件夹的句柄（Handle）。无论你使用何种工具将该文件夹同步到其他设备（如 Syncthing、iCloud Drive、Dropbox），均遵循对应服务自身的隐私条款。

电脑端 AI 应用 (MCP)

默认关闭。开启“设置 → AI 应用 (MCP)”后，您连接的电脑端 AI 应用（例如 Claude Desktop、LM Studio、Cursor 或 VS Code）可以读取您允许访问的资料库内容：已保存的文章及其摘要和高亮标注；仅在您主动开启时，才会包含全文、订阅源（Feed）条目以及保存至收件箱的链接。数据直接从浏览器经由您电脑上的轻量辅助程序（aish-mcp）传输至该应用。数据绝不会经过我们的服务器，我们也无法查看。该辅助程序仅接受来自本机的连接并需要配对码；它不会存储任何文章，也不会记录转发的内容。带有您排除标签（private ，默认）的文章绝不会被共享。扩展程序会在本地设备上保留最近 50 次调用的记录（包含工具名称、时间和结果数量，不含具体内容），您可以在同一设置面板中查看。AI 应用随后向模型发送的内容取决于您选择的应用与模型：若使用本地模型，任何数据都不会离开您的电脑。您可以随时关闭该设置或选择“断开连接”。

数据分析与 Cookie

简而言之： 本网站 不使用任何 Cookie ，也不使用任何广告或跨站跟踪器。我们通过自托管的 Matomo 实例统计匿名访问数据，您可以随时关闭该统计。

浏览器插件本身不包含任何数据分析、遥测或行为追踪代码。 其发起的网络请求仅限于：你配置的 AI 服务提供商、你订阅的 RSS Feed 源、你要求抓取的网页、你设置的文库同步/备份/发布服务器，以及（若你启用了对应功能）用于 byphil Cloud、登录、许可证校验和 Send to Kindle 的 byphil 后端服务。

我们统计的数据

页面浏览量、页面语言、来源网站（referrer）、大致的国家/浏览器/设备类型，以及您与网站各部分的互动（例如点击“Add to Chrome”、价格切换、FAQ 折叠项、页面滚动位置以及小书签生成器的操作步骤）。事件数据绝不包含电子邮件地址、API key、一次性验证码、页面内容或文章数据。

配置说明

Matomo 运行在我们自己的独立服务器上（analytics.philwornath.de，位于德国），而非第三方平台。加载时已禁用 Cookie 且不进行浏览器特征指纹采集；IP 地址在存储前已完成匿名化处理；系统不会分配用户 ID 或跨站标识符，因此无法跨天或跨设备关联访问记录。数据绝不出售或与第三方共享。

由于我们不会出于跟踪目的在您的设备上存储或读取任何信息，此项统计完全基于我们了解网站使用情况的正当合法利益（GDPR 第 6(1)(f) 条），根据德国 TDDDG 第 25 条 / 欧盟电子隐私指令（ePrivacy Directive），无需展示 Cookie 授权横幅。您有权随时提出异议（GDPR 第 21 条）。

您的选择与控制权

如果您的浏览器发送了 Do Not Track 或 Global Privacy Control，统计分析将自动关闭。您也可以通过 数据分析设置 手动停用（各页面底部亦提供入口）。

浏览器本地存储的内容

仅存储功能性偏好设置，绝不用于跟踪： aish_analytics （您的退出统计偏好）、 aish_analytics_notice （您已关闭信息提示通知的状态），以及在您使用时保存的主题选择、关闭语言建议的状态与小书签生成器配置。这些数据仅保存在您的本地设备上，不会发送给我们。

字体与外部资源

字体（Inter、Space Grotesk、JetBrains Mono；基于 SIL Open Font License 开源协议）均由本站自行分发托管，因此仅访问本站不会将您的 IP 地址泄露给 Google 或任何字体服务商。仅在您主动点击外部链接，或选择打开可选的 byPhil 账户 / Stripe 结账页面时，才会产生外部网络请求。

法律依据与保留期限

绝大部分数据均直接在您的本地设备上处理，绝不会传输至我们的服务器。针对我们确实会处理的数据，其处理依据与保留期限如下：

  • 账户与登录 （电子邮件地址、一次性验证码、许可证密钥、套餐状态）—— 用于提供您所请求的账户服务，依据 GDPR 第 6(1)(b) 条。在账户存续期间保留；当您注销账户时即被彻底删除。
  • byphil Cloud （中转待摘要文本、使用计数器、Token 用量、最后请求时间、最后使用模型）—— 用于履行相关服务，依据第 6(1)(b) 条。文本仅作实时中转，不作任何存储。使用元数据在账户存续期间保留，并在注销账户时一并删除。
  • 发送到 Kindle （您发送的文章内容、您的 Kindle 接收邮箱）—— 用于执行您触发的推送操作，依据第 6(1)(b) 条。仅用于生成并发送该封电子邮件。
  • 支付与许可证验证 —— 用于履行合同及满足法定的会计合规义务，依据第 6(1)(b) 及 (c) 条。账单记录将依法定要求的期限予以保留。
  • 网站分析与卸载反馈 —— 基于我们改进网站和扩展程序的合法商业利益，依据第 6(1)(f) 条。该数据完全匿名（详见“分析与 Cookie”部分）。

您可以随时在以下页面导出您的账户数据并注销账户： byphil.eu/#account。注销账户将同步彻底删除该账户名下存储的所有数据。
