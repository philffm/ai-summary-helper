指南 · 2026 年 10 月

在 Claude、LM Studio 及其他 AI 应用中直接使用您的知识库

你的 AI 应用记不住你读过的所有内容，但 AI Summary Helper 可以。只需在本地电脑上连接两者，你的应用就能搜索已存文章、引用高亮标记并注明出处。

AI Summary Helper 支持将你的资料库共享给支持 Model Context Protocol (MCP) 的 AI 应用：Claude Desktop、LM Studio、Cursor、VS Code、Jan 以及本地 Agent。当应用发起提问时，AI Summary Helper 会在已存文章中检索，并将答案直接返回给本机上的应用。

该功能默认处于关闭状态。整个过程完全不涉及我们的服务器：扩展程序与应用仅通过电脑上的轻量辅助程序进行本地通信， aish-mcp，该程序不会存储任何文章，也不会向任何其他地方转发数据。

你可以向它提问什么

  • 基于你的阅读提问，而非全网检索。 “我保存了哪些关于 AI 和监管监控的内容？请按主题归类，并指出这些文章之间存在分歧的观点。”
  • 依据你自己的文献来源进行创作。 “起草一篇关于 AI 碳足迹成本的文章，并引用我的高亮标记。”
  • 解答合集中的核心问题。 “使用我关于通胀的合集。仅基于这些资料回答核心问题，并说明还缺少哪些维度的内容。”
  • 快速消化“稍后阅读”内容。 “我‘稍后阅读’列表中本周有哪些待读项？请为每篇提供一份 5 分钟速读总结。”
  • 高效筛选你的订阅内容。 “浏览今天未读的 AI 相关订阅源内容，挑出最值得精读的三篇。”
  • 查看你的年度阅读画像。 “生成我的 2026 年度阅读回顾：核心主题、阅读量最高的月份以及最具代表性的文章。”
  • 让 Agent 帮你自动归档。 “寻找三篇关于 local-first 软件的优质资料，附上笔记并保存到我的 AISH 收件箱中。”

搭配 LM Studio 中的本地模型，所有这些操作均可在断网状态下完整运行。

开始配置

你需要安装在 Chrome、Edge 或 Brave 上的 AI Summary Helper， Node.js 20 或更高版本，以及一个 MCP 应用。

  1. 开启功能。 在 AI Summary Helper 中，打开“设置”→“AI 应用 (MCP)”并开启 允许本机上的 AI 应用使用我的资料库。
  2. 获取配对码。 在终端中运行 npx -y aish-mcp pair。命令会输出配对码并将其保存在你的用户目录中。将配对码粘贴到设置面板中，然后点击“连接”。
  3. 将 AI Summary Helper 添加到你的应用中。 使用下方对应应用的配置代码片段，然后彻底退出并重新打开该应用。
  4. 检查连接状态。 当应用启动后，设置面板会显示 已连接 。现在可以向应用询问资料库中的内容了：应用的每一次调用都会记录在面板的“最近活动”中。

Claude Desktop

Settings → Developer → Edit Config，然后添加：

{
  "mcpServers": {
    "aish": { "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

如果 Claude Desktop 找不到 npx，请使用其完整路径，可以通过在终端中运行 which npx 获取（例如 /opt/homebrew/bin/npx）。

Cursor

在 ~/.cursor/mcp.json （适用于所有项目）或 .cursor/mcp.json （适用于单个项目）中，添加与 Claude Desktop 相同的 "aish" 配置项。

VS Code

在 .vscode/mcp.json 中添加：

{
  "servers": {
    "aish": { "type": "stdio", "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

LM Studio 及其他应用

包含 mcpServers 设置项的应用（如 LM Studio 的 mcp.json、Jan 以及大多数其他应用）使用与 Claude Desktop 相同的配置。仅支持通过 HTTP 连接的应用可以在 npx -y aish-mcp --http 使用 http://127.0.0.1:47616/，并携带 Header： Authorization: Bearer <your pairing code>。若使用本地模型，请选择支持 Tool Calling 的模型，例如 Qwen 3 或 Llama 3.1 及更新版本。

你的应用可以调用的能力

工具核心功能所需权限
search_library搜索已保存的文章，支持按标签、日期或合集筛选“你的资料库”
get_article单篇文章详情，包含摘要与高亮标记“你的资料库”
list_highlights按时间倒序列出你的所有高亮标记“你的资料库”
list_due即将到期的“稍后阅读”条目“你的资料库”
list_collections、 get_collection你的合集及其包含的内容来源“你的资料库”
library_stats仅统计数据：保存趋势、热门标签与网站、阅读情绪、高亮数量“你的资料库”
get_article （附带全文）已存文章的完整纯文本内容文章全文

启用此功能时，默认仅开启 “你的资料库” 。如果需要，可在设置面板中手动开启“文章全文”、“订阅源”和“保存链接”；修改即时生效于下一次调用，无需重新连接。你的应用无法编辑或删除 AI Summary Helper 中的任何内容。

隐私与安全

  • 任何数据均不经过我们的服务器。 数据直接从你的浏览器传输到辅助程序，再传递给电脑上的应用。应用后续向模型发送什么内容，完全取决于你所选的应用和模型。使用本地模型可确保所有数据完全留在本机。
  • 被你标记为 private 的文章绝不会出现在任何搜索结果、统计或合集中。你也可以在设置面板中指定其他标签。
  • 仅限本机连接。 辅助程序仅监听 127.0.0.1，局域网内的其他设备无法访问。你访问的网站同样无法调用：它仅接收来自 AI Summary Helper 自身扩展地址的请求，且每次连接都必须携带配对码。
  • 每次调用皆清晰可见。 设置面板会列出最近 50 次调用的工具名称与时间，绝不记录任何具体内容。
  • 随时随地一键切断连接。 关闭该功能或点击“断开连接”。运行 npx -y aish-mcp reset 即可立即使旧配对码失效。
  • 保存的页面源自网络文本。 系统会告知你的应用将已存内容作为信息参考而非执行指令，但保存的网页内容仍可能存在针对 AI 的提示注入风险。除非确有需要，建议保持“保存链接”权限处于关闭状态。

故障排查

遇到的现象解决方案
面板显示 未连接你的 AI 应用未运行，或尚未配置完成。请打开应用，或在终端中运行 npx -y aish-mcp 来测试连接。
应用中未显示 AI Summary Helper 工具，或更新后缺少新工具彻底退出应用并重新打开。部分应用仅在启动时读取工具列表。
“AISH is not running”浏览器已关闭，或该功能已停用。请打开浏览器并检查设置面板。
“Scope … is not enabled”应用请求了你尚未授权的权限范围。如有需要，可在设置面板中开启相应权限。
粘贴配对码后面板一直无法连接运行 npx -y aish-mcp pair 并重新粘贴输出的配对码。配对码在执行 reset 之后会改变。。

同时运行多个 AI 应用完全没问题：它们可以共享同一个连接。
