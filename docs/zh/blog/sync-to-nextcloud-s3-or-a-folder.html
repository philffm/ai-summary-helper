使用指南 · 2026 年 10 月

如何将阅读库加密同步至 Nextcloud、S3 或本地文件夹

在您的所有电脑上访问保存的文章、摘要、高亮与笔记；存储位置完全由您掌控，仅凭您的密钥可读。只需十分钟，无需在我们这里注册任何账号。

极简速览。 在 AI Summary Helper 中打开 Settings → Sync & backup → Add a place，选择 Nextcloud/WebDAV、S3 兼容存储或电脑上的本地文件夹，并保存系统建议的密码短语。所有内容在上传前均已在浏览器端完成加密。在第二台电脑上，只需添加相同存储位置并输入密码短语即可。整个设置流程就这么简单。本页其余部分将介绍各类存储支持、同步内容细节以及故障排查方法。

为什么要这样做？因为阅读资料库值得长期留存，而你所依赖的第三方工具随时可能关停（详见此处说明）。同步到自主掌控的存储中，意味着资料库能够独立于任何单一应用或平台账号长久留存。

哪些内容会同步，哪些不会

  • 已同步内容： 已保存文章及其全文与摘要、标签、高亮标注、个人笔记与批注，以及收藏集。
  • 未同步内容： 您的 API key、登录凭据、同步本身的认证信息以及单设备配置。备份与同步功能会特意排除这些敏感项。
  • 每页仅保留单篇文章： 若在两台电脑上保存了同一页面，最终会合并为一篇文章（标签与缺失字段将自动合并）。
  • 按字段合并修改： 一台电脑修改标题、另一台电脑添加标签，两处改动都会保留。若两端修改了同一字段，则以最新更改为准，各设备保持一致。

第 1 步：选择存储位置

Nextcloud 或其他 WebDAV 服务器

最适合已自建 Nextcloud 或使用托管服务的用户（许多欧洲服务商均提供）。您需要准备三样信息：

  1. 您的文件地址。 在 Nextcloud 中通常类似于 https://your-server/remote.php/dav/files/your-username/。在 Nextcloud 中打开 Files → Settings 并复制此处显示的 WebDAV 地址。
  2. 您的用户名。
  3. 应用专属密码（App Password），而非您的主密码。 在 Nextcloud 中： Settings → Security → Devices & sessions → create a new app password。若日后需要撤销访问权限，只需删除该条目即可。

选择一个文件夹名称，例如 aish-sync。系统会自动为您创建该文件夹。其他 WebDAV 服务器（如各类 NAS 设备、ownCloud）工作原理相同，仅地址格式有所差异。

S3 兼容对象存储桶

最适合偏好对象存储的用户：如 AWS S3、Cloudflare R2、Backblaze B2、MinIO 等。创建一个存储桶，然后生成一个 Access Key 仅限此存储桶的专属密钥 ，并为其配置读取、写入、列出和删除权限。请切勿使用账号的主密钥。在插件中，输入 Endpoint 端点地址（例如 https://s3.eu-central-1.amazonaws.com，或服务商提供的具体地址）、存储桶名称、区域 Region（若服务商未作要求可保留默认）、Access Key ID 及 Secret Key。

电脑上的本地文件夹

最适合已有其他工具在各设备间同步文件夹的场景：如 Syncthing、桌面端网盘客户端、iCloud Drive 或 USB 闪存盘。选择 本台电脑上的文件夹 并选取一个 您新建的专属空文件夹，例如 Documents/AISH-sync。Chrome 不允许直接将桌面（Desktop）、文档（Documents）或下载（Downloads）根目录作为此类文件夹，因此请选择子文件夹。此功能适用于电脑端 Chrome 和 Edge。需要注意两点：浏览器重启后可能会再次要求授权访问权限（设置界面中提供了相应按钮），且文件夹仅在浏览器运行期间保持同步。

第 2 步：选择加密并妥善保管密码短语

添加存储位置时， Encrypted 默认处于选中状态，且用途为 Sync my devices 。插件会建议 6 个随机单词作为您的密码短语。您可以点击 Another suggestion 直到选出满意的组合，或自行设置（至少 12 个字符，强度较弱时会有提示）。

连接成功后，这 6 个单词仅会显示一次。请将它们保存到密码管理器中；“复制”按钮会将它们以连字符连接的整串文本存入剪贴板，方便在配置文件或即时通讯工具中粘贴传递。凭借这串短语，您可在任何设备上打开该存储位置；若遗失，包括我们在内的任何人都无法读取文件。在初次配置的电脑上，您可在该位置的设置中再次查看： Show passphrase。如果您使用的是自定义密码短语，系统不会在任何地方保存它，插件也无法再次显示。

存储服务商能看到的内容仅限于：经过混淆的文件及其名称、文件数量、文件大小以及修改时间。服务商无法查看文章标题、链接或具体正文。您的资料库在离开设备前已在浏览器中通过 AES-256-GCM 完成加密。

第 3 步：添加第二台电脑

  1. 安装插件并打开 Settings → Sync & backup → Add a place。
  2. 输入相同的服务器信息（或选择相同的文件夹）。
  3. 插件检测到该文件夹中已存在加密资料库后，会要求输入密码短语。输入时无论大小写、使用空格或连字符分隔均可正常识别。
  4. 系统会提示您先确认已对本机完成备份，因为加入同步会将本机资料库与文件夹中的内容合并，若存在冲突则以文件夹中的内容为准。请使用 Make a backup now。
  5. 点击 Connect。如果资料库较庞大，首次同步可能需要一些时间；界面会实时显示同步进度。

仅备份、恢复与发布功能

  • 仅备份。 选择 Backup only 而非 Sync my devices ，电脑便只会向该存储位置写入数据而绝不读取。需要时可从该位置的设置中执行恢复：它会还原所有内容，若本机与远端存在差异则以远端为准，且绝不会删除任何数据。
  • 发布至个人网站。 另一种独立的位置类型 Readable（Readable）会为您的个人站点生成纯文本文件，仅包含您打上特定标签的文章，并附带可选的网页浏览界面。除非您主动开启，否则笔记与正文全文均不会包含在内，因为任何能访问该文件夹的人都可以直接读取内容。请勿将明文可读位置用于存放私密数据。

常见问题与故障排查

“Allow access to the folder again”（重新允许访问文件夹）

浏览器重启后会自动收回文件夹访问权限。请点击位于 Sync & backup顶部的按钮。如果持续提示失败，该文件夹可能是 Chrome 受保护的系统目录（Desktop、Documents、Downloads 或用户主目录）：请选择您自行创建的子文件夹。

“The server did not accept the username and password”（服务器未接受用户名和密码）

对于 Nextcloud，请使用应用专属密码（App Password）。同时检查地址结尾是否包含您的用户名目录，并确认双重认证（2FA）未拦截应用密码。

“Wrong passphrase”（密码短语错误）

检查输入的单词：大小写、空格与连字符均不影响，但每个单词必须完全拼写正确。在已配置好的电脑上，打开该位置的设置并点击 Show passphrase。若在所有设备上均已遗失，文件将彻底无法打开：此时请在此处移除该位置，新建一个存储位置，并从当前电脑上的本地资料库重新开始同步。

检测到大量待处理的删除操作

如果另一台设备单次删除了大量文章，插件会先应用其中少数几条，并在执行其余删除前弹出确认提示，防止因单次误操作清空整个资料库。确认无误后，点击按钮即可继续应用。

某台电脑已有数月未联网同步

脱机大约三个月后，该电脑重新同步时将仅推送此期间的更改，且不会主动执行删除操作，从而避免在其他设备上已被删除的历史文章意外复原。

常见问题

我需要注册你们的服务账号吗？

不需要。同步直接在您的浏览器与您输入的存储服务之间进行通信。我们不运营任何同步服务器。

手机端可以使用吗？

Android 设备支持使用。配套应用（可从 GitHub Releases 页面下载 APK 安装包；暂未上架 Google Play）可在 Settings → Library sync中加入您的资料库。最快捷的方式是使用二维码：在浏览器中打开存储位置设置，点击 Show code for the phone 并进行扫码。该二维码包含您的服务器登录凭据，请仅在您本人的手机上扫描。手机端可浏览您保存的文章、摘要与高亮标注，笔记支持双向同步。在手机端生成的网页摘要与标注段落也会同步至资料库中（仅限资料库中尚不存在的新页面：浏览器本地的正文绝不会被覆盖）。目前暂未提供 iPhone 应用。

我可以添加多个存储位置吗？

可以。常见的方案是：设置一个加密位置用于多台电脑间同步，并在另一个服务商处设置一个仅备份位置。

将资料库放在云端安全吗？

比绝大多数方案更为安全，因为服务商处仅存放加密后的密文文件。但整体安全性仍取决于您的密码短语强度与设备安全。请阅读 客观的安全限制与说明，其中已明确说明本加密实现尚未经过第三方独立审计。
