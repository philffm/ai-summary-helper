从 Bookmarklet 到 2.0：现在的 AI Summary Helper 究竟是什么

它起初只是一枚用于推送到 Kindle 阅读的一键小书签。历经两年与彻底的架构重写，如今它所具备的大多数功能，在最初一百位用户加入时甚至都还不存在。

AI Summary Helper 是一款免费开源的 Chrome 扩展，支持通过你自己的 AI 服务商或完全本地的模型总结任何网页，设置定时提醒以便稍后阅读，并将你的阅读记录转化为可检索、相互关联的知识归档。 最初版本并没有这些特性。以下是它当时的样子，以及一步步演进至今日的历程。

这款工具究竟是如何诞生的

2024 年 7 月，它还只是一枚小书签（Bookmarklet）——连扩展程序都算不上。当时的情景很熟悉：四处寻找有趣的文章，一口气打开十几个标签页，然后像大多数人一样，根本没时间读完。最初的设想非常简单且出于个人需求：一个支持自定义 Prompt 的摘要工具，将生成的内容直接插入页面，这样当你使用 Reabble 的 Send-to-Kindle 工具推送文章到 Kindle 时，摘要也能随之一并带过去。这就是当时产品的全部。单一 AI 服务商、一个 Prompt 输入框。一个可以在任何地方（包括 iOS Safari）运行的小书签版本，以及一个为希望随时调整 Prompt 的用户准备的 Chrome 扩展。

几周后它的活跃用户就突破了 100 人——这确实令人意外，因为它的初衷只是为了解决我个人的阅读习惯，而非做一款商业产品。

从那时到 2.0，究竟改变了什么

核心理念从未改变——按你的方式生成摘要，并在比浏览器标签页体验更好的地方阅读。但围绕这一理念的一切，都迎来了彻底升级：

从单一服务商，扩展到 5 种自由选择

v1 仅支持 OpenAI、自备 API key 及单一 Endpoint。2.0 则支持使用你自己的 API key 接入 OpenAI、Google Gemini、Mistral 和 DeepSeek，更提供了基于 Ollama 的纯本地运行方案——只要你愿意，网页内容完全无需离开你的本地设备。此外，我们也为不想折腾 API key 管理的用户提供了可选的托管服务（byphil Cloud），但从不强制。这绝非单纯的功能叠加，而是重塑了产品的本质。v1 默认需要你信任某一家公司，而 2.0 绝不强求你信任任何未经你许可的第三方。

从简单的“插入页面”，演变为真正的工作流

最初的核心初衷——稍后阅读，在比浏览器更专注的环境中阅读——依然未变，但它不再只是简单将摘要粘贴进 DOM 中。现在右键点击网页即可使用 Summarize & Close Tab：选择提醒时间（明天、周末、本周、专题调研阶段），添加备注，并在 RSVP 浮层中快速浏览完摘要后自动关闭标签页。Chrome 通知会在你指定的精准时刻唤醒阅读——而不是遥遥无期的“改天”或“等想起来再说”。

堆积如山的收藏文章，蜕变为清晰可导览的知识库

v1 完全没有历史记录功能——摘要只存在于当前页面，关闭即消失。现在，每篇保存的文章都会存入本地可检索的归档中，配备文本高亮（以及 AI 自动推荐重点段落的“幽灵高亮”）、阅读分析热力图，以及基于 D3 的知识图谱，按主题聚合你的阅读轨迹，而非杂乱无章的列表。

曾经 Kindle 是全部意义，如今只是众多选择之一

借助 Reabble 工具 Send-to-Kindle 曾是项目存在的唯一原因。这项原生支持依然保留，但如今脱离浏览器阅读有了更多选择：通过 AirDrop 发送到 iPhone 或 iPad（直接在 Apple Books 中打开），或通过局域网 Wi-Fi 使用 LocalSend 发送到 KOReader 等设备。将内容移出浏览器、转移到专为阅读而生的设备这一底层逻辑始终如一，只是实现路径更加丰富。

始终未变的初心

它依然免费、依然开源（采用 MIT 协议，完整代码公开在 GitHub），且所有核心功能均无需注册账号。这一点绝不妥协——这也正是 v1 最初以小书签形式诞生的原因：由一个希望真正掌控属于自己的阅读工具、而非按月租用服务的人所构建。

常见问题

这和最初的小书签是同一个项目吗？
是的——依然是同一个开源项目、同一个 GitHub 仓库，自 2024 年 7 月以来持续迭代。对于希望免安装、跨浏览器使用的用户，小书签版本也依然可用。

使用它必须拥有 OpenAI 账号吗？
不需要。v1 时确实如此，但很久之前就已经不再受限。你可以使用任何支持的 AI 服务商，或者通过 Ollama 跑纯本地模型，完全不需要任何外部账号。

Gumroad 版本后来怎么样了？
项目最初设立在 Gumroad 是为了接收早期用户的支持。扩展本身一直保持免费开源——Gumroad 从未作为该工具的付费门槛。

AI Summary Helper 是一款免费的 Chrome 扩展程序。
