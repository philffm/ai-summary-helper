产品 · 2026年11月

byPhil Cloud 现在支持欧盟模式：一个开关，如实标注

可选的托管服务现在可以只把请求发送到欧盟端点，模型选择器会告诉您哪些模型来自欧盟公司，哪些只是运行在欧盟区域。

简而言之。 如果您使用 byPhil Cloud，现在可以开启 优先使用欧盟服务器。此后请求只会发送到模型服务商的欧盟端点，不会回退到其他地方。模型选择器会把每个模型标记为 欧盟公司 或 欧盟服务器，并为每个服务商提供一键 自动选择 预设。这是一项带欧盟选项的便利功能，并不是声称本服务完全主权自主。本文解释两者的区别。

有哪些变化

byPhil Cloud 是使用 AI Summary Helper 的可选托管方式：它包含在您的 byPhil 账户中，因此无需 API key。此前您选好模型后，路由会挑最便宜、最快的线路。现在模型选择器新增了欧盟模式，布局也更清晰：

  • 一个开关。 开启 优先使用欧盟服务器 后，请求会固定发往模型服务商的欧盟端点。如果某个模型没有欧盟线路，请求不会被悄悄发到别处。
  • 自动预设。 自动选择、 自动选择 · Mistral、 自动选择 · Google、 自动选择 · DeepSeek、 自动选择 · Anthropic 以及 自动选择 · OpenAI 会为您选择合适的模型。开启欧盟开关后，它们只会选择有欧盟线路的模型。
  • 两种标记。 欧盟公司 表示该服务商总部位于欧洲（Mistral，位于巴黎）。 欧盟服务器 表示其他地区的公司在欧盟区域运行该模型。
  • 搜索与最近使用。 最近使用的模型显示在顶部，搜索框可以找到任意云端模型。没有欧盟线路的模型仍可选择，但会加以标记，避免您无意中切换。

模型选择器与使用模型的另外两种方式（自己的 key 和本地 Ollama 模型）放在同一处，因此改变主意只需点一下（三种方式对比）。

欧盟公司和欧盟服务器不是一回事

这正是多数产品页面含糊带过的部分。一个模型可能在 物理上 位于欧洲，却仍属于受美国法律管辖的公司。美国《CLOUD Act》允许美国当局要求总部在美国的服务商交出其控制的数据，无论数据存放在哪里；这与 GDPR 如何协调存在争议（法律背景及来源）。因此我们把两种情况分开标注，由您决定对您阅读的内容而言哪一种更重要。

  • 欧盟公司： 受欧盟法律和所在国法律管辖。如果您在意司法管辖权，这一项适合您。
  • 欧盟服务器： 处理过程中您的文本留在欧盟境内。如果您在意数据所在位置，这一项适合您，并且还能使用并非来自欧洲的更强模型。

两者都不是保证。服务商、合作关系和投资方都会变化，请查看服务商的最新条款。

它做不到什么

把局限说清楚，比讲一个漂亮故事更重要：

  • 托管服务的服务器和数据库运行在德国的 IONOS。之后您的文本会经由美国公司 OpenRouter 发送给模型服务商。欧盟开关固定的是模型运行的地点，并不改变参与的是哪些公司。
  • 如果您需要最稳妥的方案，请使用您信任的服务商和自己的 key，或使用 Ollama 本地模型，这样网页文本永远不会离开您的电脑。
  • 模型并不相同。欧洲模型是日常阅读的合理选择，但如果您需要目前最好的质量，带欧盟线路的美国模型可能更胜任。如何取舍由您决定，这正是模型选择器的意义。

为什么这样设计

数字主权不在于拥有最好的模型。模型会改进，也会更换所有者、价格和条款。真正保护您的是能够切换：从一个模型换到另一个，从云端换到自己的 key，从自己的 key 换到本地模型，而不丢失资料库，也不必重新学习工具。无论如何，您的文章、摘要和高亮都留在您的设备上（隐私政策）；模型选择器只决定由谁来阅读您提问页面的文本。

因此欧盟模式是这架阶梯上的又一级，而不是终点。它让最省事的方案（无需 key、无需配置）在文本去向上多一分谨慎。

如何开启

  1. 打开 AI Summary Helper 中的模型选择器，然后选择 byPhil Cloud。
  2. 开启 优先使用欧盟服务器 （在设置中）。
  3. 选择带有以下标记的模型： 欧盟公司 或 欧盟服务器 ，或者选择 自动选择 预设。

常见问题解答

使用 byPhil Cloud 需要 API key 吗？

不需要。它包含在您的 byPhil 账户中。如果您愿意，仍然可以使用自己的 key 或本地模型。

byPhil Cloud 是主权自主的选择吗？

不是，我们也不这样描述它。它运行在德国，但通过美国公司 OpenRouter 连接模型。如需最大程度的掌控，请使用自己的 key 或本地模型。

如果模型没有欧盟线路会怎样？

它仍可选择，但会加以标记。开启欧盟开关后， 自动选择 绝不会选中它，请求也不会被改道到欧盟以外。

欧盟公司和欧盟服务器该选哪个？

如果您最看重司法管辖权，请选欧盟公司。如果您希望数据留在欧盟但需要更强的模型，请选欧盟服务器。

AI Summary Helper 是一款免费、开源的浏览器扩展。可使用自己的 key、运行本地模型，或使用 byPhil Cloud。
