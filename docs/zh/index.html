常见问题

安装前需知

按主题、服务商、隐私、归档或平台搜索答案。

使用该工具需要注册账户吗？

不需要。安装后，带上你自己的 AI 服务商密钥或使用本地 Ollama 模型，即可开始保存。只有使用可选的 byphil Cloud 访问或额外的 Kindle/LocalSend 发送时才需要账号。 查看服务商选项 →

哪些数据会被发送到外部？

只有摘要请求会发送到你配置的 AI 服务商。RSS 也需要向你订阅的订阅源发起请求；AI 摘要回顾仅在你主动请求时发送标题和简短片段。搜索、重复检测、标签和推荐都在本地运行。 了解设备端架构 →

我的页面或高亮内容会被用于训练模型吗？

AI Summary Helper 不会使用你的内容训练自己的模型。使用 BYOK 时，适用你所选服务商的数据政策。使用 Ollama 时，摘要请求留在你的机器上。 了解隐私模型 →

是否可以完全脱离云端依赖运行？

可以。将它指向本地 Ollama 模型，摘要步骤也会留在你的机器上。其他一切本来就已在本地运行。 对比 BYOK 与 Ollama →

我的阅读归档存放在哪里？

默认存放在你设备上的浏览器中。你可以将其导出为 Markdown，或加密备份到你自己的 Nextcloud、WebDAV 服务器、S3 存储桶或本地文件夹。 阅读同步指南 →

如果我清除浏览器数据会怎样？

如果没有备份，清除本地浏览器数据可能会删除本地归档。在清除浏览器数据或切换配置文件之前，请先导出你的资料库，或配置加密同步到你自己的存储。 阅读备份与同步指南 →

支持哪些 AI 服务商和模型？

你可以使用 OpenAI、Gemini、Mistral、DeepSeek、兼容的自定义端点，或本地 Ollama 模型。带上你自己的密钥，或使用可选的 byphil Cloud 访问。 了解 BYOK 如何运作 →

我可以摘要 PDF、YouTube 视频和 RSS 条目吗？

可以。摘要浏览器中打开的 PDF 或从磁盘附加的文件、通过字幕摘要 YouTube 视频，以及来自内置 RSS 阅读器的文章。 观看工作流视频 → 了解订阅源摘要合集 →

AI 摘要有多可靠？

AI 输出可能有误，不能替代对原文的核实。追问的回答会显示其所依据的段落，方便你将摘要与原始页面进行对比。 了解 10 秒来源核查 →

支持哪些浏览器和平台？

使用浏览器扩展、原生侧边栏或书签小工具。Android 配套应用可从手机添加链接；iOS 暂不可用。 了解浏览器与采集工作流 →

如何安装 Android 配套应用？

从以下位置下载 APK： 最新发布页面，然后在 设置 → 手机收件箱 下扫描二维码进行配对。目前尚未上架 Google Play。 了解采集如何融入工作流 →

Support Pass 能解锁什么？

Support Pass 为独立开源开发提供资金，并可解锁可选的 byphil Cloud AI 访问或额外的 Kindle/LocalSend 发送。你的本地归档和本地使用不会因此被锁定。 了解可选云端的边界 →

如果我停止赞助该项目，已保存的内容会受影响吗？

您的归档数据将完整保留在原处——即您设备上的浏览器本地存储中。Support Pass 仅用于解锁依赖云端的增值功能（如 byphil Cloud AI、无限次 Kindle/LocalSend 推送），绝不会限制您访问或管理已有保存内容。 看看 Digest 如何让收藏重新有用 →

这个项目开源吗？

是的——该扩展程序的源代码已公开在 GitHub，采用 AGPL-3.0 许可证。个人、教育及非营利用途可免费使用；企业若需在 AGPL 条款范围外使用，可获取商业授权。 了解本地架构 →
