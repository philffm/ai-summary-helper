Kuvitus, tekoälyn luoma

Opas · Lokakuu 2026

Käytä kirjastoasi Claudessa, LM Studiossa ja muissa tekoälysovelluksissa

Tekoälysovelluksesi unohtaa kaiken lukemasi. AI Summary Helper muistaa sen. Yhdistä ne omalla tietokoneellasi, niin sovelluksesi voi hakea tallennetuista artikkeleistasi, lainata korostuksiasi ja viitata lähteisiisi.

AI Summary Helper voi jakaa kirjastosi Model Context Protocolia (MCP) tukevien tekoälysovellusten kanssa: Claude Desktop, LM Studio, Cursor, VS Code, Jan ja paikalliset agentit. Sovelluksesi kysyy kysymyksen, AI Summary Helper etsii tiedon tallennetuista artikkeleistasi ja vastaus palaa suoraan omalla laitteellasi toimivaan sovellukseen.

Ominaisuus on oletuksena pois päältä. Palvelimemme ei osallistu tähän mitenkään: selainlaajennus ja sovellus viestivät keskenään tietokoneellasi toimivan pienen apuohjelman kautta, aish-mcp, joka ei tallenna artikkeleita eikä välitä mitään minnekään muualle.

Mitä voit kysyä

  • Kysy lukemisistasi, älä internetiltä. ”Mitä olen tallentanut tekoälystä ja valvonnasta? Ryhmittele teemoittain ja kerro, mistä asioista artikkelit ovat eri mieltä.”
  • Kirjoita omista lähteistäsi. ”Luonnostele julkaisu tekoälyn CO₂-kustannuksista ja lainaa korostuksiani.”
  • Vastaa kokoelman kysymykseen. ”Käytä inflaatiokokoelmaani. Vastaa sen kysymykseen vain näitä lähteitä käyttäen ja kerro, mitä puuttuu.”
  • Pysy ajan tasalla tallennetuista artikkeleista. ”Mitä lue myöhemmin -listallani erääntyy tällä viikolla? Anna jokaisesta viiden minuutin tiivistelmä.”
  • Seulo syötteesi. ”Käy läpi tämän päivän lukemattomat tekoälysyötteet ja kerro kolme lukemisen arvoista.”
  • Tarkastele vuottasi. ”Tee lukuvuoteni 2026 kooste: suosituimmat aiheet, vilkkain kuukausi ja vuoden määrittäneet artikkelit.”
  • Anna agentin tallentaa puolestasi. ”Etsi kolme hyvää lähdettä local-first-ohjelmistoista ja tallenna ne AISH-saapuneet-kansiooni muistiinpanon kera.”

LM Studion paikallisella mallilla kaikki tämä toimii myös ilman verkkoyhteyttä.

Käyttöönotto

Tarvitset AI Summary Helperin Chromessa, Edgessä tai Bravessa, Node.js 20 tai uudemman sekä MCP-sovelluksen.

  1. Ota käyttöön. Avaa AI Summary Helperissä Asetukset → Tekoälysovellukset (MCP) ja ota käyttöön Salli tämän tietokoneen tekoälysovellusten käyttää kirjastoani.
  2. Hanki pariliitoskoodi. Suorita terminaalissa npx -y aish-mcp pair. Se tulostaa pariliitoskoodin ja tallentaa sen käyttäjäkansioosi. Liitä koodi asetusnäkymään ja valitse Yhdistä.
  3. Lisää AI Summary Helper sovellukseesi. Käytä alta sovellukseesi sopivaa koodinpätkää, sulje sitten sovellus kokonaan ja avaa se uudelleen.
  4. Tarkista yhteys. Asetusnäkymässä lukee Yhdistetty kun sovelluksesi on käynnissä. Kysy sovellukseltasi jotain kirjastostasi: jokainen sen tekemä kutsu näkyy asetusnäkymän kohdassa Viimeaikainen toiminta.

Claude Desktop

Settings → Developer → Edit Config, ja lisää sitten:

{
  "mcpServers": {
    "aish": { "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

Jos Claude Desktop ei löydä komentoa npx, käytä sen koko polkua, jonka which npx tulostaa terminaalissa (esimerkiksi /opt/homebrew/bin/npx).

Cursor

Tiedostoon ~/.cursor/mcp.json (kaikki projektit) tai .cursor/mcp.json (yksi projekti), lisää sama "aish" -määritys kuin Claude Desktopille.

VS Code

Tiedostoon .vscode/mcp.json:

{
  "servers": {
    "aish": { "type": "stdio", "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

LM Studio ja muut sovellukset

Sovellukset, joissa on mcpServers -asetus (LM Studion mcp.json, Jan ja useimmat muut), käyttävät samaa määritystä kuin Claude Desktop. Sovellukset, jotka muodostavat yhteyden vain HTTP:n kautta, voivat käyttää komentoa npx -y aish-mcp --http osoitteessa http://127.0.0.1:47616/, otsakkeella Authorization: Bearer <pariliitoskoodisi>. Valitse paikalliseksi malliksi sellainen, joka tukee työkalukutsuja (tool calling), kuten Qwen 3 tai Llama 3.1 ja uudemmat.

Vain Kirjastosi on päällä, kun kytket ominaisuuden käyttöön. Ota Artikkelin koko teksti, Syötteet ja Tallenna linkkejä käyttöön asetusnäkymästä, jos haluat ne; muutokset tulevat voimaan seuraavassa kutsussa ilman uudelleenyhdistämistä. Sovelluksesi ei voi muokata tai poistaa mitään AI Summary Helperissä.

Yksityisyys ja turvallisuus

  • Mikään ei kulje palvelimemme kautta. Tiedot siirtyvät selaimestasi apuohjelmaan ja edelleen tietokoneellasi olevaan sovellukseen. Se, mitä sovellus lähettää mallilleen, riippuu valitsemastasi sovelluksesta ja mallista. Paikallinen malli pitää kaiken omalla laitteellasi.
  • Artikkelit, joihin lisäät tunnisteen private , eivät koskaan näy, missään hakutuloksessa, määrässä tai kokoelmassa. Voit valita toisen tunnisteen asetusnäkymässä.
  • Vain oma tietokoneesi voi muodostaa yhteyden. Apuohjelma kuuntelee vain osoitetta 127.0.0.1, joten mikään muu verkossasi oleva laite ei pääse siihen käsiksi. Vierailusi verkkosivustotkaan eivät voi käyttää sitä: se hyväksyy vain AI Summary Helperin oman laajennusosoitteen, ja jokaisessa yhteydessä on oltava pariliitoskoodisi.
  • Näet jokaisen kutsun. Asetusnäkymä listaa viimeisimmät 50 kutsua työkalun nimen ja ajan kera, ei koskaan sisältöä.
  • Voit katkaista yhteyden milloin tahansa. Kytke ominaisuus pois päältä tai valitse Katkaise yhteys. Suorita npx -y aish-mcp reset mitätöidäksesi vanhan pariliitoskoodin.
  • Tallennetut sivut ovat tekstiä verkosta. Sovellustasi ohjeistetaan käsittelemään niitä tietona, ei ohjeina, mutta tallennettu sivu voi silti yrittää johtaa tekoälyä harhaan. Pidä Tallenna linkkejä -käyttöoikeus pois päältä, ellet käytä sitä.

Jos jokin ei toimi

NäetMitä tehdä
Näkymässä lukee Ei yhdistettyTekoälysovelluksesi ei ole käynnissä tai sitä ei ole vielä määritetty. Avaa se tai suorita npx -y aish-mcp terminaalissa testataksesi yhteyttä.
Sovelluksesi ei näytä AI Summary Helper -työkaluja tai uudet puuttuvat päivityksen jälkeenSulje sovellus kokonaan ja avaa se uudelleen. Jotkin sovellukset lukevat työkaluluettelon vain käynnistyessään.
”AISH is not running”Selaimesi on suljettu tai ominaisuus on kytketty pois päältä. Avaa selain ja tarkista asetusnäkymä.
”Scope … is not enabled”Sovelluksesi pyysi jotain, mitä et ole sallinut. Ota se käyttöön asetusnäkymässä, jos haluat sallia sen.
Yhteys ei muodostu koodin liittämisen jälkeenSuorita npx -y aish-mcp pair ja liitä sen tulostama koodi uudelleen. Se vaihtuu komennolla reset.

Useamman tekoälysovelluksen samanaikainen käyttö onnistuu vaivattomasti: ne jakavat saman yhteyden.
