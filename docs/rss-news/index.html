Questions

Before you install

Search the answers by topic, provider, privacy, archive or platform.

Do I need an account to use it?

No. Install it, bring your own AI provider key or use a local Ollama model, and start saving. An account is only needed for optional byphil Cloud access or extra Kindle/LocalSend sends. See the provider options →

What actually leaves my browser?

Only the summarization request goes to the AI provider you configured. RSS also needs requests to your subscribed feeds; an AI recap sends headlines and short snippets only when you request it. Search, duplicate detection, tags and recommendations run locally. See the on-device architecture →

Which AI providers and models are supported?

You can use OpenAI, Gemini, Mistral, DeepSeek, a compatible custom endpoint, or a local Ollama model. Bring your own key, or use optional byphil Cloud access. Learn how BYOK works →

Can I summarize PDFs, YouTube videos and RSS items?

Yes. Summarize PDFs opened in the browser or attached from disk, YouTube videos through their captions, and articles from the built-in RSS reader. Watch the workflow videos → Read about feed digests →

How reliable are the AI summaries?

AI output can be wrong and does not replace checking the source. Follow-up answers show the passage they rely on, so you can compare the summary with the original page. Learn the 10-second source check →

Which browsers and platforms are supported?

Use the browser extension, native side panel or bookmarklet. An Android companion adds links from your phone; iOS is not available yet. See the browser and capture workflow →

Is this open source?

Yes — the extension's source is public on GitHub, under the AGPL-3.0 license. It is free for personal, educational and non-profit use; companies that want to use it outside the AGPL's terms can get a commercial license. Read about the local architecture →
