Guide · Oktober 2026

Använd ditt bibliotek i Claude, LM Studio och andra AI-appar

Din AI-app glömmer allt du har läst. AI Summary Helper kommer ihåg det. Koppla ihop dem på din egen dator så kan appen söka bland dina sparade artiklar, citera dina markeringar och ange dina källor.

AI Summary Helper kan dela ditt bibliotek med AI-appar som stöder Model Context Protocol (MCP): Claude Desktop, LM Studio, Cursor, VS Code, Jan och lokala agenter. Din app ställer en fråga, AI Summary Helper slår upp svaret bland dina sparade artiklar, och svaret går direkt tillbaka till appen på din dator.

Funktionen är avstängd som standard. Inget passerar våra servrar: tillägget och appen pratar med varandra via ett litet hjälpprogram på din dator, aish-mcp, som varken sparar artiklar eller vidarebefordrar något någon annanstans.

Vad du kan fråga

  • Fråga det du har läst, inte internet. ”Vad har jag sparat om AI och övervakning? Gruppera efter tema och berätta var artiklarna skiljer sig åt.”
  • Skriv utifrån dina egna källor. ”Skriv ett utkast till ett inlägg om AI:s koldioxidavtryck och citera mina markeringar.”
  • Besvara frågan i en samling. ”Använd min samling om inflation. Besvara frågan enbart utifrån dessa källor och berätta vad som saknas.”
  • Kom ikapp med sparade artiklar. ”Vad står på tur den här veckan från min spara till senare-lista? Ge mig en femminutersversion av varje.”
  • Prioritera i dina flöden. ”Gå igenom dagens olästa flödesinlägg om AI och berätta vilka tre som är värda att läsa.”
  • Se ditt läsår. ”Skapa min årssammanfattning för läsningen 2026: toppämnen, mest aktiva månad och artiklarna som präglade året.”
  • Låt en agent spara åt dig. ”Hitta tre bra källor om local-first-mjukvara och spara dem i min AISH-inkorg med en anteckning.”

Med en lokal modell i LM Studio fungerar allt detta även med nätverket avstängt.

Kom igång

Du behöver AI Summary Helper i Chrome, Edge eller Brave, Node.js 20 eller senare, samt en MCP-app.

  1. Slå på det. Öppna Inställningar → AI-appar (MCP) i AI Summary Helper och aktivera Låt AI-appar på den här datorn använda mitt bibliotek.
  2. Hämta din parkopplingskod. Kör följande i en terminal: npx -y aish-mcp pair. Den visar en parkopplingskod och sparar den i din användarmapp. Klistra in koden i inställningspanelen och välj Anslut.
  3. Lägg till AI Summary Helper i din app. Använd kodavsnittet för din app nedan, stäng sedan appen helt och öppna den igen.
  4. Kontrollera anslutningen. Inställningspanelen visar Ansluten så snart din app körs. Fråga din app något om ditt bibliotek: varje anrop den gör syns under Senaste aktivitet i panelen.

Claude Desktop

Settings → Developer → Edit Config, lägg sedan till:

{
  "mcpServers": {
    "aish": { "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

Om Claude Desktop inte kan hitta npx, använd dess fullständiga sökväg, som which npx visar i en terminal (till exempel /opt/homebrew/bin/npx).

Cursor

I ~/.cursor/mcp.json (alla projekt) eller .cursor/mcp.json (ett projekt), lägg till samma "aish" -post som för Claude Desktop.

VS Code

I .vscode/mcp.json:

{
  "servers": {
    "aish": { "type": "stdio", "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

LM Studio och andra appar

Appar med en mcpServers -inställning (LM Studios mcp.json, Jan och de flesta andra) använder samma post som Claude Desktop. Appar som bara ansluter via HTTP kan använda npx -y aish-mcp --http på http://127.0.0.1:47616/, med headern Authorization: Bearer <din parkopplingskod>. För en lokal modell, välj en som har stöd för tool calling, till exempel Qwen 3 eller Llama 3.1 och senare.

Integritet och säkerhet

  • Inget går via våra servrar. Data går från din webbläsare till hjälpprogrammet och vidare till appen på din dator. Vad appen sedan skickar till sin modell beror på vilken app och modell du har valt. En lokal modell behåller allt på din maskin.
  • Artiklar du taggar med private visas aldrig, varken i sökresultat, statistik eller samlingar. Du kan välja en annan tagg i inställningspanelen.
  • Endast din dator kan ansluta. Hjälpprogrammet lyssnar endast på 127.0.0.1, så inget annat på ditt nätverk kan nå det. Webbplatser du besöker kan inte heller använda det: det accepterar endast AI Summary Helpers egen tilläggsadress, och varje anslutning måste innehålla din parkopplingskod.
  • Du kan se varje anrop. Inställningspanelen visar de senaste 50 anropen med verktygsnamn och tidpunkt, aldrig innehållet.
  • Du kan bryta anslutningen när som helst. Stäng av funktionen eller välj Koppla från. Kör npx -y aish-mcp reset för att göra den gamla parkopplingskoden ogiltig.
  • Sparade sidor är text från webben. Din app instrueras att behandla dem som information och inte som instruktioner, men en sparad sida kan ändå försöka vilseleda en AI. Låt behörigheten Spara länkar vara avstängd om du inte använder den.

Om något inte fungerar

Du serÅtgärd
Panelen visar Inte anslutenDin AI-app körs inte eller är inte konfigurerad än. Öppna den, eller kör npx -y aish-mcp i en terminal för att testa anslutningen.
Din app visar inga AI Summary Helper-verktyg, eller saknar nya efter en uppdateringStäng appen helt och öppna den igen. Vissa appar läser bara in verktygslistan när de startar.
”AISH is not running”Din webbläsare är stängd eller så är funktionen avstängd. Öppna webbläsaren och kontrollera inställningspanelen.
”Scope … is not enabled”Din app efterfrågade något du inte har tillåtit. Slå på det i inställningspanelen om du vill använda det.
Panelen ansluter aldrig efter att du klistrat in kodenKör npx -y aish-mcp pair och klistra in koden den visar igen. Den ändras efter reset.

Det går utmärkt att köra flera AI-appar samtidigt – de delar på samma anslutning.
