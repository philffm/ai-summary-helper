你的 API Key。你的模型。你的資料。

大多數 AI 工具都會在你與模型之間架設一層伺服器。以下將說明少了這層中介時會有何改變，以及哪些部分仍取決於你的設定。

每一次 AI 摘要的運作流程都大同小異：傳出文字，取回摘要。決定你是否能信任該工具的關鍵，在於誰處於中間位置。許多產品會在中間架設自家伺服器，你正在閱讀的內容在傳送給預設模型前，都會先經過他們的伺服器。

在這裡，「自備 API Key」究竟代表什麼

你只需向信任的提供商申請 API Key，貼到 AI Summary Helper 並選擇模型即可。當你摘要網頁時，擴充功能的背景程序會直接將文字發送到該提供商，並即時串流傳回結果。使用自己的 API Key 時，整個過程中完全沒有 AI Summary Helper 的伺服器介入。

你也可以將它指向在自己電腦上運行的模型（例如透過 Ollama）。在這種情況下，網頁文字完全不會離開你的電腦。

你的 API Key 儲存在哪裡

API Key 儲存在瀏覽器的本機擴充功能儲存空間，而非同步儲存空間。這意味著它不會透過瀏覽器帳號同步複製到其他裝置；反之，你需要在每個瀏覽器中各自輸入一次。API Key 僅會用於與你設定的提供商通訊。

這能保護什麼，又無法保護什麼

這一點必須精確說明：自備 API Key 只是去除了中間人，但並未去除模型提供商。任何傳送到雲端託管模型的內容，依然受該提供商的服務條款與資料保留政策規範，請務必詳閱。只有本機模型才能確保文字完全保留在你的電腦中，不過本機模型通常比雲端託管模型規模更小、速度更慢。

本專案完全開源，因此你不需要盲目信任這些承諾。處理 API Key 與請求的原始碼都在儲存庫中，隨時可供檢視。

選擇適合你的配置方案

  1. 日常閱讀： 選擇你認同其條款的雲端託管模型提供商。速度快、品質優良，且 API Key 完全由你掌控。
  2. 處理敏感內容： 使用本機模型。雖然速度較慢且能力稍弱，但資料完全不會離開電腦。
  3. 測試與探索： 新增多個提供商，並在同一篇文章上比較回答。這是了解哪款模型最適合哪類文本的最快途徑。

重點不在於哪種配置才是唯一解答，而是選擇權始終掌握在你手中。

AI Summary Helper 是一款免費的 Chrome 擴充功能。
