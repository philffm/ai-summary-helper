byPhil Cloud 現在支援歐盟模式：一個開關，誠實標示

選用的託管服務現在可以只將要求傳送到歐盟端點，模型選擇器會告訴您哪些模型來自歐盟企業，哪些只是在歐盟區域執行。

重點摘要。 如果您使用 byPhil Cloud，現在可以開啟 優先使用歐盟伺服器。之後要求只會傳送到模型供應商的歐盟端點，不會退回到其他地方。模型選擇器會將每個模型標示為 歐盟企業 或 歐盟伺服器，並為每個供應商提供一鍵 自動 預設。這是附帶歐盟選項的便利功能，並非宣稱本服務完全自主。本文說明兩者的差異。

有哪些改變

byPhil Cloud 是使用 AI Summary Helper 的選用託管方式：它包含在您的 byPhil 帳戶中，因此不需要 API Key。以往您選好模型後，路由會挑最便宜、最快的路徑。現在模型選擇器新增了歐盟模式，版面也更清楚：

  • 一個開關。 開啟 優先使用歐盟伺服器 後，要求會固定傳往模型供應商的歐盟端點。如果某個模型沒有歐盟路由，要求不會被默默送到別處。
  • 自動預設。 自動、 自動 · Mistral、 自動 · Google、 自動 · DeepSeek、 自動 · Anthropic 以及 自動 · OpenAI 會為您挑選合適的模型。開啟歐盟開關後，它們只會挑選有歐盟路由的模型。
  • 兩種標章。 歐盟企業 表示供應商設於歐洲（Mistral，位於巴黎）。 歐盟伺服器 表示其他地區的公司在歐盟區域執行該模型。
  • 搜尋與最近使用。 最近使用的模型顯示在最上方，搜尋框可找到任何雲端模型。沒有歐盟路由的模型仍可選取，但會加上標示，讓您不會不小心切換。

模型選擇器與使用模型的另外兩種方式（自己的金鑰與本機 Ollama 模型）放在同一處，因此改變主意只需點一下（三種方式比較）。

歐盟企業與歐盟伺服器並不相同

這正是多數產品頁面含糊帶過的部分。一個模型可能在 實體上 位於歐洲，卻仍屬於受美國法律管轄的公司。美國《CLOUD Act》允許美國當局要求總部在美國的供應商交出其掌控的資料，無論資料存放何處；這與 GDPR 如何相容仍有爭議（法律背景與資料來源）。因此我們將兩種情況分開標示，由您決定對您閱讀的內容而言哪一種重要。

  • 歐盟企業： 受歐盟法律與所在國法律管轄。如果您在意司法管轄權，適合選這一項。
  • 歐盟伺服器： 處理期間您的文字留在歐盟境內。如果您在意資料所在位置，適合選這一項，而且還能使用非歐洲的更強模型。

兩者都不是保證。供應商、合作關係與投資者都會改變，請查看供應商目前的條款。

它做不到什麼

把限制說清楚，比說一個漂亮的故事更重要：

  • 託管服務的伺服器與資料庫在德國的 IONOS 上執行。之後您的文字會經由美國公司 OpenRouter 傳給模型供應商。歐盟開關固定的是模型執行的地點，並不改變參與的是哪些公司。
  • 如果您需要最穩妥的設定，請使用您信任的供應商和自己的金鑰，或使用 Ollama 本機模型，網頁文字永遠不會離開您的電腦。
  • 模型並不相同。歐洲模型是日常閱讀的合理選擇，但如果您需要現有最佳品質，具歐盟路由的美國模型可能更能勝任。如何取捨由您決定，這正是模型選擇器的意義。

為什麼這樣設計

數位主權不在於擁有最好的模型。模型會進步，也會更換擁有者、價格與條款。真正保護您的是能夠切換：從一個模型換到另一個，從雲端換到自己的金鑰，從自己的金鑰換到本機模型，而不遺失資料庫，也不必重新學習工具。無論如何，您的文章、摘要與醒目標示都留在您的裝置上（隱私權政策）；模型選擇器只決定由誰閱讀您提問頁面的文字。

因此歐盟模式是這道階梯的又一階，而非終點。它讓最省事的選項（不需金鑰、不需設定）對文字的去向多一分謹慎。

如何開啟

  1. 開啟 AI Summary Helper 中的模型選擇器，然後選擇 byPhil Cloud。
  2. 開啟 優先使用歐盟伺服器 （位於設定中）。
  3. 選擇帶有以下標章的模型： 歐盟企業 或 歐盟伺服器 ，或選擇 自動 預設。

常見問題

使用 byPhil Cloud 需要 API Key 嗎？

不需要。它包含在您的 byPhil 帳戶中。如果您願意，仍可使用自己的金鑰或本機模型。

byPhil Cloud 是自主主權的選擇嗎？

不是，我們也不這樣描述它。它在德國執行，但透過美國公司 OpenRouter 連接模型。若要最大程度的掌控，請使用自己的金鑰或本機模型。

如果模型沒有歐盟路由會怎樣？

它仍可選取，但會加上標示。開啟歐盟開關後， 自動 絕不會選中它，要求也不會被改送到歐盟以外。

歐盟企業和歐盟伺服器該選哪一個？

如果您最重視司法管轄權，請選歐盟企業。如果希望資料留在歐盟但需要更強的模型，請選歐盟伺服器。

AI Summary Helper 是免費的開源瀏覽器擴充功能。可使用自己的金鑰、執行本機模型，或使用 byPhil Cloud。
