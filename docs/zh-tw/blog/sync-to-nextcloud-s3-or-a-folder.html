如何將閱讀庫加密同步至 Nextcloud、S3 或本機資料夾

在所有電腦上同步已儲存的文章、摘要、重點與筆記。儲存位置由您決定，僅能以您的密鑰讀取。只需 10 分鐘，無需註冊我們的帳號。

簡易速覽。 在 AI Summary Helper 中開啟 Settings → Sync & backup → Add a place，選擇 Nextcloud/WebDAV、S3 相容儲存空間或電腦上的資料夾，並保留系統建議的密碼短語（passphrase）。所有資料在瀏覽器中加密後才會上傳。在第二部電腦上，只需新增相同儲存位置並輸入密碼短語即可。這就是全部的設定流程。本頁其餘部分將介紹各儲存空間類型、同步內容以及遇到問題時的處理方式。

為什麼要這樣做？因為閱讀庫值得長久保存，而您依賴的工具隨時可能停止營運（詳情請參閱此處）。同步至您擁有的儲存空間，意味著即使某個應用程式或帳號不再可用，閱讀庫依然完好如初。

哪些內容會同步，哪些不會

  • 會同步： 已儲存的文章（含全文與摘要）、標籤、重點畫線、您的筆記與註釋，以及收藏夾。
  • 不會同步： 您的 API Key、登入資訊、同步登入憑證本身以及個別裝置的專屬設定。備份與同步會特意排除這些項目。
  • 每個頁面保留一篇： 若在兩部電腦上儲存了相同頁面，最終會合併為單一文章（標籤與缺失欄位將自動合併）。
  • 依欄位逐項合併編輯： 若在一台電腦上修改標題，在另一台電腦上新增標籤，兩項變更都會保留。若同時修改同一個欄位，則以較新的變更為準，各裝置皆維持一致。

步驟 1：選擇儲存位置

Nextcloud 或其他 WebDAV 伺服器

如果您已經自建 Nextcloud，或使用託管服務（許多歐洲雲端服務商均有提供），這是最佳選擇。您只需要三樣東西：

  1. 檔案的存取位址。 Nextcloud 的格式通常如下： https://your-server/remote.php/dav/files/your-username/。在 Nextcloud 中開啟 Files → Settings 並複製該處顯示的 WebDAV 位址。
  2. 您的使用者名稱。
  3. 應用程式專用密碼（App Password），而非主要密碼。 在 Nextcloud 中： Settings → Security → Devices & sessions → create a new app password。若日後想撤銷存取權限，直接刪除該項目即可。

選擇一個資料夾名稱，例如 aish-sync。系統會自動為您建立。其他 WebDAV 伺服器（許多 NAS 裝置、ownCloud）也是同樣的運作方式，僅位址格式略有不同。

S3 相容儲存桶（Bucket）

適合偏好物件儲存（Object Storage）的使用者：AWS S3、Cloudflare R2、Backblaze B2、MinIO 等。建立一個 Bucket，然後建立一組存取金鑰（Access Key） 僅限此 Bucket 並賦予該 Bucket 的讀取、寫入、列出與刪除權限。切勿使用帳號的主要金鑰。在擴充功能中輸入端點位址（Endpoint，例如 https://s3.eu-central-1.amazonaws.com，或您的服務商所提供的位址）、Bucket 名稱、地區（Region，若服務商無要求可保留預設）、Access Key ID 及 Secret Key。

電腦上的本機資料夾

適合已經在使用其他工具在裝置間同步資料夾的使用者：例如 Syncthing、桌面同步客戶端、iCloud Drive 或 USB 隨身碟。選擇 本機電腦上的資料夾 並選取一個 自行建立的全新空白資料夾，例如 Documents/AISH-sync。Chrome 不允許直接選擇「桌面」、「文件」或「下載」等根目錄，因此請選擇其中的子資料夾。此功能適用於電腦版 Chrome 及 Edge。有兩點需要注意：瀏覽器重新啟動後可能需要再次授權存取（設定畫面會顯示授權按鈕），且資料夾僅在瀏覽器開啟運作時持續同步。

步驟 2：選擇加密模式並妥善保存密碼短語

新增儲存位置時， Encrypted 為預設選取，同步用途預設為 Sync my devices 。擴充功能會建議由 6 個隨機單字組成的密碼短語。您可以點擊 Another suggestion 直到產生滿意的組合，也可以自訂密碼（至少 12 個字元，若強度不足會顯示提示）。

連線完成後，這 6 個單字只會顯示一次。請將它們儲存至密碼管理器；「複製」按鈕會以連字號連接這組單字並複製到剪貼簿，方便在設定檔或即時通訊軟體中傳遞且不易格式錯亂。有了這組密碼短語，您就能在任何裝置上開啟儲存庫；沒有它，包括我們在內的任何人都無法解密檔案。在完成設定的本機電腦上，您可以隨時在該儲存位置的設定中重新查看： Show passphrase。若您使用的是自訂密碼短語，系統不會儲存在任何地方，因此擴充功能無法再次顯示。

儲存服務商能看到的僅有：經過加密混淆的檔案與檔名、檔案數量、檔案大小以及變更時間。他們無法得知文章標題、連結或內文。您的閱讀庫在離開裝置前，已在瀏覽器內透過 AES-256-GCM 完成加密。

步驟 3：新增第二部電腦

  1. 安裝擴充功能並開啟 Settings → Sync & backup → Add a place。
  2. 輸入相同的伺服器資訊（或選取相同的資料夾）。
  3. 擴充功能偵測到該資料夾已包含加密的閱讀庫，並會要求輸入密碼短語。大小寫不拘，使用空格或連字號分隔皆可辨識。
  4. 系統會要求確認您已先為此裝置建立備份，因為加入同步會將此電腦的閱讀庫與資料夾中的內容合併，若兩者發生衝突，將以資料夾內容為準。請點選 Make a backup now。
  5. 點擊 Connect。如果閱讀庫龐大，首次同步可能需要一些時間；畫面上會顯示進度。

僅備份、還原與發佈

  • 僅備份（Backup only）。 選擇 Backup only 而非 Sync my devices ，電腦就只會單向寫入該儲存位置，絕不讀取。需要時可從該儲存位置的設定中執行還原：系統會復原所有內容，若此電腦有不同之處則以儲存庫內容為準，且不會刪除任何資料。
  • 發佈至個人網站。 另一種儲存位置模式 Readable，會為您已標籤的文章寫入明文檔案以供個人網站使用，並可選用檢視頁面。除非主動開啟，否則筆記與全文不會匯出，因為任何能存取該資料夾的人都能讀取。請勿將明文可讀位置用於機密或私隱資料。

常見問題排解

「Allow access to the folder again」（再次允許存取資料夾）

瀏覽器重新啟動後會收回資料夾存取權限。請點擊頂端的按鈕： Sync & backup。如果持續失敗，該資料夾可能是 Chrome 受保護的目錄（桌面、文件、下載或使用者家目錄）：請改選您自行建立的子資料夾。

「The server did not accept the username and password」（伺服器無法接受使用者名稱與密碼）

使用 Nextcloud 時請務必建立應用程式專用密碼。檢查位址結尾是否為您的使用者名稱資料夾，並確認雙重驗證（2FA）未阻擋應用程式密碼。

「Wrong passphrase」（密碼短語錯誤）

檢查單字拼寫：大小寫、空格或連字號均不影響，但每個單字都必須正確。在已完成設定的電腦上，開啟該儲存位置設定並點選 Show passphrase。如果您在所有裝置上都遺失了密碼短語，將無人能夠開啟這些檔案：請在此處移除該儲存位置，建立新位置，並以本機電腦上的閱讀庫重新開始。

出現大量待刪除提示

若另一部裝置同時刪除了大量文章，擴充功能會先套用少數刪除並在處理剩餘項目時彈出詢問，避免因單次誤操作而清空整個閱讀庫。確認無誤後，點擊按鈕即可套用變更。

電腦數月未連線同步

離線約三個月後，電腦只會傳送這段期間新增或修改的內容，不會主動執行刪除，確保在其他裝置上已刪除的舊文章不會意外被復原。

常見問題

我需要註冊你們的帳號嗎？

不需要。同步是直接由您的瀏覽器與輸入的儲存空間通訊。我們沒有營運任何同步伺服器。

可以在手機上使用嗎？

Android 可以。隨附 App（可從 GitHub Releases取得 APK；尚未上架 Google Play）可在 Settings → Library sync中加入您的閱讀庫。最快的方式是透過行動條碼：在瀏覽器中開啟儲存位置設定，點擊 Show code for the phone 並進行掃描。該條碼包含您的伺服器登入憑證，因此請僅供自己的手機掃描。手機端會顯示已儲存的文章、摘要及重點畫線，筆記亦支援雙向同步。在手機上摘要的頁面與標註的段落也會匯入閱讀庫，但僅限於閱讀庫尚未收錄的頁面：瀏覽器現有的內文絕不會被覆蓋。目前尚無 iPhone 專用 App。

我可以設定多個儲存位置嗎？

可以。常見的配置是設定一個加密位置用於多部電腦間同步，並在另一個雲端服務商設定一個「僅備份」位置。

把閱讀庫放到雲端安全嗎？

比大多數方案更安全，因為雲端服務商只持有加密後的檔案。但整體安全性仍取決於您的密碼短語強度與裝置防護。請詳閱 透明局限性說明，包括本加密機制尚未經過獨立第三方審計。

AI Summary Helper 是一款免費且開源的瀏覽器擴充功能。在您主動新增儲存位置之前，同步功能處於關閉狀態。
