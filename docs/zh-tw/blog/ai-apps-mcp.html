指南 · 2026 年 10 月

在 Claude、LM Studio 及其他 AI 應用程式中使用您的資料庫

你的 AI 應用會忘記你讀過的所有內容，但 AI Summary Helper 能幫你記住。只要在你的電腦上將兩者連線，AI 應用就能搜尋已儲存的文章、引用你的重點劃線並標註出處。

AI Summary Helper 可將你的資料庫分享給支援 Model Context Protocol (MCP) 的 AI 應用：Claude Desktop、LM Studio、Cursor、VS Code、Jan 以及本地 Agent。當應用提出問題時，AI Summary Helper 會在已儲存的文章中查找，並直接在你的本機電腦上將答案回傳給該應用。

此功能預設為關閉。整個過程完全不涉及我們的伺服器：擴充功能與應用程式是透過你電腦上的輕量小程式相互通訊， aish-mcp，該程式不會儲存任何文章，也不會將任何資料轉發到其他地方。

你可以詢問的內容

  • 向你的閱讀積累提問，而非搜尋整個網路。 「我儲存了哪些關於 AI 與監控的文章？請依主題分組，並指出文章觀點的不同之處。」
  • 基於你自己的資料來源進行撰寫。 「草擬一篇關於 AI 碳排放成本的文章，並引用我的重點劃線。」
  • 解答收藏夾中的問題。 「使用我關於通貨膨脹的收藏夾。僅根據這些資料來源回答問題，並說明缺少了哪些資訊。」
  • 跟進稍後閱讀清單。 「我的稍後閱讀清單中這週有哪些到期？為每篇提供 5 分鐘速讀版本。」
  • 快速篩選你的 Feed 訂閱。 「瀏覽今天未讀的 AI 相關 Feed，挑選出最值得閱讀的 3 篇。」
  • 回顧你的年度閱讀歷程。 「製作我的 2026 年度閱讀回顧：熱門主題、閱讀量最多的月份以及最具代表性的文章。」
  • 讓 Agent 幫你儲存資料。 「尋找 3 個關於 local-first 軟體的優質來源，並附上備註儲存至我的 AISH 收件匣。」

在 LM Studio 中搭配本地模型使用時，即使中斷網路連線，這一切也能正常運作。

設定方式

你需要安裝在 Chrome、Edge 或 Brave 上的 AI Summary Helper， Node.js 20 或更高版本，以及一個 MCP 應用程式。

  1. 開啟功能。 在 AI Summary Helper 中，開啟「設定」→「AI 應用 (MCP)」並開啟 允許此電腦上的 AI 應用使用我的資料庫。
  2. 取得配對碼。 在終端機中執行 npx -y aish-mcp pair。它會顯示一組配對碼並儲存在你的使用者資料夾中。請將配對碼貼上至設定面板，然後點選「連線」。
  3. 將 AI Summary Helper 新增至你的應用程式。 使用下方對應你應用的設定片段，接著將應用程式完全關閉後重新開啟。
  4. 確認連線狀態。 當你的應用程式啟動後，設定面板會顯示 已連線 。向你的應用詢問與資料庫相關的問題：每次呼叫都會顯示在面板的「近期活動」中。

Claude Desktop

Settings → Developer → Edit Config，然後新增：

{
  "mcpServers": {
    "aish": { "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

如果 Claude Desktop 找不到 npx，請使用其完整路徑，可透過在終端機中執行 which npx 來查詢（例如 /opt/homebrew/bin/npx）。

Cursor

在 ~/.cursor/mcp.json （所有專案）或 .cursor/mcp.json （單一專案）中，新增與 Claude Desktop 相同的 "aish" 項目。

VS Code

在 .vscode/mcp.json 中：

{
  "servers": {
    "aish": { "type": "stdio", "command": "npx", "args": ["-y", "aish-mcp"] }
  }
}

LM Studio 與其他應用程式

具備 mcpServers 設定的應用程式（例如 LM Studio 的 mcp.json、Jan 以及大多數其他應用程式）採用與 Claude Desktop 相同的配置。僅支援 HTTP 連線的應用程式可以使用 npx -y aish-mcp --http ，監聽於 http://127.0.0.1:47616/，並附帶標頭 Authorization: Bearer <your pairing code>。若使用本地模型，請選擇支援工具調用 (Tool Calling) 的模型，例如 Qwen 3 或 Llama 3.1 及更新版本。

你的應用程式可以執行的操作

工具功能簡介所需權限
search_library搜尋已儲存的文章，可依標籤、日期或收藏夾進行篩選你的資料庫
get_article單一文章內容及其摘要與重點劃線你的資料庫
list_highlights你的重點劃線（依最新時間排序）你的資料庫
list_due即將到期的稍後閱讀項目你的資料庫
list_collections、 get_collection你的收藏夾及其資料來源你的資料庫
library_stats僅統計數據：儲存歷史趨勢、熱門標籤與網站、閱讀心情、重點劃線統計你的資料庫
get_article 包含全文文章的完整儲存文字（純文字格式）文章全文
list_feed_items來自 Feed 訂閱項目的內容訂閱摘要
save_url將連結及備註儲存至收件匣，並標記為由 AI 應用新增儲存連結

開啟此功能時，只有 你的資料庫 處於啟用狀態。如果需要，可在設定面板中開啟「文章全文」、「Feed」和「儲存連結」；變更會在下一次呼叫時立即生效，無須重新連線。你的應用程式無法編輯或刪除 AI Summary Helper 中的任何內容。

隱私與安全性

  • 任何資料都不會經過我們的伺服器。 資料直接由瀏覽器傳輸給輔助小程式，再傳至你電腦上的應用程式。應用程式隨後向模型發送的內容，完全取決於你選擇的應用與模型。若使用本地模型，所有資料皆完整保留在你的本機電腦上。
  • 被你標記為 private 的文章絕不會出現在任何搜尋結果、統計數據或收藏夾中。你可以在設定面板中指定其他標籤。
  • 僅限你的電腦連線。 輔助程式僅監聽 127.0.0.1，因此區域網路中的其他裝置皆無法存取。你瀏覽的網站也無法使用它：它僅接受 AI Summary Helper 擴充功能本身的位址，且每次連線都必須攜帶配對碼。
  • 所有呼叫紀錄一目了然。 設定面板會列出最近 50 次呼叫的工具名稱與時間，絕不會記錄內容。
  • 你可以隨時切斷連線。 關閉此功能或點選「中斷連線」。執行 npx -y aish-mcp reset 可使舊的配對碼立即失效。
  • 儲存的頁面屬於來自網路的純文字。 雖然系統已指示應用將其視為資料而非指令，但儲存的網頁內容仍可能嘗試誤導 AI。除非有需要，否則建議保持「儲存連結」權限關閉。

疑難排解

遇到的情況解決方法
面板顯示 未連線你的 AI 應用尚未執行或尚未完成設定。請開啟應用，或在終端機中執行 npx -y aish-mcp 以測試連線。
你的應用程式中沒有顯示 AI Summary Helper 工具，或更新後缺少新工具將應用程式完全關閉後重新開啟。部分應用僅在啟動時讀取工具清單。
「AISH is not running」你的瀏覽器已關閉，或該功能已停用。請開啟瀏覽器並確認設定面板。
「Scope … is not enabled」你的應用請求了尚未允許的權限。若有需要，請在設定面板中將其開啟。
貼上配對碼後，面板始終無法連線執行 npx -y aish-mcp pair 並重新貼上所顯示的配對碼。配對碼會在執行 reset 後變更。。

同時執行多個 AI 應用程式完全沒有問題：它們會共用同一個連線。
