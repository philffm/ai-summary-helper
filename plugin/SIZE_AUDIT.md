# AISH size audit (2026-10-10)

Scope: what the store package contains and where it can shrink. Measured with `npm run size` (per file raw and deflated; the deflated total is close to the zip). Estimates below are not measured until marked done.

## Numbers (`plugin/src`, version 2.2.x)
- 148 files, 6.3 MB raw, **1.63 MB deflated** (store zips: about 1.82 MB).
- The package grew from a few hundred KB mostly through three things: PDF reading (PDF.js), 13 languages and the app's own features (feeds, history graph, research mode).

| Area | Deflated | Raw | Note |
| --- | --- | --- | --- |
| `lib/` | 570 KB | 2.7 MB | `pdf.worker.mjs` 352 KB, `pdf.mjs` 114 KB, `d3.min.js` 90 KB, `afinn-111.json` |
| `_locales/` | 482 KB | 1.8 MB | 13 languages, ~37 KB each; 1443 keys in `en`, ~1235 used |
| `modules/` | 327 KB | 1.0 MB | 90 files, not minified |
| root files | 133 KB | 558 KB | `styles.css` 36 KB deflated (197 KB raw), `background.js`, `popup.html` |
| `content/` | 46 KB | 130 KB | also shipped next to the bundled `content.js` |
| icons, fonts | 74 KB | 95 KB | |

## Backlog (largest first, all estimates)
1. **Use the minified PDF.js builds** (`pdf.min.mjs`, `pdf.worker.min.mjs`). `lib/pdf*.mjs` are unminified (57k lines). Saves ~100-150 KB deflated, ~1 MB raw. Check that `content/pdfExtractor.js` still resolves the worker path.
2. **Minify JS and CSS in the build.** `build.sh` only copies and bundles `content.js`. A minifier (esbuild) over `modules/`, `background.js`, `styles.css` saves ~120-150 KB. Keep the unminified sources in the repo; minification is fine for store review.
3. **Reduce d3 to what `archiveGraph.js` uses** (select, scale, force, zoom, drag): 90 KB to ~30 KB deflated.
4. **Prune unused locale keys.** Nothing removes strings that code no longer uses (e.g. "Skip for now", "How should AI Summary Helper think?"). Prune in `scripts/feed-i18n.mjs`, ~50-70 KB. Do not drop languages for size.
5. **Do not ship what is not loaded.**
   - `content/*.js` are only inputs for the content-script bundle (the bundler imports them; nothing loads them at runtime). ~46 KB. Verify, then exclude them in the build.
   - `translations.json`, `readme.md`, `privacy.md`, `compatible-tools.json`, `donationMessages.json` have no reference in `plugin/src` (text search only). ~15 KB. Verify before deleting; `compatible-tools.json` and `privacy.md` are generated by the build, so exclude rather than delete.

Realistic total for 1-4: **400-500 KB**, so about 1.3 MB.

## Not worth it
- Dropping languages: ~37 KB each, and translations are a feature.
- Lazy-loading PDF.js from a CDN: MV3 does not allow remote code.
- Install size barely affects startup. Parse time of the popup modules matters more; measure before optimising for it.

## How to track it
```bash
npm run size                                   # plugin/src
npm run size -- plugin/dev/aish-extension-chrome   # a built folder
npm run size -- --top 30
```
The last block of the output lists unminified text files over 20 KB, which is the quickest check for item 2. After a step above, rerun it and update the numbers here. A size budget in CI would be the follow-up once item 2 is done.
